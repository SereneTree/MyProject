# 🚀 从零开始：全栈项目云端部署与合规指南（小白友好版）

这是一份专为第一次进行网站上线操作的开发者准备的详细指南。本指南将整个上线流程分为四个阶段，不仅包含技术操作，还详细解答了域名备案、资质要求、支付申请等合规性问题。

---

## 📅 核心原则：尽早部署，分步进行
不要等到代码全部写完才去部署！很多功能（如支付、短信验证码）依赖公网环境才能调试，而且域名备案需要 1-2 周时间。尽早部署能帮你避开 80% 的“上线翻车”风险。

---

## 阶段一：资质与基础设施准备（现在立即开始）

这是最耗时的一步，建议立刻着手办理。

### 1. 域名购买与备案

**Q: 域名备案到底是什么？**
在中国大陆，任何通过域名访问的网站都必须向工信部进行“ICP 备案”（类似于给网站上“户口”）。如果没有备案，云服务商会拦截你的域名访问。

**Q: 我可以用个人身份备案吗？**
**可以！** 个人完全可以备案，备案类型叫“个人性质备案”。
- **限制**：个人备案的网站名称不能包含“公司、企业、商城、论坛、金融”等敏感词，网站内容也不能涉及盈利性商业活动。
- **Tip**：在备案填表时，网站名称尽量起得“人畜无害”一些，比如“学习笔记分享”、“个人技术测试”，千万别写“XX电商平台”、“XX支付系统”。等备案通过后，你网站实际跑什么内容，只要不违法，一般查得没那么严（但不能太嚣张）。

**操作步骤：**
1. 注册阿里云或腾讯云账号，完成**个人实名认证**。
2. 进入“域名注册”页面，搜索并购买一个你喜欢的域名（如 `.com` 约 70元/年，`.top` 或 `.cn` 会更便宜）。
3. 购买成功后，进入云平台的“ICP 备案”系统，跟着向导填写信息、上传身份证正反面、人脸识别。
4. 提交后，云平台客服会先审核（1-2天），如果没问题会提交给管局审核（1-2周）。期间请**保持手机畅通**，管局可能会打电话核实（核实时就说是自己做个个人技术博客玩玩）。

### 2. 服务器与数据库准备

- **购买云服务器**：推荐在买域名的同一家云平台购买“轻量应用服务器”（2核2G 或 2核4G 足够起步），系统选择 **Ubuntu 22.04 LTS**。
  - *Tip*：如果你的服务器和域名在同一家，备案会方便很多。
- **云数据库（可选但强烈推荐）**：虽然你可以在服务器上自己装 MySQL，但对于新手，购买云数据库（RDS）最省心，不用管备份和安全配置。

## 阶段二：支付与短信功能申请（与备案并行）

这是新手最容易卡壳的地方，因为涉及到资质问题。

### 1. 支付链路申请（微信/支付宝）

**核心痛点：个人能不能申请支付接口？**
**答案是：正规渠道下，个人（没有营业执照）很难申请到直接的支付接口。**

目前主流的解决方案有以下几种：

- **方案 A：注册个体工商户（最推荐的正规途径）**
  - **资质要求**：营业执照。
  - **操作**：现在很多地方可以通过“一网通办”小程序免费在线注册“个体工商户”营业执照。有了它，你就可以光明正大地去微信支付/支付宝申请“商户号”，费率正常（约 0.6%），资金直接结算到你的个人银行卡。
- **方案 B：使用第三方“第四方支付”或免签支付（适合个人，但有风险）**
  - 如果你实在不想办执照，市面上有一些“免签支付”平台（如某些发卡网、虎皮椒等），它们利用自己的商户号帮你代收款，然后扣除较高手续费后转给你。
  - **风险**：资金不受自己控制，平台跑路风险大，且微信/支付宝一直在打击这类平台，容易被封接口。
- **方案 C：学习阶段的替代方案**
  - 如果只是为了跑通技术链路展示给别人看，不涉及真实大额交易，可以在页面上放个静态的“微信收款码”图片，用户扫码转账后，你手动在后台给他开通权限（虽然不优雅，但最简单）。

### 2. 手机验证码（短信服务）申请

- **平台选择**：阿里云、腾讯云都有短信服务。
- **资质要求**：现在大多数云平台的短信服务，要求发送的内容必须经过模板审核。如果是“验证码”类短信，**个人实名认证**的账号通常是可以申请的（需要你提供已备案的域名或者已上线的App/小程序截图作为证明）。
- **操作**：
  1. 在云平台开通“短信服务”。
  2. 申请“短信签名”（如【你的项目名】）。
  3. 申请“短信模板”（如：您的验证码为 ${code}，5分钟内有效）。
  4. 拿到 `AccessKey`，写进你的 Node.js 代码环境变量里。

## 阶段三：搭建测试环境（代码上云）

此时你的域名可能还在备案中，没关系，我们先用**服务器的公网 IP** 跑起来。

### 1. 服务器环境初始化
使用终端 SSH 连接到你的服务器，执行以下命令安装必要软件：

```bash
# 更新系统包
sudo apt update && sudo apt upgrade -y

# 安装 Node.js (推荐通过 NVM 安装)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
# 重新加载终端配置后：
nvm install 20 # 安装 Node 20

# 安装 Git、Nginx
sudo apt install git nginx -y

# 安装进程管理工具 PM2
npm install -g pm2
```

### 2. 部署代码
1. 把你的代码推送到 GitHub/Gitee。
2. 在服务器上 Clone 你的代码：`git clone 你的仓库地址`。
3. 进入项目目录，配置环境变量：
   - 复制 `.env.example` 为 `.env`。
   - 填入你买好的云数据库地址（或者本地装的数据库地址）。
4. **后端启动**：
   ```bash
   cd server
   npm install
   npx prisma generate
   npx prisma migrate deploy # 同步数据库表结构
   pm2 start index.mjs --name "my-api" # 后台运行后端
   ```
5. **前端打包**：
   ```bash
   cd .. (回到根目录)
   npm install
   npm run build
   ```
   打包完成后，把 `dist` 目录移到 Nginx 能访问的地方：
   `sudo cp -r dist /var/www/myproject`

### 3. 用 IP 测试访问
修改 Nginx 默认配置，把请求转发给你的前端和后端。此时你可以用 `http://你的服务器IP` 来访问你的网站，并开始调试短信和支付的回调接口了！

## 阶段四：正式上线（备案完成后）

恭喜！当你的域名备案通过，你就可以正式向全世界发布你的作品了。

### 1. 域名解析
进入云平台域名控制台，添加一条 `A 记录`，将 `www` 和 `@`（代表不带www的裸域名）解析到你的服务器公网 IP。

### 2. Nginx 绑定域名
修改服务器上的 Nginx 配置文件（通常在 `/etc/nginx/sites-available/default`）：

```nginx
server {
    listen 80;
    server_name www.yourdomain.com yourdomain.com; # 换成你的域名

    # 前端静态文件
    location / {
        root /var/www/myproject;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:3001/api/; # 你的 Node 后端端口
        proxy_set_header Host $host;
    }
}
```
重启 Nginx：`sudo systemctl restart nginx`。

### 3. 开启 HTTPS（小绿锁）
为了安全和支付接口的要求，网站必须用 HTTPS。
使用免费工具 Certbot 一键配置：
```bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```
Certbot 会自动帮你修改 Nginx 配置并申请免费的 SSL 证书。

### 4. 最终检查清单 ✅
- [ ] 域名可以通过 HTTPS 正常访问。
- [ ] 环境变量里的数据库密码、支付密钥等已经是生产环境的真实数据。
- [ ] 所有的短信发送、支付扫码、回调逻辑在真实环境下测试通过。
- [ ] 关掉代码里没必要的 `console.log`，保持控制台整洁。

🎉 **至此，你的全栈项目就完美部署到云端啦！**
