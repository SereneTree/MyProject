# 支付链路搭建指南（面向非技术背景的个人开发者）

## 1. 核心目标总结
针对您作为个人开发者的背景，我们将采用 **“办理个体工商户 + 官方正规接入”** 的方案，为您的“计算机专业学习与发展规划平台”搭建安全、手续费最低（0.6%）的微信和支付宝支付链路。

## 2. 当前状态分析
- **数据库**：您的数据库（`prisma/schema.prisma`）中的 `Order`（订单表）已经非常完善，预留了对接真实支付所需的字段，如 `externalTradeNo`（微信/支付宝官方单号）、`paymentChannel`（支付渠道）、`rawCallback`（官方通知记录）等。
- **后端代码**：目前的 `server/index.mjs` 中的 `/api/orders` 接口是一个“假支付”逻辑，即用户点击购买，系统就直接把订单状态标记为“已支付”。
- **前端代码**：尚未实现“展示真实支付二维码”及“等待支付成功”的交互界面。

## 3. 决定与假设
- **身份决定**：由于微信和支付宝官方**不直接对个人开放**支付接口，您已决定通过办理“个体工商户”执照来获取官方接入资格。这是目前最正规、资金最安全且手续费最低的方式。
- **支付场景假设**：您的项目是一个网站，所以最适合的支付产品是 **“微信 Native 支付（电脑扫码）”** 和 **“支付宝电脑网站支付/手机网站支付”**。

## 4. 详细实施步骤（白话版）

### 第一步：准备“通行证”（办理个体工商户执照）
*相当于给您的网站办一个合法的“身份证”，有了它，腾讯和阿里才会允许您的网站自动收钱。*
1. **办理执照**：您可以在淘宝搜索“个体工商户代办”，或者在您当地的政务服务网免费申请。不需要实际租办公室，通常几天就能拿到电子营业执照。
2. **准备材料**：营业执照照片、您的身份证正反面照片、一张您本人的银行卡（用来绑定收钱，钱会直接打到这张卡里）。

### 第二步：去微信/支付宝“开户”（申请官方接口）
*拿着刚才的“身份证”，去腾讯和阿里的系统里注册账号，获取后续写代码必须用到的“接头暗号”（密钥）。*
1. **支付宝侧**：
   - 登录 [支付宝商家中心](https://b.alipay.com/)，用营业执照注册企业账号。
   - 在“产品中心”申请开通 **电脑网站支付**。
   - 获取 `AppID` 和 `私钥/公钥`（请像保护银行卡密码一样保存好）。
2. **微信侧**：
   - 登录 [微信支付商户平台](https://pay.weixin.qq.com/)，注册成为商家。
   - 申请开通 **Native 支付**（即网页扫码支付）。
   - 获取 `商户号 (MCHID)` 和 `API 密钥`。

### 第三步：后端代码改造（让服务器能和微信/支付宝对话）
*将获取到的“接头暗号”写进代码里。这一步需要修改 `server/index.mjs`。*
1. **安装工具包**：我们会给项目安装微信和支付宝的官方代码库（SDK），它们能帮我们把复杂的加密逻辑简化。
2. **改造下单接口（生成二维码）**：
   - 当用户点击购买时，我们的服务器不再直接把订单改成“已支付”。
   - 而是拿着商品价格和名称，去向微信/支付宝请求：“我要收199元，请给我一个收款二维码”。
   - 拿到二维码的链接后，把它传给前端。
3. **新增回调接口（接收付款成功通知）**：
   - 增加两个专用的 URL 地址（例如 `/api/payment/notify`）。
   - **这是整个支付最关键的一环**：当用户用手机扫码付完钱后，微信/支付宝会在后台“偷偷”给我们的服务器发送一条消息：“这个订单已经付过钱啦”。
   - 我们的服务器收到消息后，核对无误，再将数据库里订单的状态改为“已支付”，并给用户开通对应的会员权限。

### 第四步：前端代码改造（展示二维码给用户）
*这一步主要是修改 React 相关的代码（`src/` 目录下）。*
1. **弹窗展示二维码**：用户点击“购买”后，弹出一个精美的框，里面是用第三步生成的链接转换成的二维码图片。
2. **轮询查询结果**：用户扫码的时候，网页会在后台每隔2秒问一次服务器：“他付完钱了吗？”。一旦服务器说“付完了（因为收到了第三步的回调）”，网页就自动跳转到“购买成功”页面。

### 第五步：测试与上线
1. **沙箱测试**：在真正花钱之前，支付宝提供了一个“沙箱环境”（相当于模拟器），我们可以用虚拟货币进行完整的购买测试。
2. **部署上线**：确认一切运转正常后，将代码发布到您的云服务器上，您的网站就可以正式开始盈利了。

## 5. 验证标准
1. **业务流程闭环**：用户能看到付款码 -> 手机扫码付钱 -> 钱进入了您的个人银行卡 -> 网页自动提示成功 -> 用户账号成功变成了“职场进阶版会员”。
2. **异常处理机制**：如果用户扫码后没付钱就关了网页，订单会保持“待支付”状态，不会出现系统错乱。
