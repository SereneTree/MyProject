# 计算机专业学习与发展规划平台技术实现文档

---

## 1. 文档目标

本文档基于《计算机专业学习与发展规划平台 PRD》，将产品需求转化为可研发落地的技术方案，覆盖系统架构、前后端模块、数据模型、权限控制、接口设计、管理后台、埋点分析、部署方案和 MVP 迭代计划。

### 1.1 适用范围
- 用户端网站：学习资源首页、作业详情页、个人中心、会员与付费、咨询服务页。
- 管理后台：课程内容管理、作业模块管理、用户管理、订单管理、咨询线索管理、数据统计。
- 核心业务能力：三级资源分类、作业内容模块化展示、会员权限控制、按学期付费、咨询线索转化。

### 1.2 MVP 目标
- 能够展示年级、课程、作业标题三级资源结构。
- 能够按会员等级控制作业详情页内容可见范围。
- 能够完成用户注册、登录、资料完善和个人中心查看。
- 能够支持免费体验版、学业提升版、职场进阶版三档会员。
- 能够记录咨询意向表单，并支持后台跟进。

## 2. 技术选型

### 2.1 推荐技术栈
| 层级 | 技术方案 | 说明 |
|---|---|---|
| 前端框架 | React + TypeScript | 适合快速构建内容型网站和管理后台 |
| UI 组件库 | Ant Design | 表格、表单、筛选、后台管理组件成熟 |
| 路由 | React Router | 支持用户端和管理端路由拆分 |
| 状态管理 | Zustand / Redux Toolkit | MVP 推荐 Zustand，复杂度较低 |
| 请求库 | Axios / Fetch 封装 | 统一处理 Token、错误码、权限提示 |
| 后端框架 | Node.js + NestJS | 模块化清晰，适合中后台和业务 API |
| 数据库 | MySQL | 适合用户、订单、内容、权限等结构化数据 |
| 缓存 | Redis | 用于登录态、验证码、热点资源缓存 |
| 搜索 | MySQL FULLTEXT / Meilisearch | MVP 可先用 MySQL，后续升级独立搜索 |
| 对象存储 | S3 / COS / TOS | 存储图片、附件、代码文件、富文本资源 |
| 部署 | Docker + Nginx | 方便前后端分离部署 |

### 2.2 选型原则
- MVP 阶段优先降低复杂度，核心目标是验证内容、会员和咨询转化闭环。
- 用户端和管理端可共用同一套前端工程，通过路由和权限区分。
- 后端优先设计清晰的数据模型和权限体系，避免后续会员权益扩展困难。

## 4. 核心业务设计

### 4.1 资源三级分类

### 4.1.1 分类层级
- 年级：大一、大二、大三、大四。
- 课程：C 语言、数据结构、操作系统、计算机网络、数据库、算法、机器学习等。
- 作业：具体作业标题，归属于某一门课程和某个适用年级。

### 4.1.2 首页展示逻辑
- 默认根据用户资料中的年级选中对应年级。
- 未登录用户默认展示“大一”或热门年级内容。
- 课程树默认展示热门课程，支持展开全部课程。
- 作业列表支持按年级、课程、关键词、难度、会员标识筛选。

### 4.1.3 数据加载策略
- 首页首屏接口返回年级列表、热门课程、热门作业，减少首屏请求数量。
- 课程树和作业列表可按需分页加载。
- 热门课程、热门作业使用 Redis 缓存。

---

### 4.2 作业详情页模块权限

### 4.2.1 会员等级定义
| 会员等级 | 系统枚举 | 价格 | 权限定位 |
|---|---|---|---|
| 免费体验版 | free | 0 | 看方向、看思路、看预览 |
| 学业提升版 | study | 199元/学期 | 看完整解析和完整知识点 |
| 职场进阶版 | career | 399元/学期 | 看企业应用、AI 实现和扩展项目 |

### 4.2.2 内容模块定义
| 模块 | module_type | 最低可见会员 | 说明 |
|---|---|---|---|
| 作业概要 | overview | free | 所有用户可见 |
| 思路引导 | thinking_guide | free | 展示方向和部分关键步骤 |
| 基础知识点预览 | knowledge_preview | free | 展示概念名称和简短说明 |
| 完整参考解析 | full_solution | study | 展示完整过程、关键步骤、错误提醒 |
| 完整知识点提炼 | full_knowledge | study | 展示完整知识体系和学习建议 |
| 企业实际应用案例 | enterprise_case | career | 展示真实业务或工程应用 |
| AI 技术实现展示 | ai_implementation | career | 展示 AI 辅助分析、编码、调试或优化 |
| 扩展知识与项目实战 | extension_project | career | 展示扩展资料和项目能力迁移 |

### 4.2.3 权限判断规则
```ts
const memberRank = {
  free: 0,
  study: 1,
  career: 2,
};

function canViewModule(userLevel: MemberLevel, requiredLevel: MemberLevel) {
  return memberRank[userLevel] >= memberRank[requiredLevel];
}
```

### 4.2.4 前端展示策略
- 有权限：直接展示完整模块内容。
- 无权限：展示模块标题、价值说明、部分预览和升级按钮。
- 未登录：提示登录后查看免费体验内容。
- 会员过期：按免费体验版权限展示，并提示续费。

### 4.2.5 后端安全策略
- 权限判断必须在后端完成，前端只做展示控制。
- 未授权模块不能从 API 返回完整内容，避免通过浏览器抓包获取。
- 返回内容时按照用户会员等级过滤模块字段。

### 4.3 会员与订单

### 4.3.1 会员周期
- 学业提升版：199 元 / 学期。
- 职场进阶版：399 元 / 学期。
- 一个学期建议按 180 天处理，后续可根据真实校历配置。

### 4.3.2 会员状态
| 状态 | 说明 |
|---|---|
| active | 生效中 |
| expired | 已过期 |
| pending_payment | 待支付 |
| cancelled | 已取消 |
| refunded | 已退款 |

### 4.3.3 升级规则
- 免费体验版可直接购买学业提升版或职场进阶版。
- 学业提升版升级职场进阶版时，MVP 可采用补差价方案。
- 订单支付成功后生成或更新用户会员有效期。
- 同等级续费时，若当前会员未过期，则在当前到期时间后顺延。

### 4.4 咨询线索转化

### 4.4.1 咨询入口
- 顶部导航咨询服务入口。
- 作业详情页职场进阶模块中的咨询推荐。
- 个人中心会员权益中的优先咨询入口。
- 大三、大四用户浏览升学、留学、职业内容时的测评表单入口。

### 4.4.2 咨询表单字段
- 用户姓名。
- 手机号 / 微信号 / 邮箱。
- 当前学校、专业、年级。
- 目标方向：就业、考研、保研、留学、暂不确定。
- 当前困惑描述。
- 期望咨询时间。

### 4.4.3 后台跟进状态
| 状态 | 说明 |
|---|---|
| new | 新线索 |
| contacted | 已联系 |
| qualified | 有效线索 |

## 7. 权限与安全

### 7.1 用户权限
| 角色 | 权限 |
|---|---|
| 游客 | 浏览首页、查看作业概要、访问登录注册页 |
| 普通用户 | 查看免费体验版内容、收藏、提交咨询表单 |
| 学业提升版会员 | 查看完整参考解析和完整知识点 |
| 职场进阶版会员 | 查看全部学习模块、企业应用、AI 实现和项目扩展 |
| 管理员 | 管理内容、用户、订单、咨询线索 |
| 咨询顾问 | 查看和跟进被分配的咨询线索 |

### 7.2 接口鉴权
- 使用 JWT Access Token + Refresh Token。
- Access Token 过期时间建议 2 小时。
- Refresh Token 过期时间建议 14 天。
- 管理后台接口必须校验角色权限。
- 内容详情接口必须校验会员等级并过滤返回模块。

### 7.3 数据安全
- 密码使用 bcrypt / argon2 哈希。
- 手机号、邮箱、联系方式等敏感信息在日志中脱敏。
- 管理后台操作需要记录审计日志。
- 支付回调需要签名校验。
- 用户资料收集前需要记录隐私授权版本。

## 8. 前端实现细节

### 8.1 首页
- 使用左右布局或三栏布局。
- 左侧为年级筛选。
- 中间为课程树。
- 右侧为作业列表。
- 移动端改为顶部筛选 + 列表模式。

### 8.2 作业详情页
- 页面加载时调用 `/api/assignments/:id`。
- 后端返回当前用户可见模块和不可见模块的预览信息。
- 每个模块由 `ContentModule` 组件渲染。
- 无权限模块显示 `UpgradePrompt`。

### 8.3 会员与付费页
- 展示三档会员卡片。
- 每张卡片包含名称、定位文案、权益、价格、适合人群和 CTA。
- 支持从作业详情页携带 `from_assignment_id` 进入购买页，用于统计转化。

### 8.4 管理后台
- 内容管理支持 Markdown 编辑器。
- 作业模块支持选择 `module_type` 和 `required_level`。
- 发布前可预览不同会员等级看到的页面效果。
- 咨询线索支持筛选、备注、状态流转和导出。

### 9.2 核心漏斗
```text
首页访问
  -> 作业详情访问
  -> 未解锁模块曝光
  -> 点击升级
  -> 创建订单
  -> 支付成功
  -> 咨询页访问
  -> 咨询表单提交
  -> 咨询成交
```

## 10. 部署方案

### 10.1 环境划分
| 环境 | 用途 |
|---|---|
| local | 本地开发 |
| dev | 联调测试 |
| staging | 预发布验收 |
| production | 线上环境 |

### 10.2 服务部署
- 前端构建产物部署到 Nginx 或 CDN。
- 后端 API 使用 Docker 部署。
- MySQL 使用云数据库或独立容器。
- Redis 使用云 Redis 或独立容器。
- 上传资源放到对象存储，数据库只保存 URL 和元数据。

### 10.3 CI/CD
```text
代码提交
  -> lint
  -> unit test
  -> build
  -> docker image
  -> deploy dev/staging
  -> manual approval
  -> deploy production
```

## 12. 关键风险与应对

| 风险 | 技术应对 |
|---|---|
| 会员内容被抓包绕过 | 后端按权限过滤内容，前端不接收无权限正文 |
| 内容管理复杂 | 作业内容模块化，支持动态配置模块类型和最低会员等级 |
| 首页资源太多导致性能问题 | 分页、懒加载、热门缓存、搜索索引 |
| 支付状态不一致 | 支付回调幂等、订单状态机、定时对账 |
| 咨询线索丢失 | 表单提交落库、失败重试、后台状态流转 |
| 个人信息泄露 | 脱敏展示、权限隔离、审计日志、加密存储 |
| 学术合规风险 | 后台内容审核、敏感内容标记、考试竞赛类内容限制完整解法 |

## 13. 后续待确认事项

- 是否采用真实支付，还是 MVP 阶段先使用模拟支付。
- 学期时长是否固定为 180 天，还是允许后台配置。
- 内容编辑采用 Markdown 还是富文本编辑器。
- 是否需要支持学校维度的课程和作业差异化。
- AI 技术实现展示是静态内容，还是后续接入 AI 对话能力。
- 咨询服务是否需要顾问分配、日程预约和 IM 沟通。
- 是否需要从第一版开始支持微信登录、短信登录和微信公众号转化。
