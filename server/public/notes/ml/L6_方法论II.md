# L6 方法论 II - 学习笔记

## 1. 机器学习管道（Pipeline）

### 1.1 什么是管道
- 管道 = 操作的序列
- 监督学习管道 = 从预测变量（输入）到预测（输出）的操作序列

**示例管道**（二分类线性分类器）：
> x_i → x_i^T w → ≷ 0 → ŷ_i

### 1.2 管道 vs 工作流
- **管道**：数据操作的序列（部署时使用）
- **工作流**：我们采取的步骤序列（如：先定义问题→收集数据→选模型→训练）

### 1.3 参数数量与样本数
- 多项式回归：9个样本 → 零MSE需要至少8阶多项式
- **需要比模型自由度更多的样本**来避免过拟合

### 1.4 丰富输入的高风险
- RGB图片 (A×B像素)：输入维度 = 3×A×B
- 线性模型系数 = 3×A×B + 1
- 需要远超过此数的训练图片

### 1.5 特征提取
- 从原始数据中提取有意义的特征（如鸢尾花的萼片/花瓣长度宽度）
- 管道 = 特征提取阶段 T + 线性模型
- **整个管道都需要部署**

### 1.6 管道不只是模型
- 机器学习解决方案包括多个阶段：
  - 转换阶段
  - 多个并行模型
  - 聚合阶段
- **我们部署整个管道，而非单个模型**

### 1.7 手工设计 vs 训练
- 模型必须用数据构建
- 管道中的其他阶段可以是手工设计或训练的
- 训练后，管道参数固定
- 不应训练模型后再改变管道其他阶段

## 2. 归一化（Normalisation）

### 2.1 属性空间中的距离
距离概念是许多机器学习技术的基础：
- 回归：预测误差 e_i = y_i - ŷ_i
- 分类：样本到边界的距离（逻辑回归）、样本间距离（kNN）
- 聚类：样本到原型的距离（K-means）
- 密度估计：标准差 = 样本到均值的平均距离

### 2.2 数值表示的影响
属性可能：
- 使用不同单位（英里 vs 公里）
- 具有不同量纲（重量 vs 高度）
- 有不同动态范围（厘米 vs 千米）

### 2.3 等效数值表示
若属性值在同一数值范围内，系数可直接比较：
> ŷ = x^T w = 3 + 100x_A + 20x_B

若 x_A 和 x_B 范围相似，则 x_A 对响应的影响更大。

### 2.4 最小-最大归一化（Min-Max）
> **z = (x - min(x)) / (max(x) - min(x))**

- 产生 [0,1] 范围内的值
- 参数：min(x) 和 max(x)
- **对异常值敏感**

### 2.5 标准化（Standardisation）
> **z = (x - μ) / σ**

- 产生均值为0、标准差为1的属性
- 参数：μ（均值）和 σ（标准差）
- 在神经网络中非常常用

### 2.6 归一化注意事项
1. 使用数据集设定参数 → 用于测试和部署
2. 部署时可能出现超范围值
3. 异常值可能严重影响（尤其是 Min-Max）
4. 存在非线性缩放选项（如 softmax 缩放、对数缩放）
5. 不同缩放可能导致不同模型解

## 3. 数据转换（Transformations）

### 3.1 什么是转换
- 改变样本表示方式的数据操作
- 将样本从一个空间映射到另一个空间
- 归一化就是一种转换

### 3.2 转换类型

| 类型 | 描述 |
|------|------|
| 线性转换 | 旋转+缩放，维度不变 |
| 非线性转换 | 无唯一描述 |
| 降维 | 目标空间维度 < 原始空间 |

### 3.3 主成分分析（PCA）
- 线性转换，识别数据对齐的方向（成分）
- 维度不变，但为每个成分分配**得分**
- 得分可用于排名，移除最不重要的成分 → **降维**

### 3.4 非线性转换示例
- 将数据映射到新空间，每个新属性 = 样本到某中心的距离
- 原始空间不可分 → 目标空间可分
- 管道 = 非线性转换 + 线性分类器 + 逻辑函数

### 3.5 核方法（Kernel Methods）
- 支持向量机（SVM）隐式定义转换（使用核函数）
- 两种场景：
  - 已知转换方式 → 只需学习目标空间的模型
  - 未知转换 → 需要学习转换本身

### 3.6 特征选择（Feature Selection）
- 假设只有部分属性相关
- M个属性 → 2^M - 1 个子集

**过滤法（Filtering）**：
- 单独考虑每个属性
- 简单快速
- 忽略属性间交互

**包裹法（Wrapping）**：
- 考虑属性间交互
- 训练不同子集的模型，验证评估
- 可用贪心搜索减少计算量

### 3.7 特征提取（Feature Extraction）
- 从复杂数据（图片、音频）中提取少量设计好的特征
- 数字信号/图像处理提供丰富选项
- 可大幅降低数据维度

## 4. 集成方法（Ensembles）

### 4.1 原理
- 不是选择最佳模型族，而是让多个模型**协同工作**
- 基模型需要尽可能**多样化**
- 多样性来源：随机子集数据、随机子集属性、不同模型族

### 4.2 Bagging（装袋法）
- **Bootstrap**：从数据集随机抽取样本
- Bagging 生成 K 个子数据集 → 训练 K 个简单基模型
- 最终预测 = 基模型预测的**平均或投票**
- f(x) = Σ f_k(x) / K

### 4.3 决策树（Decision Trees）
- 通过对单个预测变量的分裂规则递归划分预测变量空间
- 表示为树结构：根 = 全部数据，叶 = 决策区域
- 目标：创建**纯净叶子**（尽可能只含同一类样本）

**构建方式**：
1. 从根开始递归二分裂
2. 选择使纯度最高的分裂
3. 纯度度量：熵、基尼指数
4. 停止条件（如区域内样本数）

**问题**：
- 容易过拟合（需要剪枝/停止条件）
- 不同训练集可能产生不同树结构
- XOR 问题：适合树表示但难以学习

### 4.4 随机森林（Random Forests）
- 决策树的集成
- 随机化训练样本和预测变量
- 预测 = 各树预测的平均
- 通常有很好的准确率
- 训练成本较高，可解释性较差

### 4.5 Boosting（提升法）
- 与 Bagging 不同：生成**序列**的基模型
- 每个后续模型**关注前面模型处理不好的样本**
- 每个新基模型依赖于前面的模型

**Bagging vs Boosting**：
| 方法 | 训练方式 | 减少的误差 | 原理 |
|------|---------|-----------|------|
| Bagging | 并行 | 方差 | 多模型平均 |
| Boosting | 串行 | 偏差 | 逐步纠错 |

## 5. 诊断：经验方法

当事情不如预期时：

### 5.1 特征/数据分析
- 通常在选模型之前的第一步
- 理解问题复杂性，判断哪些模型可能有效

### 5.2 模型复杂度
- 检查模型假设
- 复杂度不宜太小也不宜太大
- 参数数量 vs 样本数

### 5.3 高偏差 vs 高方差
- 画训练/验证曲线判断
- 与模型复杂度相关

### 5.4 误差分析
- 检查模型犯错的样本
- 寻找错误模式/原因

### 5.5 分析训练模型
- 检查模型参数及其解释
- 可验证决策过程
- 与**可解释AI**相关
