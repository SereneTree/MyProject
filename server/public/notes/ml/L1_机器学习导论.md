# L1 机器学习导论 - 学习笔记

## 1. 什么是机器学习

### 1.1 定义
机器学习（又称统计学习）通常定义为：
- **从原始数据中提取模式来获取知识的能力**（Goodfellow, Bengio, Courville）
- **一组用于建模和理解复杂数据集的工具**（James, Witten, Hastie, Tibshirani）

### 1.2 本课程的观点
本课程（QHM5703）采用**部署优先（问题优先）** 的视角：
- 先有问题，再获取数据集，最后产出模型
- 定义为：**一组工具和方法论，利用数据解决科学、工程和商业问题**

> ⚠️ 注意：机器学习 ≠ AI。一些AI方案使用机器学习，一些不用；机器学习也可用于解决非AI问题。

---

## 2. 数据与知识

### 2.1 数据
- 数据是观测或测量的物化
- 数据集是数据的集合，由一组预定义属性描述的条目组成

| 动物 | 体重 [g] | 心率 [bpm] |
|------|----------|-----------|
| 野鼠 | 22 | 480 |
| 兔子 | 2.5×10³ | 250 |
| 座头鲸 | 30×10⁶ | 30 |

> 术语注意：条目(item)、样本(sample)、实例(instance)、点(point) 含义相同；特征(feature)、变量(variable)、属性(attribute) 含义相同。

### 2.2 知识的三种表示
| 表示形式 | 示例 |
|---------|------|
| 命题（陈述、规律） | 体型越小的动物心率越快 |
| 叙述（描述、故事） | 动物的体型似乎与心率相关... |
| 模型（数学或计算机） | r = 235 × m^(-1/4) |

**在机器学习中，我们使用模型来表示知识。**

### 2.3 数学模型与计算机模型等价
- 数学模型可以实现为计算机程序
- 每个计算机模型都有对应的数学表达式
- 例如：y = x + 3x² 等价于 Python 代码 `y = x + 3*x**2`

## 3. 科学与伪科学

- 科学不是关于精密仪器、数学或理论，而是关于**评估知识**
- 命题本身不是科学的或非科学的，**评估它们的方式**才是科学或非科学的
- 伪科学示例：探测者声称能用探水杖找到地下水，但无法通过科学验证

---

## 4. 机器学习的两个阶段

| 阶段 | 描述 |
|------|------|
| **学习阶段** | 构建模型 |
| **部署阶段** | 使用模型 |

### 基本方法论
1. **训练（Training）**：使用数据集创建模型，即**拟合模型**
2. **测试（Testing）**：使用新的、未见过的数据评估模型在部署时的性能

> 没有严格的方法论，模型很可能毫无用处。

## 5. 机器学习分类体系（Taxonomy）

### 5.1 监督学习（Supervised Learning）
- 给定新条目，其中一个属性的值未知
- 目标：根据已知属性**估计（猜测）缺失的值**
- 模型将**预测变量 x** 映射到**标签 y**
- 使用**带标签样本的数据集**构建模型

#### 分类 vs 回归
| 类型 | 标签类型 | 示例 |
|------|---------|------|
| **分类（Classification）** | 离散变量 | 垃圾邮件检测：0=垃圾邮件，1=非垃圾邮件 |
| **回归（Regression）** | 连续变量 | 根据体重预测动物心率 |

### 5.2 无监督学习（Unsupervised Learning）
- 目标：发现数据集的**底层结构**
- 应用：客户细分、社交社区发现、推荐系统、进化分析

#### 结构发现
- **聚类分析（Cluster Analysis）**：关注数据点分组
- **基发现（Basis Discovery）**：识别感兴趣的方向
- **密度估计（Density Estimation）**：描述样本在属性空间中分布的统计模型

## 7. 关键要点

1. **没有数据就没有机器学习**，但机器学习不仅仅是关于数据
2. 知识用**模型**表示，模型描述属性之间的关系
3. 机器学习区分不同类型的问题、技术和模型，形成分类体系
4. 监督学习需要标签，无监督学习不需要
5. **了解你的领域知识**——例如涡虫的心率无法从现有数据集中推测
