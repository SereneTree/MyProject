# L4 分类 I - 学习笔记

## 1. 分类问题概述

### 1.1 问题定义
- 分类（又称决策或检测）问题中：
  - 构建模型对一组预测变量产生**标签**
  - 标签是**离散变量**，每个值称为一个**类（class）**
- 机器学习分类问题需要：
  - 模型 ŷ = f(x)
  - 带标签数据集 {(x_i, y_i)}
  - 模型质量概念

### 1.2 二分类示例
- 情感分析：正面(1) vs 负面(0)
- 大型电影评论数据集：2500训练 + 2500测试

### 1.3 多分类示例
- 手写数字识别（MNIST）：10个类别(0-9)
- 60000训练图像 + 10000测试图像，28×28像素

---

## 2. 数据集在属性空间中的表示

### 2.1 属性空间表示
- 标签可以用数值在纵轴上表示（但排序和距离概念不适用于分类变量）
- 更常用的方式：在预测变量空间中用不同符号表示不同标签

### 2.2 分类器的表示
- 回归模型 → 属性空间中的曲线/曲面
- 分类模型 → 预测变量空间中的**决策区域**
- 决策区域由**决策边界**分隔
- 分类模型 = 预测变量空间的**分区**

## 3. 线性分类器

### 3.1 最简单的边界
| 预测变量维度 | 线性边界形状 |
|-------------|------------|
| 1维 | 一个点（阈值） |
| 2维 | 一条直线 |
| 3维 | 一个平面 |

### 3.2 定义
- 线性边界由方程 **w^T x = 0** 定义
- 扩展向量 x = [1, x₁, x₂, ...]^T，w 为系数向量

**分类规则**：
- 若 w^T x_i > 0 → 一侧
- 若 w^T x_i < 0 → 另一侧
- 若 w^T x_i = 0 → 在边界上

### 3.3 基本质量指标

| 指标 | 公式 |
|------|------|
| **经验准确率 Â** | 正确预测数 / 样本数 |
| **错误率 Ê** | 错误预测数 / 样本数 = 1 - Â |

> 对于分类变量，唯一可执行的操作是**比较**（y_i = ŷ_i 是否成立）

### 3.4 最佳线性分类器

**线性可分**：存在线性分类器达到 Â=1, Ê=0

**线性不可分**：最佳线性分类器 Â<1, Ê>0，目标是达到最高准确率

## 4. 逻辑模型（Logistic Model）

### 4.1 从边界到确定性

关键观察：
- 离决策边界越远，分类正确的**确定性**越高
- 靠近边界时，处于"噪声区域"

**样本到边界的距离**：d_i = w^T x_i

### 4.2 逻辑函数
> **p(d) = e^d / (1 + e^d) = 1 / (1 + e^{-d})**

性质：
- p(0) = 0.5
- d → +∞ 时 p(d) → 1
- d → -∞ 时 p(d) → 0

### 4.3 分类器的确定性
令 d = w^T x_i：

| 位置 | 确定性 |
|------|--------|
| 在边界上 (w^T x_i = 0) | p(x_i) = 0.5 |
| 在 ● 区域 (w^T x_i > 0) | p(x_i) → 1（远离边界） |
| 在 ○ 区域 (w^T x_i < 0) | p(x_i) → 0（远离边界） |

- **p(x_i)** = 分类器对 y_i = ● 的确定性
- **1 - p(x_i)** = 分类器对 y_i = ○ 的确定性

### 4.4 似然函数
对于带标签数据集，分类器的全局确定性：

> **L = ∏(y_i=○) [1-p(x_i)] × ∏(y_i=●) p(x_i)**

L 称为**似然函数**，定义了一个质量指标。

取对数得**对数似然**：
> l = Σ(y_i=○) log[1-p(x_i)] + Σ(y_i=●) log[p(x_i)]

### 4.5 逻辑回归分类器
**最大化 L 或 l 的线性分类器 = 逻辑回归分类器**
- 可使用梯度下降求解

> 注意：逻辑回归是分类方法，尽管名字中有"回归"！因为间接地解决了一个回归问题（分类器的确定性）。

## 5. K 近邻（kNN）

### 5.1 参数方法 vs 非参数方法

| 类型 | 特点 |
|------|------|
| 参数方法（如线性分类器） | 假定边界形状，寻找最佳参数 |
| 非参数方法（如kNN） | 不假定边界形状，更灵活 |

### 5.2 最近邻（NN, K=1）
- 新样本被分配到**最近的训练样本**的标签
- 边界不显式定义（但存在且可获取）
- 需要记住整个训练数据集 → **基于实例的方法**

### 5.3 K 近邻（kNN）
算法步骤：
1. 计算新样本到所有训练样本的距离
2. 提取 K 个最近邻
3. 统计每个类的邻居数量
4. 分配邻居中最多的类

### 5.4 K 值的影响

| K 值 | 边界复杂度 | 风险 |
|------|-----------|------|
| 小（如1） | 复杂 | 过拟合 |
| 大 | 简单 | 欠拟合 |

> K 增大 → 边界变简单 → 从过拟合走向欠拟合

注意：
- 二分类问题中 K 通常取**奇数**（避免平局）
- kNN 可轻松扩展到多分类
- kNN 不涉及训练（每次分类都使用所有样本）

### 5.5 kNN 思考题
- 若数据集中 70个A类 + 30个B类
- k=100 → 所有样本分类为A类，Â=70%
- k=71 → 所有样本分类为A类，Â=70%
- k=31 → 取决于近邻分布

## 6. 分类器总结

### 6.1 核心概念
- 分类器 = 预测变量空间的分区（决策区域 + 决策边界）
- 使用数据集构建分类器

### 6.2 灵活性与复杂度
- 线性边界 → 简单、刚性
- kNN → 边界复杂度取决于 K 值
- 欠拟合/过拟合概念同样适用

### 6.3 似然 vs 准确率
- 逻辑回归使用似然/对数似然（不是准确率）作为训练目标
- kNN 使用邻居比例（不是准确率）
- 准确率和错误率是**部署质量**指标，不一定用于训练

> 质量度量不一定等于训练代价——回顾"代价 vs 质量"概念
