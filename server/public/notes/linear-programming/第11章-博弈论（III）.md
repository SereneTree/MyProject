# 第十一章：博弈论（III）

## 11.1 一般二人博弈（General 2-Player Games）

### 非零和博弈
- 两个玩家的收益**不一定**互为相反数
- 需要用**双矩阵** $(A, B)$ 描述
- $a_{i,j}$ = Rosemary的收益，$b_{i,j}$ = Colin的收益

### 最佳回应（Best Response）
**定义11.2**：
- Rosemary对 $c_j$ 的最佳回应：$\arg\max_{r_i \in R} u_R(r_i, c_j)$
- Colin对 $r_i$ 的最佳回应：$\arg\max_{c_j \in C} u_C(r_i, c_j)$

### Nash均衡（非零和博弈）
**定义11.3**：$(r_i, c_j)$ 是Nash均衡，当且仅当：
- $r_i$ 是Rosemary对 $c_j$ 的最佳回应
- $c_j$ 是Colin对 $r_i$ 的最佳回应

### 寻找Nash均衡的方法
1. 在收益矩阵中标记每个玩家的最佳回应
   - Rosemary：每列中最大的 $a_{i,j}$ 对应的行
   - Colin：每行中最大的 $b_{i,j}$ 对应的列
2. 被两个玩家同时标记的格子即为Nash均衡

### 混合策略Nash均衡
- 在非零和博弈中，混合策略Nash均衡更复杂
- 两个玩家的期望收益不互为相反数
- 不能直接用零和博弈的LP方法

### 最优性原理（对零和博弈的推广）
在零和博弈中，Nash均衡可以通过最大化安全水平来找到。在非零和博弈中，这个方法不适用——两个玩家不再有完全对立的利益。

## 11.2 囚徒困境（The Prisoner's Dilemma）

### 博弈设定
两个嫌疑人被分别审讯，每人可以选择"坦白"或"沉默"：

|  | Colin坦白 | Colin沉默 |
|--|----------|----------|
| Rosemary坦白 | (-5, -5) | (0, -10) |
| Rosemary沉默 | (-10, 0) | (-1, -1) |

### 分析
- **最佳回应**：无论对方选什么，坦白总是更好的选择
  - 若Colin坦白：Rosemary坦白得-5 > 沉默得-10
  - 若Colin沉默：Rosemary坦白得0 > 沉默得-1
- **Nash均衡**：（坦白，坦白），收益为 (-5, -5)
- **帕累托最优**：（沉默，沉默），收益为 (-1, -1)

### 困境的本质
- Nash均衡**不是**帕累托最优
- 个体理性导致集体非最优结果
- 这是"合作困难"的经典例证

### 重要结论
> 在囚徒困境中，理性玩家会选择"坦白"（支配策略），尽管双方都"沉默"会得到更好的结果。

## 11.3 Braess悖论（Braess's Paradox）

### 悖论描述
- 在交通网络中，**增加一条道路**反而可能导致所有人的通行时间**增加**
- 类似于囚徒困境：个体最优选择导致整体效率下降

### 例题分析
- 100辆车从S到T，有两条路径
- 两条路径各有限制：一条有高延迟（与流量成正比），另一条有固定延迟
- Nash均衡：50辆车走路径1，50辆车走路径2，通行时间=65分钟
- 新增一条快速路后，Nash均衡变为所有车选择"更优"路径，但通行时间=80分钟

### 无政府代价（Price of Anarchy）
- 定义：Nash均衡下的社会福利与最优社会福利之比
- 衡量缺乏中央协调时的效率损失
- Braess悖论是PoA > 1的极端例子

### 承诺策略（Commitment Strategy）
- 在某些博弈中，一个玩家可以通过**公开承诺**自己的策略来改变博弈结果
- Golden Balls游戏中，Rosemary承诺"一定偷"迫使Colin选择"分"
- 这将博弈结果从（偷，偷）= (0, 0) 变为（偷，分）= (全拿, 0) → 实际上通过威胁改变对方行为

## 考试重点总结

1. **非零和博弈的双矩阵表示**与**Nash均衡的寻找方法**
2. **最佳回应标记法**：在矩阵中标记最佳回应，交集为Nash均衡
3. **囚徒困境**：支配策略导致次优结果
4. **Nash均衡 vs 帕累托最优**的区别
5. **Braess悖论**：增加资源反而降低效率
6. **无政府代价**的概念
7. **承诺策略**如何改变博弈结果
