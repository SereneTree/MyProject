# 第七章：对偶性（I）

## 7.1 对偶问题的引入

### 动机：寻找目标函数的上界
考虑最大化问题：$\max\, 2x_1 + 3x_2 + x_3$

通过将约束乘以非负常数并相加，可以得到目标函数的上界：
- 第一个约束乘以3：$2x_1 + 3x_2 + x_3 \leq 3x_1 + 3x_2 + 3x_3 \leq 30$
- 第一个约束 + 第二个约束×2：$\leq 26$
- 第一个约束×2 + 第三个约束：$\leq 24$

**核心想法**：选择乘数 $y_1, \ldots, y_m \geq 0$ 使得：
1. 左边系数 ≥ 目标函数系数（确保不等式方向正确）
2. 右边值尽可能小（找到最紧的上界）

### 对偶问题的形式化

给定原问题（Primal）：
$$\max\, c^Tx \quad \text{s.t.}\, Ax \leq b,\, x \geq 0$$

其对偶问题（Dual）为：
$$\min\, b^Ty \quad \text{s.t.}\, A^Ty \geq c,\, y \geq 0$$

### 原问题与对偶问题的对应关系

| 原问题（max） | 对偶问题（min） |
|--------------|---------------|
| 最大化 | 最小化 |
| 非负变量 $x_j \geq 0$ | $\geq$ 约束 |
| 无限制变量 $x_j$ | $=$ 约束 |
| 目标 $c^Tx$ | RHS $c$ |
| LHS $Ax$ | LHS $A^Ty$ |
| RHS $b$ | 目标 $b^Ty$ |
| $\leq$ 约束 | 非负变量 $y_i \geq 0$ |
| $=$ 约束 | 无限制变量 $y_i$ |

### 求对偶的步骤
1. 确保所有不等式方向正确（max问题：$\leq$ 或 $=$）
2. 为每个约束引入一个对偶变量 $y_i$：$\leq$ 约束 → $y_i \geq 0$；$=$ 约束 → $y_i$ 无限制
3. 对偶目标函数为 $b^Ty$
4. 为每个原变量 $x_j$ 构造一个约束：LHS = $A$ 的第 $j$ 列与 $y$ 的乘积，RHS = $c_j$；$x_j \geq 0$ → $\geq$ 约束，$x_j$ 无限制 → $=$ 约束

### 对偶的基本性质
1. 原问题的每个约束 → 对偶的一个变量
2. 原问题的每个变量 → 对偶的一个约束
3. 对偶的对偶 = 原问题
4. 每个原问题有唯一的对偶

## 7.2 弱对偶定理与强对偶定理

### 弱对偶定理（Weak Duality）
**定理7.1**：若 $x$ 是原问题的可行解，$y$ 是对偶问题的可行解，则：
$$c^Tx \leq b^Ty$$

**含义**：对偶问题的任何可行解都给出原问题目标值的上界。

**证明思路**：
1. 由对偶可行性：$c_j \leq \sum_{i} a_{i,j}y_i$，乘以 $x_j \geq 0$ 得 $c_jx_j \leq \sum_i a_{i,j}x_jy_i$
2. 由原问题可行性：$\sum_j a_{i,j}x_j \leq b_i$，乘以 $y_i \geq 0$ 得 $\sum_j a_{i,j}x_jy_i \leq b_iy_i$
3. 求和得 $c^Tx \leq b^Ty$

### 弱对偶的推论
- 若原问题可行但目标无界 → 对偶问题不可行
- 若对偶问题可行但目标无界 → 原问题不可行
- 若 $c^Tx^* = b^Ty^*$（两个可行解目标值相等）→ 两者都是最优解

### 强对偶定理（Strong Duality）
**定理7.3**：若原问题有最优解 $x^*$（目标值 $z^*$），则对偶问题也有最优解 $y^*$（目标值 $z^*$）。

即：**最优原解与最优对偶解的目标值相等**。

### 强对偶定理的证明思路
1. 用单纯形法求解原问题得到最终单纯形表
2. 设最终表中松弛变量列的系数为 $q_1, \ldots, q_m$
3. 令 $y_i^* = -q_i \geq 0$（因为最终表中 $q_i \leq 0$）
4. 验证 $y^*$ 满足对偶约束：$c_j \leq \sum_i y_i^* a_{i,j}$
5. 计算对偶目标值：$b^Ty^* = -\sum_i q_i b_i = z^*$（等于原问题最优值）

### 最优性证书（Certificate of Optimality）
- 强对偶定理的一个重要应用：**验证最优性**
- 只需找到一个对偶可行解 $y$ 使得 $c^Tx = b^Ty$
- 这比证明 $x$ 优于所有其他可行解简单得多
- $y$ 被称为 $x$ 的**最优性证书**
