# 第八章：对偶性（II）

## 8.1 互补松弛性（Complementary Slackness）

### 定理8.1：互补松弛原理
设 $x$ 是原问题（标准不等式形式）的可行解，$y$ 是对偶问题的可行解。则 $x$ 和 $y$ 都是最优解**当且仅当**以下两个条件同时成立：

1. **对每个 $j = 1, \ldots, n$**：$x_j = 0$ 或 $\sum_{i=1}^m a_{i,j}y_i = c_j$
2. **对每个 $i = 1, \ldots, m$**：$y_i = 0$ 或 $\sum_{j=1}^n a_{i,j}x_j = b_i$

### 直觉理解

| 原问题 | 对偶问题 | 含义 |
|-------|---------|------|
| 变量 $x_j > 0$（非零） | 对应约束 $\sum_i a_{i,j}y_i = c_j$（取等） | 原变量非零 → 对偶约束紧 |
| 约束不紧（松弛变量 $s_i > 0$） | 对应对偶变量 $y_i = 0$ | 原约束松 → 对偶变量零 |

### 使用互补松弛性验证最优解的步骤
1. 验证 $x$ 是原问题的可行解
2. 利用互补松弛条件列出关于 $y$ 的方程组：
   - 若 $x_j \neq 0$ → 对偶第 $j$ 个约束取等
   - 若原第 $i$ 个约束不紧 → $y_i = 0$
3. 求解方程组得到 $y$
4. 验证 $y$ 是对偶问题的可行解
5. 若可行 → $x$ 和 $y$ 都是最优解

### 例题
验证 $x_1 = 17/2, x_2 = 7/2, x_3 = 0$ 是最优解：
1. 计算松弛变量：$s_1 = 1 > 0$, $s_2 = 0$, $s_3 = 0$
2. $x_1, x_2 \neq 0$ → 对偶约束1、2取等：$2y_2 - y_3 = 2$, $-4y_2 + 3y_3 = -1$
3. 第一约束不紧（$s_1 > 0$）→ $y_1 = 0$
4. 解得 $y_1 = 0, y_2 = 5/2, y_3 = 3$
5. 验证 $y$ 对偶可行 ✓ → 最优

### 非退化情况
- 若 $x$ 是非退化的BFS，则互补松弛性给出的方程组有**唯一解**
- 退化情况下可能有多个解，只需找到一个对偶可行的即可

## 8.2 对偶的经济解释

### 混合问题（饮食问题）的对偶
- 原问题：学生选择便宜食物满足营养需求
- 对偶问题：营养品商人设定最高价格

**对偶变量的含义**：
- $y_i$ 代表满足第 $i$ 种营养需求的"价格"
- 对偶变量 = 目标函数关于约束右端项的变化率（类似导数）
- 若某约束不紧（如维生素C过量），则 $y_i = 0$（放松此约束不改变成本）

### 生产问题的对偶
- 原问题：最大化收入，受资源约束
- 对偶问题：最小化资源总"价值"

**对偶变量的含义**：
- $y_i$ = 第 $i$ 种资源的**影子价格**（边际价值）
- 即：多获得一单位该资源，收入可增加多少

**互补松弛性的经济含义**：
- 若某资源未用完（约束不紧）→ 其影子价格为0（买更多无用）
- 若某过程的收益严格大于资源成本 → 应该运行此过程（$x_j > 0$）

## 8.3 Min-Max 问题建模

### 问题类型
求 $\min\, \max\{p_1, p_2, p_3, p_4\}$（最小化最大运行时间）

### 建模技巧
引入新变量 $m$ 表示最大值：
$$m \geq p_1, \quad m \geq p_2, \quad m \geq p_3, \quad m \geq p_4$$
然后 $\min\, m$

**关键**：虽然一般解中 $m$ 不一定等于 $\max\{p_i\}$，但最优解中 $m = \max\{p_i\}$ 必然成立（否则可以减小 $m$）

## 8.4 分段线性目标函数（Piecewise Linear Objectives）

### 凹函数的最大化
- 分段线性**凹函数**可以直接用LP处理
- 凹函数 = "向下弯曲"的函数（如递减收入）

### 建模方法
将目标函数 $f(x)$ 表示为多个线性片段的组合：
$$f(x) = f_1(x) + f_2(x) + \cdots + f_k(x)$$
其中每个 $f_i$ 是一个线性函数，且 $f_i$ 仅在特定区间内有效。

**技巧**：利用LP的最优解性质保证自动选择正确的片段

1. **互补松弛性的完整叙述**——定理+含义
2. **用互补松弛性验证最优解**——典型考题
3. **互补松弛性求解对偶变量的步骤**
4. **对偶变量的经济解释**：影子价格
5. **Min-Max建模技巧**：引入 $m$ 变量
6. **互补松弛性在等式/无限制变量问题中的推广**
7. **退化BFS时互补松弛性可能给多组解**
