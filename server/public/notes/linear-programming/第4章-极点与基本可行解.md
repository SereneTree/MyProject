# 第四章：极点与基本可行解

## 4.1 最优解与极点

### 标准方程形式（Standard Equation Form）
将标准不等式形式通过引入松弛变量转化为：
$$\text{maximize} \quad c^Tx$$
$$\text{subject to} \quad Ax = b, \quad x \geq 0$$

- 每个不等式 $a_i^Tx \leq b_i$ 变为 $a_i^Tx + s_i = b_i$，$s_i \geq 0$
- 松弛变量 $s_i$ 衡量约束的"松弛程度"

### 核心定理

**定理**：如果线性规划有最优解，则存在一个**极点**是最优解。

**证明思路**：
1. 设 $x$ 是最优解但不是极点
2. 则存在两个不同可行解 $y, z$ 使得 $x = \lambda y + (1-\lambda)z$
3. 由最优性：$c^Tx = \lambda c^Ty + (1-\lambda)c^Tz$
4. 必须有 $c^Ty = c^Tz = c^Tx$，即 $y, z$ 也是最优解
5. 继续分解直到到达极点

## 4.2 基本可行解（Basic Feasible Solution, BFS）

### 定义
考虑标准方程形式 $Ax = b$，$x \geq 0$，其中 $A$ 是 $m \times n$ 矩阵（$m \leq n$）。

**基本解**：
1. 选择 $m$ 个线性无关的列（称为**基列**）
2. 将其余 $n-m$ 个变量（**非基变量**）设为0
3. 求解 $m$ 个方程得到 $m$ 个**基变量**的值

**基本可行解（BFS）**：所有基变量 $\geq 0$ 的基本解

### 关键性质

| 性质 | 内容 |
|------|------|
| 基本可行解 ↔ 极点 | 每个BFS对应可行域的一个极点，反之亦然 |
| BFS个数有限 | 最多 $\binom{n}{m}$ 个 |
| 最优解的存在性 | 若有最优解，必存在BFS为最优解 |

### 基变量与非基变量
- **基变量**：对应基列的变量，值由方程组确定
- **非基变量**：不在基中的变量，值为0
- 当某个基变量恰好为0时，称为**退化的BFS**

### 定理：BFS 与极点的等价性

**引理**：如果 $x$ 是可行解且对应的列线性相关，则 $x$ 不是极点。

**证明思路**：
- 列线性相关 → 存在非零向量 $d$ 使得 $Ad = 0$
- 可构造 $x + \theta d$ 和 $x - \theta d$ 都是可行解
- $x$ 可表示为它们的凸组合，故 $x$ 不是极点

## 4.3 几何与基本可行解

### 从几何到代数

| 几何概念 | 代数对应 |
|---------|---------|
| 约束面 | 方程 $a_i^Tx + s_i = b_i$ |
| 顶点（极点） | 基本可行解 |
| 约束面相交 | 非基变量=0（松弛变量为0 → 约束紧） |

### 例题步骤
1. 将不等式约束加入松弛变量变为等式
2. 写出增广矩阵 $[A | b]$
3. 选择不同的 $m$ 列组合作为基
4. 求解对应的基本解
5. 检查是否所有变量 $\geq 0$（BFS条件）
6. 判断基本解在可行域内部还是外部

### 基本解不可行的情况
- 基本解不一定是可行解
- 基本解对应的交点可能在可行域**外部**
- 只有满足 $x \geq 0$ 的基本解才是基本可行解

---

## 考试重点总结

1. **BFS与极点的等价性**——这是连接几何与代数的桥梁
2. **构造基本可行解的步骤**：选基列 → 非基变量设0 → 求解基变量
3. **判断基本解是否可行**：检查所有变量是否 $\geq 0$
4. **退化的BFS**：某个基变量恰好为0
5. **最优解必在BFS处取得**——单纯形算法的理论依据
6. **$\binom{n}{m}$ 是BFS个数的上界**
