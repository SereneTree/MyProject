# 第二章：线性规划建模

## 2.1 生产问题（Production Problems）

### 建模方法
生产问题涉及将输入资源通过不同过程转化为输出产品。核心建模步骤：

1. **识别决策变量**：为每个过程/活动引入一个变量
2. **引入辅助变量**：为输入输出关系引入哑变量（dummy variables）
3. **表达目标与约束**：用变量表示目标和约束条件
4. **简化**：代入消元

### 三类生产问题

| 问题类型 | 目标 | 约束 |
|---------|------|------|
| 最大化收入 | 最大化产品价值 | 资源限制 |
| 最小化成本 | 最小化资源成本 | 产量需求 |
| 最大化利润 | 最大化（收入 - 成本） | 可能无约束 |

### 关键技巧：辅助变量
- 引入辅助变量表示中间量（如产量、资源消耗量等）
- **辅助变量必须声明为无限制（unrestricted）**，否则可能引入额外约束
- 例如：$x = 4p_1 + 3p_3 + 6p_4$（$x$ 为产量，$p_i$ 为过程运行时间）

### 例题：工厂生产问题
- 4个过程、2种产品、3种资源
- 决策变量 $p_1, p_2, p_3, p_4$：各过程运行时间
- 目标函数：$\max\, 4000p_1 + 1800p_2 + 4800p_3 + 11400p_4$
- 约束：金属、电力、劳动力的总量限制

## 2.2 运输问题（Transportation Problems）

### 问题特征
- 从若干**供应地**向若干**需求地**运送物资
- 目标：最小化总运输成本
- 成本与运输量成线性关系

### 建模方法
- 变量 $x_{i,j}$：从供应地 $i$ 运到需求地 $j$ 的数量
- 目标函数：$\min \sum_{i,j} c_{i,j} \cdot x_{i,j}$（$c_{i,j}$ 为单位运输成本）
- 供应约束：$\sum_j x_{i,j} \leq s_i$（$s_i$ 为供应量）
- 需求约束：$\sum_i x_{i,j} \geq d_j$（$d_j$ 为需求量）

### 例题：矿石运输
- 2个矿山、3个仓库
- 6个决策变量 $x_{1,1}, x_{1,2}, x_{1,3}, x_{2,1}, x_{2,2}, x_{2,3}$
- 约束：各矿山供应上限 + 各仓库需求下限

## 2.3 整数解与分数解（Integer vs Fractional Solutions）

### 关键区别
- 线性规划的变量默认为**连续量**（可取分数值）
- 某些实际问题要求变量为**整数**（如建造数量）
- 整数规划（Integer Programming）是更难的问题

### 例题：投资问题
- 变量 $a$（广告次数，整数）和 $b$（建筑物数量，0或1）
- 放松整数约束后，LP最优解可能与IP最优解不同
- LP的分数解可能不是可行整数解

### 重要结论
> 放松整数约束得到的LP最优值是IP最优值的**下界**（对最小化问题为上界）

## 考试重点总结

1. **生产问题的三种建模方式**：最大化收入、最小化成本、最大化利润
2. **辅助变量必须为 unrestricted**——这是常犯的错误
3. **运输问题的双下标变量**命名和约束形式
4. **整数解与分数解的区别**：LP放松是IP的界
5. **建模的通用流程**：识别选择 → 引入变量 → 表达关系 → 简化
