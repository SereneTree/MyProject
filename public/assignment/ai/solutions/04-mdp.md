# HW4: MDP（马尔可夫决策过程）题目解析

## 知识点概述

本次作业覆盖马尔可夫决策过程的核心内容：
- **MDP基础概念**：马尔可夫性质、Bellman方程、策略与最优策略
- **折扣因子γ的影响**：短视 vs 远视
- **值迭代（Value Iteration）**：通过迭代更新状态值直到收敛
- **策略迭代（Policy Iteration）**：策略评估 + 策略改进
- **两种方法的关系与收敛性**

---

## 第一部分：MDP 热身问题

### 核心概念解析

#### (a) 马尔可夫性质（Markov Property）
**定义**：动作结果只取决于**当前状态**，与历史状态和动作序列无关。

> 直观理解：未来只取决于现在，与过去无关。"给定现在，未来与过去条件独立"。

#### (b) Bellman方程
**定义**：通过一步前瞻（one-step lookahead）递归定义最优效用值：

```
V*(s) = max_a Σ T(s,a,s') [R(s,a,s') + γV*(s')]
```

**用途**：建立当前时刻效用值与下一时刻效用值之间的关系。

#### (c) 策略（Policy）
- **策略 π**：从状态到动作的映射函数 π(s) → a
- **最优策略 π***：遵循后能最大化期望效用的策略

#### (d) 折扣因子 γ 的影响

| γ 值 | 效果 |
|------|------|
| γ = 0 | 只考虑**即时奖励**，完全忽视未来 |
| γ = 1 | 未来奖励与当前奖励**等价**，可能不收敛 |
| 0 < γ < 1 | 平衡当前与未来，保证算法收敛 |

> **为什么限制 0 < γ < 1**：防止无限时间步的奖励累积到无穷大（确保收敛性）。

#### (e) 策略迭代的两个步骤
1. **策略评估（Policy Evaluation）**：给定策略π，计算每个状态的V^π(s)
2. **策略改进（Policy Improvement）**：基于当前V值贪心选择更好的策略

## 第二部分：值迭代 vs 策略迭代 深入分析

### 值迭代更新公式
```
V_{k+1}(s) = max_a Σ T(s,a,s') [R(s,a,s') + γV_k(s')]
```

### 策略迭代公式
**策略评估**：
```
V^πi_{k+1}(s) = Σ T(s, π(s), s') [R(s, π(s), s') + γV^πi_k(s')]
```

**策略改进**：
```
π_{i+1}(s) = arg max_a Σ T(s, a, s') [R(s, a, s') + γV^πi(s')]
```

### 题目解析

**问题**：如何证明策略迭代收敛时得到最优策略？

**证明思路**：
1. 策略改进定理：如果 π_new ≠ π_old，则 V^{π_new} ≥ V^{π_old}
2. 有限状态空间中策略数量有限
3. 每次改进严格更好 → 最终必收敛
4. 收敛时 π_new = π_old，满足Bellman最优性条件

**问题**：策略迭代中每次只做一轮Bellman更新（而非到收敛），结果会改变吗？

**答案**：仍能得到最优策略，但需要修改终止条件。
- 实际上此时策略迭代退化为值迭代
- 值迭代 = 每轮一次评估 + 策略提取

## 第三部分：Racing MDP（赛车MDP问题）

### 问题描述

车子随机移动2、3或4格（等概率），可以选择 Move 或 Stop：
- Move：无奖励，继续移动
- Stop：获得当前总移动格数的奖励
- 总格数 ≥ 6：游戏结束，奖励为0

**状态**：{0, 2, 3, 4, 5, Done}

### (a) 转移函数 T(s, a, s')

| 当前状态 | 动作 | 转移 |
|---------|------|------|
| 任意 s≠Done | Stop | → Done (概率1) |
| 0 | Move | → {2,3,4} (各1/3) |
| 2 | Move | → {4,5,Done} (各1/3) |
| 3 | Move | → 5(1/3), Done(2/3) |
| 4 | Move | → Done (概率1) |
| 5 | Move | → Done (概率1) |

### (b) 奖励函数 R(s, a, s')

```
R(s, Stop, Done) = s  (当 s ≤ 5)
R(s, a, s') = 0      (其他情况)
```

### (c) 值迭代执行（γ = 1）

| 状态 | V₀ | V₁ | V₂ | V₃ | V₄ |
|------|----|----|----|----|-----|
| 0 | 0 | 0 | 3 | 10/3 | 10/3 |
| 2 | 0 | 2 | 3 | 3 | 3 |
| 3 | 0 | 3 | 3 | 3 | 3 |
| 4 | 0 | 4 | 4 | 4 | 4 |
| 5 | 0 | 5 | 5 | 5 | 5 |

**计算过程**（以V₂为例）：
- V₂(0) = max{Stop: 0, Move: 1/3×(V₁(2)+V₁(3)+V₁(4))} = max{0, 1/3×(2+3+4)} = 3
- V₂(2) = max{Stop: 2, Move: 1/3×(V₁(4)+V₁(5)+0)} = max{2, 1/3×(4+5+0)} = 3
- V₂(3) = max{Stop: 3, Move: 1/3×(V₁(5)+0+0)} = max{3, 5/3} = 3
- V₂(4) = max{Stop: 4, Move: 0} = 4
- V₂(5) = max{Stop: 5, Move: 0} = 5

### (d) 最优策略

| 状态 | 0 | 2 | 3 | 4 | 5 |
|------|---|---|---|---|---|
| π* | Move | Move | Stop | Stop | Stop |

**直觉**：
- 状态0和2：当前累积太少，冒险移动期望收益更高
- 状态3、4、5：已有足够累积，停下锁定收益更安全

### (e) γ = 0.1 的影响

当γ很小时：
- 更注重**即时奖励**，变得更贪心
- 收敛更快但策略可能更保守
- 可能在状态2就选择Stop（因为未来奖励被大幅折扣）

## 核心考点总结

| 考点 | 关键公式/理解 |
|------|-------------|
| Bellman方程 | V*(s) = max_a Σ T(s,a,s')[R + γV*(s')] |
| 值迭代 | 反复应用Bellman更新直到收敛 |
| 策略迭代 | 评估当前策略 → 贪心改进 → 重复 |
| γ的作用 | 平衡短期vs长期，保证收敛 |
| 马尔可夫性 | 未来只取决于当前状态 |
| 策略提取 | π(s) = arg max_a Q(s,a) |
| 收敛保证 | 有限MDP + γ<1 → 必收敛 |
