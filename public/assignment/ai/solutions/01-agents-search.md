# HW1: Agents & Search（智能体与搜索）题目解析

## 知识点概述

本次作业涵盖人工智能的两大基础主题：
- **智能体（Agents）**：理性智能体的定义、环境类型对理性行为的影响
- **搜索算法（Search）**：无信息搜索（BFS、DFS、UCS）与有信息搜索（Greedy、A*）的执行过程与对比

## 第一部分：吸尘器世界与智能体理性

### 核心知识点

**理性智能体**的定义：在给定感知序列的情况下，选择能最大化期望性能度量的动作。

**环境特性**对理性判断的影响：
- 静态 vs 动态环境
- 传感器可靠性
- 奖励/惩罚结构

### 题目解析

#### 场景1：静态环境 + 最短时间清洁所有灰尘
- **答案**：理性 ✓
- **解析**：灰尘只在初始时存在，不会新增。机器人按照固定策略（脏就吸、在A就右移、在B就左移）能够高效清洁所有灰尘。

#### 场景2：静态环境 + 最大化收益（清洁+1，移动-1）
- **答案**：不理性 ✗
- **解析**：灰尘清洁完毕后，机器人仍然持续左右移动，每次移动扣1分。一个理性的智能体应该在清洁完成后停止移动。

#### 场景3：动态环境 + 最大化收益（清洁+1，移动-1）
- **答案**：不理性 ✗
- **解析**：在动态环境中，更理性的策略是：停在当前位置等待灰尘出现，偶尔探索另一个房间。持续移动的策略假设灰尘频繁且规律地出现，这并非最优。

#### 场景4：静态环境 + 位置传感器不可靠
- **答案**：不理性 ✗
- **解析**：当位置传感器不可靠时，机器人无法确定自己的真实位置，可能在错误的方向上移动，导致无法有效清洁。

### 考试重点
> 判断智能体理性与否的关键：是否在**给定信息和环境特性**下做出了**最优决策**。

## 第二部分：图搜索算法

### 核心知识点

| 算法 | 完备性 | 最优性 | 时间复杂度 | 策略 |
|------|--------|--------|-----------|------|
| DFS | 否（图搜索下完备） | 否 | O(b^m) | LIFO 栈 |
| BFS | 是 | 是（等代价） | O(b^d) | FIFO 队列 |
| UCS | 是 | 是 | O(b^(C*/ε)) | 优先队列（路径代价） |
| Greedy | 否 | 否 | O(b^m) | 优先队列（h(n)） |
| A* | 是 | 是（h可采纳） | O(b^d) | 优先队列（f=g+h） |

### 题目解析：图搜索执行

给定搜索图（S为起点，G为终点），各算法的执行：

#### DFS（深度优先搜索）
- **展开顺序**：从右到左加入frontier → 先展开左侧子节点
- **路径**：S → D → G
- **特点**：不一定找到最短路径，但内存效率高

#### BFS（广度优先搜索）
- **展开顺序**：按层级逐层扩展
- **路径**：S → D → G
- **特点**：找到最少步骤的路径（等代价时最优）

#### UCS（一致代价搜索）
- **展开顺序**：按路径代价从小到大
- **路径**：S → A → C → G
- **特点**：找到代价最小的路径，是Dijkstra算法的前端版本

## 第三部分：寻宝搜索（图搜索 + 启发式）

### 题目解析

在有向加权图中，从A出发寻找宝藏（红色节点为目标），使用不同搜索算法：

#### DFS
- **Explored set**：A, C, F, B, G
- **路径**：A → C → G，代价 = 3
- **注意**：DFS不保证最优

#### BFS
- **Explored set**：A, E
- **路径**：A → E，代价 = 3
- **注意**：BFS按层扩展，先找到的目标不一定代价最小

#### UCS
- **Explored set**：A, D, C, G
- **路径**：A → D → G，代价 = 2
- **注意**：UCS保证找到代价最小路径

#### Greedy Search
- **Explored set**：A, E
- **路径**：A → E，代价 = 3
- **注意**：贪心搜索只看启发式值，可能非最优

#### A* Search
- **Explored set**：A, D, G
- **路径**：A → D → G，代价 = 2
- **注意**：A* 结合了 g(n)+h(n)，在h可采纳时保证最优

## 第四部分：启发式与A*

### 核心知识点

- **可采纳性（Admissibility）**：h(n) ≤ h*(n)，即启发式永远不会高估真实代价
- **一致性（Consistency）**：h(n) ≤ c(n,a,n') + h(n')，满足三角不等式

### 题目解析

1. **DFS总是比A*展开更多节点？**
   - **False**：幸运的DFS可能只展开d个节点就找到目标，而A*可能需要展开更多节点

2. **曼哈顿距离对于车（rook）移动是否可采纳？**
   - **False**：车可以一步走多格，曼哈顿距离会高估步数。例如4×4棋盘对角移动只需2步，但曼哈顿距离为6

3. **两个可采纳启发式之和仍然可采纳？**
   - **False**：两个都不超过真实值的启发式，相加可能超过真实值。但取最大值（max）仍然可采纳

4. **可采纳性是否蕴含一致性？**
   - **False**：可采纳不一定一致。反例：h(S)=4, h(A)=1, cost(S,A)=1，则h(S) > cost(S,A) + h(A) 违反三角不等式

## 第五部分：自动驾驶状态空间搜索

### 核心知识点

- **状态空间大小** = 方向 × 位置 × 速度 = 4 × M × N × (v_max + 1)
- 状态表示：(朝向, x坐标, y坐标, 当前速度)

### 题目解析

1. **曼哈顿距离是否可采纳？** → **否**
   - 车辆可以加速到 v>1，因此实际到达目标的步数可能少于曼哈顿距离

2. **非平凡的可采纳启发式**：
   - 弱：到达目标所需的最少转弯次数
   - 中：d_manhattan / v_max（假设以最大速度直线行驶）
   - 强：考虑减速动力学的放松问题（需要减速到0才能停下）

## 总结对比

| 概念 | 关键要点 |
|------|---------|
| 理性智能体 | 在给定环境和感知下最大化期望效用 |
| 搜索完备性 | 算法是否一定能找到解 |
| 搜索最优性 | 算法是否一定能找到最优解 |
