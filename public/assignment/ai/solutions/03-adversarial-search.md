# HW3: Adversarial Search（对抗搜索）题目解析

## 知识点概述

本次作业覆盖博弈论中的对抗搜索算法：
- **Minimax算法**：零和博弈中的最优决策
- **α-β剪枝**：减少搜索节点的优化技术
- **Expectimax**：处理不确定性（概率节点）的变体
- **Minimax vs Expectimax 对比**：确定性对手 vs 随机对手

---

## 第一部分：Minimax 基础

### 核心知识点

**Minimax算法**：
- 适用于**零和博弈**（一方的收益 = 另一方的损失）
- MAX玩家选择**最大化**效用值的动作
- MIN玩家选择**最小化**效用值的动作
- 从叶子节点向上回传值

**博弈树求值规则**：
```
V(MAX节点) = max(子节点值)
V(MIN节点) = min(子节点值)
```

### 题目解析

对于给定的博弈树：
- 向上三角形（△）= MAX节点
- 向下三角形（▽）= MIN节点
- 从叶子节点开始，逐层回传最优值

> **关键**：假设双方都最优行动，回传的是**博弈值（game value）**。

---

## 第二部分：α-β 剪枝

### 核心知识点

**剪枝规则**：
- **α**：MAX节点目前能保证的**最小值**（下界）
- **β**：MIN节点目前能保证的**最大值**（上界）
- **剪枝条件**：当 α ≥ β 时，当前分支无需继续搜索

**剪枝发生的情况**：
| 情况 | 条件 | 解释 |
|------|------|------|
| α剪枝 | MIN节点的β ≤ 祖先MAX的α | MAX已有更好选择，MIN的这个分支不会被选 |
| β剪枝 | MAX节点的α ≥ 祖先MIN的β | MIN已有更好选择，MAX的这个分支不会被选 |

### 题目解析

对于与第一题相同的博弈树，从左到右搜索：
- 搜索到第一个分支后，α/β值被更新
- 后续分支如果无法改善已知的最优值，则被**剪枝**
- 被剪掉的节点不需要评估

> **考试技巧**：画出搜索顺序，标注每个节点的α、β值，当 α≥β 时标记剪枝。

## 第三部分：Expectimax

### 核心知识点

**Expectimax**将MIN节点替换为**机会节点（Chance Node）**：
```
V(MAX节点) = max(子节点值)
V(Chance节点) = Σ P(子节点) × V(子节点)  // 期望值
```

对于均匀分布：V(Chance) = (V₁ + V₂ + V₃) / 3

### 题目解析

将原博弈树的MIN节点改为Chance节点（均匀随机选择）：
- 不再取最小值，而是计算**加权平均**
- Expectimax值通常**高于**Minimax值（因为对手不再最优）

---

## 第四部分：Minimax vs Expectimax 深入对比

### 核心知识点

| 特性 | Minimax | Expectimax |
|------|---------|-----------|
| 对手模型 | 完全理性（最优对手） | 随机/概率性对手 |
| 计算 | min/max | 期望值 |
| 保守程度 | 极度保守（最坏情况） | 基于概率的平衡 |
| 适用场景 | 零和博弈、对手理性 | 对手非最优/随机环境 |

### 题目解析

**问题**：如何修改Minimax以处理骰子等随机事件？

**答案**：
- 在骰子节点处，将min/max操作替换为**加权求和**
- 每个结果按其概率加权：E[V] = Σ P(outcome_i) × V(outcome_i)
- 公平骰子每面概率 = 1/6

**问题**：Expectimax是否可能比Minimax做出更差的决策？

**答案**：**是的**。
- Minimax准备应对**最坏情况**，是保守策略
- Expectimax基于**平均结果**，可能过于乐观
- 当低概率但高危害的事件实际发生时，Minimax的保守决策更安全

---

## 第五部分：Expectimax 与 α-β 剪枝

### 核心知识点

**关键结论**：α-β剪枝**不能**应用于Expectimax！

### 题目解析

**为什么不能剪枝？**
- Chance节点计算的是**期望值（平均值）**
- 即使当前看到的子节点值很小，后续子节点可能有很大的值
- 任何一个子节点的值都会影响平均值的计算
- 无法像Minimax那样确定某个分支"肯定不会被选"

> **对比**：在Minimax中，如果MAX已经有一个值为10的选择，MIN分支中看到了一个11，就知道MIN会选更小的，但Expectimax不行——因为计算的是平均值。

---

## 第六部分：α-β 剪枝详细步骤

### 执行过程要点

对于新的博弈树，需要逐步追踪：

1. **初始化**：根节点 α = -∞, β = +∞
2. **传递规则**：
   - 子节点继承父节点的α、β值
   - MAX节点更新α：α = max(α, 子节点值)
   - MIN节点更新β：β = min(β, 子节点值)
3. **剪枝判断**：每次更新α或β后检查是否 α ≥ β
4. **回传值**：将确定的节点值回传给父节点

### 考试答题模板

```
步骤1：展开左子树，计算值
步骤2：更新父节点的 α 或 β
步骤3：展开下一个子树
步骤4：检查是否满足剪枝条件 (α ≥ β)
步骤5：若满足则剪枝，跳过剩余子树
步骤6：回传最终值给父节点
```

## 总结对比

| 概念 | 关键公式/规则 |
|------|-------------|
| Minimax值 | V(s) = max/min of children |
| Expectimax值 | V(s) = Σ P(c)×V(c) |
| α-β剪枝条件 | α ≥ β 时剪枝 |
| α的含义 | MAX已保证的最低收益 |
| β的含义 | MIN已保证的最高代价 |
| 剪枝对Expectimax | 不适用（无法提前判断） |
| 搜索顺序影响 | 好的顺序 → 更多剪枝 → 更高效 |
