- **搜索启发式**：MRV（最小剩余值）、LCV（最少约束值）

## 第一部分：讨论题 — Forward Checking vs AC-3

### 核心知识点

| 方法 | 一致性范围 | 触发条件 | 传播深度 |
|------|-----------|---------|---------|
| Forward Checking | 当前变量的邻居 | 变量赋值时 | 仅一层 |
| AC-3 | 整个约束图 | 初始化/变量赋值 | 传播到所有相关弧 |

### 解析

**Forward Checking（前向检查）**：
- 当变量X被赋值时，只检查X的约束弧，削减X邻居的域
- 在此停止，不进一步传播

**AC-3（弧一致性算法）**：
- 不仅检查X的邻居，还会**递归传播**
- 如果某个邻居的域被削减了，继续检查受影响的弧
- 直到没有更多域可以被削减为止

> **考试重点**：FC 是 AC-3 的子集。AC-3 更强但计算代价更高。

### 启发式选择的理由

**MRV（最小剩余值）** — "下一个选谁？"
- **Fail-fast策略**：先选域最小的变量
- 尽早发现死胡同，减少搜索空间

**LCV（最少约束值）** — "选什么值？"
- 选择对邻居约束最少的值
- 目标是保留最多的后续选择空间

## 第二部分：空中交通管制 CSP

### 题目建模

**变量**：A, B, C, D, E（五架飞机）

**域**：(跑道类型, 时间槽) 的元组
- 跑道类型 ∈ {国际, 国内}
- 时间槽 ∈ {1, 2, 3, 4}

**约束**：
| 约束 | 形式化表示 | 类型 |
|------|-----------|------|
| B 必须在时间槽1降落 | B[time] = 1 | 一元约束 |
| D 在时间槽3或之后 | D[time] ≥ 3 | 一元约束 |
| A 最迟时间槽2 | A[time] ≤ 2 | 一元约束 |
| D 在 C 之前 | D[time] < C[time] | 二元约束 |
| 同跑道不同时间 | Xi ≠ Xj (若同跑道) | 二元约束 |

### 弧一致性执行过程

AC-3 执行步骤：

1. **先施加一元约束**：
   - B 的域：{1}（删去2,3,4）
   - A 的域：{1, 2}（删去3,4）
   - D 的域：{3, 4}（删去1,2）

2. **弧传播**：
   - A→B：A的域中删去1（因为B=1时A不能也=1同跑道）→ A = {2}
   - C→B：C的域中删去1 → C = {2, 3, 4}
   - C→A：C的域中删去2（C必须>D≥3） → C = {3, 4}
   - C→D：C的域中删去3（需要C>D，D≥3） → C = {4}
   - D→C：D的域中删去4（需要D<C=4） → D = {3}
   - E→D：E的域中删去3（同跑道约束） → E = {1, 2, 4}

### 回溯搜索（MRV + Forward Checking）

赋值顺序：**(B, 1), (A, 2), (C, 3), (C, 4), (D, 3), (E, 1)**

解析：
1. B 域最小={1}，赋值 B=1
2. A 域={2}，赋值 A=2
3. C 尝试 C=3，但与 D<C 约束冲突（D域变空）→ **回溯**
4. C=4，满足约束
5. D=3（唯一剩余值）
6. E=1

## 第三部分：课程安排 CSP

### 问题建模

**变量**：C1-C5（5门课程）

**域**（能教授的教授）：
- C1: {A, C}
- C2: {A}（只有A能教）
- C3: {B, C}
- C4: {B, C}
- C5: {A, B}

**二元约束**（时间重叠的课程不能同一教授）：
- C1 ≠ C2（时间重叠）
- C2 ≠ C3（时间重叠）
- C2 ≠ C4（时间重叠）
- C3 ≠ C4（时间重叠）

### AC-3 执行结果

由于 C2 = {A}（单元素域），强制传播：
- C1 ≠ A → C1 = {C}
- C3 ≠ A → C3 不受影响（域中没有A）
- C4 ≠ A → C4 不受影响

C3 ≠ C4 约束：无法进一步削减

### 回溯搜索求解

1. C2 = A（MRV选择域最小的）
2. C1 = C（唯一剩余值）
3. C3 和 C4 需要不同值：C3=B, C4=C 或 C3=C, C4=B
4. C5 = B 或 A（取决于C3/C4的赋值）

最终解之一：C1=C, C2=A, C3=B, C4=C, C5=A

> **注意**：C4=C 意味着教授C同时教C1和C4，但C1(8:00-9:00)与C4(9:00-10:00)不重叠，所以允许。

## 核心考点总结

| 考点 | 关键理解 |
|------|---------|
| CSP建模 | 正确识别变量、域、约束（一元vs二元） |
| AC-3 vs FC | AC-3传播到整个图，FC仅传播一层 |
| MRV | 选域最小的变量 → fail-fast |
| LCV | 选约束邻居最少的值 → 保留更多选择 |
| 回溯搜索 | 搜索 + 推理的结合，遇到死胡同才回退 |
| 弧一致性 | 对每条弧，域中每个值在对方域中都有支持 |
