# 人工智能 (AI) 大作业题目解析总览

本目录包含人工智能课程5次大作业的详细题目解析与知识点讲解。

## 内容目录

| 序号 | 主题 | 核心知识点 |
|------|------|-----------|
| 1 | Agents & Search（智能体与搜索） | 理性智能体、BFS/DFS/UCS/A*搜索算法、启发式函数 |
| 2 | CSP（约束满足问题） | 前向检查、AC-3弧一致性、MRV/LCV启发式、回溯搜索 |
| 3 | Adversarial Search（对抗搜索） | Minimax算法、α-β剪枝、Expectimax、博弈树 |
| 4 | MDP（马尔可夫决策过程） | Bellman方程、值迭代、策略迭代、折扣因子 |
| 5 | RL（强化学习） | Q-learning、TD学习、模型vs无模型学习、探索与利用 |

## 学习建议

1. 先理解每个主题的核心概念定义
2. 结合题目理解算法的具体执行过程
3. 注意各算法之间的联系与区别（如 Minimax vs Expectimax, Value Iteration vs Policy Iteration）
4. 重点掌握搜索算法的时间/空间复杂度及适用场景
