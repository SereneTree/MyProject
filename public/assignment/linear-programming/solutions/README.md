```
├── 基础概念

│   └── 标准形式（等式形式）
├── 求解方法
│   ├── 图形法（二维问题）
│   │   ├── 约束线绘制
│   │   ├── 可行域确定
│   │   └── 法向量/等值线判断最优
│   ├── 单纯形法
│   │   ├── 基变量与非基变量
│   │   ├── 单纯形表构建
│   │   ├── 主元选择（最大系数法则）
│   │   ├── 行变换与迭代
│   │   └── 最优性判定（所有系数 ≤ 0）
│   └── 两阶段单纯形法
│       ├── 人工变量引入
│       ├── Phase I：最小化人工变量之和
│       └── Phase II：求解原目标函数
├── 建模技巧
│   ├── 决策变量定义
│   ├── 约束条件转化
│   └── 目标函数建立

    ├── 凸集性质证明
    ├── 基本解与极点的关系
    └── 单纯形法收敛性
```
