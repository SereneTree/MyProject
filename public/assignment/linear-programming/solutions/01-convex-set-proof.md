# Problem 1：凸集证明 (5 分)

## 题目

设 P ⊆ ℝⁿ 是一个凸集，即对所有 x, y ∈ P 和 λ ∈ [0,1]，有 λx + (1-λ)y ∈ P。

**证明**：标准等式形式线性规划的所有可行解的集合是一个凸集。

---

## 核心知识点

### 1. 凸集的定义

- **凸集**：集合 S 是凸的，当且仅当对任意 x, y ∈ S 和 λ ∈ [0,1]，凸组合 λx + (1-λ)y ∈ S
- **直观理解**：集合中任意两点的连线段完全包含在集合内
- **凸组合**：z = λx + (1-λ)y，其中 0 ≤ λ ≤ 1

### 2. 标准等式形式

线性规划的标准等式形式：

```
maximize  c^T x
subject to  Ax = b
            x ≥ 0
```

其中：
- A 是 m×n 矩阵
- b 是 m 维向量  
- c 是 n 维目标系数向量
- x 是 n 维决策变量向量

可行域定义为：F = { x ∈ ℝⁿ | Ax = b, x ≥ 0 }

---

## 详细解答

### 证明思路

要证 F 是凸集，需要证明：对任意 x, y ∈ F 和 λ ∈ [0,1]，有 z = λx + (1-λ)y ∈ F。

即需要验证 z 满足两个条件：
1. Az = b（等式约束）
2. z ≥ 0（非负约束）

### 完整证明

**设** x, y ∈ F，即：
- Ax = b 且 x ≥ 0
- Ay = b 且 y ≥ 0

**取** 任意 λ ∈ [0,1]，令 z = λx + (1-λ)y。

**验证等式约束：**

$$Az = A(λx + (1-λ)y)$$
$$= λAx + (1-λ)Ay$$
$$= λb + (1-λ)b$$
$$= b$$

因此 Az = b ✓

**验证非负约束：**

由于 x ≥ 0, y ≥ 0, λ ≥ 0, (1-λ) ≥ 0，所以：

$$z = λx + (1-λ)y ≥ λ·0 + (1-λ)·0 = 0$$

因此 z ≥ 0 ✓

**结论：** z ∈ F，故 F 是凸集。 ∎

---

## 证明要点总结

| 步骤 | 关键操作 | 依据 |
|------|---------|------|
| 1 | 设两个可行解 x, y | 凸集定义的前提 |
| 2 | 构造凸组合 z = λx + (1-λ)y | 凸集定义要求 |
| 3 | 验证 Az = b | 利用矩阵乘法的线性性 |
| 4 | 验证 z ≥ 0 | 利用非负数的线性组合仍非负 |

---

## 延伸知识

- **多面体 (Polyhedron)**：有限个线性不等式的交集 {x | Ax ≤ b}，总是凸集
- **极点 (Extreme Point)**：不能表示为集合中其他两点凸组合的点
- **LP 基本定理**：若 LP 有最优解，则一定有极点最优解
- 凸性保证了局部最优就是全局最优（LP 的核心理论基础）
