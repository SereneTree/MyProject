# Problem 2：矩阵形式与基本解 (8 分)

## 题目

考虑以下线性规划：

```
maximize   120x₁ + 100x₂
subject to  2x₁ + 2x₂ + x₃ = 8
            5x₁ + 3x₂ + x₄ = 15
            x₁, x₂, x₃, x₄ ≥ 0
```

(i) 将线性规划转换为矩阵形式  
(ii) 确定一组基变量，并解释  
(iii) 确定一个基本解，并解释  
(iv) 找到一个极点解，并解释  

---

## 核心知识点

### 1. LP 的矩阵形式

标准等式形式 LP 的矩阵表示：

```
maximize   c^T x
subject to  Ax = b
            x ≥ 0
```

### 2. 基变量与基矩阵

- **基 (Basis)**：从 A 的 n 列中选出 m 列线性无关的列，构成 m×m 可逆矩阵 B
- **基变量 (Basic Variables)**：对应 B 中列的变量
- **非基变量 (Non-basic Variables)**：不在基中的变量

### 3. 基本解 (Basic Solution)

- 将非基变量设为 0
- 解方程 Bx_B = b，得到基变量的值
- 若 x_B ≥ 0，则为**基本可行解 (BFS)**

### 4. 极点 (Extreme Point)

- 可行域中不能表示为其他两个可行点凸组合的点
- **重要定理**：LP 标准形式中，基本可行解 ⟺ 极点

---

## 详细解答

### (i) 矩阵形式

$$c = \begin{pmatrix} 120 \\ 100 \\ 0 \\ 0 \end{pmatrix}, \quad A = \begin{pmatrix} 2 & 2 & 1 & 0 \\ 5 & 3 & 0 & 1 \end{pmatrix}, \quad b = \begin{pmatrix} 8 \\ 15 \end{pmatrix}, \quad x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{pmatrix}$$

矩阵形式：
```
maximize   c^T x
subject to  Ax = b
            x ≥ 0
```

其中 A 是 2×4 矩阵，m = 2（约束数），n = 4（变量数）。

---

### (ii) 确定基变量

从 A 中选 m = 2 列构成基矩阵 B，要求 B 可逆（即列线性无关）。

**选择 B = {x₃, x₄}**（即 A 的第 3、4 列）：

$$B = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = I_2$$

B 是单位矩阵，显然可逆（det(B) = 1 ≠ 0）。

**基变量**：x₃, x₄  
**非基变量**：x₁, x₂

**解释**：选择的两列线性无关，构成的 2×2 子矩阵可逆，因此构成合法的基。x₃ 和 x₄ 是松弛变量，恰好使基矩阵为单位矩阵。

---

### (iii) 确定基本解

**步骤**：
1. 令非基变量 = 0：x₁ = 0, x₂ = 0
2. 求解 Bx_B = b：

$$\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} x_3 \\ x_4 \end{pmatrix} = \begin{pmatrix} 8 \\ 15 \end{pmatrix}$$

解得：x₃ = 8, x₄ = 15

**基本解**：x = (0, 0, 8, 15)^T

**验证**：
- 等式约束：2(0) + 2(0) + 8 = 8 ✓，5(0) + 3(0) + 15 = 15 ✓
- 非负性：所有分量 ≥ 0 ✓

因为所有基变量 ≥ 0，这是一个**基本可行解 (BFS)**。

---

### (iv) 极点解

**极点解就是基本可行解**（两者等价）。

上面得到的 x = (0, 0, 8, 15)^T 就是一个极点。

**更进一步**，我们可以尝试其他基来找更好的极点：

**选择 B = {x₁, x₂}**（A 的第 1、2 列）：

$$B = \begin{pmatrix} 2 & 2 \\ 5 & 3 \end{pmatrix}$$

det(B) = 2×3 - 2×5 = 6 - 10 = -4 ≠ 0，可逆。

$$B^{-1} = \frac{1}{-4}\begin{pmatrix} 3 & -2 \\ -5 & 2 \end{pmatrix} = \begin{pmatrix} -3/4 & 1/2 \\ 5/4 & -1/2 \end{pmatrix}$$

$$x_B = B^{-1}b = \begin{pmatrix} -3/4 & 1/2 \\ 5/4 & -1/2 \end{pmatrix}\begin{pmatrix} 8 \\ 15 \end{pmatrix} = \begin{pmatrix} -6 + 7.5 \\ 10 - 7.5 \end{pmatrix} = \begin{pmatrix} 1.5 \\ 2.5 \end{pmatrix}$$

得到 x₁ = 1.5, x₂ = 2.5, x₃ = 0, x₄ = 0

**验证**：所有分量 ≥ 0 ✓ → 这也是一个极点（BFS）。

**目标值**：120(1.5) + 100(2.5) = 180 + 250 = **430**

对比第一个极点的目标值：120(0) + 100(0) = **0**

所以 (1.5, 2.5, 0, 0) 是一个更优的极点解。

---

## 所有可能的基及其基本解

| 基变量 | B 可逆？ | 基本解 | 可行？ | 目标值 |
|--------|---------|--------|--------|--------|
| {x₁, x₂} | ✓ | (1.5, 2.5, 0, 0) | ✓ | 430 |
| {x₁, x₃} | ✓ | (3, 0, 2, 0) | ✓ | 360 |
| {x₁, x₄} | ✓ | (4, 0, 0, -5) | ✗ | — |
| {x₂, x₃} | ✓ | (0, 5, -2, 0) | ✗ | — |
| {x₂, x₄} | ✓ | (0, 4, 0, 3) | ✓ | 400 |
| {x₃, x₄} | ✓ | (0, 0, 8, 15) | ✓ | 0 |

最优极点解为 **(1.5, 2.5, 0, 0)**，目标值 = **430**。

---

## 关键概念对比

| 概念 | 定义 | 关系 |
|------|------|------|
| 基本解 | 非基变量=0后解出的解 | 可能不可行 |
| 基本可行解 (BFS) | 基本解 + 所有分量 ≥ 0 | = 极点 |
| 极点 | 不能表示为其他两点凸组合 | = BFS |
| 最优解 | 目标值最大的可行解 | 必在极点取到 |
