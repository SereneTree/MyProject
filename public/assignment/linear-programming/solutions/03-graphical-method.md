# Problem 3：图形法求最优解 (6 分)

## 题目

对以下两个线性规划问题，画出约束条件、限制，并清楚地标出可行域。在图中找到最优解，并用法向量解释如何找到最优解。

### (1)
```
maximize   4x₁ + x₂
subject to  2x₁ + x₂ ≤ 100
            x₁ + x₂ ≤ 80
            x₁ ≤ 40
            x₁, x₂ ≥ 0
```

### (2)
```
maximize   2x + 3y
subject to  x + y ≤ 4
            3x + y ≤ 6
            x + 3y ≤ 6
            x, y ≥ 0
```

---

## 核心知识点

### 1. 图形法步骤

1. **画出每条约束的边界线**（将 ≤ 变为 =）
2. **确定每条约束的可行半平面**（代入原点判断方向）
3. **画出非负约束**（x₁ ≥ 0, x₂ ≥ 0）
4. **求所有半平面的交集**（即可行域，用阴影标记）
5. **画出目标函数的等值线**（c^T x = k）
6. **用法向量方向移动等值线**，找到最后离开可行域的极点

### 2. 法向量法

- 目标函数 c^T x = k 的法向量为 c
- 法向量指向目标函数增大的方向
- 沿法向量方向移动等值线，最后触碰到的可行域顶点即为最优解

### 3. 交点求解

- 最优解位于可行域的某个顶点（极点）
- 通过解联立方程组确定交点坐标

---

## 详细解答

### 问题 (1) 求解

**约束边界线：**

| 约束 | 边界线方程 | 类型 |
|------|-----------|------|
| C1 | 2x₁ + x₂ = 100 | ≤ |
| C2 | x₁ + x₂ = 80 | ≤ |
| C3 | x₁ = 40 | ≤ |
| C4 | x₁ = 0 | ≥ |
| C5 | x₂ = 0 | ≥ |

**关键交点（可行域顶点）：**

1. **O = (0, 0)**：坐标轴原点
2. **A = (40, 0)**：x₁ = 40 与 x₂ = 0 的交点
3. **B = (40, 20)**：x₁ = 40 与 2x₁ + x₂ = 100 的交点
   - 代入 x₁ = 40：2(40) + x₂ = 100 → x₂ = 20
4. **C = (20, 60)**：2x₁ + x₂ = 100 与 x₁ + x₂ = 80 的交点
   - 两式相减：x₁ = 20，代入得 x₂ = 60
5. **D = (0, 80)**：x₁ = 0 与 x₁ + x₂ = 80 的交点

**验证各顶点可行性：**

| 顶点 | C1: 2x₁+x₂≤100 | C2: x₁+x₂≤80 | C3: x₁≤40 | 可行？ |
|------|---------|---------|---------|--------|
| O(0,0) | 0≤100 ✓ | 0≤80 ✓ | 0≤40 ✓ | ✓ |
| A(40,0) | 80≤100 ✓ | 40≤80 ✓ | 40≤40 ✓ | ✓ |
| B(40,20) | 100≤100 ✓ | 60≤80 ✓ | 40≤40 ✓ | ✓ |
| C(20,60) | 100≤100 ✓ | 80≤80 ✓ | 20≤40 ✓ | ✓ |
| D(0,80) | 80≤100 ✓ | 80≤80 ✓ | 0≤40 ✓ | ✓ |

**目标函数值：**

| 顶点 | z = 4x₁ + x₂ |
|------|--------------|
| O(0,0) | 0 |
| A(40,0) | 160 |
| B(40,20) | **180** ← 最优 |
| C(20,60) | 140 |
| D(0,80) | 80 |

**法向量分析：**

- 目标函数 z = 4x₁ + x₂，法向量 c = (4, 1)
- 法向量方向大致指向右偏下方（x₁ 方向权重大）
- 沿 c 方向移动等值线 4x₁ + x₂ = k，k 增大时等值线向右上移动
- 最后离开可行域的点为 **B = (40, 20)**

**最优解：x₁ = 40, x₂ = 20，最优值 z = 180**

---

### 问题 (2) 求解

**约束边界线：**

| 约束 | 边界线方程 | 类型 |
|------|-----------|------|
| C1 | x + y = 4 | ≤ |
| C2 | 3x + y = 6 | ≤ |
| C3 | x + 3y = 6 | ≤ |
| C4 | x = 0 | ≥ |
| C5 | y = 0 | ≥ |

**关键交点计算：**

1. **O = (0, 0)**
2. **A = (2, 0)**：3x + y = 6 与 y = 0 → x = 2
3. **B**：C2 与 C1 的交点
   - 3x + y = 6, x + y = 4
   - 相减：2x = 2 → x = 1, y = 3
   - B = (1, 3)
   - 验证 C3：1 + 3(3) = 10 > 6 ✗ → **B 不可行！**

4. **B'**：C2 与 C3 的交点
   - 3x + y = 6, x + 3y = 6
   - 第一式 ×3：9x + 3y = 18
   - 相减：8x = 12 → x = 3/2, y = 6 - 3(3/2) = 3/2
   - B' = (3/2, 3/2)
   - 验证 C1：3/2 + 3/2 = 3 ≤ 4 ✓ → **可行**

5. **C = (0, 2)**：x + 3y = 6 与 x = 0 → y = 2

6. **D**：C1 与 C3 的交点
   - x + y = 4, x + 3y = 6
   - 相减：-2y = -2 → y = 1, x = 3
   - D = (3, 1)
   - 验证 C2：3(3) + 1 = 10 > 6 ✗ → **D 不可行！**

**可行域顶点（按序）：** O(0,0), A(2,0), B'(3/2, 3/2), C(0,2)

**目标函数值：**

| 顶点 | z = 2x + 3y |
|------|-------------|
| O(0,0) | 0 |
| A(2,0) | 4 |
| B'(3/2, 3/2) | 3 + 4.5 = **7.5** ← 最优 |
| C(0,2) | 6 |

**法向量分析：**

- 目标函数 z = 2x + 3y，法向量 c = (2, 3)
- 法向量方向指向右上偏 y 方向（y 权重更大）
- 沿 c 方向移动等值线 2x + 3y = k，最后离开可行域的点为 **B' = (3/2, 3/2)**

**最优解：x = 3/2, y = 3/2，最优值 z = 7.5**

## 图形法核心技巧

| 步骤 | 注意事项 |
|------|---------|
| 画约束线 | 找两个截距点连线即可 |
| 确定可行侧 | 代入原点：若满足则原点侧为可行侧 |
| 标可行域 | 所有约束可行侧的交集 |
| 画法向量 | 从原点出发，方向为 c = (c₁, c₂) |
| 找最优点 | 沿法向量方向，等值线最后触碰到的顶点 |

---

## 常见错误提示

1. 忘记检查交点是否满足**所有**约束（不只是求交的那两个）
2. 法向量方向搞反（最大化是沿 c 方向，最小化是沿 -c 方向）
3. 可行域顶点遗漏（尤其是与坐标轴的交点）
