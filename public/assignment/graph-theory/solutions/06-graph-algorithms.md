# 图遍历、强连通、最小生成树与最短路 (Problems 28–37)

## 核心知识点

### 1. BFS 广度优先搜索 (Breadth-First Search)

**算法步骤：**
1. 选取起始顶点 s，入队列 Q，标记已访问
2. 从 Q 中取出队首顶点 v
3. 遍历 v 的所有未访问邻居，标记并入队
4. 重复 2-3 直到 Q 为空

**性质：**
- 产生**最短路径树**（无权图）
- 时间复杂度：O(V + E)
- 先访问距起点近的顶点

**生成树特点**：BFS 树中，任何非树边连接**同层或相邻层**的顶点。

### 2. DFS 深度优先搜索 (Depth-First Search)

**算法步骤：**
1. 选取起始顶点 s，标记已访问
2. 选择 s 的一个未访问邻居 w，递归 DFS(w)
3. 当所有邻居都已访问时回溯
4. 重复直到所有可达顶点都被访问

**性质：**
- 时间复杂度：O(V + E)
- 会产生深的分支
- 非树边一定是**祖先-后代**关系（Back edges）

**生成树特点**：DFS 树中，非树边一定连接祖先与后代。

### 3. 强连通分量 (Strongly Connected Components)

**定义**：有向图中，若从 u 到 v 有有向路径，且从 v 到 u 也有有向路径，则 u, v 强连通。

**强连通分量 (SCC)**：极大强连通子图。

**识别方法：**
- 对每对顶点检查双向可达性
- 或用 Kosaraju / Tarjan 算法（O(V+E)）

### 4. Prim 算法（最小生成树）

**算法步骤：**
1. 选取任一起始顶点，加入已选集 S
2. 在所有连接 S 和 V\S 的边中，选**权重最小**的边
3. 将该边和对端顶点加入 S
4. 重复直到 S = V

**复杂度**：O(E log V)（用优先队列）

**关键**：贪心策略，每步选最小跨边。

### 5. Kruskal 算法（最小生成树）

**算法步骤：**
1. 将所有边按权重**从小到大**排序
2. 依次考察每条边：若不构成环则加入树
3. 重复直到选了 n-1 条边

**复杂度**：O(E log E)

**环判断**：使用并查集 (Union-Find)

### 6. Dijkstra 算法（最短路径）

**适用条件**：**非负权重**图

**算法步骤：**
1. 初始化：dist[s] = 0，其余 = ∞
2. 从未确定集中取 dist 最小的顶点 u
3. 对 u 的所有邻居 v：若 dist[u] + w(u,v) < dist[v]，更新 dist[v]
4. 将 u 标记为已确定
5. 重复直到所有顶点确定

**复杂度**：O(V² ) 或 O((V+E) log V)（用堆）

### 7. Bellman-Ford 算法（最短路径）

**适用条件**：可有**负权边**（但无负环）

**算法步骤：**
1. 初始化：dist[s] = 0，其余 = ∞
2. 重复 V-1 轮：对每条边 (u,v,w)，若 dist[u] + w < dist[v]，更新 dist[v]
3. 第 V 轮再扫一遍，若还有更新 → 存在负环

**复杂度**：O(V·E)

## 题目解析

### Problem 28: BFS 求生成树

**解题步骤：**

1. 选择起始顶点（通常按字典序最小）
2. 维护队列和访问标记
3. 按 BFS 逐层展开，记录每次发现的**树边**

**答题格式：**
```
起始顶点: A
Queue: [A]

Step 1: Visit A, neighbors: B, C, D (未访问)
  Tree edges: {A,B}, {A,C}, {A,D}
  Queue: [B, C, D]

Step 2: Visit B, neighbors: E, F (未访问)
  Tree edges: {B,E}, {B,F}
  Queue: [C, D, E, F]

Step 3: Visit C, neighbors: ... (已访问的跳过)
...

Spanning Tree Edges: {A,B}, {A,C}, {A,D}, {B,E}, {B,F}, ...
```

> **注意**：如有多个未访问邻居，按**字母/数字顺序**选取（除非题目另有说明）。

### Problem 29: DFS 求生成树

**解题步骤：**

1. 选择起始顶点
2. 沿一个分支深入到底
3. 回溯时尝试其他分支
4. 记录所有树边

**答题格式：**
```
起始顶点: A

DFS(A):
  → Visit B (tree edge: {A,B})
    DFS(B):
      → Visit E (tree edge: {B,E})
        DFS(E):
          → Visit F (tree edge: {E,F})
            DFS(F): no unvisited neighbors, backtrack
          backtrack to E
        backtrack to B
      → Visit C (tree edge: {B,C})
        ...

Spanning Tree Edges: {A,B}, {B,E}, {E,F}, {B,C}, ...
```

### Problem 30: 找强连通分量

**解题步骤：**

1. 对有向图，从每个顶点出发，确定可达的顶点集
2. 找出满足**双向可达**的最大顶点子集

**实操方法（小图可用观察法）：**
- 画出图，找所有环路
- 环上的所有顶点互相强连通
- 不在任何环上的单独顶点自成一个 SCC

**答题格式：**
```
SCC 1: {v₁, v₂, v₃}  （因为 v₁→v₂→v₃→v₁ 构成环）
SCC 2: {v₄}           （v₄ 无法回到自身通过其他顶点）
SCC 3: {v₅, v₆}       （v₅→v₆→v₅ 构成环）
```

### Problem 31: Prim 算法求最小生成树

**解题步骤（表格法）：**

选择起始顶点（如 A），逐步记录：

| 步骤 | S (已选集) | 候选边 (跨越 S 与 V\S) | 选择的最小边 | 加入顶点 |
|------|-----------|----------------------|------------|---------|
| 0 | {A} | {A,B}=3, {A,C}=5 | {A,B}=3 | B |
| 1 | {A,B} | {A,C}=5, {B,D}=2, {B,E}=4 | {B,D}=2 | D |
| 2 | {A,B,D} | {A,C}=5, {B,E}=4, {D,E}=1 | {D,E}=1 | E |
| ... | ... | ... | ... | ... |

**MST 权重** = 所有选中边权之和

### Problem 32: Prim 算法找两棵最小生成树

**说明**：当存在权重相同的多条候选边时，选择不同边可产生不同的 MST。

**方法**：在某步存在 tie（相同最小权重的边）时，分别选不同的边，得到两棵不同的 MST（但总权重相同）。

### Problem 33–34: Kruskal 算法求最小生成树

**解题步骤（排序法）：**

1. 列出所有边及权重
2. 按权重升序排列
3. 依次加入，跳过会形成环的边

| 步骤 | 考察边 | 权重 | 是否形成环？ | 决策 |
|------|--------|------|------------|------|
| 1 | {D,E} | 1 | 否 | ✓ 加入 |
| 2 | {B,D} | 2 | 否 | ✓ 加入 |
| 3 | {A,B} | 3 | 否 | ✓ 加入 |
| 4 | {B,E} | 4 | 是（B-D-E-B）| ✗ 跳过 |
| 5 | {A,C} | 5 | 否 | ✓ 加入 |
| ... | ... | ... | ... | ... |

> **判断成环**：加入边后，若两端点已在同一连通分量中 → 成环。

### Problem 35: Dijkstra 算法求最短路径

**解题步骤（表格法）：**

起始顶点 A，初始 dist[A]=0，其余 = ∞

| 步骤 | 确定顶点 | dist[A] | dist[B] | dist[C] | dist[D] | dist[E] | 更新说明 |
|------|---------|---------|---------|---------|---------|---------|---------|
| init | — | 0 | ∞ | ∞ | ∞ | ∞ | |
| 1 | A | **0** | 3 | 5 | ∞ | ∞ | 经 A→B=3, A→C=5 |
| 2 | B | 0 | **3** | 5 | 5 | 7 | 经 B→D=2, B→E=4 |
| 3 | C | 0 | 3 | **5** | 5 | 6 | 经 C→E=1 |
| 4 | D | 0 | 3 | 5 | **5** | 6 | |
| 5 | E | 0 | 3 | 5 | 5 | **6** | |

**最短路径树**：记录每个顶点的前驱 (predecessor)，逆推可得路径。

### Problem 36–37: Bellman-Ford 算法

**解题步骤：**

对所有边重复松弛 V-1 轮：

```
初始: dist[a]=0, 其余=∞

Round 1: 对每条边 (u,v,w):
  if dist[u] + w < dist[v]: dist[v] = dist[u] + w

Round 2: 重复...

...

Round V-1: 最终结果
```

**答题格式（表格追踪每轮更新）：**

| 轮次 | dist[a] | dist[b] | dist[c] | dist[d] | 更新边 |
|------|---------|---------|---------|---------|--------|
| init | 0 | ∞ | ∞ | ∞ | — |
| 1 | 0 | 4 | 2 | ∞ | (a,b)=4, (a,c)=2 |
| 2 | 0 | 3 | 2 | 5 | (c,b)=1更新b, (b,d)=2 |
| 3 | 0 | 3 | 2 | 5 | 无更新→终止 |

**最短 a→c 路径**：直接 a→c，距离 = 2

> **与 Dijkstra 的区别**：Bellman-Ford 可处理负权边，但更慢 O(VE)。

## Prim vs Kruskal 对比

| 特性 | Prim | Kruskal |
|------|------|---------|
| 思路 | 从一个顶点"生长" | 全局按权排序选边 |
| 数据结构 | 优先队列 | 并查集 |
| 适合 | 稠密图 | 稀疏图 |
| 复杂度 | O(E log V) | O(E log E) |
| 初始需要 | 选起始顶点 | 无需 |

## Dijkstra vs Bellman-Ford 对比

| 特性 | Dijkstra | Bellman-Ford |
|------|----------|-------------|
| 负权边 | ✗ 不支持 | ✓ 支持 |
| 负环检测 | ✗ | ✓ |
| 复杂度 | O((V+E)log V) | O(VE) |
| 思路 | 贪心（每步确定一个最近点） | 动态规划（逐轮松弛） |

## 速记要点

| 要点 | 内容 |
|------|------|
| BFS 特点 | 层次遍历、无权最短路 |
| DFS 特点 | 深入优先、回边检测环 |
| SCC 判定 | 双向可达的极大子集 |
| Prim 口诀 | 选最小跨边，扩展已选集 |
| Kruskal 口诀 | 按权排序，不成环就加 |
| Dijkstra 口诀 | 选最近未确定点，松弛邻居 |
| Bellman-Ford 口诀 | V-1 轮全边松弛，第V轮检负环 |
| MST 边数 | 恒为 V - 1 |
