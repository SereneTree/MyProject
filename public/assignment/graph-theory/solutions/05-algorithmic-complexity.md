# 算法复杂度 (Problems 26–27)

## 核心知识点

### 1. 大 O 表示法 (Big-O Notation)

**定义**：\(f(n) = O(g(n))\) 当且仅当存在常数 c > 0 和 \(n_0\)，使得对所有 \(n \geq n_0\)：
\[f(n) \leq c \cdot g(n)\]

**直觉**：f 的增长速度不超过 g（上界）。

### 2. 常见复杂度阶层

\[O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)\]

### 3. 大 O 的运算规则

| 规则 | 公式 |
|------|------|
| 常数因子 | O(c·f) = O(f) |
| 加法 | O(f + g) = O(max{f, g}) |
| 乘法 | O(f · g) = O(f) · O(g) |
| 传递性 | f = O(g), g = O(h) → f = O(h) |
| 多项式 | \(a_k n^k + \cdots + a_0 = O(n^k)\) |

---

## 题目解析

### Problem 26(a)(i): 证明 f(n) + g(n) = O(max{f(n), g(n)})

**证明：**

设 h(n) = max{f(n), g(n)}。

对所有 n：
\[f(n) \leq h(n) \quad \text{且} \quad g(n) \leq h(n)\]

因此：
\[f(n) + g(n) \leq h(n) + h(n) = 2h(n)\]

取 c = 2, \(n_0 = 1\)，则对所有 \(n \geq n_0\)：
\[f(n) + g(n) \leq 2 \cdot \max\{f(n), g(n)\}\]

由大 O 定义，\(f(n) + g(n) = O(\max\{f(n), g(n)\})\)。 ∎

---

### Problem 26(a)(ii): 证明大 O 的传递性

**题意：** 若 f(n) = O(g(n)) 且 g(n) = O(h(n))，则 f(n) = O(h(n))。

**证明：**

由 f(n) = O(g(n))：存在 \(c_1, n_1\) 使得 \(f(n) \leq c_1 \cdot g(n)\)（当 \(n \geq n_1\)）。

由 g(n) = O(h(n))：存在 \(c_2, n_2\) 使得 \(g(n) \leq c_2 \cdot h(n)\)（当 \(n \geq n_2\)）。

取 \(c = c_1 \cdot c_2\), \(n_0 = \max\{n_1, n_2\}\)：

当 \(n \geq n_0\) 时：
\[f(n) \leq c_1 \cdot g(n) \leq c_1 \cdot c_2 \cdot h(n) = c \cdot h(n)\]

因此 f(n) = O(h(n))。 ∎

---

### Problem 26(b): 多项式的大 O

**题意：** 设 \(f(n) = a_0 + a_1 n + a_2 n^2 + a_3 n^3\)，证明 \(f(n) = O(n^3)\)。

**证明：**

对 \(n \geq 1\)：
\[|f(n)| = |a_0 + a_1 n + a_2 n^2 + a_3 n^3|\]
\[\leq |a_0| + |a_1| n + |a_2| n^2 + |a_3| n^3\]
\[\leq |a_0| n^3 + |a_1| n^3 + |a_2| n^3 + |a_3| n^3\]（因为 \(n^k \leq n^3\) 当 k ≤ 3, n ≥ 1）
\[= (|a_0| + |a_1| + |a_2| + |a_3|) \cdot n^3\]

取 \(c = |a_0| + |a_1| + |a_2| + |a_3|\), \(n_0 = 1\)：

\(f(n) \leq c \cdot n^3\) 对所有 \(n \geq 1\) 成立。

因此 \(f(n) = O(n^3)\)。 ∎

---

### Problem 26(c): 证明 \(2^{2n}\) 不是 \(O(2^n)\)

**证明（反证法）：**

假设 \(2^{2n} = O(2^n)\)。

则存在 c > 0, \(n_0\) 使得对所有 \(n \geq n_0\)：
\[2^{2n} \leq c \cdot 2^n\]

即：
\[\frac{2^{2n}}{2^n} \leq c\]
\[2^n \leq c\]

但 \(2^n \to \infty\) 当 \(n \to \infty\)，所以不存在常数 c 满足 \(2^n \leq c\) 对所有大 n 成立。

**矛盾！**

因此 \(2^{2n}\) 不是 \(O(2^n)\)。 ∎

> **核心直觉**：\(2^{2n} = (2^n)^2 = 4^n\)，而 \(4^n / 2^n = 2^n \to \infty\)，所以 \(4^n\) 的增长远快于 \(2^n\)。

### Problem 27: 欧几里得算法复杂度分析

**算法描述**：
- 输入：非负整数 a ≥ b
- 令 \(r_0 = a, r_1 = b\)
- 每轮：\(r_{n-2} = q_n \cdot r_{n-1} + r_n\)，其中 \(0 \leq r_n < r_{n-1}\)
- 当 \(r_{n-1} = 0\) 时停止，输出 \(\gcd(a,b) = r_{n-2}\)

---

**(i) 若 \(r_n\) 每轮减少 1，算法运行多少轮？**

**解答：**

\(r_0 = a\)（初始最大余数 ≤ a）。若每轮减少 1：

最多运行 **a 轮**（即 \(r_0\) 轮），此时 \(r_a = 0\)。

更精确地：输入大小为 \(\log_2 a + \log_2 b\)，所以最多 \(O(a) = O(2^{\log_2 a})\) 轮——这是指数级的（相对输入大小）。

---

**(ii) 证明 \(r_n < r_{n-2} / 2\)（每两轮至少减半）**

**证明（分三种情况）：**

**Case 1**: \(r_{n-1} \leq r_{n-2}/2\)

由于 \(r_n < r_{n-1} \leq r_{n-2}/2\)，结论成立。 ✓

**Case 2**: \(r_{n-1} > r_{n-2}/2\)（即 \(r_{n-2}/2 < r_{n-1} < r_{n-2}\)）

此时 \(q_n = 1\)（因为 \(r_{n-2} = 1 \cdot r_{n-1} + r_n\)）

\[r_n = r_{n-2} - r_{n-1} < r_{n-2} - r_{n-2}/2 = r_{n-2}/2\] ✓

**Case 3**: \(r_{n-1} = r_{n-2}\)

不可能发生，因为 \(r_n < r_{n-1}\) 要求 \(r_{n-1} < r_{n-2}\)（严格递减）。

两种有效情况均给出 \(r_n < r_{n-2}/2\)。 ∎

---

**(iii) 算法轮数的上界**

**推导：**

由 (ii)，每两轮余数至少减半：
\[r_{2k} < \frac{r_0}{2^k} = \frac{a}{2^k}\]

当 \(r_{2k} < 1\) 时算法必已停止（因为余数为非负整数，< 1 即 = 0）：
\[\frac{a}{2^k} < 1 \implies 2^k > a \implies k > \log_2 a\]

因此算法最多运行 \(2k = 2\log_2 a\) 轮。

由于输入大小 s = \(\log_2 a + \log_2 b\)，有 \(\log_2 a \leq s\)。

**结论**：算法最多运行 **O(s) = O(log₂ a + log₂ b)** 轮，即**线性于输入大小**（多项式时间）。

## 速记要点

| 要点 | 内容 |
|------|------|
| O(f+g) | = O(max{f, g}) |
| O 传递性 | f=O(g), g=O(h) → f=O(h) |
| 多项式 | 最高次项决定复杂度 |
| 证明"不是 O" | 反证法：推出需有界但实际趋于无穷 |
| 欧几里得算法 | 每两轮减半 → O(log a) 轮 → 多项式时间 |
