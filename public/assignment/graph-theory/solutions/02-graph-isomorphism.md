# 图同构 (Problems 10–12)

## 核心知识点

### 1. 图同构的定义

两个图 G₁ = (V₁, E₁) 和 G₂ = (V₂, E₂) **同构 (isomorphic)**，记作 G₁ ≅ G₂，当且仅当：

存在一个双射 \(f: V_1 \to V_2\)，使得 \(\{u, v\} \in E_1 \iff \{f(u), f(v)\} \in E_2\)

通俗理解：**两个图"形状相同"，只是顶点标签不同。**

### 2. 同构的必要条件（快速排除法）

以下条件**全部满足**才有可能同构（但满足不保证一定同构）：

| 不变量 | 说明 |
|--------|------|
| 顶点数 | \|V₁\| = \|V₂\| |
| 边数 | \|E₁\| = \|E₂\| |
| 度序列 | 排列后相同 |
| 连通分量数 | 相同 |
| 环的数量和长度 | 对应相同 |
| 补图也同构 | G₁ 的补 ≅ G₂ 的补 |

### 3. 证明同构的方法

**构造法**：找到具体的顶点映射 f，并验证边的保持关系。

**步骤：**
1. 计算两个图的度序列，确认相同
2. 将度相同的顶点分组
3. 在同度顶点间尝试建立映射
4. 验证映射保持所有边关系

## 题目解析

### Problem 10: 证明 G₁ 和 G₂ 同构

**图描述：**
- G₁ 有顶点 {a, b, c, d, e}
- G₂ 有顶点 {a', b', c', d', e'}

**解题步骤：**

**Step 1 — 计算度序列：**
- 分别统计两个图中每个顶点的度
- 确认度序列排列相同

**Step 2 — 根据度匹配顶点：**
- 度为 k 的顶点只能映射到度为 k 的顶点

**Step 3 — 构造映射并验证：**

例如（具体取决于图结构），设映射：
```
f(a) = a', f(b) = c', f(c) = b', f(d) = d', f(e) = e'
```

**Step 4 — 验证：**
对 E(G₁) 中每条边 {u, v}，检查 {f(u), f(v)} ∈ E(G₂)：

| G₁ 中的边 | 映射后 | G₂ 中存在？ |
|-----------|--------|------------|
| {a, b} | {a', c'} | ✓ |
| {a, c} | {a', b'} | ✓ |
| ... | ... | ✓ |

所有边对应 → **同构成立** ✓

### Problem 11: 证明 G 和 G' 同构

**图描述：**
- G: 顶点 {a, b, c, d, e}
- G': 顶点 {a', b', c', d', e'}

**通用解题模板：**

```
1. |V(G)| = |V(G')| = 5 ✓
2. |E(G)| = |E(G')| ✓ （逐个数边）
3. 度序列：
   G:  deg(a)=?, deg(b)=?, deg(c)=?, deg(d)=?, deg(e)=?
   G': deg(a')=?, deg(b')=?, deg(c')=?, deg(d')=?, deg(e')=?
   排序后相同 ✓
4. 构造映射 f:
   f(a) = ?, f(b) = ?, f(c) = ?, f(d) = ?, f(e) = ?
5. 逐边验证映射保持性 ✓
```

> **解题技巧**：先找度唯一的顶点（如只有一个度为3的顶点），这些顶点的映射是确定的，大大减少搜索空间。

### Problem 12: 证明 G₁ 和 G₂ 同构

**图描述：**
- G₁: 顶点 {1, 2, 3, 4}
- G₂: 顶点 {a, b, c, d}

**解答：**

**Step 1**: 两图均有 4 个顶点

**Step 2**: 计算边数（数边）

**Step 3**: 度序列对比

**Step 4**: 构造映射

对于 4 个顶点的小图，可以：
1. 找度最大的顶点互相对应
2. 检查邻居结构是否匹配
3. 写出完整映射

**验证格式：**
```
映射 f: 1→a, 2→c, 3→b, 4→d

边验证：
{1,2} ∈ E(G₁) → {f(1),f(2)} = {a,c} ∈ E(G₂) ✓
{1,3} ∈ E(G₁) → {f(1),f(3)} = {a,b} ∈ E(G₂) ✓
{2,4} ∈ E(G₁) → {f(2),f(4)} = {c,d} ∈ E(G₂) ✓
...
所有边均保持 → G₁ ≅ G₂ ✓
```

## 判断不同构的方法

如果要**证明两个图不同构**，只需找到一个不变量不匹配：

1. 顶点数不等
2. 边数不等
3. 度序列不同
4. 一个有三角形 (K₃) 而另一个没有
5. 一个连通而另一个不连通
6. 最短环长度不同

**示例**：C₆（6-环）和 K₃,₃（完全二部图）
- 顶点数 = 6 ✓，边数 = 6 (C₆) vs 9 (K₃,₃) ✗ → **不同构**

## 速记要点

| 要点 | 内容 |
|------|------|
| 同构 = | 存在保边双射 |
| 证明同构 | 构造具体映射 + 逐边验证 |
| 证明不同构 | 找一个不变量不匹配 |
| 常用不变量 | 顶点数、边数、度序列、连通性、环结构 |
| 解题切入点 | 从度唯一/最大的顶点开始匹配 |
