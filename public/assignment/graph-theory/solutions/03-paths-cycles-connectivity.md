# 路径、回路与连通性 (Problems 13–21)

## 核心知识点

### 1. 基本术语

| 术语 | 英文 | 定义 |
|------|------|------|
| **途径 (Walk)** | Walk | 顶点和边的交替序列，边和顶点**可重复** |
| **迹 (Trail)** | Trail | **边不重复**的途径（顶点可重复） |
| **路径 (Path)** | Path | **边和顶点都不重复**的途径 |
| **回路 (Cycle)** | Cycle | 起点=终点的路径（除首尾外无重复顶点） |
| **闭途径** | Closed walk | 起点=终点的途径 |

### 2. 长度

- 路径/途径的**长度** = 经过的边数（不是顶点数）
- n 个顶点的路径长度 = n - 1
- n 个顶点的回路有 n 条边

### 3. 连通性

- **连通图 (Connected)**：任意两顶点之间存在路径
- **连通分量 (Component)**：极大连通子图
- **桥 (Bridge)**：删除后图不再连通的边
- **割点 (Cut vertex)**：删除后图不再连通的顶点

### 4. 关键定理

- **定理**：若图 G 中存在从 u 到 v 的途径，则必存在从 u 到 v 的路径
- **定理**：连通图删去一条边后仍连通 ⟺ 该边在某个回路上
- **定理**：图 G 连通 ⟺ G 的任何边割都不为空

## 题目解析

### Problem 13: 列出所有路径、回路、迹

**题意：** 给定图 G，找出：
- (i) 从 v₁ 到 v₈ 的所有路径
- (ii) G 的所有回路
- (iii) 从 v₃ 到 v₅ 长度为 3 的所有迹

**解题方法：**

**(i) 找所有路径（v₁ → v₈）：**
- 从 v₁ 出发，DFS 遍历，记录不重复顶点的所有路线
- 列出形如：v₁ → v₂ → v₃ → ... → v₈ 的序列

**(ii) 找所有回路：**
- 从每个顶点出发寻找能回到自身的不重复路径
- 注意：环的等价性（从不同顶点出发走同一个环算一个）

**(iii) 长度为 3 的迹（v₃ → v₅）：**
- 恰好经过 3 条不重复的边
- 列举：v₃ → ? → ? → v₅（中间可经过已访问顶点，但边不重复）

> **解题技巧**：画图后系统性枚举，按字典序列出避免遗漏。

### Problem 14: 找出所有回路

**方法：**
1. 找出图中所有环（观察图结构）
2. 从最小环开始，逐步找较大的环
3. 注意：两个小环共享边时，外圈也构成一个回路

**示例**：若图中有三角形 a-b-c-a 和四边形 b-c-d-e-b
- 回路 1：a → b → c → a（长度 3）
- 回路 2：b → c → d → e → b（长度 4）
- 回路 3：a → b → e → d → c → a（长度 5，外圈）

---

### Problem 15: 找从 A 到 R 的所有路径及长度

**方法：**
1. 确定所有从 A 出发可达 R 的路线
2. 对每条路径，数边数 = 长度
3. 按长度排列

**答题格式：**
```
Path 1: A → B → D → R,  length = 3
Path 2: A → C → E → R,  length = 3
Path 3: A → B → C → E → R,  length = 4
...
```

### Problem 16: 证明路径和回路的性质

**(i) n 个顶点的路径长度为 n-1**

**证明：**
设路径为 \(v_1, v_2, \ldots, v_n\)，其中所有顶点互不相同。
路径经过的边为 \(\{v_1,v_2\}, \{v_2,v_3\}, \ldots, \{v_{n-1},v_n\}\)。
边数 = n - 1。
因此路径长度 = n - 1。 ∎

**(ii) n 个顶点的回路有 n 条边**

**证明：**
设回路为 \(v_1, v_2, \ldots, v_n, v_1\)，其中 \(v_1, \ldots, v_n\) 互不相同。
边为 \(\{v_1,v_2\}, \{v_2,v_3\}, \ldots, \{v_{n-1},v_n\}, \{v_n,v_1\}\)。
边数 = n。 ∎

**(iii) 回路中每个顶点度为 2**

**证明：**
在回路 \(v_1, v_2, \ldots, v_n, v_1\) 中，每个顶点 \(v_i\) 恰好关联两条边：
- \(\{v_{i-1}, v_i\}\)（或 \(\{v_n, v_1\}\) 当 i=1）
- \(\{v_i, v_{i+1}\}\)（或 \(\{v_n, v_1\}\) 当 i=n）

因此 \(\deg(v_i) = 2\) 对所有 i 成立。 ∎

### Problem 17: 最小度 ≥ k → 存在长度 ≥ k 的路径

**证明：**

设 \(\delta(G) \geq k\)（最小度至少为 k）。

取 G 中最长路径 \(P = v_0, v_1, \ldots, v_m\)。

顶点 \(v_m\) 的度 \(\geq k\)，其所有邻居必在 P 上（否则可延伸路径，与"最长"矛盾）。

因此 \(v_m\) 在 P 上至少有 k 个邻居，故 P 至少有 k+1 个顶点，即路径长度 m ≥ k。 ✓

**推论（k ≥ 2 时有长度 ≥ k+1 的回路）：**

设 \(v_m\) 的邻居中在 P 上最早出现的为 \(v_j\)（j ≤ m-k）。
则 \(v_j, v_{j+1}, \ldots, v_m, v_j\) 构成回路，长度 = m - j + 1 ≥ k + 1。 ∎

### Problem 18: 判断连通性

**方法：**
- 从任一顶点出发做 BFS/DFS
- 若能访问所有顶点 → 连通
- 若有不可达顶点 → 不连通

**答题格式：**
```
Graph (a): 连通。从任意顶点出发可达所有其他顶点。
Graph (b): 不连通。{v₁, v₂, v₃} 和 {v₄, v₅} 之间无边相连，构成两个连通分量。
```

### Problem 19: 仅有两个奇度顶点 a, b → 它们必连通

**证明（反证法）：**

假设 a 和 b 不连通，即它们在不同连通分量中。

设 a 所在连通分量为 C_a。在 C_a 中，a 是唯一奇度顶点。

但根据握手定理，任何图（包括子图）中奇度顶点个数为偶数。

C_a 中只有一个奇度顶点（a），这与握手定理矛盾。

因此假设不成立，a 和 b 必连通。 ∎

### Problem 20: 删边后仍连通 ⟺ 边在某回路上

**证明（充要条件，两个方向）：**

**(⟹)** 设删去边 e = {u, v} 后 G-e 仍连通。
则在 G-e 中存在 u 到 v 的路径 P。
P 加上边 e 构成 G 中的回路，且 e 在此回路上。 ✓

**(⟸)** 设 e = {u, v} 在 G 的某回路 C 上。
删去 e 后，u 和 v 仍可通过 C 上的其余边连通（绕一圈）。
对任意两顶点 x, y：
- 若原 x-y 路径不经过 e → 路径不受影响
- 若原路径经过 e → 将 e 替换为 C 上绕行部分，仍可连通

因此 G-e 连通。 ✓

### Problem 21: 连通图的边分解，顶点集有交

**题意：** G₁, G₂ 是连通图 G 的边分解（E(G₁) ∪ E(G₂) = E(G)，E(G₁) ∩ E(G₂) = ∅），则 V(G₁) ∩ V(G₂) ≠ ∅。

**证明（反证法）：**

假设 V(G₁) ∩ V(G₂) = ∅。

取 u ∈ V(G₁), v ∈ V(G₂)。
因 G 连通，存在 u-v 路径 P。
P 必经过某条边 {a, b}，其中 a ∈ V(G₁), b ∈ V(G₂)。
边 {a, b} ∈ E(G) = E(G₁) ∪ E(G₂)。
- 若 {a, b} ∈ E(G₁) → b ∈ V(G₁)，矛盾（b ∈ V(G₂) 且假设无交）
- 若 {a, b} ∈ E(G₂) → a ∈ V(G₂)，矛盾（a ∈ V(G₁) 且假设无交）

两种情况均矛盾，故假设不成立。V(G₁) ∩ V(G₂) ≠ ∅。 ∎

## 速记要点

| 要点 | 内容 |
|------|------|
| Walk vs Trail vs Path | 越来越严格：可重复 → 边不重复 → 都不重复 |
| 路径长度 | = 边数 = 顶点数 - 1 |
| 回路边数 | = 顶点数 |
| 删边不断连 | ⟺ 边在回路上（非桥） |
| 最小度 ≥ k | → 有长 ≥ k 的路径、长 ≥ k+1 的回路 |
| 奇度顶点 | 必须成对出现在同一连通分量 |
