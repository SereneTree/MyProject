### 常见题型与解法速查

| 题型 | 解法 |
|------|------|
| "写出 V 和 E" | 观察图逐个列 |
| "求邻接矩阵" | n×n 矩阵，有边=1 |
| "证明同构" | 构造映射 + 逐边验证 |
| "证明不同构" | 找不变量差异 |
| "求所有路径/回路" | DFS 枚举 |
| "证明连通性命题" | 反证法 + 握手定理 |
| "求 Prüfer 码" | 最小叶 → 记邻居 → 删叶 |
| "由 Prüfer 码画树" | 不在码中最小 → 连码头 |
| "证明 O(...)" | 找常数 c 和 n₀ |
| "证明不是 O" | 反证 → 推出矛盾 |
| "BFS/DFS 生成树" | 按算法逐步展开 |
| "Prim MST" | 选最小跨边 |
| "Kruskal MST" | 排序选边不成环 |
| "Dijkstra 最短路" | 贪心选最近未确定点 |
| "Bellman-Ford" | V-1 轮全边松弛 |

## 答题规范提示

1. **证明题**：明确写出"设…"、"因为…"、"所以…"、"∎"
2. **构造题**：画图 + 列表格 + 最后写结论
3. **算法执行题**：用表格逐步追踪状态变化
4. **存在性/不可能性**：优先用反证法
5. **图相关**：始终验证顶点数、边数与握手定理一致性
