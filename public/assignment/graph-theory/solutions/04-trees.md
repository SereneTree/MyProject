# 树 (Problems 22–25)

## 核心知识点

### 1. 树的定义与等价条件

**树 (Tree)**：连通且无回路的图。

以下对 n 个顶点的图 G 等价：
1. G 是树
2. G 连通且有 n-1 条边
3. G 无回路且有 n-1 条边
4. G 中任意两顶点间恰有唯一路径
5. G 连通，删去任一边后不连通（每条边都是桥）
6. G 无回路，添加任一边后恰产生一个回路

### 2. 树的基本性质

| 性质 | 公式/结论 |
|------|-----------|
| 边数 | \|E\| = \|V\| - 1 |
| 叶子 | 度为 1 的顶点（至少有 2 个，n ≥ 2 时） |
| 度数和 | \(\sum \deg(v) = 2(n-1)\) |

### 3. Prüfer 编码 (Prüfer Code)

**从标记树到 Prüfer 码（编码过程）：**
1. 找到标号最小的叶子（度为 1 的顶点）
2. 记录该叶子的**唯一邻居**的标号
3. 删去该叶子
4. 重复直到只剩 2 个顶点
5. 得到长度为 n-2 的序列

**从 Prüfer 码到树（解码过程）：**
1. 设码为 \(a_1, a_2, \ldots, a_{n-2}\)，顶点集 {1, 2, ..., n}
2. 找**不在剩余码中出现**的最小标号 → 与 \(a_1\) 连边
3. 删去 \(a_1\)，重复
4. 最后剩余两个顶点互连

**重要性质：**
- n 个标记顶点的标记树恰有 \(n^{n-2}\) 棵（Cayley 公式）
- 顶点 v 在 Prüfer 码中出现次数 = deg(v) - 1

## 题目解析

### Problem 22: 求给定树的 Prüfer 编码

**解题步骤（以具体示例演示）：**

假设树有顶点 1~8，按规则逐步删叶子：

```
Round 1: 最小叶子 = ?, 其邻居 = ? → 码第1位
Round 2: 删去后，最小叶子 = ?, 其邻居 = ? → 码第2位
...
Round 6: 最后一对删除 → 码第6位
```

**逐步示例（假设树结构）：**

设树边为 {1-3, 2-3, 3-5, 4-5, 5-6, 6-7, 6-8}

| 步骤 | 最小叶子 | 邻居（记入码） | 删除后剩余 |
|------|---------|--------------|-----------|
| 1 | 1 | 3 | {2,3,4,5,6,7,8} |
| 2 | 2 | 3 | {3,4,5,6,7,8} |
| 3 | 4 | 5 | {3,5,6,7,8} |
| 4 | 3 | 5 | {5,6,7,8} |
| 5 | 7 | 6 | {5,6,8} |
| 6 | 8 | 6 | {5,6} |

**Prüfer 码**：(3, 3, 5, 5, 6, 6)

### Problem 23: 由 Prüfer 码 (3, 2, 3, 2, 3) 画树

**解码过程：**

n = 7（码长 5 → n = 5 + 2 = 7），顶点集 {1, 2, 3, 4, 5, 6, 7}

码：**3, 2, 3, 2, 3**

| 步骤 | 剩余码 | 不在码中的最小标号 | 连边 |
|------|--------|-----------------|------|
| 1 | 3,2,3,2,3 | 不在{3,2}中的最小 = 1 | {1, 3} |
| 2 | 2,3,2,3 | 不在{2,3}中的最小 = 4 | {4, 2} |
| 3 | 3,2,3 | 不在{3,2}中的最小 = 5 | {5, 3} |
| 4 | 2,3 | 不在{2,3}中的最小 = 6 | {6, 2} |
| 5 | 3 | 不在{3}中的最小 = 2 | {2, 3} |
| 最后 | 空 | 剩余 {3, 7} | {3, 7} |

**树的边集**：{1-3, 4-2, 5-3, 6-2, 2-3, 3-7}

**验证**：
- 7 个顶点，6 条边 ✓
- 顶点 3 在码中出现 3 次 → deg(3) = 4 ✓
- 顶点 2 在码中出现 2 次 → deg(2) = 3 ✓

### Problem 24: 已知度分布，求叶子数

**题意：** 树有 5 个度为 2 的顶点，3 个度为 3 的顶点，4 个度为 4 的顶点。求度为 1 的顶点数。

**解答：**

设有 x 个度为 1 的顶点。
总顶点数 n = x + 5 + 3 + 4 = x + 12

树有 n - 1 条边，由握手定理：
\[\sum \deg(v) = 2(n-1)\]
\[1 \cdot x + 2 \cdot 5 + 3 \cdot 3 + 4 \cdot 4 = 2(x + 12 - 1)\]
\[x + 10 + 9 + 16 = 2(x + 11)\]
\[x + 35 = 2x + 22\]
\[x = 13\]

**答：有 13 个度为 1 的顶点（叶子）。**

### Problem 25: 已知度分布，求顶点数和边数

**题意：** 树有 2n 个度为 1 的顶点，3n 个度为 2 的顶点，n 个度为 3 的顶点。

**解答：**

总顶点数：|V| = 2n + 3n + n = 6n

树的边数：|E| = |V| - 1 = 6n - 1

**验证（握手定理）：**
\[\sum \deg(v) = 1 \cdot 2n + 2 \cdot 3n + 3 \cdot n = 2n + 6n + 3n = 11n\]
\[2|E| = 2(6n - 1) = 12n - 2\]

设等式成立：11n = 12n - 2 → n = 2

**答：**
- n = 2
- 顶点数 = 6×2 = 12
- 边数 = 12 - 1 = 11

**验证**：度数和 = 11×2 = 22 = 2×11 ✓

## 速记公式

| 概念 | 公式 |
|------|------|
| 树的边数 | \|E\| = n - 1 |
| 标记树数量 | \(n^{n-2}\)（Cayley 公式） |
| Prüfer 码长度 | n - 2 |
| 顶点 v 在码中出现次数 | deg(v) - 1 |
| 叶子不出现在 Prüfer 码中 | 因为 deg = 1, 出现 0 次 |
| 求叶子数公式 | \(x = 2 - \|V_{other}\| + \sum_{v \neq leaf} \deg(v)\) |

## 解题口诀

> **编码**：最小叶 → 记邻居 → 删叶 → 重复  
> **解码**：不在码中最小 → 与码头连 → 删码头 → 重复 → 最后两个互连
