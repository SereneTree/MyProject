# 计算机网络 Group Project 解析总览

本目录包含计算机网络课程大作业（Group Project）的完整题目解析和知识点讲解。

## 项目主题

**探索从 IPv4 到 IPv6 的过渡（Exploring the Transition from IPv4 to IPv6）**

## 内容目录

| 序号 | 主题 | 核心知识点 |
|------|------|-----------|
| 1 | IPv4 vs IPv6 技术对比与过渡机制 | 地址耗尽问题、IPv6特性、过渡技术（双栈/隧道/NAT64） |
| 2 | 项目方法论与论证框架 | Prompt Engineering、AI辅助研究、论证结构、证据验证 |

## 项目背景

- **角色定位**：作为 IETF 工作组的网络工程师团队
- **核心目标**：研究分析 IPv4 到 IPv6 的过渡，为 IESG 提出建议——互联网是否应尽快完全过渡到 IPv6
- **交付物**：中期项目进展日志 + 最终视频演示
- **评估要点**：使用 GenAI 工具、批判性思维和研究来支持论点

## 学习建议

1. 先掌握 IPv4/IPv6 的核心技术差异
2. 理解过渡机制（双栈、隧道、翻译）的优缺点
3. 关注真实世界数据（IANA报告、IGF统计）来支撑论点
4. 学习如何构建有效的、基于证据的论证
