## 6.1 树的基本概念

### 定义
> **树（Tree）** 是 n（n≥0）个节点的有限集合。
> - n=0 时称为**空树**
> - n>0 时满足：有且仅有一个特定节点称为**根（Root）**；其余节点可分为 m（m≥0）个互不相交的有限集，每个集合本身又是一棵树，称为根的**子树（Subtree）**

### 基本术语

| 术语 | 定义 |
|------|------|
| **节点的度** | 节点拥有的子树个数 |
| **树的度** | 树中各节点度的最大值 |
| **叶子节点** | 度为 0 的节点（终端节点） |
| **分支节点** | 度不为 0 的节点（非终端节点） |
| **父节点/子节点** | 有直接连接关系的上/下层节点 |
| **兄弟节点** | 同一父节点的子节点 |
| **节点的层次** | 根为第 1 层，往下依次加 1 |
| **树的深度** | 树中节点的最大层次 |
| **有序树** | 子树从左到右有次序之分 |
| **无序树** | 子树无次序之分 |
| **森林** | m（m≥0）棵互不相交的树的集合 |

## 6.2 二叉树（Binary Tree）

### 6.2.1 定义

> **二叉树**是 n（n≥0）个节点的有限集，或为空树，或由一个根节点及**左子树**和**右子树**两棵互不相交的二叉树组成。

**二叉树特点**：
- 每个节点**至多**有两棵子树
- 子树有**左右之分**，次序不能颠倒（有序树）
- 二叉树不是树的特例（虽然结构相似）

### 6.2.2 二叉树的五种基本形态

```
1. 空树        2. 单根节点      3. 只有左子树    4. 只有右子树    5. 左右子树都有
   ∅              ○               ○                ○                ○
                                  │                 │              ╱  ╲
                                  ○                 ○             ○    ○
```

### 6.2.3 重要性质

**性质1**：二叉树第 i 层上至多有 $2^{i-1}$ 个节点（i≥1）

**性质2**：深度为 k 的二叉树至多有 $2^k - 1$ 个节点

**性质3**：若叶子数为 $n_0$，度为 2 的节点数为 $n_2$，则 $n_0 = n_2 + 1$

> 推导：设总节点数 $n = n_0 + n_1 + n_2$，总分支数 = $n_1 + 2n_2 = n - 1$，所以 $n_0 = n_2 + 1$

**性质4**：具有 n 个节点的**完全二叉树**深度 $k = \lfloor \log_2 n \rfloor + 1$

**性质5**：对完全二叉树按层序编号（1 到 n），节点 i 满足：
- 若 $i > 1$：父节点编号 $= \lfloor i/2 \rfloor$
- 若 $2i \leq n$：左孩子编号 = $2i$；否则无左孩子
- 若 $2i+1 \leq n$：右孩子编号 = $2i+1$；否则无右孩子

### 6.2.4 特殊二叉树

| 类型 | 定义 |
|------|------|
| **满二叉树** | 深度为 k 且有 $2^k-1$ 个节点的二叉树 |
| **完全二叉树** | 按层序编号，与同深度满二叉树编号完全对应（最后一行从左到右连续） |

## 6.3 二叉树的存储结构

### 6.3.1 顺序存储
- 按完全二叉树编号，用数组存储
- 下标 i 对应节点，左孩子下标 2i，右孩子 2i+1
- **适合完全二叉树**，稀疏树浪费空间

### 6.3.2 链式存储（二叉链表）

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;  // 左右孩子指针
} BiTNode, *BiTree;
```

- n 个节点的二叉链表有 **n+1 个空指针域**（可用于线索）

### 三叉链表（带父指针）
```c
typedef struct BiTPNode {
    ElemType data;
    struct BiTPNode *parent, *lchild, *rchild;
} BiTPNode, *BiPTree;
```

## 6.4 二叉树的遍历

> **遍历**：按某种规则，对二叉树中每个节点**访问一次**且仅一次。

### 三种递归遍历

| 遍历方式 | 顺序 | 递归描述 |
|---------|------|---------|
| **先序（Pre-order）** | 根→左→右 | VLR |
| **中序（In-order）** | 左→根→右 | LVR |
| **后序（Post-order）** | 左→右→根 | LRV |

**示例**：
```
        A
       / \
      B   C
     / \
    D   E
```
- 先序：A B D E C
- 中序：D B E A C
- 后序：D E B C A

### 递归实现
```c
// 中序遍历
void InOrderTraverse(BiTree T) {
    if (T) {
        InOrderTraverse(T->lchild);
        printf("%c", T->data);
        InOrderTraverse(T->rchild);
    }
}
```

### 层序遍历（BFS）
使用**队列**实现：
```c
void LevelOrderTraverse(BiTree T) {
    if (!T) return;
    EnQueue(Q, T);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);
        Visit(p->data);
        if (p->lchild) EnQueue(Q, p->lchild);
        if (p->rchild) EnQueue(Q, p->rchild);
    }
}
```

### 遍历序列还原二叉树
- **先序 + 中序** → 唯一确定二叉树
- **后序 + 中序** → 唯一确定二叉树
- **先序 + 后序** → 不能唯一确定（单分支情况有歧义）

## 6.5 线索二叉树

### 动机
- n 节点二叉链表有 n+1 个空指针域，可利用这些空域存放"线索"

### 规则
```
若节点有左孩子：lchild 指向左孩子；否则指向其中序前驱
若节点有右孩子：rchild 指向右孩子；否则指向其中序后继
增加标志位：ltag=0（左孩子），ltag=1（前驱）
            rtag=0（右孩子），rtag=1（后继）
```

```c
typedef struct BiThrNode {
    ElemType data;
    struct BiThrNode *lchild, *rchild;
    int ltag, rtag;  // 0: 孩子，1: 线索
} BiThrNode, *BiThrTree;
```

## 6.6 树与二叉树的转换

### 树 → 二叉树
1. 兄弟节点之间加连线
2. 保留每个节点与其最左子节点的连线，删除与其他子节点的连线
3. 旋转 45°

**规律**：树的根节点转化后**无右子树**

### 森林 → 二叉树
1. 先将各棵树转为二叉树
2. 将各二叉树根节点依次作为前一棵树根节点的右子树

## 6.7 哈夫曼树（Huffman Tree）

### 相关概念
- **权值**：节点的权重
- **带权路径长度（WPL）**：$\text{WPL} = \sum_{i=1}^{n} w_i \times l_i$（$w_i$ 为权值，$l_i$ 为路径长度）
- **哈夫曼树（最优二叉树）**：带权路径长度**最小**的二叉树

### 哈夫曼算法（贪心构造）
1. 将 n 个权值作为 n 棵单节点二叉树
2. **选取权值最小的两棵树**合并，新节点权值 = 两树权值之和
3. 重复步骤 2，直到只剩一棵树

**哈夫曼树的特点**：
- 没有度为 1 的节点（**正则二叉树**）
- n 个叶子节点的哈夫曼树共有 **2n-1** 个节点
- 哈夫曼树不唯一（权值相同时选法不同）

### 哈夫曼编码
- 左分支记 0，右分支记 1（或反之）
- 任意字符的编码不是其他字符编码的前缀 → **前缀编码**
- 用于**数据压缩**

**示例**：权值 {5, 6, 7, 8, 15}

构造过程：
1. {5,6} → 11 → {7,8,11,15}
2. {7,8} → 15 → {11,15,15}
3. {11,15} → 26 → {15,26}（两个15选哪个都可）
4. 合并为根节点

WPL = 编码长度 × 频率 之和（最小）

## 6.8 树的存储结构

### 双亲表示法
```c
#define MAX_TREE_SIZE 100
typedef struct {
    ElemType data;
    int parent;  // 父节点下标，根节点为 -1
} PTNode;
typedef struct {
    PTNode nodes[MAX_TREE_SIZE];
    int r, n;  // 根的位置，节点数
} PTree;
```

### 孩子表示法（孩子链表）
- 每个节点维护一个孩子链表

### 孩子兄弟表示法（左孩子右兄弟）
```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild;  // 第一个孩子
    struct CSNode *nextsibling; // 下一个兄弟
} CSNode, *CSTree;
```
- 本质上就是**二叉链表**表示，与树转二叉树等价

## 重点总结

| 考点 | 要点 |
|------|------|
| 性质3 | $n_0 = n_2 + 1$ |
| 完全二叉树深度 | $k = \lfloor\log_2 n\rfloor + 1$ |
| 完全二叉树父子关系 | 父 = $\lfloor i/2 \rfloor$；左孩 = $2i$；右孩 = $2i+1$ |
| 二叉链表空指针 | 共 n+1 个 |
| 遍历顺序 | 先序VLR，中序LVR，后序LRV |
| 还原二叉树 | 先序/后序 + 中序可唯一确定 |
| 哈夫曼树 | WPL 最小；无度为1节点；共2n-1个节点 |
| 哈夫曼编码 | 前缀编码；左0右1（或左1右0） |
