# 第5章 数组与广义表

## 5.1 数组与线性表的关系

### 数组的本质
- 数组是线性表的**推广**：数据元素本身也是一个数据结构
- 一维数组：$A = (a_1, a_2, \ldots, a_n)$，每个元素为原子
- 二维数组：每个元素 $a_i$ 是一个一维数组（行）
- n 维数组：每个元素是一个 (n-1) 维数组

### 数组的特性
- 每个元素类型相同（均匀类型）
- d 维数组中每个元素有 d 个直接前驱和 d 个直接后继
- 数组的维数和各维长度一旦确定，元素关系不再变化 → **适合顺序存储**
- 基本操作：只有**取值**和**赋值**（无插入/删除）

## 5.2 数组的顺序存储

### 一维数组地址计算
$$\text{LOC}[i] = b + i \times L$$
其中 $b$ 为基地址，$L$ 为每个元素占用单元数。

### 二维数组地址计算（按行优先）
$$\text{LOC}[i, j] = \text{LOC}[0,0] + (i \times n + j) \times L$$

一般形式：
$$\text{LOC}[i, j] = c_0 + c_1 i + c_2 j$$
- $c_2 = L$
- $c_1 = n \times c_2$（n 为列数）
- $c_0 = b = \text{LOC}[0,0]$

### n 维数组地址计算
$$\text{LOC}[j_1, j_2, \ldots, j_n] = c_0 + \sum_{i=1}^{n} c_i j_i$$

其中 $c_n = L$，$c_{i-1} = c_i \times b_i$（$b_i$ 为第 i 维的大小）。

> **行优先**（C/Pascal）：低下标（行号）变化慢，高下标（列号）变化快
> **列优先**（Fortran）：高下标变化慢，低下标变化快

### 示例题
已知 `ElemType A[3..7, 0..9, 1..6, 5..12]`，每元素占 8 个单元，起始地址 1000，求 `LOC[6,1,4,7]`：
- 各维大小：$b_1=5, b_2=10, b_3=6, b_4=8$
- $c_4=8,\ c_3=8\times8=64,\ c_2=64\times6=384,\ c_1=384\times10=3840$（已调整下标偏移）
- `LOC[6,1,4,7] = 1000 + 3840×(6-3) + 384×(1-0) + 64×(4-1) + 8×(7-5) = 13112`

## 5.3 矩阵的压缩存储

**目的**：对特殊矩阵节省存储空间。

### 5.3.1 对称矩阵

**特点**：$a_{ij} = a_{ji}$（n×n 矩阵）

**存储方法**：只存下三角（含主对角线），共 $\dfrac{n(n+1)}{2}$ 个元素

映射关系（按行存入 `sa[0..n(n+1)/2-1]`）：
$$k = \begin{cases} \dfrac{i(i-1)}{2} + j - 1 & i \geq j \text{（下三角）} \\ \dfrac{j(j-1)}{2} + i - 1 & i < j \text{（转换为下三角）} \end{cases}$$

### 5.3.2 三角矩阵

**特点**：对角线以下（或以上）全为常数 c

**存储方法**：共 $\dfrac{n(n+1)}{2} + 1$ 个空间，`sa[0] = c`

| 类型 | k 的计算 |
|------|---------|
| 下三角矩阵（$i \geq j$） | $k = \dfrac{(i-1)(2n-i+2)}{2} + j - i + 1$ |
| 上三角矩阵（$i \leq j$） | $k = \dfrac{i(i-1)}{2} + j$ |

### 5.3.3 带状矩阵（对角矩阵）

**特点**：非零元素集中在以主对角线为中心的 L 条对角线带内

**存储方法**：
1. 按对角线顺序存储：共 $n \times L$ 个元素
2. 按行存储（除首尾行外每行 L 个，共 $(n-1)L + 1$ 个元素）
   - $k = (i-1) \times L + (j-i)$，条件：$1 \leq i,j \leq n$，$|i-j| \leq (L-1)/2$

### 5.3.4 随机稀疏矩阵

**特点**：绝大多数元素为零（稀疏度 $\delta = t/(m \times n) \leq 0.05$）

**两种存储方案**：

#### 三元组表
```c
#define MAXSIZE 1000
typedef struct {
    int i, j;     // 行号、列号
    ElemType e;   // 非零元素值
} Triple;
typedef struct {
    Triple data[MAXSIZE + 1];  // data[0] 不用
    int mu, nu, tu;            // 行数、列数、非零元素数
} TSMatrix;
```

**转置算法**：
- **方法一（普通）**：按列扫描，时间 O(n×t)
- **方法二（快速转置）**：辅助数组 `num[]` 和 `cpot[]`，时间 **O(n+t)**
  - `num[col]`：a 中第 col 列的非零元素数
  - `cpot[col]`：b 中第 col 列第一个非零元在 b.data 中的位置
  - `cpot[1]=1`；`cpot[col] = cpot[col-1] + num[col-1]`（$2 \leq col \leq n$）

#### 十字链表（正交链表）
```c
typedef struct OLNode {
    int i, j;
    ElemType e;
    struct OLNode *right, *down;  // 行后继、列后继
} OLNode, *OLink;
typedef struct {
    OLink *rhead, *chead;  // 行链表头、列链表头
    int mu, nu, tu;
} CrossList;
```
- 行方向：right 指针连接同行非零元素
- 列方向：down 指针连接同列非零元素
- 适合非零元素位置或数量**频繁变化**的场景

## 5.4 广义表（Generalized List）

### 5.4.1 定义

> **广义表**是零个或多个**原子**或**子表**的有限序列，记作 $LS = (d_1, d_2, \ldots, d_n)$

| 术语 | 定义 |
|------|------|
| **原子** | 不可再分的元素（单个值） |
| **子表** | 广义表中作为元素的广义表 |
| **表长** | 第一层元素的个数 |
| **表深** | 括号嵌套的最大层次 |
| **表头（Head）** | 表的第一个元素 |
| **表尾（Tail）** | 去掉表头后剩余元素组成的**广义表**（非空表的表尾仍是广义表） |

### 广义表举例

| 广义表 | 表长 | 表深 | 表头 | 表尾 |
|--------|------|------|------|------|
| A = () | 0 | 1 | - | - |
| B = (a, ()) | 2 | 2 | a | (()) |
| C = ((a,b), c, d) | 3 | 2 | (a,b) | (c,d) |
| D = (a, D) | 2 | ∞ | a | (D) |

**注意**：
- 广义表是**线性表的推广**（所有元素为原子时退化为线性表）
- **共享**（可重入表）：多个广义表共享同一子表
- **递归**（递归表）：自身作为自己的子表，如 D=(a,D)

### 广义表分类
```
线性表 ⊂ 纯表 ⊂ 可重入表 ⊂ 递归表
（纯表对应树结构，可重入表包含共享，递归表包含递归）
```

### 5.4.2 广义表的 ADT

```
ADT GList {
    基本操作：
        InitGList(&L)           // 创建空广义表
        CreateGList(&L, S)      // 由串 S 创建广义表 L
        CopyGList(&T, L)        // 复制
        GListLength(L)          // 求表长
        GListDepth(L)           // 求表深
        GListEmpty(L)           // 判空
        GetHead(L)              // 取表头
        GetTail(L)              // 取表尾
        InsertFirst_GL(&L, e)   // 插入
        DeleteFirst_GL(&L, &e)  // 删除
        Traverse_GL(L, Visit()) // 遍历
} ADT GList
```

### 5.4.3 广义表的存储结构

**头尾链表**：
```c
typedef enum { ATOM, LIST } ElemTag;
typedef struct GLNode {
    ElemTag tag;  // 标志：0=原子，1=子表
    union {
        AtomType atom;    // 原子值
        struct { struct GLNode *hp, *tp; } ptr;  // 头指针、尾指针
    };
} *GList;
```

## 重点总结

| 考点 | 要点 |
|------|------|
| 二维数组地址 | $\text{LOC}[i,j] = b + (i \times n + j) \times L$（行优先） |
| 对称矩阵压缩 | 只存下三角，$k = i(i-1)/2 + j - 1$（$i \geq j$） |
| 稀疏矩阵 | 三元组表（顺序）或十字链表（链式） |
| 快速转置 | O(n+t)，用 num[] 和 cpot[] 辅助数组 |
| 广义表定义 | 原子或子表的有限序列 |
| 表尾 | 去掉表头后的剩余**广义表**（不是元素） |
| 广义表深度 | 括号嵌套最大层数；空表深度为 1 |
