## 4.1 串的基本概念

### 定义
> **串（字符串）**是由零个或多个字符组成的有限序列，记作 $S = \text{"} a_1 a_2 \cdots a_n \text{"}$

| 术语 | 定义 |
|------|------|
| **串长** | 串中字符的个数 n |
| **空串** | 长度为 0 的串（n=0），记作 `""` 或 `∅` |
| **空白串** | 由空格字符组成的串（与空串不同） |
| **子串** | 串中任意个连续字符组成的子序列 |
| **主串** | 包含子串的串 |
| **子串位置** | 子串首字符在主串中的位序 |
| **串相等** | 两串长度相等且对应字符相同 |

## 4.3 串的存储结构

### 4.3.1 定长顺序存储（静态存储）
```c
#define MAXSTRLEN 255
typedef char SString[MAXSTRLEN + 1];
// SString[0] 存放串长，SString[1..MAXSTRLEN] 存字符
```

### 4.3.2 堆分配存储（动态存储）
```c
typedef struct {
    char *ch;   // 若非空串，指向字符数组基地址
    int length; // 串长
} HString;
```

### 4.3.3 链式存储
```c
// 块链结构，每个节点存多个字符，提高存储密度
#define CHUNKSIZE 80
typedef struct Chunk {
    char ch[CHUNKSIZE];
    struct Chunk *next;
} Chunk;
typedef struct {
    Chunk *head, *tail;
    int curlen;
} LString;
```

## 4.4 串的模式匹配

> **模式匹配**：在主串 S 中查找模式串 T 的位置（子串定位）

### 4.4.1 朴素算法（BF 算法）

**思想**：从主串 S 的第 pos 个字符起，逐一与模式串 T 比较。

```c
int Index(SString S, SString T, int pos) {
    i = pos;  j = 1;
    while (i <= S[0] && j <= T[0]) {
        if (S[i] == T[j]) { i++; j++; }
        else { i = i - j + 2; j = 1; }  // 回溯
    }
    if (j > T[0]) return i - T[0];  // 匹配成功
    else return 0;
}
```

**时间复杂度**：最坏 O(n × m)，其中 n = |S|，m = |T|

---

### 4.4.2 KMP 算法

**核心思想**：利用已匹配的信息，主串指针**不回溯**，只移动模式串指针。

**next 数组定义**：
$$\text{next}[j] = \begin{cases} 0 & j = 1 \\ \max\{k \mid 1 < k < j, \text{且} p_1\cdots p_{k-1} = p_{j-k+1}\cdots p_{j-1}\} & \text{集合非空} \\ 1 & \text{其他} \end{cases}$$

**next 数组计算示例**：

模式串：`a b a a b c a c`

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T[j] | a | b | a | a | b | c | a | c |
| next[j] | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |

**KMP 匹配算法**：
```c
int Index_KMP(SString S, SString T, int pos) {
    i = pos;  j = 1;
    while (i <= S[0] && j <= T[0]) {
        if (j == 0 || S[i] == T[j]) { i++; j++; }
        else j = next[j];  // 不回溯 i，j 跳至 next[j]
    }
    if (j > T[0]) return i - T[0];
    else return 0;
}
```

**时间复杂度**：O(n + m)

---

### 4.4.3 nextval 数组（KMP 改进）

消除不必要的比较（当 T[j] == T[next[j]] 时跳过）：

```
if T[next[j]] == T[j]:
    nextval[j] = nextval[next[j]]
else:
    nextval[j] = next[j]
```

## 4.5 BF vs KMP 对比

| 对比项 | BF 算法 | KMP 算法 |
|--------|---------|----------|
| 主串回溯 | 需要 | 不需要 |
| 时间复杂度 | O(n×m) | O(n+m) |
| 实现难度 | 简单 | 较复杂 |
| 适用场景 | 一般情况 | 重复字符多的模式串 |

## 重点总结

| 考点 | 要点 |
|------|------|
| 串的定义 | n 个字符的有限序列；空串≠空白串 |
| 子串 | 任意连续字符序列 |
| BF 算法 | 暴力匹配，O(n×m)，主串指针回溯 |
| KMP next 数组 | 由模式串自身求得，利用已匹配信息 |
| KMP 时间 | O(n+m)，主串指针不回溯 |
| nextval | KMP 改进，进一步减少无效比较 |
