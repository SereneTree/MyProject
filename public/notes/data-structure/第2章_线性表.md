# 第2章 线性表

## 2.1 线性结构的基本概念

### 线性结构的四个特征
1. 集合中必有唯一的"第一个元素"
2. 集合中必有唯一的"最后一个元素"
3. 除最后元素外，每个数据元素都有唯一的"后继"
4. 除第一元素外，每个数据元素都有唯一的"前驱"

### 线性表的定义
> 线性表是 n（n≥0）个具有**相同数据类型**的数据元素的有限序列，通常记为：
> $$(a_1, a_2, \ldots, a_{i-1}, a_i, a_{i+1}, \ldots, a_n)$$
> 其中 n 为表的长度，n=0 时称为**空表**。

## 2.2 线性表的抽象数据类型

### ADT 定义
```
ADT List {
    数据对象：D = { aᵢ | aᵢ ∈ ElemSet, i=1,2,...,n, n≥0 }
    数据关系：R1 = { <aᵢ₋₁, aᵢ> | aᵢ ∈ D, i=2,...,n }
    基本操作：
        InitList(*L)        // 构造空线性表 L
        DestroyList(*L)     // 销毁线性表 L
        ClearList(*L)       // 清空线性表 L（重置为空表）
        ListEmpty(L)        // 判断是否为空表
        ListLength(L)       // 返回元素个数
        GetElem(L, i, *e)   // 取第 i 个元素的值
        LocateElem(L, e)    // 返回等于 e 的元素位序
        PriorElem(L, cur_e, *pre_e)  // 返回前驱
        NextElem(L, cur_e, *next_e)  // 返回后继
        ListInsert(*L, i, e) // 在第 i 位前插入 e
        ListDelete(*L, i, *e) // 删除第 i 位元素
} ADT List
```

### 操作分类
| 类型 | 操作 |
|------|------|
| 引用型（不改变数据） | ListEmpty, ListLength, GetElem, LocateElem, PriorElem, NextElem |
| 加工型（改变数据） | InitList, DestroyList, ClearList, ListInsert, ListDelete |

### 典型应用：集合合并（A = A ∪ B）
```c
void union(List *LA, List *LB) {
    La_len = ListLength(LA);
    while (!ListEmpty(LB)) {
        ListDelete(LB, 1, e);       // 逐个取出 LB 元素
        if (!LocateElem(LA, e))
            ListInsert(LA, ++La_len, e); // 不重复则插入 LA
    }
    DestroyList(LB);
}
```

## 2.3 顺序存储结构（顺序表）

### 概念
- 用**一组地址连续的存储单元**依次存储线性表的数据元素
- 逻辑上相邻的元素，物理上也相邻
- 基地址：第一个元素的存储位置

### 地址计算公式
$$\text{LOC}(a_i) = \text{LOC}(a_1) + (i-1) \times C$$
其中 C 为每个数据元素占用的存储单元数。

### C 语言类型定义
```c
#define MAXLISTSIZE 80
typedef struct {
    ElemType *elem;  // 内存空间基地址
    int length;      // 当前长度
    int listsize;    // 最大允许存储容量
} SqList;
```

### 基本操作时间复杂度

| 操作 | 时间复杂度 | 说明 |
|------|------------|------|
| InitList | O(1) | 分配内存 |
| LocateElem | O(n) | 顺序查找 |
| ListInsert | O(n) | 平均移动 n/2 个元素 |
| ListDelete | O(n) | 平均移动 (n-1)/2 个元素 |
| DestroyList | O(1) | 释放内存 |

### 插入操作分析
- 在第 i 位插入，需移动 $a_i \sim a_n$ 共 n-i+1 个元素
- 等概率下平均移动次数：$E_{in} = \dfrac{n}{2}$

### 删除操作分析
- 删除第 i 个元素，需移动 $a_{i+1} \sim a_n$ 共 n-i 个元素
- 等概率下平均移动次数：$E_{de} = \dfrac{n-1}{2}$

### 顺序表特点总结
| 优点 | 缺点 |
|------|------|
| 随机访问任意元素，时间 O(1) | 插入/删除需大量移动元素 |
| 存储密度高 | 存储空间需预先分配，难以扩充 |
| 逻辑与物理相邻一致 | 插入/删除频繁时效率低 |

## 2.4 链式存储结构（链表）

### 概念
- 数据元素存放在**任意**存储单元中（可不连续）
- 每个节点包含：**数据域**（存放数据）+ **指针域**（存放后继地址）

```
┌──────┬──────┐
│ data │ next │  → 节点结构
└──────┴──────┘
```

### 单链表（带头节点）
```
H → a₁ → a₂ → ... → aₙ → ∧
```
- **头指针**：指向头节点
- **头节点**：辅助节点，简化操作（插入/删除首元素时不需特殊处理）

### C 语言类型定义
```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

### 链表操作

**创建链表（头插法）**
```c
LinkedList creat() {
    head = (LinkedList)malloc(sizeof(node));
    head->next = NULL;
    scanf("%d", &x);
    while (x != 9999) {
        p = (LinkedList)malloc(sizeof(node));
        p->data = x;
        p->next = head->next;
        head->next = p;
        scanf("%d", &x);
    }
    return head;
}
```

**单链表逆置（头插法）**
```c
LinkedList invert1(LinkedList head) {
    LinkedList p = head->next, r;
    head->next = NULL;
    while (p != NULL) {
        r = p->next;        // 暂存后继
        p->next = head->next;
        head->next = p;
        p = r;
    }
    return head;
}
```

### 顺序表 vs 链表对比

| 比较项目 | 顺序表 | 链表 |
|---------|--------|------|
| 存储方式 | 连续内存 | 任意内存 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n)，需移动元素 | O(1)（已知位置） |
| 存储密度 | 高（无指针开销） | 低（有指针开销） |
| 适用场景 | 频繁访问，较少增删 | 频繁增删，较少随机访问 |

## 2.5 参数传递方式（C/C++）

| 传递方式 | 语法 | 特点 |
|---------|------|------|
| 值传递 | `void f(int a)` | 拷贝，不影响原值 |
| 指针传递 | `void f(int *a)` | 传地址，可修改原值 |
| 引用传递 | `void f(int &a)` | C++ 特性，直接操作原变量 |

## 重点总结

| 考点 | 要点 |
|------|------|
| 线性表定义 | n 个相同类型元素的有限序列 |
| 顺序表地址计算 | $\text{LOC}(a_i) = \text{LOC}(a_1) + (i-1) \times C$ |
| 顺序表插入平均移动次数 | n/2 |
| 顺序表删除平均移动次数 | (n-1)/2 |
| 链表节点结构 | 数据域 + 指针域 |
| 头节点作用 | 简化边界情况处理 |
| 链表逆置 | 头插法，O(n) |
