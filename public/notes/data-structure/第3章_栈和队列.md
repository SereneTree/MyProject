# 第3章 栈与队列

## 3.1 栈（Stack）

### 3.1.1 基本概念

> **栈**是限定只在表的一端（**栈顶**）进行插入和删除操作的**特殊线性表**。
> 特点：**后进先出（LIFO，Last In First Out）**

```
        ┌───┐  ← 栈顶（top）  push/pop
        │ aₙ│
        │...│
        │ a₂│
        │ a₁│  ← 栈底（bottom）
        └───┘
```

### 与线性表、队列的比较

| 操作 | 线性表 | 栈 | 队列 |
|------|--------|-----|------|
| 插入位置 | 任意位置 | 仅栈顶（n+1） | 仅队尾（n+1） |
| 删除位置 | 任意位置 | 仅栈顶（n） | 仅队头（1） |
| 访问顺序 | 随机 | LIFO | FIFO |

### ADT 定义
```
ADT Stack {
    数据关系：约定 aₙ 端为栈顶，a₁ 端为栈底
    基本操作：
        init_stack(s)           // 初始化空栈
        empty_stack(s)          // 判空
        push_stack(s, x)        // 入栈
        pop_stack(s)            // 出栈
        gettop_stack(s)         // 读取栈顶元素
        clear_stack(s)          // 清空
        current_size_stack(s)   // 求栈中元素个数
}
```

### 3.1.2 顺序栈

#### 类型定义
```c
typedef struct {
    ElemType *top;    // 栈顶指针
    ElemType *base;   // 栈底指针
    int stacksize;    // 最大容量
} SqStack;
```

#### 重要状态判断
```
栈空条件：S.top == S.base       （此时出栈则下溢）
栈满条件：S.top == S.base + stacksize  （此时入栈则上溢）
```

#### 基本操作实现
```c
// 初始化
Status InitStack(SqStack &S) {
    S.base = (ElemType*)malloc(100 * sizeof(ElemType));
    S.stacksize = 100;
    S.top = S.base;
    return OK;
}

// 判空
Status StackEmpty(SqStack S) {
    return (S.top == S.base) ? TRUE : FALSE;
}

// 入栈
Status Push(SqStack &S, ElemType e) {
    if (S.top - S.base >= S.stacksize) return OVERFLOW;
    *S.top++ = e;
    return OK;
}

// 出栈
Status Pop(SqStack &S, ElemType &e) {
    if (S.top == S.base) return ERROR;
    e = *--(S.top);
    return OK;
}

// 取栈顶
Status GetTop(SqStack S, ElemType &e) {
    if (S.top == S.base) return ERROR;
    e = *(S.top - 1);
    return OK;
}
```

#### 双栈共享存储
- 两个栈共用一段连续内存，从两端向中间增长
- 栈1从低地址向高增长，栈2从高地址向低增长
- 上溢条件：两个栈顶相遇

### 3.1.3 链栈

#### 类型定义
```c
typedef struct node {
    ElemType data;
    struct node *next;
} LinkStack;
LinkStack *top;  // 栈顶指针（头指针）
```

**注意**：
- 链栈**不需要头节点**（只在栈顶插入/删除）
- 指针方向：从栈顶 → 栈底（与单链表相同方向）
- 不能反向（从栈底到栈顶），否则删除栈顶需要遍历整个链表

```c
// 链栈入栈
Status Push_LinkStack(LinkStack **top, ElemType e) {
    s = (LinkStack*)malloc(sizeof(LinkStack));
    s->data = e;
    s->next = *top;
    *top = s;
    return OK;
}

// 链栈出栈
Status Pop_LinkStack(LinkStack **top, ElemType &e) {
    if (*top == NULL) return ERROR;
    e = (*top)->data;
    p = *top;
    *top = (*top)->next;
    free(p);
    return OK;
}
```

### 3.1.4 栈的应用

#### 1. 数制转换（十进制 → N 进制）
**原理**：$N = (N \div d) \times d + N \bmod d$，余数从低位到高位，用栈逆序输出

```c
void conversion() {
    InitStack(S);
    cin >> N;
    while (N) {
        Push(S, N % 8);
        N = N / 8;
    }
    while (!StackEmpty(S)) {
        Pop(S, e);
        cout << e;
    }
}
```

#### 2. 括号匹配
**三种错误情况**：
1. 遇到右括号与栈顶左括号不匹配
2. 遇到右括号但栈为空（"不速之客"）
3. 表达式结束但栈不为空（左括号未被匹配）

**算法思路**：
- 遇到左括号 → 入栈
- 遇到右括号 → 与栈顶比较，匹配则出栈，不匹配则报错
- 结束时栈为空 → 匹配成功

#### 3. 迷宫求解（回溯法）
- 使用栈保存从入口到当前位置的路径
- 进入新位置 → 入栈；无路可走 → 出栈回溯
- 到达出口时，栈中内容即为路径

#### 4. 表达式求值

**三种表示方法**：

| 表示法 | 格式 | 示例（a+b*c） |
|--------|------|--------------|
| 中缀（Infix） | 操作符在两操作数之间 | a+b*c |
| 前缀（Prefix） | 操作符在操作数之前 | +a*bc |
| 后缀（Postfix）| 操作符在操作数之后 | abc*+ |

**中缀表达式求值（双栈法）**：
- **OPTR 栈**：存放运算符
- **OPND 栈**：存放操作数
- 按优先级比较规则决定是否执行运算

**中缀转后缀规则**：
1. 操作数直接输出到后缀
2. 运算符优先级 > 栈顶：入栈
3. 运算符优先级 ≤ 栈顶：弹出栈顶到后缀，再重复比较
4. `(`：直接入栈；`)`：弹出直到 `(`

#### 5. 递归实现原理
- 系统调用栈：保存**返回地址、参数列表、局部变量**
- 每次调用压入工作记录，返回时弹出

**递归转非递归方法**：
1. 尾递归 → 迭代（循环）
2. 自建模拟栈代替系统栈

**递归特点**：
- 优点：简洁直观，易于理解
- 缺点：时间效率低，空间开销大

## 3.2 队列（Queue）

### 3.2.1 基本概念

> **队列**是限定在表的一端（**队尾 rear**）插入，另一端（**队头 front**）删除的特殊线性表。
> 特点：**先进先出（FIFO，First In First Out）**

```
front → a₁ → a₂ → ... → aₙ ← rear
  删除端                  插入端
```

### 基本操作
```
init_queue(q)         // 初始化
empty_queue(q)        // 判空
en_queue(q, x)        // 入队
dl_queue(q)           // 出队
gethead_queue(q)      // 取队头
clear_queue(q)        // 清空
current_size_queue(q) // 求长度
```

---

### 3.2.2 链式队列

#### 类型定义
```c
typedef struct QNode {
    ElemType data;
    struct QNode *next;
} QNode;

typedef struct {
    QNode *front;  // 队头指针
    QNode *rear;   // 队尾指针
} LinkQueue;
```

#### 基本操作
```c
// 初始化（不带头节点）
Status InitQueue(LinkQueue *Q) {
    Q->front = Q->rear = NULL;
    return OK;
}

// 入队
Status EnQueue(LinkQueue *Q, ElemType e) {
    s = (QNode*)malloc(sizeof(QNode));
    s->data = e;
    s->next = NULL;
    if (Q->rear == NULL) Q->front = Q->rear = s;
    else { Q->rear->next = s; Q->rear = s; }
    return OK;
}

// 出队
Status DeQueue(LinkQueue *Q, ElemType &e) {
    if (Q->front == NULL) return ERROR;
    p = Q->front;
    e = p->data;
    Q->front = p->next;
    if (Q->front == NULL) Q->rear = NULL;
    free(p);
    return OK;
}
```

### 3.2.3 循环队列（顺序队列）

**普通顺序队列问题**：频繁入队出队后出现"假溢出"
**解决**：将存储空间视为**环形**

```
队空条件：front == rear
队满条件：(rear + 1) % MAXSIZE == front
队列长度：(rear - front + MAXSIZE) % MAXSIZE
```

#### 类型定义
```c
#define MAXQUEUESIZE 100
typedef struct {
    ElemType *base;
    int front;   // 队头下标
    int rear;    // 队尾下标
} SqQueue;
```

## 重点总结

| 考点 | 要点 |
|------|------|
| 栈的特性 | LIFO；只能在栈顶操作 |
| 顺序栈状态 | 空：top==base；满：top-base>=stacksize |
| 链栈方向 | 指针从栈顶→栈底 |
| 队列特性 | FIFO；队尾入，队头出 |
| 循环队列判空/满 | 空：front==rear；满：(rear+1)%MAXSIZE==front |
| 栈的典型应用 | 进制转换、括号匹配、迷宫、表达式求值、递归 |
| 表达式转换 | 中缀→后缀，用运算符栈，按优先级处理 |
