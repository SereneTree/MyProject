# 第10章 内部排序

## 10.1 排序概述

### 基本概念
> **排序**：将一组"无序"的记录序列调整为"有序"记录序列的过程（按关键字非递减或非递增重排）。

### 排序分类

| 分类维度 | 类别 | 说明 |
|---------|------|------|
| 按数据位置 | 内部排序 | 所有记录在内存中完成 |
|           | 外部排序 | 排序过程需内外存交换 |
| 按稳定性 | 稳定排序 | 相等关键字记录相对顺序不变 |
|          | 不稳定排序 | 相等关键字相对顺序可能改变 |
| 按辅助空间 | 原地排序 | 辅助空间 O(1) |
|            | 非原地排序 | 辅助空间 O(n) 或更多 |

### 评价标准
1. **时间开销**：比较关键字次数 + 移动记录次数
2. **空间开销**：辅助存储空间

### 数据类型定义
```c
#define MAXSIZE 20
typedef int KeyType;
typedef struct {
    KeyType key;
    InfoType otherinfo;
} RedType;
typedef struct {
    RedType r[MAXSIZE + 1];  // r[0] 空闲或作哨兵
    int length;
} SqList;
```

## 10.2 插入排序

### 10.2.1 直接插入排序

**思想**：每次将 R[i] 插入到前面已排好的 R[1..i-1] 中适当位置。

```c
void InsertSort(SqList &L) {
    for (i = 2; i <= L.length; i++)
        if (LT(L.r[i].key, L.r[i-1].key)) {
            L.r[0] = L.r[i];      // 哨兵
            L.r[i] = L.r[i-1];
            for (j = i-2; L.r[0].key < L.r[j].key; j--)
                L.r[j+1] = L.r[j];
            L.r[j+1] = L.r[0];
        }
}
```

**哨兵的作用**：简化边界条件判断，提高效率。

**性能分析**：

| 情况 | 比较次数 | 移动次数 | 时间复杂度 |
|------|---------|---------|-----------|
| 最好（正序） | n-1 | 0 | O(n) |
| 最坏（逆序） | n(n-1)/2 | n(n-1)/2 | O(n²) |
| 平均 | ~n²/4 | ~n²/4 | O(n²) |

- **辅助空间**：O(1)；**稳定排序**

### 10.2.2 希尔排序（缩小增量排序）

**思想**：
1. 按增量 d 将序列分组，组内用直接插入排序
2. 减小增量 d，重复上述过程
3. 直到 d=1（整体排序）

```c
void ShellSort(SqList &L, int dlta[], int t) {
    for (k = 0; k < t; k++) {
        dk = dlta[k];
        for (i = dk+1; i <= L.length; i++)
            if (L.r[i].key < L.r[i-dk].key) {
                L.r[0] = L.r[i];
                for (j = i-dk; j > 0 && L.r[0].key < L.r[j].key; j -= dk)
                    L.r[j+dk] = L.r[j];
                L.r[j+dk] = L.r[0];
            }
    }
}
```

**性能**：时间复杂度约 O(n^1.3)，辅助空间 O(1)；**不稳定排序**
- 最后增量必须为 1；增量序列相邻值避免有公因子

## 10.3 交换排序

### 10.3.1 冒泡排序

**思想**：相邻元素比较，逆序则交换，较小元素"上浮"。

```c
void BubbleSort(SqList &L) {
    n = L.length; sorted = FALSE;
    for (i = 0; i < n-1 && (!sorted); i++) {
        sorted = TRUE;
        for (j = 1; j < n-i; j++)
            if (L.r[j].key > L.r[j+1].key) {
                L.r[j] ↔ L.r[j+1];
                sorted = FALSE;
            }
    }
}
```

**性能分析**：

| 情况 | 比较次数 | 时间复杂度 |
|------|---------|-----------|
| 最好（正序） | n-1 | O(n) |
| 最坏（逆序） | n(n-1)/2 | O(n²) |
| 平均 | O(n²) | O(n²) |

- **辅助空间**：O(1)；**稳定排序**

### 10.3.2 快速排序

**思想（分治法）**：
1. 选定一个基准记录 r[p]（通常取第一个）
2. 一趟排序将序列分为两部分：左侧 ≤ r[p]，右侧 ≥ r[p]
3. 对左右部分递归进行快速排序

**一趟划分**：
```c
int Partition(SqList &L, int low, int high) {
    L.r[0] = L.r[low];          // 基准记录暂存
    pivotkey = L.r[low].key;
    while (low < high) {
        while (low < high && L.r[high].key >= pivotkey) --high;
        L.r[low] = L.r[high];   // 比基准小的移到左边
        while (low < high && L.r[low].key <= pivotkey) ++low;
        L.r[high] = L.r[low];  // 比基准大的移到右边
    }
    L.r[low] = L.r[0];          // 基准放到最终位置
    return low;
}
```

**性能分析**：

| 情况 | 时间复杂度 | 辅助空间 |
|------|-----------|---------|
| 最好（每次均匀划分） | O(n log n) | O(log n) |
| 平均 | O(n log n) | O(log n) |
| 最坏（正序/逆序） | O(n²) | O(n) |

- **不稳定排序**；平均性能是目前最好的内部排序方法之一

## 10.4 选择排序

### 10.4.1 简单选择排序

**思想**：每趟从待排序中选出关键字最小的记录，放到有序区末尾。

```c
void SelectSort(SqList &L) {
    for (i = 1; i < L.length; i++) {
        j = i;
        for (k = i+1; k <= L.length; k++)
            if (L.r[j].key > L.r[k].key) j = k;
        if (i != j) L.r[i] ↔ L.r[j];
    }
}
```

**性能**：
- 比较次数恒为 $C = n(n-1)/2$，与初始顺序无关
- 移动次数：最好 0，最坏 3(n-1)
- **时间 O(n²)，辅助空间 O(1)；不稳定排序**

### 10.4.2 堆排序

**堆的定义**：n 个关键字序列 $(k_1, k_2, \ldots, k_n)$ 满足：
$$k_i \leq k_{2i} \text{ 且 } k_i \leq k_{2i+1} \quad \text{（小根堆）}$$
$$k_i \geq k_{2i} \text{ 且 } k_i \geq k_{2i+1} \quad \text{（大根堆）}$$

**堆排序（大根堆）步骤**：
1. 建初始大根堆：从 $\lfloor n/2 \rfloor$ 到 1，依次对各子树调整
2. 重复 n-1 趟：
   - 将堆顶（最大值）与最后一个元素交换
   - 对缩小了的无序区重新调整为堆

**堆调整（筛选）**：
```c
void HeapAdjust(HeapType &H, int s, int m) {
    rc = H.r[s];
    for (j = 2*s; j <= m; j *= 2) {
        if (j < m && H.r[j].key < H.r[j+1].key) j++;
        if (rc.key > H.r[j].key) break;
        H.r[s] = H.r[j]; s = j;
    }
    H.r[s] = rc;
}
```

**性能**：时间 O(n log n)，辅助空间 O(1)；**不稳定排序**
- 最坏情况仍为 O(n log n)，适合大规模数据

## 10.5 归并排序

**思想（2路归并）**：
- 将序列视为 n 个长度为 1 的有序子序列
- 两两合并，得到 ⌈n/2⌉ 个长度为 2 的有序子序列
- 重复合并，直到只剩一个序列

```c
void Merge(RedType SR[], RedType &TR[], int i, int m, int n) {
    for (j = m+1, k = i; i <= m && j <= n; k++) {
        if (SR[i].key <= SR[j].key) TR[k] = SR[i++];
        else TR[k] = SR[j++];
    }
    if (i <= m) TR[k..n] = SR[i..m];
    if (j <= n) TR[k..n] = SR[j..n];
}
```

**性能**：任意情况时间 O(n log n)，辅助空间 O(n)；**稳定排序**

---

## 10.6 基数排序（分配排序）

**思想（LSD 方法，低位优先）**：
- 不比较关键字，通过多次"分配"和"收集"实现排序
- 将关键字看作 d 位 rd 进制数，从最低位到最高位依次排序

**示例**（rd=10, d=3）：
```
原始：{477, 241, 467, 5, 363, 81, 5}
第1趟（个位）：{241, 81, 363, 5, 5, 477, 467}
第2趟（十位）：{5, 5, 241, 363, 467, 477, 81}
第3趟（百位）：{5, 5, 81, 241, 363, 467, 477}
```

**性能**：时间 O(d(n+rd))，辅助空间 O(rd+n)；**稳定排序**

## 10.7 各排序方法综合比较

| 排序方法 | 最好时间 | 平均时间 | 最坏时间 | 辅助空间 | 稳定性 |
|---------|---------|---------|---------|---------|--------|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔排序 | — | O(n^1.3) | — | O(1) | 不稳定 |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| **快速排序** | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| **堆排序** | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| **归并排序** | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 基数排序 | O(d(n+rd)) | O(d(n+rd)) | O(d(n+rd)) | O(rd+n) | 稳定 |

### 排序算法选择建议
- **n 较小（<50）**：直接插入排序（稳定）或简单选择排序
- **n 较大**：快速排序（平均最优）、堆排序（最坏 O(n log n)）或归并排序
- **基本有序**：直接插入排序或冒泡排序
- **需要稳定性**：直接插入、冒泡或归并排序
- **不能随机访问（链表）**：插入排序、归并排序、基数排序

## 重点总结

| 考点 | 要点 |
|------|------|
| 稳定排序 | 直接插入、冒泡、归并、基数 |
| 不稳定排序 | 希尔、快速、简单选择、堆 |
| 原地排序（O(1)空间） | 直接插入、希尔、冒泡、快速、简单选择、堆 |
| O(n log n) 排序 | 快速（平均）、堆、归并 |
| 快排最坏情况 | 正序/逆序，退化为 O(n²) |
| 堆排序构建堆 | 从 n/2 到 1 依次筛选 |
| 归并排序空间 | O(n)（需额外辅助数组） |
