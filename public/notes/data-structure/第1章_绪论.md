# 第1章 绪论

## 1.1 数据结构是什么

### 数学建模的两类问题
| 类型 | 描述 | 模型 |
|------|------|------|
| 数值计算类 | 求解方程、计算面积等 | 数学公式 |
| 非数值计算类 | 表、树、图等结构 | 数据结构 |

### 典型案例
- **线性结构**：电话号码查询（姓名 → 号码，一对一关系）
- **树形结构**：磁盘目录文件系统（一对多关系）
- **图结构**：交通网络（多对多关系）

> **核心公式（N. Wirth，1976）：算法 + 数据结构 = 程序**

---

## 1.2 基本概念与术语

| 术语 | 定义 |
|------|------|
| **数据** | 计算机处理的对象 |
| **数据元素** | 数据的基本单位（记录、表项） |
| **数据项** | 数据元素的组成部分（原子项 / 组合项） |
| **数据对象** | 性质相同的数据元素集合，是数据的子集 |
| **数据结构** | 带结构的数据元素集合（逻辑结构 + 存储结构 + 操作） |
| **数据类型** | 变量的值的种类（基本类型 / 构造类型） |

### 四种基本逻辑结构

```
集合结构   ——  元素间只有"同属一个集合"的关系
线性结构   ——  元素间一对一关系  (线性表)
树形结构   ——  元素间一对多关系  (树、二叉树)
图/网状结构 ——  元素间多对多关系  (图)
```

### 逻辑结构的二元组表示
```
Data_Structure = (D, R)
D —— 数据元素的有穷集合
R —— D 上关系的有穷集合
```

### 四种存储结构
1. **顺序存储**：数据元素存放在连续的存储单元中
2. **链式存储**：附加指针字段，记录后继/相关节点地址
3. **索引存储**：数据元素分组，用索引表记录各组起始位置
4. **散列存储**：由关键字通过哈希函数计算存储地址

## 1.3 抽象数据类型（ADT）

### 概念
- **ADT**：数学模型 + 定义在该模型上的操作集合，与计算机无关
- 特点：**将使用与实现分离**，提高软件复用性

### 三元组描述
```
ADT = (D, S, P)
D —— 数据对象
S —— D 上的关系集合
P —— 操作集合
```

### ADT 描述格式
```
ADT 抽象数据类型名 {
    数据对象：<定义>
    数据关系：<定义>
    基本操作：
        操作名(参数列表)
            初始条件：<描述>
            操作结果：<描述>
} ADT 抽象数据类型名
```

### 两层结构
```
逻辑结构 + 操作定义  →  用户层（概念层）  ← 抽象数据类型
存储结构 + 操作实现  →  计算机层（实现层）
```

## 1.4 算法及其分析

### 1.4.1 算法的五个性质
| 性质 | 说明 |
|------|------|
| **有穷性** | 算法必须在有限步骤内终止，每步在有限时间完成 |
| **确定性** | 每条指令含义确切，无二义性，只有一个入口和出口 |
| **可行性** | 算法中所有操作均可通过基本操作有限次执行实现 |
| **输入** | 零个或多个输入 |
| **输出** | 一个或多个输出 |

### 1.4.2 好算法的评价标准
1. **正确性**：满足具体问题需求
2. **可读性**：便于阅读和理解
3. **健壮性**：输入非法数据时能合理响应
4. **高效性与低存储需求**：时间短、空间少

---

### 1.4.3 时间复杂度

#### 大 O 表示法
> 若存在正常数 $c$ 和 $n_0$，使得对所有 $n \geq n_0$，$|T(n)| \leq c|g(n)|$，则记 $T(n) = O(g(n))$

#### 推导步骤
1. 用常数 1 替换所有加法常数
2. 只保留最高阶项
3. 去掉最高阶项的系数

#### 常见时间复杂度（由低到高）
```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³)
                    指数级：O(2ⁿ) < O(n!) < O(nⁿ)
```

#### 经典例题
| 代码结构 | 时间复杂度 |
|---------|------------|
| 单条语句 | O(1) |
| 单层 for 循环（n 次） | O(n) |
| 双层 for 循环（各 n 次） | O(n²) |
| 三层 for 循环（各 n 次） | O(n³) |
| 气泡排序（最坏） | O(n²) |

**示例**：计算 1+2+...+100
```c
// 方法1: T(n) = O(n)
int i, sum = 0, n = 100;
for(i = 1; i <= n; i++) sum += i;

// 方法2: T(n) = O(1)
int sum = 0, n = 100;
sum = (1 + n) * n / 2;
```

#### 最好、最坏、平均复杂度
- 有些算法的执行次数随输入数据集变化
- 例：气泡排序
  - 最好情况（已有序）：O(n)
  - 最坏情况（逆序）：O(n²)，执行 n(n-1)/2 次
  - 平均情况：O(n²)

---

### 1.4.4 空间复杂度

$$S(n) = O(f(n))$$

算法所占存储空间包括：
- **固定部分**：程序代码、常量、简单变量、固定长度结构变量
- **可变部分**：与问题规模相关的存储空间

## C 语言基础回顾

### 数组
```c
typedef int Scores[30];
Scores class051;  // 存储30个学生成绩
```

### 结构体
```c
typedef struct {
    int no;
    char title[40];
} BookType;
BookType book1;
```

### 结构体指针
```c
typedef struct {
    int no;
    char title[40];
} *BookPtr;
BookPtr pbook;
// 访问成员：(*pbook).no 或 pbook->no
```

## 重点总结

| 考点 | 要点 |
|------|------|
| 数据结构四要素 | 逻辑结构、存储结构、操作 |
| 四种逻辑结构 | 集合、线性、树、图 |
| 四种存储方式 | 顺序、链式、索引、散列 |
| 时间复杂度推导 | 保留最高阶，去系数 |
| 常见复杂度关系 | O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) |
