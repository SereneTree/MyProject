# 第7章 图（Graph）

## 7.1 图的基本概念

### 定义
> **图（Graph）** = (V, VR)
> - V：顶点（数据元素）的非空有穷集合
> - VR：弧（关系）的有穷集合

### 基本术语

| 术语 | 定义 |
|------|------|
| **有向图** | 弧 `<vi, vj>` 有方向，vi 为弧尾，vj 为弧头 |
| **无向图** | 边 `(vi, vj)` 无方向，(vi,vj)=(vj,vi) |
| **完全图（无向）** | 每两顶点间都有边，边数 $e = n(n-1)/2$ |
| **有向完全图** | 每两顶点间都有弧，弧数 $e = n(n-1)$ |
| **稀疏图** | $e < n \log n$ |
| **稠密图** | 边数较多的图 |
| **网（Network）** | 边/弧附有权值的图 |
| **邻接** | 有边/弧连接的两顶点关系 |
| **度** | 顶点关联的边数，$\sum D(v_i) = 2e$ |
| **入度** | 有向图中以该顶点为弧头的弧数 |
| **出度** | 有向图中以该顶点为弧尾的弧数 |
| **路径** | 相邻顶点的序列 |
| **路径长度** | 路径上的边/弧数（或权值之和） |
| **简单路径** | 顶点不重复的路径 |
| **回路（环）** | 第一顶点和最后顶点相同的路径 |
| **连通图** | 无向图中任意两顶点间有路径 |
| **强连通图** | 有向图中任意两顶点间互有路径 |
| **生成树** | 含图中所有顶点的极小连通子图 |
| **生成森林** | 非连通图各连通分量的生成树集合 |

## 7.2 图的存储结构

### 7.2.1 邻接矩阵（顺序存储）

```c
#define MAX_VERTEX_NUM 20
typedef struct ArcCell {
    VRType adj;      // 权值类型（无权图为0/1）
    InfoType *info;  // 弧的其他信息
} ArcCell, AdjMatrix[MAX_VERTEX_NUM][MAX_VERTEX_NUM];

typedef struct {
    VertexType vexs[MAX_VERTEX_NUM]; // 顶点向量
    AdjMatrix arcs;                   // 邻接矩阵
    int vexnum, arcnum;
    GraphKind kind;
} MGraph;
```

**特点**：
- 无向图的邻接矩阵是**对称矩阵**
- 顶点 i 的度 = 第 i 行非零元素之和（无向图）
- 建图时间复杂度：O(n²)
- **适合稠密图**

### 7.2.2 邻接表（链式存储）

```c
typedef struct ArcNode {
    int adjvex;           // 该弧所指向的顶点位置
    struct ArcNode *nextarc;
    int weight;
    InfoType *info;
} ArcNode;

typedef struct VNode {
    VertexType data;      // 顶点信息
    ArcNode *firstarc;    // 第一条依附于该顶点的弧
} VNode, AdjList[MAX_VERTEX_NUM];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
    GraphKind kind;
} ALGraph;
```

**特点**：
- 无向图每条边出现两次，共 n+2e 个节点
- 有向图每条弧出现一次，共 n+e 个节点
- 建图时间复杂度：O(n+e)
- **适合稀疏图**

### 邻接矩阵 vs 邻接表

| 比较项 | 邻接矩阵 | 邻接表 |
|--------|---------|--------|
| 空间 | O(n²) | O(n+e) |
| 判断边是否存在 | O(1) | O(n) 最坏 |
| 求顶点度 | O(n) | O(n) |
| 遍历时间 | O(n²) | O(n+e) |
| 适用图类型 | 稠密图 | 稀疏图 |

## 7.3 图的遍历

### 辅助数据结构
```c
Boolean visited[MAX_VERTEX_NUM];  // 访问标记数组，初始全 FALSE
```

### 7.3.1 深度优先搜索（DFS）

> 类似树的先序遍历，使用**栈（递归）**实现

**算法思想**：
1. 访问顶点 v，标记为已访问
2. 依次对 v 的**未访问邻接顶点**递归进行 DFS

```c
void DFSTraverse(Graph G) {
    for (v = 0; v < G.vexnum; v++) visited[v] = FALSE;
    for (v = 0; v < G.vexnum; v++)
        if (!visited[v]) DFS(G, v);
}

void DFS(Graph G, int v) {
    visit(v); visited[v] = TRUE;
    for (w = FirstAdjVex(G, v); w > -1; w = NextAdjVex(G, v, w))
        if (!visited[w]) DFS(G, w);
}
```

**时间复杂度**：
- 邻接矩阵：O(n²)
- 邻接表：O(n+e)

### 7.3.2 广度优先搜索（BFS）

> 类似树的层序遍历，使用**队列**实现

**算法思想**：
1. 访问顶点 v，入队
2. 出队顶点 u，访问所有未访问邻接顶点并入队
3. 重复直到队列为空

```c
void BFSTraverse(Graph G) {
    for (v = 0; v < G.vexnum; v++) visited[v] = FALSE;
    InitQueue(Q);
    for (v = 0; v < G.vexnum; v++)
        if (!visited[v]) {
            visit(v); visited[v] = TRUE; EnQueue(Q, v);
            while (!QueueEmpty(Q)) {
                DeQueue(Q, u);
                for (w = FirstAdjVex(G, u); w > -1; w = NextAdjVex(G, u, w))
                    if (!visited[w]) { visited[w] = TRUE; visit(w); EnQueue(Q, w); }
            }
        }
}
```

### DFS vs BFS

| 对比项 | DFS | BFS |
|--------|-----|-----|
| 辅助结构 | 栈（递归） | 队列 |
| 适用于 | 找路径、连通性、拓扑排序 | 最短路径（无权图） |
| BFS 生成树高度 | 较高 | 较低 |

## 7.4 最小生成树（MST）

> **最小生成树**：连通网中边权之和最小的生成树

**MST 性质**：设 U 是 V 的真子集，若 (u,v) 是连接 U 和 V-U 的最小权值边，则一定存在包含该边的最小生成树。

### 7.4.1 Prim 算法（加点法）

**思想**：从一个顶点出发，每次选择连接已选集合 U 和未选集合 V-U 的**最小权值边**，将对应顶点加入 U。

```c
// 辅助数组 closedge[j]
// closedge[j].lowcost: 当前与 vj 关联的最小权边权值
// closedge[j].adjvex:  U 集合中对应顶点下标
void Prim(MGraph G, VertexType u) {
    k = LocateVex(G, u);
    for (j = 0; j < G.vexnum; j++)
        closedge[j] = {k, G.arcs[k][j].adj};
    for (i = 1; i < G.vexnum; i++) {
        k = minimum(closedge);       // 选最小权边
        output(closedge[k].adjvex, k);
        closedge[k].lowcost = 0;     // 并入 U 集
        for (j = 0; j < G.vexnum; j++)  // 更新候选边
            if (G.arcs[k][j].adj < closedge[j].lowcost)
                closedge[j] = {k, G.arcs[k][j].adj};
    }
}
```

**时间复杂度**：O(n²)，**适合稠密图**

### 7.4.2 Kruskal 算法（加边法）

**思想**：将所有边按权值从小到大排序，依次选择**不产生回路**的最小权边。

**算法步骤**：
1. 初始化：n 个顶点各为独立树
2. 按权值升序排列所有边
3. 依次检验每条边 (u,v)：若 u,v 属于不同树 → 加入，合并两棵树；否则跳过
4. 重复直到选出 n-1 条边

**时间复杂度**：O(e log e)，**适合稀疏图**

| 算法 | 时间复杂度 | 适合 |
|------|------------|------|
| Prim | O(n²) | 稠密图 |
| Kruskal | O(e log e) | 稀疏图 |

## 7.5 有向无环图（DAG）的应用

### 7.5.1 拓扑排序

> **拓扑排序**：将有向图的顶点排列成线性序列，使每个顶点出现在其所有前驱顶点之后。

**应用场景**：
- AOV 网（顶点表示活动，弧表示优先关系）
- 判断有向图是否含环

**算法**（入度为零的顶点优先）：
1. 将所有入度为 0 的顶点入栈
2. 出栈一个顶点，输出，计数器 count++
3. 将该顶点所有后继的入度减 1；若某后继入度变为 0，则入栈
4. 重复 2-3 直到栈空
5. 若 count < n，则图有环，排序失败

```c
Status TopologicalSort(ALGraph G) {
    FindInDegree(G, indegree);
    InitStack(S);
    for (i = 0; i < G.vexnum; i++) if (!indegree[i]) push(S, i);
    count = 0;
    while (!StackEmpty(S)) {
        pop(S, i); printf(i); count++;
        for (p = G.vertices[i].firstarc; p; p = p->nextarc) {
            k = p->adjvex;
            if (!(--indegree[k])) push(S, k);
        }
    }
    return (count < G.vexnum) ? ERROR : OK;
}
```

**时间复杂度**：O(n+e)

### 7.5.2 关键路径

**AOE 网**：顶点表示事件，弧表示活动（带权值=持续时间）

**相关概念**：
| 符号 | 含义 |
|------|------|
| ve(j) | 事件 vj 的最早发生时间 |
| vl(j) | 事件 vj 的最迟发生时间 |
| e(i) | 活动 aᵢ 的最早开始时间 |
| l(i) | 活动 aᵢ 的最迟开始时间 |
| **关键活动** | e(i) == l(i) 的活动 |
| **关键路径** | 从源到汇的最长路径（=项目最短工期） |

**计算步骤**：
1. **拓扑排序**，计算 ve 值：  
   $ve(0) = 0$；$ve(j) = \max\{ve(i) + dut(\langle i,j\rangle)\}$（i 为 j 的前驱）
2. **逆拓扑顺序**，计算 vl 值：  
   $vl(n-1) = ve(n-1)$；$vl(j) = \min\{vl(k) - dut(\langle j,k\rangle)\}$（k 为 j 的后继）
3. 计算各活动的 e(i) 和 l(i)：  
   $e(i) = ve(j)$；$l(i) = vl(k) - dut(\langle j,k\rangle)$
4. **e(i) == l(i)** 的活动即为关键活动

## 7.6 最短路径

### 7.6.1 Dijkstra 算法（单源最短路径）

**适用**：有向网（边权为非负数）

**思想**：贪心策略，逐步扩展已确定最短路径的顶点集 S

**辅助数据**：
- `dist[k]`：源点 v0 到顶点 k 当前已知的最短路径长度
- `path[k]`：最短路径上 k 的前驱顶点

**算法步骤**：
1. 初始化：`dist[k] = G.arcs[v0][k]`
2. 选出 dist 最小且未在 S 中的顶点 u，加入 S
3. 更新：对 u 的所有邻接顶点 k，若 `dist[u] + G.arcs[u][k] < dist[k]`，则更新 dist[k]
4. 重复步骤 2-3，共 n-1 次

**时间复杂度**：O(n²)

### 7.6.2 Floyd 算法（每对顶点最短路径）

**适用**：求所有顶点对之间的最短路径

**思想**：动态规划，逐步以每个顶点 k 为中间顶点，更新最短路径

```c
for (k = 0; k < n; k++)
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            if (D[i][k] + D[k][j] < D[i][j])
                D[i][j] = D[i][k] + D[k][j];
```

**时间复杂度**：O(n³)

## 重点总结

| 考点 | 要点 |
|------|------|
| 完全图边数 | 无向：n(n-1)/2；有向：n(n-1) |
| 度与边数关系 | $\sum D(v_i) = 2e$ |
| 邻接矩阵空间 | O(n²) |
| 邻接表空间 | O(n+e)（无向 n+2e，有向 n+e） |
| DFS 辅助结构 | 栈（递归） |
| BFS 辅助结构 | 队列 |
| DFS/BFS 时间 | 矩阵 O(n²)；邻接表 O(n+e) |
| Prim 时间 | O(n²)，适合稠密图 |
| Kruskal 时间 | O(e log e)，适合稀疏图 |
| 拓扑排序时间 | O(n+e)，有环则失败 |
| 关键活动 | e(i) == l(i) |
| Dijkstra 时间 | O(n²)，单源，非负权 |
| Floyd 时间 | O(n³)，全源 |
