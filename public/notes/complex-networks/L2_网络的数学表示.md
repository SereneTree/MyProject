## 1. 无向网络

### 1.1 正式定义

无向网络 $G = (V, E)$ 由两个集合构成：
- $V$：节点集合
- $E$：无序节点对的集合 $\{v_i, v_j\}$

**关键符号：**

| 符号 | 含义 |
|------|------|
| $n = \|V\|$ | **阶数（Order）**：节点数 |
| $m = \|E\|$ | **规模（Size）**：边数 |
| 端点（Endpoints） | 边 $\{v_i, v_j\}$ 的两个节点 $v_i$、$v_j$ |
| 关联（Incident） | 边与其两个端点的关系 |

---

## 2. 网络类型

### 2.1 简单网络（Simple Network）

- 无重边（Multi-edge）
- 无自环（Self-loop）

### 2.2 多重图（Network with Multi-edges / Self-loops）

- **重数（Multiplicity）**：两节点间边的数量
- **自环（Self-loop）**：节点连向自身的边

### 2.3 加权网络（Weighted Network）

边附带数值属性（权重），如距离、费用、次数。

### 2.4 有向网络（Directed Network / Digraph）

边为有序对 $(v_i, v_j)$，从**尾（tail）** $v_i$ 指向**头（head）** $v_j$。

### 2.5 二部图（Bipartite Network）

两类节点集合 $V_1$、$V_2$，边**只连接不同类**的节点。

**应用：** 人-事件参与、用户-商品推荐等。

## 3. 邻接矩阵（Adjacency Matrix）

### 3.1 简单无向网络

$$A_{ij} = \begin{cases} 1 & \text{若 } i \text{ 与 } j \text{ 之间有边} \\ 0 & \text{否则} \end{cases}$$

**关键性质：$A$ 是对称矩阵，即 $A_{ij} = A_{ji}$**

**示例（4 节点网络）：**
```
    1 2 3 4
1 [ 0 1 1 0 ]
2 [ 1 0 1 1 ]
3 [ 1 1 0 0 ]
4 [ 0 1 0 0 ]
```

### 3.2 多重图与自环

$$A_{ij} = \text{节点 } i \text{ 与 } j \text{ 之间边的重数}$$
$$A_{ii} = 2 \text{（单个自环计数为 2）}$$

> **规则：** 对于无向网络，自环按端点数计数（单自环 = 2 个端点）。

### 3.3 加权网络

$$A_{ij} = w_{ij}$$（边的权重），无边则为 0。

### 3.4 有向网络

$$A_{ij} = 1 \text{ 表示从 } i \text{ 到 } j \text{ 有有向边}$$

**不一定对称！**（$A_{ij} \neq A_{ji}$ 是可能的）

有向多重图中：
- $A_{ij}$ = 从 $i$ 指向 $j$ 的边数（重数）
- $A_{ii} = 1$（单个有向自环，与无向图不同）

## 4. 度（Degree）

### 4.1 无向网络

$$k_i = \sum_{j=1}^n A_{ij} \quad \text{（第 } i \text{ 行之和）}$$

**总度数公式：**

$$2m = \sum_{i=1}^n k_i$$

**平均度：**

$$c = \frac{1}{n}\sum_{i=1}^n k_i = \frac{2m}{n}$$

**密度（Density）：**

$$\rho = \frac{m}{\binom{n}{2}} = \frac{2m}{n(n-1)} = \frac{c}{n-1}$$

> **重要结论：** 绝大多数真实网络是**稀疏的**，当 $n \to \infty$ 时 $\rho \to 0$。

### 4.2 有向网络

- **入度（In-degree）：** $k_i^{in} = \sum_j A_{ji}$（第 $i$ **列**之和）
- **出度（Out-degree）：** $k_i^{out} = \sum_j A_{ij}$（第 $i$ **行**之和）

**总入度 = 总出度 = 边数 $m$**

---

## 5. 网络同构（Isomorphism）

**定义：** 若存在双射 $f: V \to V'$，使得 $v_i$ 与 $v_j$ 在 $G$ 中相连 $\Leftrightarrow$ $f(v_i)$ 与 $f(v_j)$ 在 $G'$ 中相连，则 $G$ 与 $G'$ **同构**。

**矩阵形式：** $G$ 与 $G'$ 同构 $\Leftrightarrow$ $A'$ 可由 $A$ 置换行列得到。

> **注意：** 同构的网络被视为**不同的**网络（只是节点标签不同）。

## 7. 关联矩阵（Incidence Matrix）

大小为 $n \times m$ 的矩阵 $B$：

**无向网络：**
$$B_{ij} = \begin{cases} 1 & \text{若节点 } i \text{ 是边 } j \text{ 的端点} \\ 0 & \text{否则} \end{cases}$$

**有向网络（含符号）：**
$$B_{ij} = \begin{cases} 1 & \text{若边 } j \text{ 从节点 } i \text{ 出发（出边）} \\ -1 & \text{若边 } j \text{ 指向节点 } i \text{（入边）} \\ 0 & \text{否则} \end{cases}$$

## 8. 游走、路径、环

| 概念 | 定义 |
|------|------|
| **游走（Walk）** | 节点序列 $v_1, v_2, \ldots, v_k$，每对相邻节点之间有边；可重复节点/边 |
| **路径（Path）** | 不重复节点的游走 |
| **环（Cycle）** | 首尾相同的闭合路径 |
| **无环图（Acyclic）** | 不含环的网络（如引用网络） |

**路径长度：**
- 无权重：经过的边数
- 有权重：经过边的权重之和

**最短路径（Shortest Path）：** 边数（或权重之和）最小的路径。

**直径（Diameter）：** 网络中任意节点对最短路径的**最大值**。

### 游走数量定理

长度为 $r$ 的游走数量：

$$N_{ij}(r) = (A^r)_{ij}$$

即邻接矩阵的 $r$ 次幂的 $(i,j)$ 元素。

**直觉推导：**
- 长度为 2 的游走：$N_{ij}(2) = \sum_k A_{ik}A_{kj} = (A^2)_{ij}$
- 长度为 3：$N_{ij}(3) = (A^3)_{ij}$，以此类推

## 9. 连通性与分量

### 9.1 无向网络

**连通（Connected）：** 任意两节点之间存在路径。

**连通分量（Component）：** 满足以下条件的节点集合：
1. 集合内任意两节点之间有路径
2. 集合是**极大的**（不能再加入节点而保持连通性）

> **性质：** 两个不同分量之间**没有**边。

**邻接矩阵特征：** 若将同一分量的节点相邻编号，邻接矩阵呈**块对角**形式。

### 9.2 有向网络

| 概念 | 定义 |
|------|------|
| **弱连通分量** | 将有向边视为无向边后的连通分量 |
| **强连通分量** | 极大的节点集合，集合内任意两节点之间存在**双向有向路径** |
| **出分量（Out-C）** | 从某强连通分量出发，可到达的所有节点 |
| **入分量（In-C）** | 可以到达某强连通分量的所有节点 |

**关系：** 强连通分量 = 其出分量 ∩ 其入分量

## 10. 拉普拉斯矩阵（Laplacian Matrix）

### 10.1 定义

$$L = D - A$$

其中 $D$ 为**度矩阵**（对角矩阵）：

$$D_{ii} = k_i, \quad D_{ij} = 0 \; (i \neq j)$$

**元素形式：**

$$L_{ij} = \begin{cases} k_i & i = j \\ -1 & i \neq j \text{ 且 } i, j \text{ 之间有边} \\ 0 & \text{否则} \end{cases}$$

### 10.2 示例

4 节点网络（边：1-2, 1-3, 2-3, 2-4）：

```
     1   2   3   4
1 [  2  -1  -1   0 ]
2 [ -1   3  -1  -1 ]
3 [ -1  -1   2   0 ]
4 [  0  -1   0   1 ]
```

### 10.3 重要性质

| 性质 | 说明 |
|------|------|
| 每行/每列之和为 0 | $\sum_j L_{ij} = 0$ |
| 正半定矩阵 | 所有特征值 $\geq 0$ |
| $\lambda_1 = 0$ | 最小特征值为 0，对应特征向量全为 1 |
| **零特征值数量 = 连通分量数量** | **关键性质！** |
| 第二小特征值（代数连通度） | 若 $> 0$ 则网络连通 |

> **注意：** 拉普拉斯矩阵**没有有向网络的推广形式**。

## 11. 二部图与一模投影

### 11.1 关联矩阵（二部图）

设 $V_1$ 有 $n_1$ 个节点，$V_2$ 有 $n_2$ 个节点，关联矩阵 $B$ 为 $n_1 \times n_2$：

$$B_{ij} = \begin{cases} 1 & \text{若 } i \in V_1 \text{ 与 } j \in V_2 \text{ 相连} \\ 0 & \text{否则} \end{cases}$$

### 11.2 一模投影（One-mode Projection）

将二部图投影为单类节点的网络：

- **$V_1$ 的投影**：$V_1$ 中两节点相连 $\Leftrightarrow$ 它们有公共的 $V_2$ 邻居，**边权重 = 公共邻居数**
- **$V_2$ 的投影**：类似定义

> **重要特性：** 一模投影中，同一组（group）内的节点自然形成**团（Clique）**。

## 12. 数据存储方式

| 方式 | 描述 | 空间复杂度 | 适用场景 |
|------|------|-----------|----------|
| **邻接矩阵** | $n \times n$ 矩阵 | $O(n^2)$ | 稠密网络、快速查询 |
| **邻接表（字典）** | 每节点存邻居列表 | $O(n+m)$ | 稀疏网络 |
| **边列表** | 所有边的节点对 | $O(m)$ | 存储简洁 |
