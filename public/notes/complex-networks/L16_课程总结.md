## 1. 各讲核心内容速查

### L1：复杂网络导论

| 要点 | 内容 |
|------|------|
| 网络科学定义 | 通过研究关系来理解复杂系统的工具与理论 |
| 网络类型 | 技术、信息、社会、生物 |
| 区别于普通网络 | 存在 Hub 节点、小世界特性 |

### L2：网络数学表示

| 要点 | 内容 |
|------|------|
| 网络类型 | 有向/无向、多重图、简单图、加权图、二部图、一模投影 |
| 路径概念 | 游走、路径、环、最短路径、直径 |
| 连通性 | 分量（有向：弱/强连通、入分量、出分量） |
| 矩阵表示 | 邻接矩阵、关联矩阵、拉普拉斯矩阵 |
| 数据存储 | 邻接表、边列表 |

### L3：中心性度量

| 度量 | 公式 | 重要性依据 |
|------|------|-----------|
| 度 | $k_i = \sum_j A_{ij}$ | 连接数量 |
| 特征向量 | $\kappa \mathbf{x} = A^T \mathbf{x}$ | 邻居的重要性 |
| Katz* | $\mathbf{x} = (I-\alpha A^T)^{-1}\mathbf{1}$ | 重要性 + 基础值 |
| PageRank* | $\mathbf{x} = (I-\alpha A^T D^{-1})^{-1}\mathbf{1}$ | 重要性 + 独占性 + 基础值 |
| 接近 | $C_i = n/\sum_j d_{ij}$ | 分量内平均距离 |
| 调和 | $C_i' = \frac{1}{n-1}\sum_{j\neq i}\frac{1}{d_{ij}}$ | 全网络平均距离 |
| 介数 | $x_i = \sum_{j,k}\sigma_{jk}(i)/\sigma_{jk}$ | 最短路径经过比例 |

*注：Katz 和 PageRank 在考试中标注为不考。

### L5：节点群组

| 概念 | 说明 |
|------|------|
| 聚类系数 $C_i$ | $= 2e_i/[k_i(k_i-1)]$，节点邻域的紧密程度 |
| Watts-Strogatz $C_{WS}$ | $= (1/n)\sum_i C_i$，全局平均聚类系数 |
| 团（Clique） | 完全连接的节点子集 |
| K-核 | 每节点至少有 $k$ 个邻居的连通子集 |

### L6：社区检测（模块度）

| 要点 | 内容 |
|------|------|
| 模块度函数 | $Q = \frac{1}{2m}\sum_{i,j}\left(A_{ij} - \frac{k_ik_j}{2m}\right)\delta_{g_ig_j}$ |
| 检测算法 | 节点移动、Girvan-Newman（删除高介数边）、贪心、Louvain |

### L7-L9：随机网络模型

| 模型 | 固定量 | 核心特征 |
|------|--------|---------|
| $G(n,m)$ | 节点数 + 边数 | 均匀分布，难以计算 |
| $G(n,p)$ | 节点数 + 连边概率 | 泊松度分布、小直径 |
| 配置模型 | 节点数 + 度序列 | 固定局部性质，可含重边/自环 |
| Watts-Strogatz | 正则格网 + 重连概率 | **小世界**特性 |
| Barabási-Albert | 增长 + 优先连接 | **无标度**特性（幂律度分布） |

**概率公式：**

$$P(G_{n,m}) = \frac{1}{\binom{n(n-1)/2}{m}}, \quad P(G_{n,p}) = p^m(1-p)^{\binom{n}{2}-m}$$

$$P(G_{\text{config}}) = \frac{\prod_i k_i!}{(2m-1)!!\cdot\prod_{i<j}m_{ij}!\cdot\prod_i(2s_i)}$$

### L13：空间与时态网络

| 要点 | 内容 |
|------|------|
| 平面网络 | 边不相交的网络，$n - m + f = 2$ |
| γ 指数 | $m/(3n-6)$，边密度 |
| α 指数 | $(m-n+1)/(2n-5)$，面密度 |
| 时态网络 | 节点/边有时间区间，时间尊重路径 |

### L14：渗流

| 要点 | 内容 |
|------|------|
| 超度分布 | $q_k = (k+1)p_{k+1}/\langle k \rangle$ |
| 渗流阈值 | $\varphi_c = \langle k \rangle/(\langle k^2 \rangle - \langle k \rangle) = 1/g_1'(1)$ |
| 应用 | 鲁棒性分析、流行病传播 |

## 2. 复杂网络的两大核心特征

### 2.1 小世界性（Small-World）

$$\text{高聚类系数 } C + \text{ 小平均路径长度 } l$$

- **模型：** Watts-Strogatz 模型能复现此特性

### 2.2 无标度性（Scale-Free）

$$\text{幂律度分布：} P(k) \propto k^{-\alpha}$$

- 少数 Hub 节点拥有极高度
- 无特征度数尺度
- **模型：** Barabási-Albert 模型（优先连接）能复现此特性

## 3. 全课程公式总汇

### 矩阵

$$L = D - A, \quad (A^r)_{ij} = \text{长度为 } r \text{ 的游走数}$$

### 中心性

$$k_i = \sum_j A_{ij}, \quad C_i = \frac{n}{\sum_j d_{ij}}, \quad C_i' = \frac{1}{n-1}\sum_{j\neq i}\frac{1}{d_{ij}}, \quad x_i = \sum_{j,k}\frac{\sigma_{jk}(i)}{\sigma_{jk}}$$

### 群组与社区

$$C_i = \frac{2e_i}{k_i(k_i-1)}, \quad C_{WS} = \frac{1}{n}\sum_i C_i, \quad Q = \frac{1}{2m}\sum_{i,j}\left(A_{ij} - \frac{k_ik_j}{2m}\right)\delta_{g_ig_j}$$

### 随机网络

$$\langle k \rangle_{G(n,p)} = (n-1)p, \quad p_k^{G(n,p)} \approx \frac{c^k}{k!}e^{-c}, \quad q_k = \frac{(k+1)p_{k+1}}{\langle k \rangle}$$

### 空间网络

$$n - m + f = 2, \quad \langle k \rangle \leq 6, \quad \gamma = \frac{m}{3n-6}, \quad \alpha = \frac{m-n+1}{2n-5}, \quad Q_{ij} = \frac{L_{ij}}{d_{ij}}$$

### 渗流

$$\varphi_c = \frac{\langle k \rangle}{\langle k^2 \rangle - \langle k \rangle} = \frac{1}{g_1'(1)}, \quad g_1(u) = \sum_k q_k u^k$$

## 4. 课程学习目标（总结）

1. **识别与描述** 不同情境下的真实网络（基础设施、IT、社会、生物）
2. **使用计算工具** 清洗、表示和可视化网络（Python + networkx）
3. **实现方法：** 中心性分析、社区检测、渗流分析
4. **应用模型：** 空间网络、时态网络、随机网络，评估统计显著性
5. **解释特性：** 小世界和无标度特性
6. **评估影响：** 数据缺失/不确定性对分析结果的影响

- **4 道题，3 小时**
- 内容：理论（定义、简单证明）+ 大量实际计算 + 结果解释

| 步骤 | 内容 |
|------|------|

1. **先读全部 4 道题**，不要急于动笔

3. **解题前先思考**，规划解法路线可节省时间
4. **注意时间分配**（3 小时 / 4 题 ≈ 45 分钟/题）
