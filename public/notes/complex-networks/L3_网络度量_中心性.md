## 1. 为什么需要网络度量？

- 大型网络太复杂，难以直接理解
- 可视化不总是足够或可能产生误导
- 需要量化**非显而易见的性质和关系**

---

## 2. 中心性的概念

> **中心性（Centrality）** 度量节点的"重要程度"。

**重要性是依赖场景的：**

| 场景 | 重要的节点 |
|------|-----------|
| 社交网络 | 朋友多的人 |
| 社交网络 | 朋友很重要的人 |
| 社交网络 | 连接不同群体的中间人 |
| 地铁网络 | 位于中心的站点 |
| 交通网络 | 桥接孤立区域的枢纽 |

**历史背景：** Padgett & Ansell (1993) 研究 1400-1434 年佛罗伦萨美第奇家族的崛起，发现中心性是理解权力的关键。

---

## 3. 度中心性（Degree Centrality）

**思想：** 节点重要 $\Leftrightarrow$ 连接数多。

**无向网络：**

$$k_i = \sum_{j=1}^n A_{ij}$$

**有向网络：**
- 入度：$k_i^{in} = \sum_j A_{ji}$（第 $i$ 列之和）
- 出度：$k_i^{out} = \sum_j A_{ij}$（第 $i$ 行之和）

> **局限：** 只关注直接连接，忽略邻居的质量。

---

## 4. 特征向量中心性（Eigenvector Centrality）

**思想：** 节点重要 $\Leftrightarrow$ 与重要节点相连。

**公式（无向）：**

$$x_i = \frac{1}{\kappa} \sum_j A_{ji} x_j$$

**矩阵形式：**

$$A\mathbf{x} = \kappa\mathbf{x} \quad \Rightarrow \quad \mathbf{x} \text{ 为 } A \text{ 的主特征向量（最大特征值 } \kappa \text{ 对应）}$$

**保证非负性：** 由 **Perron-Frobenius 定理** 保证主特征向量分量非负。

**有向网络：**
$$x_i = \frac{1}{\kappa} \sum_j A_{ji} x_j$$
节点重要 $\Leftrightarrow$ 有重要节点**指向它**。

### 4.1 有向网络的问题

| 问题 | 说明 |
|------|------|
| 零中心性传播 | 无入边的节点中心性为 0，且传播到所有连接节点 |
| 无环图失效 | 引用网络（无环）中所有节点中心性均为 0 |

**解决方案：**
1. 给每个节点"免费"赋予一定中心性 → **Katz 中心性**
2. 将中心性除以出度分配 → **PageRank**

---

## 5. Katz 中心性

**思想：** 每个节点都有基础重要性，同时从重要的连接中获益。

**公式：**

$$x_i = \alpha \sum_j A_{ji} x_j + \beta$$

**矩阵形式与解：**

$$\mathbf{x} = \alpha A^T \mathbf{x} + \beta \mathbf{1} \quad \Rightarrow \quad \mathbf{x} = (I - \alpha A^T)^{-1} \beta \mathbf{1}$$

**参数：**
- $\alpha$：邻居影响力（必须满足 $0 < \alpha < \frac{1}{\lambda}$，其中 $\lambda$ 为 $A^T$ 最大特征值）
- $\beta$：基础中心性（通常取 $\beta = 1$）

**极限行为：** 当 $\alpha \to 0$ 时，$\mathbf{x} \to \beta \mathbf{1}$（所有节点中心性相同）。

---

## 6. PageRank 中心性

**思想：** 节点将中心性**均等分配**给所有出边；每个节点有基础重要性。

**公式：**

$$x_i = \alpha \sum_j A_{ji} \frac{x_j}{k_j^{out}} + \beta$$

**矩阵形式与解：**

$$\mathbf{x} = (I - \alpha A^T D^{-1})^{-1} \beta \mathbf{1}$$

其中 $D$ 为对角矩阵，$D_{ii} = \max(k_i^{out}, 1)$

**参数：** $0 < \alpha < 1$（通常 $\alpha = 0.85$），$\beta = 1$

**特殊情况：** 对无向网络取 $\beta = 0$，$\alpha = 1$，退化为**度中心性**。

**应用：** Google 搜索引擎网页排名。

---

## 7. 四种特征向量类中心性对比

|  | **有基础中心性（$\beta=1$）** | **无基础中心性（$\beta=0$）** |
|--|:--:|:--:|
| **不除以出度** | **Katz**<br>$\mathbf{x} = (I - \alpha A^T)^{-1}\mathbf{1}$ | **特征向量**<br>$\kappa \mathbf{x} = A^T \mathbf{x}$ |
| **除以出度** | **PageRank**<br>$\mathbf{x} = (I - \alpha A^T D^{-1})^{-1}\mathbf{1}$ | **度中心性**<br>$\mathbf{x} = A^T D^{-1}\mathbf{1}$ |

---

## 8. 距离类中心性

**思想：** 节点重要 $\Leftrightarrow$ 距所有其他节点更近。

**距离定义：**
- 无权重网络：最短路径的**边数**
- 加权网络：最短路径的**权重之和**

### 8.1 接近中心性（Closeness Centrality）

$$C_i = \frac{n}{\sum_j d_{ij}}$$

**解释：** 到所有节点平均距离的倒数。

**问题：** 在非连通网络中，不同分量间距离为无穷大，无法定义。

### 8.2 调和中心性（Harmonic Centrality）

$$C_i' = \frac{1}{n-1} \sum_{j \neq i} \frac{1}{d_{ij}}$$

**优势：** 令 $1/\infty = 0$，在非连通网络中也有定义。

---

## 9. 介数中心性（Betweenness Centrality）

**思想：** 节点重要 $\Leftrightarrow$ 大量最短路径经过它（充当"桥梁"）。

**公式：**

$$x_i = \sum_{\substack{j,k \\ j \neq k \neq i}} \frac{\sigma_{jk}(i)}{\sigma_{jk}}$$

**符号说明：**
- $\sigma_{jk}$：从节点 $j$ 到节点 $k$ 的最短路径总数
- $\sigma_{jk}(i)$：其中经过节点 $i$ 的数量

**解释：**
- 高介数 → 充当桥接/中介节点
- 移除高介数节点会严重破坏通信
- 与**网络鲁棒性**密切相关

**同类度量：** 边介数（Edge Betweenness）——最短路径经过某条边的比例（用于 Girvan-Newman 社区检测）。

## 10. 完整中心性度量参考表

| 度量 | 公式 | 向量形式 | 重要性依据 |
|------|------|----------|-----------|
| **度** | $k_i = \sum_j A_{ij}$ | $\mathbf{x} = AD^{-1}\mathbf{1}$ | 连接数量 |
| **特征向量** | $x_i = \frac{1}{\kappa}\sum_j A_{ji}x_j$ | $\mathbf{x} = \kappa^{-1}A^T\mathbf{x}$ | 邻居的重要性 |
| **Katz** | $x_i = \alpha\sum_j A_{ji}x_j + \beta$ | $\mathbf{x} = (I-\alpha A^T)^{-1}\mathbf{1}$ | 邻居重要性 + 基础值 |
| **PageRank** | $x_i = \alpha\sum_j \frac{A_{ji}x_j}{k_j^{out}} + \beta$ | $\mathbf{x} = (I-\alpha A^TD^{-1})^{-1}\mathbf{1}$ | 独占性 + 重要性 + 基础值 |
| **接近** | $C_i = n/\sum_j d_{ij}$ | — | 在分量内的平均距离 |
| **调和** | $C_i' = \frac{1}{n-1}\sum_{j\neq i}\frac{1}{d_{ij}}$ | — | 在全网络的平均距离 |
| **介数** | $x_i = \sum_{j\neq k\neq i}\frac{\sigma_{jk}(i)}{\sigma_{jk}}$ | — | 经过的最短路径比例 |

## 11. 各中心性度量的直觉对比

```
度中心性    → "我有多少朋友？"
特征向量   → "我的朋友有多重要？"
Katz      → "我的朋友多重要（但每个人都有基础分）"
PageRank  → "我的朋友把重要性平均分给我（每人有基础分）"
接近中心性 → "我平均距离所有人多近？"
调和中心性 → "考虑断开连接，我距所有人多近？"
介数中心性 → "多少路径必须经过我？"
```
