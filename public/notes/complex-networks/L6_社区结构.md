## 1. 社区的定义

> **社区（Community）：** 内部连接紧密、与外部连接稀疏的节点集合。

**目标：** 将网络**划分**为若干社区，使：
- 社区**内部**：节点之间连接密集
- 社区**之间**：节点之间连接稀疏

**经典案例：** Zachary's Karate Club（1977）——通过冲突自然分裂为两派。

---

## 2. 模块度最大化原理

**核心思想：** 好的社区划分，应使**实际内部边数多于随机连接时的期望内部边数**。

**操作方法：**
1. 提出一个节点划分方案
2. 构造对比：将网络的边随机重连（但保留每个节点的度数）
3. 比较：原网络 vs. 随机网络，哪个划分内部边更多？

---

## 3. 模块度函数推导

### 3.1 符号定义

- $g_i$：节点 $i$ 所属的社区编号
- $\delta_{g_i g_j}$：Kronecker delta，$g_i = g_j$ 时为 1，否则为 0

### 3.2 步骤一：统计实际内部边

$$Q_1 = \frac{1}{2}\sum_{i,j} A_{ij} \delta_{g_i g_j}$$

（除以 2 是因为无向网络每条边被计算两次）

### 3.3 步骤二：计算随机网络的期望内部边

使用**配置模型**（固定度序列的随机网络）：

节点 $i$ 和 $j$ 之间存在边的期望概率：

$$p_{ij} = \frac{k_i k_j}{2m}$$

期望内部边数：

$$Q_2 = \frac{1}{2}\sum_{i,j} \frac{k_i k_j}{2m} \delta_{g_i g_j}$$

### 3.4 模块度定义

$$\boxed{Q = \frac{1}{2m}\sum_{i,j}\left(A_{ij} - \frac{k_i k_j}{2m}\right)\delta_{g_i g_j}}$$

**等价写法（令 $B_{ij} = A_{ij} - \frac{k_ik_j}{2m}$ 为模块度矩阵）：**

$$Q = \frac{1}{2m}\sum_{i,j} B_{ij} \delta_{g_i g_j}$$

### 3.5 性质

| 性质 | 说明 |
|------|------|
| $Q \in [-1/2, 1]$ | 范围 |
| $Q = 0$ | 划分不优于随机 |
| $Q > 0.3$ | 通常认为存在显著社区结构 |
| $\sum_j B_{ij} = 0$ | 模块度矩阵每行（列）之和为 0 |

## 4. 模块度计算示例

### 4.1 线图（Line Graph）

$n$ 个节点排成一排，划分为大小 $r$ 和 $n-r$ 的两组：

$$Q = \frac{3 - 4n + 4rn - 4r^2}{2(n-1)^2}$$

**最优划分：** 当 $n$ 为偶数时，$r = n/2$ 使模块度最大。

### 4.2 2-正则环格（Ring Lattice）

$n$ 个节点排成环，划分为 $\{1,\ldots,r\}$ 和 $\{r+1,\ldots,n\}$：

$$Q = \frac{2nr - 2r^2 - 2n}{2n^2}$$

## 5. 社区检测算法

### 5.1 节点移动算法（Node-Moving Algorithm）

**核心思想：** 贪心移动节点提升模块度。

**步骤：**
1. 随机将节点划分为两个等大的组
2. 进行一轮操作：
   - 对每个节点，计算移到另一组的模块度变化 $\Delta Q$
   - 找到使 $\Delta Q$ 最大的节点并移动（已移动的节点不再移动）
   - 重复直到每个节点移动一次
3. 找到这一轮中模块度最高的划分
4. 重复步骤 2-3，直到无法继续提升

---

### 5.2 Girvan-Newman 算法

**核心思想：** 边介数高 → 社区间的"桥"，删除桥来分裂社区。

**边介数中心性：**

$$x_e = \sum_{j \neq k} \frac{\sigma_{jk}(e)}{\sigma_{jk}}$$

其中 $\sigma_{jk}(e)$ 是经过边 $e$ 的从 $j$ 到 $k$ 最短路径数。

**步骤：**
1. 计算所有边的介数中心性
2. 删除介数最高的边
3. **重新计算**所有边的介数（必须！）
4. 重复，直到达到目标社区数

**注意：** 每次删除边后必须重新计算介数，计算代价高。

---

### 5.3 贪心模块度最大化（Greedy Modularity Algorithm）

**核心思想：** 从底向上合并社区。

**步骤：**
1. 初始：每个节点单独构成一个社区（共 $n$ 个社区）
2. 对每对社区，计算合并后模块度变化 $\Delta Q$
3. 合并使 $\Delta Q$ 最大的两个社区
4. 重复，直到无法再提升模块度

---

### 5.4 Louvain 算法

**核心思想：** 多层次聚合，将节点组视为超节点递归处理。

**复杂度：** $O(m + n \log n)$，**极快**，适用于超大网络。

**步骤：**
1. **初始化：** 每个节点在自己的社区
2. **第一遍：** 对每个节点，若将其移入邻居社区能提升模块度则移动，否则不动
3. **重复第一遍**，直到无法提升
4. **聚合：** 将当前社区视为超节点，构成新的粗粒度网络
5. **递归：** 对新网络重复步骤 2-4
6. **终止：** 直到没有任何移动能提升模块度

**优点：** 速度最快、自然产生**层次化社区结构**。

---

## 6. 算法对比

| 算法 | 方向 | 复杂度 | 特点 |
|------|------|--------|------|
| 节点移动 | 自顶向下 | 中 | 可能陷入局部最优 |
| **Girvan-Newman** | 自顶向下（删除） | 高 | 直观、适合小网络 |
| **贪心模块度** | 自底向上 | 中 | 简单、结果合理 |
| **Louvain** | 自底向上 | $O(m + n\log n)$ | **最快、层次化、高质量** |

**Zachary's Karate Club 上的表现：**

| 算法 | 模块度 $Q$ |
|------|-----------|
| 贪心（2 组） | 0.399833 |
| 贪心（不限组数） | 0.410965 |
| Louvain | **0.444904** |
