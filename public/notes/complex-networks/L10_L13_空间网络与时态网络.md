## 1. 空间网络（Spatial Networks）

### 1.1 定义

> **空间网络：** 节点和边具有空间位置、网络结构受空间约束、连接代价取决于节点间距离的网络。

**关注内容：**
- 节点的**位置**和边的**轨迹**
- 节点之间的距离（网络距离 vs. 地理距离）

### 1.2 示例

| 网络 | 节点 | 边 |
|------|------|-----|
| 道路网络 | 路口 | 道路 |
| 铁路网络 | 站点 | 铁路线段 |
| 航班网络 | 机场 | 航线 |
| 真菌根系网络 | 节点 | 菌丝 |

### 1.3 "每个网络都是空间的吗？"

**答：** 是否用空间网络建模，取决于我们是否关注空间约束。

**例子——友谊网络：**
- 许多朋友住得近（空间有影响）
- 但也可以有世界各地的朋友（空间不严格约束）
- 若研究"距离对友谊的影响"，则适合用空间网络方法

## 2. 平面网络（Planar Network）

### 2.1 定义

> **平面网络：** 可以在平面上绘制，且边**不相交**的网络。

**典型示例：** 大多数道路网络（近似平面）。

**非平面示例：** 航班网络、有立交桥的道路网络。

### 2.2 Kuratowski 定理

$$\text{网络非平面} \Leftrightarrow \text{它包含 } K_5 \text{ 或 } K_{3,3} \text{ 作为子图}$$

- $K_5$：5 个节点的完全图
- $K_{3,3}$：各 3 个节点的完全二部图

## 3. 欧拉公式（Euler's Formula）

### 3.1 公式

对任意**连通平面网络**：

$$\boxed{n - m + f = 2}$$

**不含外部面的版本：**

$$n - m + f^* = 1$$

其中：
- $n$ = 节点数
- $m$ = 边数
- $f$ = 面数（**含**外部无界面）
- $f^*$ = 有界面数（$f^* = f - 1$）

**验证示例（正方形+对角线）：** $n=4, m=5, f=3$（2 个三角形面 + 1 个外部面）
$$4 - 5 + 3 = 2 \checkmark$$

### 3.2 欧拉公式的证明思路

1. 从任意连通平面网络 $G$ 出发
2. 每次删除一条边：$m$ 减 1，$f$ 也减 1（若边是两个面的分界），$n - m + f$ **不变**
3. 不断删除边直到得到**生成树**（$m = n-1, f = 1$）
4. 此时：$n - (n-1) + 1 = 2$ ✓

## 4. 平面网络的性质

### 4.1 平均度上界

$$\langle k \rangle \leq 6$$

**证明：**

1. 每个面至少被 3 条边围成：$3f \leq 2m$
2. 由欧拉公式 $f = 2 - n + m$，代入：$3(2-n+m) \leq 2m$
3. 化简：$m \leq 3n - 6$
4. 因此：$\langle k \rangle = \frac{2m}{n} \leq 6 - \frac{12}{n} < 6$

### 4.2 最大平面网络

不能再添加任何边而保持平面性的网络：

| 属性 | 公式 |
|------|------|
| 最大边数 | $m_{max} = 3n - 6$ |
| 最大面数（含外部） | $f_{max} = 2n - 4$ |
| 最大有界面数 | $f^*_{max} = 2n - 5$ |

## 5. 空间网络度量

### 5.1 γ 指数（Gamma Index）

**来源：** Kansky, 1963

$$\gamma = \frac{m}{m_{max}} = \frac{m}{3n-6}$$

- **范围：** $[0, 1]$
- **解释：** 实际边数与最大可能边数之比，衡量平面网络的**连通度**

### 5.2 α 指数 / Meshedness

**来源：** Buhl, 2006

$$\alpha = \frac{f^*}{f^*_{max}} = \frac{m - n + 1}{2n - 5}$$

- **范围：** $[0, 1]$
- $\alpha = 0$：树（无环）
- $\alpha = 1$：最大连通平面网络
- **解释：** 有界面密度，衡量平面网络的**网格化程度**

### 5.3 绕行指数（Detour Index）

设边 $(i,j)$ 具有长度属性 $l_{ij}$，$L_{ij}$ 为网络中最短（按长度）路径。

**节点对 $(i,j)$ 的绕行指数：**

$$Q_{ij} = \frac{L_{ij}}{d_{ij}}$$

其中 $d_{ij}$ = 节点 $i$ 和 $j$ 之间的**地理直线距离**。

**节点 $i$ 的绕行指数：**

$$Q_i = \frac{1}{n-1}\sum_j Q_{ij}$$

**全网络绕行指数：**

$$Q = \frac{1}{n(n-1)}\sum_{i \neq j} Q_{ij}$$

**解释：** $Q_{ij} \geq 1$，越接近 1 表示网络越高效（实际路径接近直线距离）。

### 5.4 空间网络中的中心性

加权距离代替跳数：

- **接近中心性：** $C_i = n / \sum_j L_{ij}$（用路径**长度**代替跳数）
- **介数中心性：** 使用**最短长度路径**代替最短步数路径

## 6. 几何网络模型

以下模型基于几何规则决定是否连边：

### 6.1 k-最近邻图（k-Nearest Neighbors Graph）

每个节点连接距自己最近的 $k$ 个节点。

### 6.2 阈值图 / 圆盘图（Disc / Threshold Graph）

两节点距离 $< $ 某阈值时相连。

**示例：** 英格兰和威尔士城市，火车行程 $<1$ 小时的城市相连。

### 6.3 Delaunay 三角剖分

连接三个节点 $p_1, p_2, p_3$（形成三角形），当且仅当经过它们的**外接圆内部没有其他节点**。

**应用：** 连接罗马考古遗址，比较理论道路网络与实际道路。

### 6.4 Gabriel 图

连接两个节点，当且仅当以它们的连线为**直径**的圆盘内**没有**其他节点。

### 6.5 相对邻域图（Relative Neighbourhood Graph, RNG）

连接两个节点，当且仅当**没有**其他节点同时比两端点之间距离更近。

**关系：** RNG $\subseteq$ Gabriel 图 $\subseteq$ Delaunay 三角剖分

### 6.6 最小生成树（Minimum Spanning Tree, MST）

连接所有节点、边长度总和最小的**树**。

- 构造代价最低
- 鲁棒性最差（任意一条边失效即可能断网）

## 7. 时态网络（Temporal Network）

### 7.1 定义

> **时态网络：** 节点和边**只在特定时间区间内存在**，网络结构随时间动态变化。

**别名：**
- 动态网络（Dynamic Network）
- 时变网络（Time-varying Network）
- 增长网络（Growing Network，若节点/边只增不减）

**示例：**
- 人与人之间的实时社交互动
- 电话通话网络（每次通话是一条时态边）

### 7.2 多层结构与时间分辨率

- 时态网络可视为**多层网络**（每个时间步一层）
- **时间分辨率的选择**至关重要！

### 7.3 时间尊重路径（Time-respecting Path）

> **时间尊重路径：** 路径上的每条边必须按时间顺序出现（后一条边的时间 $\geq$ 前一条边）。

**关键区别：** 在时态网络的**投影**（将所有时态边叠加）中存在的路径，在实际时态网络中**不一定存在**！

### 7.4 时态可达性（Temporal Reachability）

**标准可达性（有向网络）：** 从节点 $v$ 出发，可以通过有向路径到达的节点集合。

**时态可达性：** 从节点 $v$ 出发，可以通过**时间尊重路径**到达的节点集合。

> **时态可达性比标准可达性更受限制。**

---

## 8. 时态网络详解示例

**场景：** 6 个人（A, B, C, D, E, F）的互动：

| 时间 | 互动 |
|------|------|
| 周一 | A-B, C-D |
| 周二 | D-F, E-C |
| 周三 | A-C（A 先还是 C 先遇 D？） |
| 周四 | A-C, E-D |
| 周五 | A-B, C-D, E-F |

**问题：** A 从周一开始知道某个八卦，所有人见面时互相传播，周末结束时谁知道？

**关键：** 答案依赖于周三 A 和 C 见面**与** C 和 D 见面的**先后顺序**！

**情形一（A 先见 C，再 C 见 D）：**
- A → C → D → E → F
- **最终：所有人都知道**

**情形二（C 先见 D，再 A 见 C）：**
- 周三 C 见 D 时 A 还没告诉 C，C 不知道八卦
- A 周四才告诉 C，但 C 周四见不到 D
- **最终：E 和 F 不知道**

> **教训：** 时态网络中，连接的**顺序**决定信息的可达性。即使整体结构（投影网络）相同，时序不同结果也完全不同。
