## 1. 核心概念定义

### 1.1 复杂系统

> 由许多相互连接的不同对象组成，且**连接结构会影响系统行为**的集合。

**例子：**
- 大脑：神经元通过树突/轴突相连
- 大学班级：学生通过社会关系相连

### 1.2 图（Graph）

图 $G = (V, E)$ 是一对集合：

- $V$：**节点**（vertices / nodes）的集合，记 $v_1, v_2, \ldots, v_n$
- $E \subseteq V \times V$：**边**（edges / links / arcs）的集合，元素为节点对 $(v_i, v_j)$

### 1.3 复杂网络（Complex Network）

> 用**图**来数学表示的**复杂系统**。

### 1.4 网络 vs. 图

| 概念 | 特征 |
|------|------|
| **图** | 抽象的数学对象 |
| **网络** | 现实系统的图表示，节点和边通常附带属性（名称、年龄、关系类型、权重等） |

## 2. 网络类型与示例

### 2.1 技术网络（Technological Networks）

物理基础设施，连接是物理性的。

| 网络 | 节点 | 边 |
|------|------|-----|
| 互联网 | 计算机/路由器 | 数据连接 |
| 电话网络 | 端点/交换机 | 电路 |
| 交通网络 | 站点/路口 | 路线 |
| 配电网络 | 变电站 | 输电线 |

### 2.2 信息网络（Information Networks）

以信息传播为核心。

| 网络 | 节点 | 边 | 特点 |
|------|------|-----|------|
| 万维网（WWW） | 网页 | 超链接 | **有向** |
| 引用网络 | 论文 | 引用关系 | **有向、无环** |
| 共引网络 | 论文 | 被同一文献共同引用 | 无向 |

**万维网爬取（BFS 算法）：**
1. 从一个网页出发
2. 找到页面上所有 URL
3. 将未访问的 URL 加入队列
4. 重复，直到无新页面
> **局限：** 只能发现主要连通分量（约占总页面的 50%）

**引用网络的特性：** 无环——论文只能引用比自己更早发表的文章，不可能形成循环引用。

### 2.3 社会网络（Social Networks）

人与人之间的互动关系。

| 网络 | 节点 | 边 |
|------|------|-----|
| 友谊网络 | 人 | 朋友关系 |
| 二部图（人-事件） | 人 + 活动 | 参与关系 |
| Zachary's Karate Club | 空手道俱乐部成员 | 社会关系 |
| 佛罗伦萨家族网络 | 贵族家族 | 婚姻关系 |

### 2.4 生物网络（Biological Networks）

| 网络 | 节点 | 边 |
|------|------|-----|
| 食物链（食物网） | 物种 | 能量流向（**有向**） |
| 神经网络 | 神经元 | 突触连接（兴奋性/抑制性） |
| 代谢网络 | 代谢物 | 生化反应 |

## 3. 典型网络详解

### 3.1 互联网结构（三层层次）

```
┌──────────────────────────────────┐
│  骨干网（Backbone）               │  长距离、高带宽（NBP、政府）
├──────────────────────────────────┤
│  ISP 层（Internet Service Provider）│  商业、大学、政府
├──────────────────────────────────┤
│  用户层（Consumer Level）         │  企业、办公室、个人
└──────────────────────────────────┘
```

**关键特点：**
- 无中央权威，只有协议（Guidelines）
- 路由器通过 **BGP（边界网关协议）** 协商路由
- 具有弹性，无完整拓扑图

### 3.2 铁路网络的多种表示

同一个物理系统可以用不同的图来表示：

| 表示方式 | 节点 | 边 | 用途 |
|----------|------|-----|------|
| **L-space** | 站点 | 相邻停靠站之间 | 计算旅行时间 |
| **P-space** | 站点 | 同一条线路的任意两站 | 计算换乘次数 |

## 4. 网络科学

### 4.1 定义

> 通过关注系统各部分之间的**关系（连接模式）**来研究复杂系统，并分析这些关系对**系统行为的影响**。

**特点：**
- 多学科交叉（物理、计算机、社会学、生物学...）
- 实证驱动
- 提供统一的理论框架

### 4.2 工具

- 可视化与交互探索
- 网络度量（节点级、全局级）
- 网络模型
- 数学与计算方法

## 5. 为什么叫"复杂"网络？

真实网络呈现出**非平凡的结构**，区别于规则格网或纯随机网络。

### 5.1 小世界性（Small-World）

- **高聚类系数**：朋友的朋友也是朋友（局部连接紧密）
- **小平均路径长度**：任意两节点之间距离短（"六度分隔"）

### 5.2 无标度性（Scale-Free）

- **幂律度分布**：$P_k \propto k^{-\alpha}$
- 少数节点（**Hub**）拥有极高度，大多数节点度数很低
- 无特征度数尺度（因此叫"无标度"）

## 6. 网络度量概览

| 范围 | 典型度量 |
|------|----------|
| **单个节点** | 度（Degree） |
| **节点对** | 最短路径距离 |
| **节点集合** | 社区结构 |
| **全局** | 聚类系数、直径 |
