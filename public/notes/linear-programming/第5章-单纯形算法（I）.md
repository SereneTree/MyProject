# 第五章：单纯形算法（I）

## 5.1 单纯形算法的直觉

### 核心思想
既然最优解一定在某个极点（BFS）处取得，那么：
1. 从一个BFS出发
2. 沿着可行域的边移动到**相邻的**BFS
3. 每次移动使目标函数值**增大**
4. 直到无法再改善为止

### 从BFS到相邻BFS
- 相邻BFS = 将一个基变量换出，一个非基变量换入
- 换入变量（entering variable）：选择使目标函数增长最大的非基变量
- 换出变量（leaving variable）：选择最先变为0的基变量（最小比检验）

### 代数推导
从标准方程形式出发，用基变量表示非基变量和目标函数：
$$z = c^Tx = \text{常数} + \sum_{j \notin B} \bar{c}_j x_j$$
- 若某个 $\bar{c}_j > 0$，增大 $x_j$ 可改善目标值
- 选择 $\bar{c}_j > 0$ 的变量作为换入变量

## 5.2 单纯形表（Simplex Tableau）

### 表的结构

|  | $x_1$ | $x_2$ | ... | $s_1$ | $s_2$ | ... | RHS |
|--|-------|-------|-----|-------|-------|-----|-----|
| 基变量 | 系数 | 系数 | ... | 系数 | 系数 | ... | 常数 |
| ... | ... | ... | ... | ... | ... | ... | ... |
| $-z$ | $\bar{c}_1$ | $\bar{c}_2$ | ... | $\bar{c}_{s1}$ | $\bar{c}_{s2}$ | ... | 目标值 |

### 算法步骤

**初始化**：
1. 将LP转化为标准方程形式
2. 选择松弛变量作为初始基变量
3. 构建初始单纯形表

**迭代**：
1. **选择换入变量**：在 $-z$ 行中选择最大正系数对应的变量
2. **选择换出变量**：对换入变量列中正系数的行，计算 RHS/系数 的最小比
3. **旋转（Pivot）**：用初等行变换使换入变量列中换出变量行的元素为1，其余为0

**终止条件**：
- $-z$ 行中所有系数 $\leq 0$ → 当前解为最优解

### 最小比检验（Minimum Ratio Test）
- 对换入变量 $x_j$，计算 $\theta_i = \frac{b_i}{a_{i,j}}$（仅当 $a_{i,j} > 0$）
- 选择最小的 $\theta_i$ 对应的基变量作为换出变量
- 这保证了新解仍然可行（所有变量 $\geq 0$）

### 算法伪代码

```
1. 将LP变为标准方程形式，加入松弛变量
2. 构建初始单纯形表
3. While (-z行有正系数):
   a. 选择正系数最大的列 → 换入变量
   b. 进行最小比检验 → 换出变量
   c. 旋转操作
4. 输出最优解
```

## 5.3 无界的线性规划

### 检测无界
- 在选择换入变量后，如果该列中**没有正系数**
- 则意味着可以无限增大换入变量而不违反任何约束
- 此时线性规划**无界**

### 判断标准
> 如果换入变量列中所有系数 $\leq 0$，则LP无界

### 例题
$$\max\, x_1 + x_2$$
$$\text{s.t.}\, x_1 - x_2 \leq 1,\, x_1, x_2 \geq 0$$
单纯形表中发现换入变量列全为非正系数 → 无界

---

## 考试重点总结

1. **单纯形表的构建与操作**——最核心的计算技能
2. **换入变量的选择**：$-z$ 行中最大正系数
3. **换出变量的选择**：最小比检验
4. **旋转操作的执行**：初等行变换
5. **无界的判断**：换入变量列无正系数
6. **最优解的读取**：基变量值 = RHS，非基变量 = 0
7. **注意**：初始基本可行解可能不显然（需要第6章的两阶段法）
