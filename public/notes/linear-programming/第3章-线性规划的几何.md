# 第三章：线性规划的几何

## 3.1 线性规划的几何直觉

### 目标函数的几何意义
- 目标函数 $c^Tx$ 可以看作向量 $c$ 与变量 $x$ 的点积
- $c^Tx = k$ 定义了一组**等值线/等值面**
- 等值线与梯度 $c$ **垂直**
- 最优解在沿梯度方向移动时等值线最后与可行域相切的点

### 约束的几何表示
- 每个线性不等式 $a^Tx \leq b$ 将空间分为两个半空间
- **可行域**是所有约束半空间的交集
- 在2D中，可行域是一个**凸多边形**
- 在3D中，可行域是一个**凸多面体**

### 最优解的位置
> **核心结论**：如果线性规划有最优解，则最优解一定在可行域的**顶点（角点）**处取得

- 最优解可能不唯一（目标函数与某条边平行时）
- 此时该边上的所有点都是最优解

---

## 3.2 不可行与无界的线性规划

### 不可行（Infeasible）
- 可行域为空集
- 约束之间存在矛盾
- 例：$x_1 \leq 1$，$x_2 \leq 1$，$x_1 + x_2 \geq 3$，$x_1, x_2 \geq 0$

### 无界（Unbounded）
- 可行域存在但目标函数值可以无限增大（最大化问题）
- 可行域延伸到无穷远，且沿此方向目标函数递增
- 例：$\max\, x_1 + x_2$，约束 $x_1 - x_2 \leq 1$，$x_1, x_2 \geq 0$

### LP的三种可能状态

| 状态 | 含义 |
|------|------|
| 有最优解 | 可行域非空且目标函数有界 |
| 不可行 | 无可行解 |
| 无界 | 有可行解但目标函数无界 |

---

## 3.3 三维情况

### 基本概念
- $a^Tx = b$ 在3D中定义一个**平面**
- 约束 $a^Tx \leq b$ 定义一个**半空间**
- 可行域是多个半空间的交集
- 顶点是3个或更多约束面的交点

### 法向量
- 每个约束 $a^Tx = b$ 的法向量是 $a$
- 法向量指向约束的"外部"（即不满足约束的方向）

---

## 3.4 凸组合与极点解

### 凸组合
**定义**：给定向量 $y, z$，其凸组合为 $w = \lambda y + (1-\lambda)z$，其中 $0 \leq \lambda \leq 1$

- 几何意义：$w$ 位于 $y$ 和 $z$ 的连线上
- 可行域中任意两点的凸组合仍在可行域中（**可行域是凸集**）

### 极点（Extreme Point）
**定义**：可行域中的点 $x$ 是极点，当且仅当它不能表示为可行域中两个不同点的凸组合

- 即：$x = \lambda y + (1-\lambda)z$，$y, z$ 可行 $\Rightarrow$ $y = z = x$
- 几何上，极点就是可行域的**顶点**

### 核心定理（直观版）
> 如果线性规划有最优解，则存在某个极点是最优解

这为单纯形算法提供了理论基础——只需检查极点即可找到最优解。

## 考试重点总结

1. **最优解在顶点处取得**——这是整个课程的核心几何直觉
2. **判断LP的状态**：有最优解 / 不可行 / 无界
3. **凸组合的定义**与**可行域是凸集**的性质
4. **极点的定义**及其与最优解的关系
5. **等值线与梯度垂直**的几何性质
