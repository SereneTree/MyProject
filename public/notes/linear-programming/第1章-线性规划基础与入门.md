# 第一章：线性规划基础与入门

## 1.1 引言

### 线性规划（Linear Programming）概述
- 线性规划是运筹学的一个分支，研究**线性优化问题**
- 目标：在约束条件下找到"最优"的方案（最大化或最小化目标函数）
- "Programming"在此处指"规划"，而非计算机编程

### 核心概念
- **数学规划（Mathematical Program）**的四个组成部分：

| 组成部分 | 说明 |
|---------|------|
| 决策变量 | 带有符号限制的变量集合 |
| 目标函数 | 决策变量的函数，需要优化 |
| 优化目标 | 最大化或最小化 |
| 约束条件 | 变量间的关系式（等式或不等式） |

### 经典例题：饮食问题（Diet Problem）
- 一名学生需要规划每日食物预算，满足维生素需求的同时最小化成本
- 引入变量 $x_1, \ldots, x_6$ 表示各类食物的份数
- 目标函数：最小化总成本
- 约束条件：4种维生素的每日最低摄入量

### 对偶与博弈论（Duality and Game Theory）
- 营养品商人的定价问题是饮食问题的**对偶**问题
- 两个问题的最优值**相等**，这是对偶性的结果
- 博弈论：研究多个独立决策者互动的问题

## 1.2 线性代数基础与符号约定

### 向量与矩阵
- 向量用小写粗体（或下划线）表示，矩阵用大写字母表示
- 所有向量为**列向量**，属于 $\mathbb{R}^n$
- 转置：$x^T = (x_1, x_2, \ldots, x_n)$

### 线性组合
**定义**：$a_1x_1 + a_2x_2 + \cdots + a_nx_n$，其中 $a_i \in \mathbb{R}$

- 当 $x_i$ 为标量时，可写作 $a^Tx$
- 当 $\mathbf{x}_i$ 为向量时，可写作 $Xa$（$X$ 是以 $\mathbf{x}_j$ 为列的矩阵）

### 点积（内积）
$$x^Ty = x_1y_1 + x_2y_2 + \cdots + x_ny_n = \sum_{i=1}^n x_iy_i$$

### 线性方程与不等式
- 线性等式：$a^Tx = b$
- 线性不等式：$a^Tx \leq b$ 或 $a^Tx \geq b$
- 任何两边都有变量的等式/不等式都可以重排为标准形式

### 向量比较
- $x \leq y$ 意味着 $x_i \leq y_i$ 对所有 $i$ 成立
- 这是**偏序关系**（partial order）——两个向量可能不可比较

### 线性无关与秩
- 向量组 $\mathbf{a}_1, \ldots, \mathbf{a}_m$ **线性无关**当且仅当 $x_1\mathbf{a}_1 + \cdots + x_m\mathbf{a}_m = \mathbf{0}$ 仅在 $x_1 = \cdots = x_m = 0$ 时成立
- 矩阵的**秩** = 最大线性无关行数 = 最大线性无关列数

## 1.3 线性规划

### 线性规划的定义
**定义**：满足以下条件的数学规划称为线性规划：
1. 变量为连续实数量
2. 目标函数是变量的**线性组合**
3. 每个约束是线性不等式或线性等式

### 标准不等式形式（Standard Inequality Form）
$$\text{maximize} \quad c^Tx$$
$$\text{subject to} \quad Ax \leq b$$
$$\quad\quad\quad\quad\quad x \geq 0$$

其中 $A \in \mathbb{R}^{m \times n}$，$c \in \mathbb{R}^n$，$b \in \mathbb{R}^m$。

### 转化为标准不等式形式的步骤

| 问题 | 解决方法 |
|------|---------|
| 变量 $x_i \leq 0$ | 令 $\bar{x}_i = -x_i$，替换后得 $\bar{x}_i \geq 0$ |
| 变量 $x_i$ 无限制 | 令 $x_i = x_i^+ - x_i^-$，其中 $x_i^+, x_i^- \geq 0$ |
| 最小化问题 | 取负目标函数：$\min\, c^Tx \Rightarrow \max\, (-c^Tx)$ |
| $a^Tx \geq b$ | 乘以 $-1$：$-a^Tx \leq -b$ |
| $a^Tx = b$ | 替换为两个不等式：$a^Tx \leq b$ 和 $-a^Tx \leq -b$ |

### 可行解与最优解

**可行解（Feasible Solution）**：满足 $Ax \leq b$ 且 $x \geq 0$ 的解 $x$

**最优解（Optimal Solution）**：对最大化问题，满足 $c^Tx \geq c^Tx'$ 对所有其他可行解 $x'$ 成立的可行解

## 考试重点总结

1. **掌握数学规划的四个组成部分**
2. **能将任意线性规划转化为标准不等式形式**——这是高频考点
3. **理解可行解与最优解的区别**
4. **线性无关与秩的概念**——后续章节的基础
5. **无限制变量的处理**：$x_i = x_i^+ - x_i^-$
6. **等式约束的处理**：替换为两个不等式
