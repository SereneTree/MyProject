## 一、TCP/IP 五层模型回顾

```
应用层    ← 进程到进程（HTTP、SMTP 等）
传输层    ← 进程到进程（TCP、UDP）
网络层    ← 主机到主机（IP）       ← 本讲内容
数据链路层 ← 节点到节点（Ethernet）
物理层    ← 比特传输
```

---

## 二、三种通信类型

| 通信类型 | 所在层次 | 说明 |
|----------|----------|------|
| **主机到主机（Host-to-Host）** | 网络层 | 数据从源主机到目标主机全路径传输 |
| **进程到进程（Process-to-Process）** | 应用层 & 传输层 | 源进程到目标进程的消息传递 |
| **节点到节点（Node-to-Node）** | 数据链路层 | 从当前设备（主机/路由器）到下一个相邻设备 |

## 三、网络层的主要功能

### 3.1 封包化（Packetizing）

**发送方（源主机）**：
- 从传输层接收**段（Segment）**
- 添加网络层头部（包含源/目的 IP 地址）
- 形成**数据报（Datagram）**
- 向下传递给数据链路层

**接收方（目标主机）**：
- 从数据链路层接收数据报
- 去掉网络层头部（解封装）
- 将载荷（Segment）传递给传输层

> **关键规则**：路由器**不允许**对其收到的数据包解封装；路由器只检查头部中的地址信息，用于转发决策。

**分片重组**：
- 如果数据包在源主机或路由器处被分片，网络层负责等待所有分片到达，**重新组装**后再交给传输层。

### 3.2 转发（Forwarding）

> **转发**是路由器将数据包从**输入链路接口**传送到**适当的输出链路接口**的本地动作。

```
路由器 R1 接收来自输入端口的数据报
    ↓ 查找转发表（Forwarding Table）
找到匹配的出口接口
    ↓ 将数据报转发到下一个路由器 R2
```

**转发表（Forwarding Table）**：
- 每台路由器都有一张转发表
- 路由器检查到达数据包头部中的某个字段值（目的 IP 地址）
- 将该字段值作为索引，在转发表中查找对应的输出接口
- 将数据包转发到该输出接口

### 3.3 路由（Routing）

> **路由**是确定数据包从发送方到接收方所经路径（路线）的过程。

- **路由算法（Routing Algorithm）**：计算这些路径的算法
- 路由算法决定转发表中的内容
- 路由算法可以是**集中式**（在中心节点运行，下发给各路由器）或**分散式**（每台路由器各自运行部分算法）

**Dijkstra 算法（最短路径）**：
- 从源节点出发，找到到所有其他节点的最短路径
- 使用**加权图**建模网络（来自图论）
- 迭代地选择距离最小的顶点，更新其邻居的距离，标记为已访问

### 3.4 错误控制（Error Control）

- 网络层**不直接提供**错误控制
- 互联网使用辅助协议 **ICMP（Internet Control Message Protocol）** 处理部分错误（如数据报被丢弃或头部信息未知）
- 网络层在数据报头部添加了**校验和（Checksum）**字段，用于检测头部损坏（但不检测整个数据报）
- 不直接在网络层做完整错误控制的原因：数据包在路由器处可能被**分片**，使得该层的错误检查效率低下

### 3.5 流量控制（Flow Control）

- 网络层**不提供任何流量控制**
- 发送方在数据准备好时就发送数据报，不考虑接收方的接收状态
- 流量控制由传输层（TCP）负责

## 四、网络通信路径示例

以主机 H1 发送数据到主机 H2 为例：

```
H1（源主机）
  │ 1. 传输层段 → 封装成数据报
  │ 2. 发送给附近的路由器 R1
R1（中间路由器）
  │ 检查数据报头部 → 查找转发表 → 转发到输出链路
R2（中间路由器）
  │ 同样操作
H2（目标主机）
  │ 从附近路由器 R2 接收数据报
  │ 提取传输层段 → 交给传输层
```

**路由器的主要作用**：
- 检查所有经过的 IP 数据报的头部字段
- 将数据报从输入端口移动到输出端口
- 实现端到端路径上的数据报转发

---

## 五、网络层协议

**IP（Internet Protocol）**是网络层的主要协议：
- 定义网络层中使用的地址格式
- 负责将数据包从源路由到目的地（每台路由器将数据报转发给路径上的下一台路由器）

## 六、关键术语对比

| 术语 | 层次 | 数据单元名称 |
|------|------|-------------|
| 段（Segment） | 传输层 | TCP/UDP 数据包 |
| **数据报（Datagram）** | **网络层** | **IP 数据包** |
| 帧（Frame） | 数据链路层 | 链路层数据包 |
