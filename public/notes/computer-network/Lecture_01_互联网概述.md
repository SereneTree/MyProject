## 一、计算机网络

### 1.1 定义

计算机网络（Computer Network）是指**相互连接的计算设备**，能够彼此交换数据并共享资源。  
**协议（Protocol）**是网络设备在交换数据时必须遵守的一套规则。

### 1.2 计算机网络的主要应用

| 应用类型 | 说明 |
|----------|------|
| **通信** | 电子邮件、社交网络、视频会议 |
| **数据共享** | 多用户访问同一数据库 |
| **软件共享** | 服务器上的软件通过网络供多用户使用 |
| **硬件共享** | 打印机、扫描仪等设备共享 |

### 1.3 计算机网络的五大基本组件

| 组件 | 说明 |
|------|------|
| **发送方（Sender / Source Host）** | 发送消息的计算机 |
| **接收方（Receiver / Destination Host）** | 接收消息的计算机 |
| **消息（Message）** | 语音、视频、图像、数据 |
| **传输介质（Transmission Media）** | 有线（电缆）或无线（空气） |
| **协议（Protocol）** | 所有网络设备交换消息时必须遵守的规则集合 |

> **数据包（Packet）**：消息被分成若干独立传输的部分，称为数据包。

### 1.4 网络硬件设备

- **主机（Host / End System）**：大型计算机、台式机、笔记本电脑、工作站、手机等。分为源主机（发送方）和目标主机（接收方）。
- **交换机（Switch）**：连接同一网络内的多台设备，转发数据包，实现资源共享。
- **路由器（Router）**：连接多个交换机及其对应的网络，充当"调度员"，选择数据包传输的最优路径。
- **传输介质（Wired）**：
  - 双绞铜线（Twisted-Pair Copper Wire）
  - 同轴电缆（Coaxial Cable）
  - 光纤（Fiber Optics）

## 二、网络拓扑类型（按拓扑结构分类）

**网络拓扑（Network Topology）**：描述网络中各节点、设备和连接之间的排列关系。

| 拓扑类型 | 特征 | 优点 | 缺点 |
|----------|------|------|------|
| **星型（Star）** | 所有设备直接连接到中央交换机 | 单个节点故障不影响全网 | 中心交换机是单点故障 |
| **总线型（Bus）** | 所有设备连接到一条主干线（Bus） | 安装简单 | 主干线故障导致全网瘫痪 |
| **环型（Ring）** | 节点排成圆环，数据单向或双向流动 | 传输稳定 | 单点故障影响全环 |
| **网状型（Mesh / Fully Connected）** | 每个节点都与其他所有节点直接相连 | 可靠性最高 | 成本高，配置复杂 |
| **混合型（Hybrid）** | 结合两种或多种拓扑结构 | 灵活，适应大型企业 | 设计复杂 |

## 三、网络规模类型（按地理范围分类）

| 类型 | 全称 | 覆盖范围 | 典型场景 |
|------|------|----------|----------|
| **LAN** | Local Area Network（局域网） | 建筑物、办公室、家庭 | 办公室网络，使用交换机连接 |
| **WAN** | Wide Area Network（广域网） | 城市、国家乃至全球 | 互联网是最大的 WAN |

> 互联网（Internet）是世界上最大的 WAN，由成千上万个相互连接的网络组成。

## 四、互联网（Internet）

### 4.1 互联网上的应用

- 电子邮件（Gmail）
- 万维网（World Wide Web / WWW）
- 即时通讯（微信、WhatsApp）
- 文件共享
- 多人网络游戏
- 流媒体视频
- 网络电话（Skype）
- 视频会议（Teams）
- 多媒体（VoIP、YouTube、网络电视）

### 4.2 互联网服务提供商（ISP）层级结构

| 层级 | 名称 | 说明 |
|------|------|------|
| **Tier 1（国际 ISP / 骨干网）** | 国际 ISP | Sprint、Verizon、AT&T、NTT 等大型电信公司，通过对等点（Peering Points）互联 |
| **Tier 2（区域 ISP / 提供商网络）** | 区域 ISP | 规模较小，连接到国际 ISP 或其他区域 ISP |
| **Tier 3（住宅 ISP / 客户网络）** | 住宅/本地 ISP | 网络边缘，直接为终端用户服务，向区域 ISP 支付费用 |

**ISP 提供的服务**：互联网接入、电子邮件、域名注册、网站托管、数据中心服务、网站开发等。

## 五、互联网接入方式

| 接入方式 | 传输介质 | 特点 |
|----------|----------|------|
| **DSL（数字用户线路）** | 现有电话线（双绞铜线） | 由本地电话公司提供；数据和语音同时传输；需要 DSL 调制解调器和 DSLAM |
| **Cable 宽带** | 有线电视线路（同轴/光纤混合） | 速度较快，但与邻居共享带宽，速度受影响 |
| **光纤宽带（Fibre）** | 光纤 | 速度最快，延迟最低 |
| **Wi-Fi（无线 LAN）** | 无线电波 | IEEE 802.11 标准；覆盖范围约数十米；需要接入点（AP） |
| **卫星（Satellite）** | 卫星信号 | 偏远地区使用；延迟较高 |
| **无线 WAN（3G/4G）** | 蜂窝网络 | 需在基站几十公里范围内；速度超过 1 Mbps |

## 六、网络延迟（Network Delay）

数据包从源主机到目标主机的总延迟由四部分组成：

$$\text{总延迟} = \text{传输延迟} + \text{传播延迟} + \text{处理延迟} + \text{排队延迟}$$

### 6.1 传播延迟（Propagation Delay）

> 一个比特从发送端传播到接收端所需的时间。

$$\text{传播延迟} = \frac{D}{S}$$

- **D**：发送方与接收方之间的距离  
- **S**：传播速度（光速量级，约 $2.4 \times 10^8$ m/s）

**例题**：距离 48,000 km，传播速度 $2.4 \times 10^8$ m/s  
$$\text{传播延迟} = \frac{48000 \times 10^3}{2.4 \times 10^8} = 200 \text{ ms}$$

### 6.2 传输延迟（Transmission Delay）

> 发送方将数据包的所有比特放入链路所需的时间。

$$\text{传输延迟} = \frac{L}{R}$$

- **L**：数据包长度（bits）  
- **R**：链路传输速率（bits/s）

**例题**：100 Mbps 的以太网，数据包 10,000 bits  
$$\text{传输延迟} = \frac{10{,}000}{100{,}000{,}000} = 100 \text{ μs}$$

### 6.3 两种延迟的区别

| 延迟类型 | 影响因素 | 与距离的关系 |
|----------|----------|-------------|
| 传播延迟 | 距离、传播速度 | 正相关 |
| 传输延迟 | 数据包大小、链路速率 | 与距离无关 |
