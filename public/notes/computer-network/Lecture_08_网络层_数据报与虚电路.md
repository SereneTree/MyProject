## 一、分组交换（Packet Switching）

> **分组交换**：数据包在网络层的路由和转发过程。

- 上层数据被分成多个可管理的**数据包**，每个包独立发送
- 源主机逐包发送；目标主机逐包接收（**不一定按序**）
- 目标主机等待同一消息的所有包到达后，再向上层交付

### 分组交换设备

| 设备 | 工作层次 | 转发依据 |
|------|----------|----------|
| **路由器（Router）** | 网络层 | 网络层数据包头部（IP 地址） |
| **交换机（Switch）** | 数据链路层 | 数据链路层帧中的字段（MAC 地址） |

---

## 二、两种分组交换服务类型

| 类型 | 说明 | 网络类型 |
|------|------|----------|
| **无连接服务（Connectionless）** | 无握手前置步骤 | 数据报网络（Datagram Network） |
| **面向连接服务（Connection-oriented）** | 先建立逻辑连接，再传输 | 虚电路网络（Virtual-Circuit Network） |

---

## 三、数据报网络（无连接服务）

### 3.1 工作原理

- 网络层协议将**每个数据包独立**处理，数据包之间无关联
- 网络层只负责将数据包从源传递到目标
- 同一消息的不同数据包**可能走不同路径**，**可能乱序**到达

### 3.2 转发过程

```
终端主机 → 数据包（携带目的地址）→ 互联网
每台路由器：
  接收数据包
    ↓ 用目的地址查找转发表
    ↓ 找到对应出口接口
    ↓ 转发到下一路由器
```

### 3.3 转发表更新

- 路由算法每隔 1~5 分钟更新转发表
- 由于转发表可随时更改，同一消息的数据包可能**走不同路径**并**乱序到达**

### 3.4 最长前缀匹配（Longest Prefix Matching）

当路由器的转发表对同一数据包的目的地址有**多个匹配项**时：
- 路由器使用**最长匹配前缀**的条目

**示例**：
- 转发表有 4 条目，假设目的地址 `11001000 00010111 00010110 10100001`
- 可能同时匹配 `/21` 和 `/24` 前缀
- 路由器选择 `/24`（更长、更精确）

## 四、虚电路网络（面向连接服务）

### 4.1 概念

> **虚电路（Virtual Circuit / VC）**：在发送数据报前，先建立一条从源到目标的虚拟路径；此后所有数据包沿**同一路径**传输。

- 数据包包含**流标签（Flow Label）/ VC 号（VC Number）**，标识虚拟路径
- 每台路由器可能为同一虚电路分配不同的 VC 号，经过每台路由器时**替换** VC 号

### 4.2 虚电路的三个组成要素

1. 从源主机到目标主机的**路径**（一系列链路和路由器）
2. 路径上每条链路的 **VC 号（流标签）**
3. 路径上每台路由器的**转发表条目**

### 4.3 虚电路的三个阶段

#### 阶段一：建立（Setup Phase）

1. 发送方传输层联系网络层，指定接收方地址
2. 网络层确定源到目标之间的**完整路径**（所有链路和路由器）
3. 为路径上的**每条链路**确定 VC 号
4. 在路径上的**每台路由器**的转发表中添加对应条目

**请求数据包传播过程**（A→B）：
```
A 发送请求包 → R1 → R3 → R4 → B

每台路由器填写转发表（三列）：
  入端口、入标签（VC#）、出端口
  （出标签在收到确认包后填写）
```

**确认数据包回传过程**（B→A）：
```
B 分配入标签（如 77）→ 确认包 R4 → R3 → R1 → A

每台路由器填写出标签（= 下一跳路由器选择的入标签）
```

#### 阶段二：数据传输（Data Transfer Phase）

- 所有数据包沿**同一路径**传输
- 每经过一台路由器，**VC 号被替换**为该路由器转发表中对应的出标签
- 数据包**按序到达**目标

**标签替换示例**（A→B）：
```
A → 标签14 → R1 → 替换为66 → R3 → 替换为22 → R4 → 替换为77 → B
```

#### 阶段三：拆除（Teardown Phase）

1. 源主机 A 发送完所有数据包后，发送**拆除数据包（Teardown Packet）**
2. 目标主机 B 响应**确认数据包**
3. 路径上所有路由器**删除**对应的转发表条目

## 五、数据报网络 vs 虚电路网络

| 对比项 | 数据报网络（Datagram） | 虚电路网络（Virtual Circuit） |
|--------|----------------------|-------------------------------|
| 连接类型 | 无连接 | 面向连接 |
| 路径 | 每包可能不同 | 所有包走同一路径 |
| 转发依据 | 目的 IP 地址（最长前缀匹配） | VC 号（流标签） |
| 数据包顺序 | 可能乱序 | 按序到达 |
| 建立开销 | 无 | 有（Setup + Teardown） |
| 成本 | 较低 | 较高 |
| 典型应用 | **互联网（IP 网络）**，数据业务 | **ATM 网络**，电话通话 |

## 七、核心概念图示

```
数据报网络：
  源 → [包1: path A→B→C] → 目标
  源 → [包2: path A→D→C] → 目标   （不同路径，可能乱序）

虚电路网络：
  建立：A → R1(VC:14) → R3(VC:66) → R4(VC:22) → B(VC:77)
  传输：所有包沿固定路径，VC 号逐跳替换
  拆除：A 发 teardown 包 → 所有路由器清除表项
```
