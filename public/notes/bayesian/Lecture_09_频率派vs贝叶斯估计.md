## 一、点估计

### 1.1 核心框架

- **频率派**：θ 固定未知，从采样分布 $f(\hat\theta|\theta)$ 评估估计量
- **贝叶斯**：θ 是随机变量，从后验 $p(\theta|Y)$ 评估估计量

### 1.2 评估标准

#### 频率派

$$\text{偏差：}\text{Bias}[\hat\theta_f,\theta] = E[\hat\theta_f] - \theta$$

- **无偏估计量**：$E[\hat\theta_f] = \theta$（偏差为 0）
- **最小方差无偏估计（MVUE）**：所有无偏估计量中方差最小的

$$\text{MSE}[\hat\theta_f] = \text{Bias}^2 + \text{Var}[\hat\theta_f]$$

#### 贝叶斯

$$\text{PMSE}[\hat\theta] = \int(\theta-\hat\theta)^2 p(\theta|Y)\,d\theta = \text{Var}[\theta|Y] + (E[\theta|Y]-\hat\theta)^2$$

PMSE 由**后验均值**最小化：$\hat\theta_b = E[\theta|Y]$

### 1.3 二项数据对比例

**数据**：$Y \sim \text{Bin}(n,\theta)$，先验 $\theta \sim \text{Beta}(1,1)$

| | 频率派 $\hat\theta_f = Y/n$ | 贝叶斯 $\hat\theta_b = (1+Y)/(2+n)$ |
|--|---------------------------|-------------------------------------|
| 偏差 | 0 | $(1-2\theta)/(2+n)$ |
| 方差 | $\theta(1-\theta)/n$ | $n\theta(1-\theta)/(2+n)^2$ |
| MSE | $\theta(1-\theta)/n$ | 偏差² + 方差 |

- 当 θ 接近先验均值 0.5 时：贝叶斯估计量 MSE 更小
- 当 θ 远离先验均值时：频率派估计量更优

> **教训**：先验选择错误会使贝叶斯估计量更差，而非更好。

## 二、区间估计

### 2.1 频率派置信区间

**定义**：若无限次重复实验，构建的 95% 置信区间中有 **95% 包含真值 θ**。

$$\hat\theta_f \pm z_{1-\alpha/2} \cdot \text{s.d.}(\hat\theta_f)$$

**不能**说"θ 在此区间的概率为 95%"（频率派中 θ 是固定的）。

### 2.2 贝叶斯可信区间

**定义**：$P(a \leq \theta \leq b | Y) = 95\%$

$$E[\theta|Y] \pm z_{1-\alpha/2} \cdot \sqrt{\text{Var}[\theta|Y]}$$

**可以**直接说"θ 在此区间的概率为 95%"（贝叶斯中 θ 是随机变量）。

### 2.3 最高密度区间（HDR）

**HDR**：包含 α% 后验概率的**最短**区间，区间内每点的密度高于区间外每点。

$$P(\theta \in R|Y) = \alpha, \quad p(\theta^*|Y) \geq p(\theta^{**}|Y) \; \forall\, \theta^* \in R, \theta^{**} \notin R$$

| | 等尾区间 | HDR |
|--|---------|-----|
| 计算方式 | 各尾截去 α/2 | 取最高密度区域 |
| 长度 | 不一定最短 | **最短** |
| 对称后验 | 两者相同 | 两者相同 |
| 偏斜/双峰后验 | 可能包含低密度区域 | 排除低密度区域，更有信息量 |

### 2.4 HDR 计算（正态近似）

当 n 较大，后验近似对称时：

$$\text{95% HDR} = E[\theta|Y] \pm 1.96\sqrt{\text{Var}[\theta|Y]}$$

### 2.5 综合例题：图书馆调查

**设定**：$n=50$ 学生，$y=18$ 人每日使用图书馆，$\theta \sim \text{Beta}(1,1)$

后验：$\theta|Y \sim \text{Beta}(19,33)$，$E[\theta|Y] = 19/52 = 0.365$，$\text{Var} = 0.00443$

| 方法 | 95% 区间 | 解读 |
|------|---------|------|
| 频率派 CI | (0.227, 0.493) | 95% 的区间包含真值 θ |
| 贝叶斯可信区间 | (0.235, 0.495) | θ 在此区间的概率为 95% |
| 贝叶斯 HDR | (0.235, 0.495) | 同上（后验近似对称） |

## 三、假设检验

### 3.1 对比框架

| | 频率派 | 贝叶斯 |
|--|--------|--------|
| 逻辑 | 矛盾反证法 | 低概率反证 |
| 依据 | p 值 = $P(\text{数据}\geq y|H_0)$ | $P(H_0|Y)$（后验概率） |
| 时序 | 数据前（pre-data） | 数据后（post-data） |
| 能否直接说 "$H_0$ 为真的概率" | ✗ | ✓ |

### 3.2 单侧检验

$H_0: \pi \leq \pi_0$ vs $H_1: \pi > \pi_0$

**例**：新药，$\pi_0 = 0.6$，$n=10$，$y=8$

- 频率派：$\text{p值} = P(Y \geq 8|\pi=0.6) = 0.1672 > 0.05$ → 不拒绝 $H_0$
- 贝叶斯（先验 $\pi\sim\text{Beta}(1,1)$，后验 $\pi|Y\sim\text{Beta}(9,3)$）：
  $$P(\pi \leq 0.6|Y=8) = \int_0^{0.6}\text{Beta}(9,3)\,d\pi = 0.1189 > 0.05$$ → 不拒绝 $H_0$

### 3.3 双侧检验

$H_0: \pi = \pi_0$ vs $H_1: \pi \neq \pi_0$

- **频率派**：计算双尾 p 值，或检查置信区间是否包含 $\pi_0$
- **贝叶斯**：计算可信区间 [c,d]；若 $\pi_0 \in [c,d]$ 则不拒绝 $H_0$

> **注意**：由于后验为连续分布，$P(\pi = \pi_0|Y) = 0$，因此贝叶斯双侧检验必须用可信区间。

### 3.4 检察官谬误（Prosecutor's Fallacy）

$$P(\text{数据}|H_0) \neq P(H_0|\text{数据})$$

- p 值回答："假设 $H_0$ 为真，看到这么极端的数据的概率是多少？"
- 贝叶斯后验回答："给定数据，$H_0$ 为真的概率是多少？"（**这才是真正想知道的**）

## 四、频率派 vs 贝叶斯总结

| | 频率派 | 贝叶斯 |
|--|--------|--------|
| θ 的性质 | 固定未知 | 随机变量 |
| 点估计 | 最小 MSE：$\hat\theta_f$ | 后验均值：$\hat\theta_b = E[\theta|Y]$ |
| 区间估计 | 置信区间 | 可信区间 / HDR |
| 区间解读 | 95% 的重复区间包含 θ | θ 在此区间的概率为 95% |
| 假设检验 | p 值（数据前） | $P(H_0|Y)$（数据后） |
