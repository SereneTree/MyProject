## 一、正态-正态共轭（连续先验）

### 模型设定

$$Y_1,\dots,Y_n|\mu \sim \text{i.i.d.}\; N(\mu,\sigma_0^2) \quad (\sigma_0^2\text{ 已知})$$

$$\mu \sim N(m, s^2) \quad (\text{先验})$$

### 后验分布

$$\boxed{\mu|Y \sim N\!\left(\frac{n\bar{y}/\sigma_0^2 + m/s^2}{n/\sigma_0^2 + 1/s^2},\;\; \frac{1}{n/\sigma_0^2 + 1/s^2}\right)}$$

### 后验均值的直觉解读

$$\text{后验均值} = \underbrace{\frac{n/\sigma_0^2}{n/\sigma_0^2 + 1/s^2}}_{\text{数据权重}}\,\bar{y} \;+\; \underbrace{\frac{1/s^2}{n/\sigma_0^2 + 1/s^2}}_{\text{先验权重}}\,m$$

**后验均值 = 样本均值与先验均值的精度加权平均**

| 情形 | 影响 |
|------|------|
| n 增大 | 数据权重增大，后验均值趋向 $\bar{y}$ |
| $s^2$ 减小（先验越紧） | 先验权重增大，后验均值趋向 $m$ |
| $\sigma_0^2/s^2$ 越大 | 先验对后验的影响越大 |

## 二、精度（Precision）的概念

**精度** = 方差的倒数：$\tau = 1/\sigma^2$

精度越大 → 分布越窄 → 不确定性越小

正态-正态更新的精度规则：

$$\underbrace{\frac{1}{s'^2}}_{\text{后验精度}} = \underbrace{\frac{1}{s^2}}_{\text{先验精度}} + \underbrace{\frac{n}{\sigma_0^2}}_{\text{数据精度}}$$

> **精度相加**：每增加一批数据，后验精度单调递增（不确定性单调减小）。

## 三、共轭先验

### 定义

若先验 $p(\theta) \in \mathcal{P}$，则后验 $p(\theta|Y)$ 也属于 $\mathcal{P}$，则称 $\mathcal{P}$ 是关于该采样模型的**共轭先验族**。

### 共轭先验汇总表

| 数据（似然） | 共轭先验 | 后验 |
|------------|----------|------|
| Binomial(n,θ) | **Beta(a,b)** | Beta(a+y, b+n-y) |
| Poisson(μ) | **Gamma(a,b)** | Gamma(a+Σy, b+n) |
| Normal(μ,σ₀²)（μ未知） | **N(m,s²)** | N(精度加权均值, 精度之和的倒数) |

**选择共轭先验的原因**：后验有解析闭合形式，计算简便。

## 四、先验参数的确定

### 方法 A：模糊先验（vague prior）

对 θ 无强烈信息 → 选参数使分布"宽泛"

- Beta：a = b = 1（均匀分布）；或 a, b 较小
- Gamma：b' 较小（方差大）
- Normal：s² 很大（方差大）

### 方法 B：根据先验均值和先验标准差确定参数

若已知先验均值 $E[\theta] = \theta_0$，先验标准差 $\text{s.d.}[\theta] = \sigma_0$，则：

#### Beta(a,b) 先验（二项数据）

$$\frac{a}{a+b} = \theta_0, \qquad \sqrt{\frac{ab}{(a+b)^2(a+b+1)}} = \sigma_0$$

联立解出 a, b。

**例**：Anna 认为 $E[\theta] = 0.2$，$\sigma_0 = 0.08$  
→ 解出 $a = 4.8$，$b = 19.2$，即 $\theta \sim \text{Beta}(4.8, 19.2)$

#### Gamma(a',b') 先验（泊松数据）

$$\frac{a'}{b'} = \theta_0, \qquad \sqrt{\frac{a'}{b'^2}} = \sigma_0$$

联立解出 a', b'。

**例**：Chase 认为交通事故均值 $E[\mu] = 2.5$，$\text{s.d.}[\mu] = 1$  
→ 解出 $a' = 6.25$，$b' = 2.5$，即 $\mu \sim \text{Gamma}(6.25, 2.5)$

## 五、先验强弱与数据的关系

| 先验特征 | 含义 |
|----------|------|
| 小方差（紧的先验） | 先验信息量大，需要更多数据才能改变后验 |
| 大方差（松散先验） | 先验信息量小，后验主要由数据决定 |
| n 很大 | 无论先验如何，后验都趋近于数据 |

> **关键洞察**：当数据量足够大，不管选什么合理的先验，后验结果都会趋于一致！
