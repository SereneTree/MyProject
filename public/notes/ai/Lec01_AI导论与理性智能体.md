## 一、什么是人工智能？

### AI的四种定义视角

| 视角 | 描述 |
|------|------|
| 像人一样思考 | 模拟人类思维过程 |
| 像人一样行动 | 通过图灵测试 |
| 理性地思考 | 基于逻辑推理 |
| **理性地行动** | **本课程采用的核心定义** |

### 理性决策（Rational Decisions）

- **理性**：最大化预定义目标
- 目标用结果的**效用（utility）**表达
- 世界是不确定的，因此使用**期望效用（expected utility）**
- **理性的行为 = 最大化期望效用**

> 本课程更准确的名称应该是"计算理性（Computational Rationality）"

### 大脑与AI

- 人类大脑善于理性决策，但并不完美
- 大脑不像软件那样模块化，难以逆向工程
- 人脑约100万亿突触 vs ChatGPT4约1.8万亿参数
- 大脑可以启发AI，但AI可以在某些任务上超越大脑

## 四、理性智能体（Rational Agents）

### 智能体的定义

- **智能体（Agent）**：感知并行动的实体
- **理性智能体**：选择最大化（期望）效用的行动
- 感知、环境、行动空间的特征决定选择理性行动的技术

### 智能体结构

```
智能体 ←→ 传感器(Sensors) → 感知(Percepts)
  ↓
执行器(Actuators) → 行动(Actions)
  ↓
环境(Environment)
```

### 环境类型对智能体设计的影响

| 环境特征 | 智能体需求 |
|----------|-----------|
| 部分可观察 | 需要记忆（内部状态） |
| 随机性 | 需要准备应对意外 |
| 多智能体 | 可能需要随机行为 |
| 静态 | 有时间计算理性决策 |
| 连续时间 | 持续运行的控制器 |
| 未知物理规律 | 需要探索 |
| 未知性能度量 | 观察/与人类交互 |

## 五、课程主题概览

本课程涵盖理性智能体的四大核心组件：

| 组件 | 核心问题 |
|------|----------|
| **搜索与规划** | 如何利用世界模型找到行动序列来达成目标？ |
| **强化学习** | 如何找到规则（策略）使每种情况下的决策最优？ |
| **概率与推理** | 如何理解世界中的不确定性？ |
| **监督学习** | 如何从数据中学习世界模型？ |

> **计算产生智能 vs 数据/经验产生智能** — 本课程覆盖两者
