## 主题2：搜索（1/2）— 无信息搜索

### 学习成果

- 将现实决策过程形式化为搜索问题
- 区分状态空间图与搜索树
- 执行DFS、BFS、UCS并追踪节点扩展顺序
- 评估完备性、最优性、时间/空间复杂度

### 搜索算法对比总结

| 算法 | 边缘 | 完备 | 最优 | 时间 | 空间 |
|------|------|------|------|------|------|
| DFS | 栈(LIFO) | 仅防循环时 | 否 | O(b^m) | O(b·m) |
| BFS | 队列(FIFO) | 是 | 仅成本为1 | O(b^s) | O(b^s) |
| UCS | 优先队列 | 是 | 是 | O(b^(C*/ε)) | O(b^(C*/ε)) |

## 主题2：搜索（2/2）— 有信息搜索

### 学习成果

- 解释启发式函数的作用
- 执行和评估贪婪搜索与A*搜索
- 验证可容许性 h(n) ≤ h*(n) 与一致性 h(A)-h(C) ≤ cost(A→C)
- 分析A*在树搜索和图搜索中的最优性条件
- 评估启发式优势 h_a ≥ h_c

### A*关键公式

$$f(n) = g(n) + h(n)$$

### 最优性条件

| 搜索 | 条件 |
|------|------|
| A*树搜索 | 启发式可容许 |
| A*图搜索 | 启发式一致 |
| UCS (h=0) | 两者都满足 |

## 主题3：博弈树（1/2）— Minimax与Alpha-Beta

### 学习成果

- 形式化对抗场景为零和博弈树
- 应用Minimax算法计算最优值
- 逐步追踪Alpha-Beta剪枝，更新α和β
- 识别剪枝分支并说明数学不等式
- 分析评估函数与深度受限搜索

### Minimax伪代码

```
value(state):
  终止 → 返回效用
  MAX → max-value(state)
  MIN → min-value(state)
```

### Alpha-Beta剪枝条件
- MIN节点：v ≤ α → 剪枝
- MAX节点：v ≥ β → 剪枝
- 完美排序：O(b^(m/2))

## 主题3：博弈树（2/2）— 不确定性

### 学习成果

- 使用Expectimax处理随机环境
- 计算机会节点的期望效用
- 对比Minimax（悲观）与Expectimax（乐观）
- 评估模型不匹配的后果

### Expectimax关键
- 机会节点：加权平均（期望值）
- 不能简单剪枝
- 模型假设必须匹配现实
