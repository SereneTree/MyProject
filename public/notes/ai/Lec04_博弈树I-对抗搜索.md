## 二、对抗博弈形式化

### 确定性博弈的定义

| 要素 | 定义 |
|------|------|
| 状态 | S（从s0开始） |
| 玩家 | P={1...N}（通常轮流行动） |
| 行动 | A（可能依赖于玩家/状态） |
| 转移函数 | S×A → S |
| 终止测试 | S → {true, false} |
| 终止效用 | S×P → R |
| 解 | 策略 π: S → A |

### 博弈类型

| 类型 | 特点 |
|------|------|
| **零和博弈** | 双方效用相反；一方最大化、一方最小化；纯竞争 |
| 一般和博弈 | 各方效用独立；合作、竞争皆有可能 |
| 团队博弈 | 所有成员共享收益 |

## 三、极小极大搜索（Minimax）

### 核心思想
- 确定性、零和博弈
- 一方最大化结果，另一方最小化结果
- 状态的**极小极大值**：面对理性对手时的最佳可达效用

### Minimax递归定义

```
value(state):
  若终止状态 → 返回效用
  若下一个为MAX → 返回 max-value(state)
  若下一个为MIN → 返回 min-value(state)

max-value(state):
  v = -∞
  对每个后继: v = max(v, value(successor))
  返回 v

min-value(state):
  v = +∞
  对每个后继: v = min(v, value(successor))
  返回 v
```

### 状态价值
- **终止状态**：效用值直接给出
- **MAX节点**：取子节点最大值
- **MIN节点**：取子节点最小值

### Minimax的性质
- 时间复杂度：O(b^m)
- 空间复杂度：O(b·m)
- 对完美对手最优，但非完美对手时不一定最好

## 四、Alpha-Beta剪枝

### 核心思想
- 不影响根节点的极小极大值计算
- 通过跟踪α和β值避免搜索不可能被选择的子树

### Alpha-Beta定义

| 参数 | 含义 |
|------|------|
| α | MAX沿当前路径到根的最佳选择（下界） |
| β | MIN沿当前路径到根的最佳选择（上界） |

### Alpha-Beta实现

```
max-value(state, α, β):
  v = -∞
  对每个后继:
    v = max(v, value(successor, α, β))
    若 v ≥ β → 返回 v   // 剪枝
    α = max(α, v)
  返回 v

min-value(state, α, β):
  v = +∞
  对每个后继:
    v = min(v, value(successor, α, β))
    若 v ≤ α → 返回 v   // 剪枝
    β = min(β, v)
  返回 v
```

### Alpha-Beta剪枝性质

| 属性 | 值 |
|------|-----|
| 正确性 | 不影响根的minimax值 |
| 子节点值 | 中间节点值可能有误 |
| 完美排序 | 时间复杂度降至O(b^(m/2))，可搜索深度翻倍 |
| 实际效果 | 仍无法完全搜索象棋等复杂游戏 |

> 这是一个**元推理（metareasoning）**的简单例子：计算关于该计算什么的计算

## 五、深度受限搜索

### 问题
- 现实博弈中无法搜索到叶节点

### 解决方案
- 搜索到有限深度
- 用**评估函数**替代终止效用

### 评估函数
- 理想：返回位置的实际minimax值
- 实践：特征的加权和
  - 例：f1(s) = 白方皇后数 - 黑方皇后数
  - 或更复杂的非线性函数（如神经网络），通过自博弈RL训练

### 地平线效应（Horizon Effect）
- 评估函数总有缺陷
- **深度越深，评估函数质量的影响越小**
- 这是特征复杂度与计算复杂度之间的重要权衡

### 吃豆人饿死问题（d=2）
- 深度2时，吃豆人现在吃和以后吃得分相同
- 没有看到更远处的得分机会 → 可能来回移动
- 解决：改进评估函数
