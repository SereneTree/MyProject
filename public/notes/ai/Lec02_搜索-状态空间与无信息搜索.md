# 第二讲：搜索——状态空间与无信息搜索

## 一、规划智能体 vs 反射智能体

### 反射智能体（Reflex Agents）
- 基于当前感知（可能有记忆）选择行动
- 不考虑行动的**未来后果**
- 只关心世界"现在是什么样"

### 规划智能体（Planning Agents）
- 考虑"如果...会怎样"
- 基于（假设的）行动后果做决策
- 必须有世界如何随行动演变的模型
- 必须制定目标（测试）
- 考虑世界"会变成什么样"
- 最优规划 vs 完备规划；规划 vs 重新规划

---

## 二、搜索问题（Search Problems）

### 搜索问题的组成要素

| 要素 | 说明 |
|------|------|
| 状态空间 | 所有可能的世界配置 |
| 后继函数 | 给定动作和成本，返回后继状态 |
| 起始状态 | 搜索的起点 |
| 目标测试 | 判断是否达到目标 |

- **解**：将起始状态转换为目标状态的动作序列（计划）

### 世界状态 vs 搜索状态

- **世界状态**：包含环境的所有细节
- **搜索状态**：只保留规划所需的信息（抽象）

> 例：吃豆人路径问题只需(x,y)位置；吃全部豆子问题需(x,y) + 豆子布尔值

---

## 三、状态空间图 vs 搜索树

### 状态空间图（State Space Graph）
- 节点 = （抽象的）世界配置
- 边 = 后继（行动结果）
- 每个状态**只出现一次**
- 通常太大无法完全存入内存

### 搜索树（Search Tree）
- 根节点 = 起始状态
- 子节点 = 后继
- 节点显示状态，但对应的是**到达该状态的计划**
- 搜索树中的节点 = 状态空间图中的路径
- 通常无法构建完整搜索树

### 核心区别

> 搜索树中有大量重复结构！状态空间图中每个状态只出现一次，但搜索树中同一状态可多次出现。

## 四、无信息搜索算法

### 搜索算法通用框架
- **边缘（Fringe）**：待考虑的部分计划
- **扩展（Expansion）**：展开潜在计划
- **探索策略**：选择扩展哪个边缘节点

### 4.1 深度优先搜索（DFS）

| 属性 | 值 |
|------|-----|
| 策略 | 扩展最深节点 |
| 实现 | 边缘为LIFO栈 |
| 时间复杂度 | O(b^m) |
| 空间复杂度 | O(b·m) |
| 完备性 | 仅在防止循环时完备 |
| 最优性 | **否** — 找到"最左"解，不考虑深度或成本 |

> b = 分支因子，m = 最大深度

### 4.2 广度优先搜索（BFS）

| 属性 | 值 |
|------|-----|
| 策略 | 扩展最浅节点 |
| 实现 | 边缘为FIFO队列 |
| 时间复杂度 | O(b^s) |
| 空间复杂度 | O(b^s) |
| 完备性 | **是** |
| 最优性 | 仅当所有成本为1时最优 |

> s = 最浅解的深度

### 4.3 迭代加深搜索（IDS）

- 思想：结合DFS的空间优势和BFS的时间/浅解优势
- 依次以深度限制1, 2, 3...运行DFS
- 看似浪费，但大部分工作在最深层
- 例：分支因子10，解在深度5：BFS需111,110节点，IDS需123,450节点

### 4.4 一致代价搜索（UCS）

| 属性 | 值 |
|------|-----|
| 策略 | 扩展成本最低的节点 |
| 实现 | 边缘为优先队列（优先级：累积成本） |
| 时间复杂度 | O(b^(C*/ε)) |
| 空间复杂度 | O(b^(C*/ε)) |
| 完备性 | **是**（假设最优解成本有限且最小弧成本为正） |
| 最优性 | **是** |

> C* = 最优解成本，ε = 最小弧成本

- UCS按递增成本等高线探索
- 优点：完备且最优
- 缺点：在所有"方向"探索，没有目标位置信息

---

## 五、统一视角：一个队列

所有搜索算法**本质相同**，只是边缘策略不同：
- DFS → 栈（LIFO）
- BFS → 队列（FIFO）
- UCS → 优先队列（按累积成本）

---

## 六、搜索与模型

- 搜索在**世界模型**上操作
- 智能体不会在真实世界中尝试所有计划
- 规划全在"模拟"中进行
- **搜索质量取决于模型质量**

---

## 考试重点

- 搜索问题的形式化定义
- 状态空间图与搜索树的区别
- DFS、BFS、UCS的完备性/最优性/复杂度对比
- 边缘数据结构的选择
- UCS等高线概念
