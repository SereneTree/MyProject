# 第七讲：马尔可夫决策过程I

## 一、网格世界（Grid World）示例

### 环境设置
- 智能体在网格中生活
- 墙壁阻挡路径
- **有噪声移动**：行动不总是按计划执行
  - 80%概率：执行预期方向
  - 10%概率：向左偏转
  - 10%概率：向右偏转
  - 碰墙则原地不动
- 每步获得奖励（可为负）
- 大奖励在终点（好或坏）
- **目标**：最大化奖励总和

---

## 二、MDP定义

### 马尔可夫决策过程的组成

| 要素 | 定义 |
|------|------|
| 状态集 S | 所有可能状态 |
| 行动集 A | 可用行动 |
| 转移函数 T(s,a,s') | 从s执行a到达s'的概率，即P(s'\|s,a) |
| 奖励函数 R(s,a,s') | 转移的奖励（有时简为R(s)或R(s')） |
| 起始状态 s₀ | 初始状态 |
| 终止状态 | 可能存在 |

### MDP = 非确定性搜索问题
- 可用Expectimax搜索解决
- 但我们有更好的工具

### "马尔可夫"的含义
- 给定当前状态，未来与过去**独立**
- 行动结果只依赖当前状态，不依赖历史

---

## 三、策略（Policies）

### 定义
- **策略 π: S → A**：给每个状态指定一个行动
- **最优策略 π***：最大化期望效用
- 显式策略定义了一个**反射智能体**

### 不同奖励下的最优策略

| 生活奖励 | 策略特点 |
|----------|----------|
| R = -2.0 | 尽快退出（不惜代价） |
| R = -0.4 | 倾向于快速到达终点 |
| R = -0.03 | 谨慎但愿意绕远 |
| R = -0.01 | 几乎不在意时间，避免风险 |

---

## 四、赛车示例（Racing）

### 状态与行动
- 状态：Cool、Warm、Overheated
- 行动：Slow、Fast

| 状态 | 行动 | 后继 | 概率 | 奖励 |
|------|------|------|------|------|
| Cool | Slow | Cool | 1.0 | +1 |
| Cool | Fast | Cool | 0.5 | +2 |
| Cool | Fast | Warm | 0.5 | +2 |
| Warm | Slow | Cool | 0.5 | +1 |
| Warm | Slow | Warm | 0.5 | +1 |
| Warm | Fast | Overheated | 1.0 | -10 |
| Overheated | — | (end) | 1.0 | 0 |

---

## 五、奖励序列的效用

### 时间偏好
- **更多还是更少？** → 更多
- **现在还是以后？** → 现在

### 折扣（Discounting）

$$U([r_0, r_1, r_2, ...]) = r_0 + \gamma r_1 + \gamma^2 r_2 + ...$$

- γ ∈ (0, 1]：折扣因子
- 越早的奖励权重越大
- 帮助算法收敛

### 折扣计算示例
- γ = 0.5：
  - U([1,2,3]) = 1×1 + 0.5×2 + 0.25×3 = 2.75
  - U([3,2,1]) = 1×3 + 0.5×2 + 0.25×1 = 5.25
  - U([1,2,3]) < U([3,2,1])

### 平稳偏好定理
- 若假设平稳偏好，则效用只有两种定义方式：
  - 加性效用（γ = 1）
  - 折扣效用（γ < 1）

### 无限效用问题
- 游戏可能永远持续 → 奖励无限？
- 解决方案：
  - 有限视野：固定T步后终止
  - 折扣：0 < γ < 1
  - 吸收状态：保证最终到达终止状态

## 六、MDP搜索树

- 每个MDP状态投射出类似Expectimax的搜索树
- **状态（State）**：s
- **Q状态（Q-state）**：(s, a) — 已选行动但结果未定
- **转移（Transition）**：(s, a, s')

### Expectimax的问题
1. 状态重复 → 需要缓存
2. 树无限延伸 → 需要深度受限计算
3. γ < 1时深层部分最终不重要

---

## 七、时间受限的值（Time-Limited Values）

### 关键思想
- 定义 $V_k(s)$ = 若游戏在k步后结束时s的最优值
- 等价于从s出发的深度k Expectimax值

### 值的收敛
- k = 0：所有值为0
- k = 1, 2, 3, ...：逐层计算
- k → ∞：值收敛到最优值

---

## 八、值迭代（Value Iteration）

### 算法

1. 初始化：$V_0(s) = 0$
2. 迭代更新：
$$V_{k+1}(s) = \max_a \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma V_k(s')]$$
3. 重复直到收敛

### 性质
- 每次迭代复杂度：O(S²A)
- **定理**：收敛到唯一最优值
- 策略可能在值完全收敛之前就已收敛

### 赛车示例计算

| k | Cool | Warm | Overheated |
|---|------|------|------------|
| 0 | 0 | 0 | 0 |
| 1 | 2 | 1 | 0 |
| 2 | 3.5 | 2.5 | 0 |
| ... | | | |

**最优策略**：π*(Cool) = Fast, π*(Warm) = Slow

---

## 九、最优量（Optimal Quantities）

| 量 | 定义 | 含义 |
|----|------|------|
| V*(s) | 从s出发并最优行动的期望效用 | 状态值 |
| Q*(s,a) | 从s执行a后并最优行动的期望效用 | Q值 |
| π*(s) | 从s出发的最优行动 | 最优策略 |
