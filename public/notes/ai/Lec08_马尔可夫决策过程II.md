# 第八讲：马尔可夫决策过程II

## 一、MDP回顾

### MDP组成

| 要素 | 说明 |
|------|------|
| 状态 S | 所有可能状态 |
| 行动 A | 可用行动 |
| 转移 P(s'\|s,a) | 转移概率 |
| 奖励 R(s,a,s') | 转移奖励（含折扣γ） |
| 起始状态 s₀ | 初始状态 |

### 关键量

| 量 | 含义 |
|----|------|
| 策略 π | 状态到行动的映射 |
| 效用 | 折扣奖励之和 |
| V值 | 从状态出发的期望未来效用（max节点） |
| Q值 | 从Q状态出发的期望未来效用（chance节点） |

---

## 二、Bellman方程

### 核心思想
> 最优的两步：1. 选择正确的第一步行动；2. 保持最优

### Bellman方程

$$V^*(s) = \max_a \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma V^*(s')]$$

$$Q^*(s,a) = \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma V^*(s')]$$

$$V^*(s) = \max_a Q^*(s,a)$$

- Bellman方程**刻画**了最优值
- 值迭代**计算**了最优值
- 值迭代就是Bellman方程的定点求解方法

### 收敛性
- 情况1：树有最大深度M → V_M持有实际值
- 情况2：γ < 1
  - V_k 和 V_{k+1} 的差距 ≤ γ^k × max|R|
  - 当k增大时，值收敛

## 三、策略评估（Policy Evaluation）

### 固定策略下的树
- 如果固定策略π(s)，搜索树更简单 — 每个状态只有一个行动
- 但树的值取决于固定了哪个策略

### 固定策略的效用

$$V^\pi(s) = \sum_{s'} T(s, \pi(s), s') [R(s, \pi(s), s') + \gamma V^\pi(s')]$$

### 计算方法
1. **迭代法**：将递归Bellman方程转为更新（类似值迭代），O(S²)每次迭代
2. **线性方程组**：没有max运算，Bellman方程就是线性方程组 → 直接求解

---

## 四、策略提取（Policy Extraction）

### 从V值提取策略
- 拥有V*(s)后，如何行动？
- 需要做一步Expectimax（策略提取）

$$\pi^*(s) = \arg\max_a \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma V^*(s')]$$

### 从Q值提取策略
- 拥有Q*(s,a)后如何行动？**极其简单**：

$$\pi^*(s) = \arg\max_a Q^*(s,a)$$

> **重要教训**：从Q值选择行动比从V值更容易！

---

## 五、策略迭代（Policy Iteration）

### 值迭代的问题
1. 每次迭代O(S²A)，较慢
2. 每个状态的"max"很少变化
3. 策略往往在值收敛之前就已收敛

### 策略迭代算法

```
1. 策略评估：对固定策略π，计算V^π直到收敛
2. 策略改进：用V^π做一步前瞻，更新策略
3. 重复直到策略不变
```

### 策略评估公式
$$V^\pi(s) = \sum_{s'} T(s, \pi(s), s') [R(s, \pi(s), s') + \gamma V^\pi(s')]$$

### 策略改进公式
$$\pi'(s) = \arg\max_a \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma V^\pi(s')]$$

### 赛车示例（γ=0.5）

| 迭代 | Cool策略 | Warm策略 |
|------|----------|----------|
| π₀ | Slow | Slow |
| π₁ | Fast | Slow |
| π₂ | Fast | Slow |

→ 一次迭代就收敛到最优策略！

### 性质
- 仍然是最优的
- 在某些条件下收敛**快得多**

---

## 六、值迭代 vs 策略迭代对比

| 方面 | 值迭代 | 策略迭代 |
|------|--------|----------|
| 更新内容 | 每次更新值和（隐式）策略 | 分开评估和改进 |
| 每轮速度 | 考虑所有行动，较慢 | 评估快（固定行动）；改进慢（像值迭代） |
| 收敛 | 值和策略都收敛 | 策略先收敛就停止 |

### 本质相同
- 都是动态规划方法
- 都使用一步前瞻Expectimax片段
- 区别仅在于是否固定策略还是对所有行动取max

---

## 七、MDP算法总结

| 目标 | 方法 |
|------|------|
| 计算最优值 | 值迭代 或 策略迭代 |
| 计算特定策略的值 | 策略评估 |
| 从值得到策略 | 策略提取（一步前瞻） |

---

## 八、动态规划补充*

### 基本步骤
1. 定义问题，识别子问题
2. 构造递归解
3. 在表中记忆子问题的解
4. 使用记忆的解计算最优解

### 斐波那契示例
- 递归方法：F(2)被重复计算8次
- DP方法：自底向上填表，每个子问题只算一次

> 历史原因：1940年代"programming"指"表格方法"

---

## 九、规划需要模型！

### 离线规划（Offline Planning）
- 解MDP就是离线规划
- 通过计算确定所有量
- **需要知道MDP的细节**
- 不实际玩游戏

### 在线学习（Online Learning）
- MDP未知时，需要**实际行动**来获取信息
- 这就是强化学习

### 双臂老虎机示例
- 离线规划：知道概率 → 选红色
- 在线学习：不知道概率 → 需要探索

### 强化学习的关键概念
| 概念 | 说明 |
|------|------|
| 探索(Exploration) | 尝试未知行动获取信息 |
| 利用(Exploitation) | 利用已知信息做最优决策 |
| 遗憾(Regret) | 学习过程中不可避免的损失 |
| 采样(Sampling) | 需要重复尝试以获得好的估计 |
