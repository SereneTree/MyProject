## 一、MDP与RL方法全景

| 场景 | 目标 | 方法 |
|------|------|------|
| **已知MDP** | 计算V*, Q*, π* | 值迭代 / 策略迭代 |
| **已知MDP** | 评估固定策略π | 策略评估 |
| **未知MDP（基于模型）** | 计算V*, Q*, π* | 在近似MDP上做VI/PI |
| **未知MDP（基于模型）** | 评估固定策略π | 在近似MDP上做PE |
| **未知MDP（无模型）** | 计算V*, Q*, π* | **Q学习** |
| **未知MDP（无模型）** | 评估固定策略π | 值学习（直接评估/TD学习） |

## 二、Q学习回顾

### 更新公式

$$Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s,a) \right]$$

- 旧估计：Q(s,a)
- 样本建议：r + γ max_{a'} Q(s', a')
- 对两者做加权平均

### 离策略学习
- 收敛到最优策略，**即使样本来自次优策略**
- 收敛条件：充分探索 + 合适的学习率

---

## 三、探索 vs 利用

### 核心矛盾
- **探索**：尝试新事物
- **利用**：根据已有知识做最优
- **关键**：纯利用往往陷入局部最优，永远找不到最优策略！

### ε-贪心（ε-Greedy）

- 每步以概率ε随机行动
- 以概率1-ε按当前策略行动
- 问题：学习完成后仍在"乱动"
- 解决：随时间降低ε

### 探索函数（Exploration Functions）

- 更好的想法：探索**尚未确定好坏的区域**，最终停止探索
- 探索函数：取值估计u和访问次数n，返回乐观效用

$$f(u, n) = u + \frac{k}{n}$$

**修改的Q更新**：
$$Q(s,a) \leftarrow r + \gamma \max_{a'} f(Q(s',a'), N(s',a'))$$

- 注意：这会将"奖励"**反向传播**到通向未知状态的状态！

## 四、遗憾（Regret）

### 定义
- 遗憾 = （期望最优奖励） - （实际获得的期望奖励，包括早期次优性）
- 即使学到了最优策略，过程中仍犯错

### 最小化遗憾
- 不仅是学习到最优
- 而是**最优地学习到最优**
- 随机探索和探索函数最终都最优，但随机探索的遗憾更高

---

## 五、近似Q学习（Approximate Q-Learning）

### 问题：状态空间太大

- 基本Q学习维护所有Q值的表格
- 现实中不可能学习每个状态
- 状态太多无法在训练中全部访问
- 状态太多无法在内存中保存Q表

### 解决方案：泛化

- 从少量训练状态的经验中学习
- 将经验泛化到新的、相似的情况
- 这是机器学习的基本思想

---

## 六、特征表示（Feature-Based Representations）

### 状态特征
- 用特征向量描述状态
- 特征是状态到实数的函数（通常是0/1）

| 特征示例 | 说明 |
|----------|------|
| 到最近幽灵的距离 | f_GST |
| 到最近豆子的距离 | f_DOT |
| 幽灵数量 | 安全程度 |
| 是否在隧道中 | 0/1特征 |

### 线性值函数

$$Q(s,a) = w_1 f_1(s,a) + w_2 f_2(s,a) + ... + w_n f_n(s,a)$$

- **目标**：学习权重w
- **优点**：经验浓缩为少量有力数字
- **缺点**：共享特征的状态可能实际值差异很大

### 近似Q学习更新

$$w_i \leftarrow w_i + \alpha \left[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \right] f_i(s,a)$$

- 直觉：调整活跃特征的权重
- 若发生意外坏事件 → 归咎于活跃特征 → 偏好所有没有该特征的状态
- 形式化：在线最小二乘

---

## 七、Q学习与最小二乘*

### 线性近似 = 回归

- 用线性函数拟合Q值
- 优化目标：最小化预测与观察之间的误差

### 过拟合问题
- 多项式次数过高 → 过拟合
- 限制模型容量（特征数量）有助于泛化

---

## 八、策略搜索（Policy Search）

### 问题
- 好的特征策略（赢游戏、最大化效用）不一定是最好的V/Q近似
- Q学习的优先级：让Q值接近（建模）
- 行动选择的优先级：让Q值排序正确（预测）
- **解决方案**：直接学习最大化奖励的策略，而非预测奖励的值

### 简单策略搜索
1. 从初始线性值函数/Q函数开始
2. 微调每个特征权重，看策略是否改善
3. 需要运行多样本回合来评估

### 爬山法（Hill Climbing）
- 从任意起点开始
- 重复：移动到最优的邻居状态
- 若无更好邻居则停止

### 改进
- 随机重启：找到全局最优
- 随机侧移：逃离肩部

## 九、强化学习案例研究

### Atari游戏

| 要素 | 设定 |
|------|------|
| 状态 | 游戏屏幕图像（256^(84×84)） |
| 行动 | 方向键+按钮组合（18种） |
| 转移 | 游戏代码（无法访问） |
| 奖励 | 游戏分数（无法访问） |

→ 使用近似Q学习 + 神经网络 + ε-贪心探索

### 机器人运动

| 要素 | 设定 |
|------|------|
| 状态 | 摄像头图像 + N个关节角度 + 加速度计 |
| 行动 | N个电机命令（连续向量） |
| 转移 | 真实世界（无法访问） |
| 奖励 | 保持直立、前进速度等 |

→ 使用策略搜索或适配Q学习到连续行动
→ 先在模拟器中学习，再部署到真实世界

### 语言助手（如ChatGPT）

**步骤1**：训练大语言模型模仿人类文本
**步骤2**：用RL微调模型生成有用文本

| 要素 | 设定 |
|------|------|
| 状态 | 当前文字序列（100,000^1000种可能） |
| 行动 | 下一个词（100,000种选择） |
| 转移 | 简单追加 |
| 奖励 | 人类评分 → 学习奖励模型R̂ → 基于模型的RL |

→ 常用策略搜索（PPO），也在研究Q学习
