# 第九讲：强化学习I

## 一、强化学习概述

### MDP已知 vs 未知

| 方面 | MDP已知 | MDP未知（RL） |
|------|---------|---------------|
| 转移T | 已知 | 未知 |
| 奖励R | 已知 | 未知 |
| 解法 | 离线计算 | 需要实际行动 |

### 强化学习的核心挑战

| 概念 | 说明 |
|------|------|
| 探索(Exploration) | 必须尝试未知行动获取信息 |
| 利用(Exploitation) | 最终必须利用已知信息 |
| 遗憾(Regret) | 早期不可避免犯"错误"，损失奖励 |
| 采样(Sampling) | 可能需要重复多次获得好的估计 |
| 泛化(Generalization) | 一个状态学到的可能适用于其他状态 |

### RL基本框架

```
智能体 → 行动(a) → 环境
智能体 ← 状态(s), 奖励(r) ← 环境
```

- 接收奖励形式的反馈
- 智能体效用由奖励函数定义
- 必须学会行动以最大化期望奖励
- 所有学习基于观察到的结果样本

## 二、强化学习方法分类

| 方法 | 思路 |
|------|------|
| 1. 基于模型 | 学习模型，求解模型，执行解 |
| 2a. 直接评估 | 从经验学习值 |
| 2b. 时序差分学习 | 从经验学习值（增量更新） |
| 2c. Q学习 | 从经验学习Q值 |
| 3. 直接策略学习 | 直接学习策略 |

### 被动 vs 主动强化学习
- **被动RL**：固定策略下的策略评估
- **主动RL**：寻找最优策略（类似值迭代）

---

## 三、基于模型的学习（Model-Based RL）

### 核心思想
1. 基于经验学习近似MDP模型
2. 像学习到的模型是正确的一样求解

### 步骤
1. **学习经验MDP模型**
   - 对每个(s, a)统计出现s'的次数
   - 从计数直接估计T(s,a,s')
   - 经历转移时发现R(s,a,s')
2. **求解学到的MDP**
   - 使用值迭代或策略迭代

### 示例

从4个回合观察到的转移 → 学习到的转移概率：
- T(B, east, C) = 1.00
- T(C, east, D) = 0.75
- T(C, east, A) = 0.25

### 优缺点

| 优点 | 缺点 |
|------|------|
| 充分利用经验（低样本复杂度） | 大状态空间可能不可扩展 |
| | RL反馈循环可能放大小的模型误差 |
| | 部分可观察时更困难 |

---

## 四、无模型学习（Model-Free Learning）

### 核心思想

估计期望的两种方式：
1. **基于模型**：估计分布P(A)，计算期望
2. **无模型**：直接从样本估计期望

> 例：计算学生平均年龄
> - 模型法：估计每个年龄概率，加权求和
> - 无模型法：直接取样本平均

---

## 五、被动强化学习

### 直接评估（Direct Evaluation）

- **目标**：估计V^π(s)
- **方法**：使用回报（从s开始的实际折扣奖励之和），多次试验取平均

### 示例

| 状态 | 计算值 |
|------|--------|
| A | -10 |
| B | +8 |
| C | +4 |
| D | +10 |
| E | -2 |

### 直接评估的优缺点

| 优点 | 缺点 |
|------|------|
| 简单易懂 | 每个状态必须单独学习 |
| 不需要T和R的知识 | 忽略状态间的连接信息 |
| 极限下收敛到正确答案 | 学习时间长 |

> 如果B和E都在策略下到达C，它们的值怎么可以不同？→ 直接评估无法利用这种结构

---

## 六、时序差分学习（TD Learning）

### 核心思想
- 从每次经验中学习！
- 每经历一次转移(s, a, s', r)，更新V(s)
- 可能结果s'更频繁地贡献更新
- **移动平均**：将值向出现的后继值靠近

### TD更新规则

$$V(s) \leftarrow V(s) + \alpha [r + \gamma V(s') - V(s)]$$

其中：
- α：学习率
- r + γV(s')：样本值
- r + γV(s') - V(s)：TD误差

### 指数移动平均
- 最近的样本更重要
- 忘记过去（远处的过去值本来就不对）
- 递减学习率α可给出收敛平均

### TD值学习的问题
- TD值学习是无模型策略评估
- 但若要将值转化为（新）策略，需要T和R来做一步前瞻
- **解决方案**：学习Q值，而非V值 → 使行动选择也无需模型

---

## 七、主动强化学习

### 与被动RL的区别
- 完整RL：寻找最优策略（类似值迭代）
- 不知道T(s,a,s')和R(s,a,s')
- 你自己选择行动
- **根本权衡**：探索 vs 利用

---

## 八、Q值迭代

### 从值迭代到Q值迭代

**值迭代**：
$$V_{k+1}(s) = \max_a \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma V_k(s')]$$

**Q值迭代**：
$$Q_{k+1}(s,a) = \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma \max_{a'} Q_k(s', a')]$$

---

## 九、Q学习（Q-Learning）

### 核心思想
- 基于样本的Q值迭代
- 边行动边学习Q(s,a)值

### Q学习更新

收到样本(s, a, s', r)后：

$$Q(s,a) \leftarrow Q(s,a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s,a)]$$

其中：
- 旧估计：Q(s,a)
- 新样本估计：r + γ max_{a'} Q(s', a')
- α加权平均

### Q学习的惊人性质

> **Q学习收敛到最优策略 —— 即使样本来自次优策略！**

这叫做**离策略学习（off-policy learning）**

### 收敛条件
1. 必须充分探索
2. 学习率必须最终足够小
3. 但不能减小得太快
4. 极限下，行动选择方式不影响收敛

---

## 十、强化学习方法总结

| 方法 | 类型 | 特点 |
|------|------|------|
| 基于模型 | 学习模型+求解 | 高效利用经验，但可扩展性差 |
| 直接评估 | 无模型被动 | 简单但忽略状态连接 |
| TD学习 | 无模型被动 | 增量更新，但需模型做决策 |
| Q学习 | 无模型主动 | 直接学习Q值，无需模型选行动 |

### 尚未解决的问题
- 如何在不太多遗憾的情况下探索？
- 如何扩展到大规模问题（俄罗斯方块10^60，围棋10^172，星际争霸|A|=10^26）？
