# L2 回归 - 学习笔记

## 1. 回归问题概述

### 1.1 问题定义
- 回归是**监督学习**问题
- 目标：使用预测变量（predictors）预测**标签（label）** 的值
- 标签是**连续变量**
- 任务：找到最佳模型，将唯一标签分配给给定的预测变量集合
- 使用带标签样本的数据集构建模型

### 1.2 回归问题示例
1. 根据房屋位置、家庭规模、收入预测家庭能耗
2. 根据过去股价预测公司股票未来值
3. 根据速度和行驶时间预测行驶距离
4. 根据过去需求和汇率预测需求
5. 根据今天温度和气压预测明天温度
6. 根据BMI、饮酒、饮食、步数预测心脏疾病概率

## 2. 数学符号

| 符号 | 含义 |
|------|------|
| x | 预测变量属性 |
| y | 标签属性 |
| N | 样本数量，i 标识每个样本 |
| x_i | 第 i 个样本的预测变量 |
| y_i | 第 i 个样本的真实标签 |
| (x_i, y_i) | 第 i 个样本 |
| f(·) | 模型 |
| ŷ_i = f(x_i) | 第 i 个样本的预测标签 |
| e_i = y_i - ŷ_i | 第 i 个样本的预测误差 |

---

## 3. 质量度量

### 3.1 误差平方与质量指标

**误差平方**：e²_i = (y_i - ŷ_i)²

基于误差平方的两个数据集质量指标：

| 指标 | 公式 |
|------|------|
| **误差平方和（SSE）** | E_SSE = Σᵢ e²_i |
| **均方误差（MSE）** | E_MSE = (1/N) Σᵢ e²_i |

### 3.2 其他质量指标

| 指标 | 公式 | 含义 |
|------|------|------|
| **均方根误差（RMSE）** | E_RMSE = √(E_MSE) | 预测误差的样本标准差 |
| **平均绝对误差（MAE）** | E_MAE = (1/N) Σ|e_i| | 绝对预测误差的平均值 |
| **R²（决定系数）** | E_R = 1 - Σe²_i / Σ(y_i - ȳ)² | 可预测的响应方差比例 |

> R² 越接近1，模型解释力越强。

## 4. 回归模型

### 4.1 简单线性回归
- 一个预测变量 x，一个标签 y
- 模型：**f(x) = w₀ + w₁x**
- 两个参数：w₀（截距）和 w₁（斜率/梯度）
- 使用数据集调参，即**训练/拟合模型**

### 4.2 简单多项式回归
- 一般形式：**f(x_i) = w₀ + w₁x_i + w₂x²_i + ... + w_D x^D_i**
- D 为多项式的**阶数**
- D=1：线性族；D=2：二次族；D=3：三次族...
- **D 是一个超参数**：设定不同值得到不同的模型族

| 阶数 D | 参数数量 | 灵活性 |
|--------|---------|--------|
| 1（线性） | 2 | 低（只能生成直线） |
| 2（二次） | 3 | 中 |
| 3（三次） | 4 | 较高 |

### 4.3 多元回归
- 两个或更多预测变量
- 第 i 个样本的第 k 个预测变量记为 x_{i,k}

### 4.4 多元线性回归

**向量表示**：
- x_i = [1, x_{i,1}, x_{i,2}, ..., x_{i,K}]^T（常数1前置）
- w = [w₀, w₁, ..., w_K]^T

**模型**：f(x_i) = w^T x_i = w₀ + w₁x_{i,1} + ... + w_Kx_{i,K}

**设计矩阵 X 和标签向量 y**：
```
X = [1  x₁,₁  x₁,₂  ...  x₁,K]
    [1  x₂,₁  x₂,₂  ...  x₂,K]
    [⋮   ⋮     ⋮    ⋱    ⋮  ]
    [1  xN,₁  xN,₂  ...  xN,K]

y = [y₁, y₂, ..., yN]^T
```

预测标签向量：**ŷ = Xw**
误差向量：**e = y - ŷ**

---

## 5. 最小二乘解

### 5.1 解析解
最小化 E_MSE 的线性模型参数向量为：

> **w_best = (X^T X)^{-1} X^T y**

- 适用于简单和多元线性回归
- 也可用于多项式模型（将预测变量的幂次视为新的预测变量）
- 逆矩阵 (X^T X)^{-1} 存在的条件：X 的所有列线性无关

### 5.2 回归作为优化问题

**初始定义（Take 1）**：
> f_best(x) = arg min_f (1/N) Σᵢ (y_i - f(x_i))²

注意：这里仅定义了在数据集上最小化 MSE，没有考虑部署时的表现——后续会修正。

## 6. 其他回归模型

除线性和多项式模型外，还有：
- 指数模型
- 正弦模型
- 径向基函数（RBF）
- 样条函数

数学公式完全相同，只是 f(·) 的表达式不同。

## 7. 灵活性、可解释性与泛化

### 7.1 灵活性（Flexibility）
- 模型的**自由度/复杂度**描述其生成不同形状的能力
- 自由度通常与**参数数量**相关
- 线性模型（2个参数）不灵活，只能生成直线
- 三次模型（4个参数）比线性更灵活

### 7.2 可解释性（Interpretability）
- 不灵活的模型产生更简单、更易解释的解
- **灵活性 ↑ → 可解释性 ↓**，存在权衡

| 模型 | 可解释性示例 |
|------|------------|
| 线性模型 | "年龄越大，收入越高" |
| 多项式模型 | "青少年时期工资不变，20-50岁增加，然后..." |

### 7.3 训练数据集上的质量
- 灵活模型的训练误差通常更低
- 但训练误差低不代表部署时表现好

### 7.4 泛化（Generalisation）
泛化是模型将学习阶段学到的知识成功转化到部署阶段的能力。

### 7.5 欠拟合与过拟合

| 现象 | 训练误差 | 部署误差 | 原因 |
|------|---------|---------|------|
| **欠拟合** | 大 | 大 | 模型太刚性，无法捕捉底层模式 |
| **过拟合** | 小 | 大 | 模型太复杂，记住了无关细节 |
| **恰好** | 小 | 小 | 正确反映底层模式，忽略无关细节 |

> **关键**：泛化能力只能通过比较训练和部署性能来评估，不能仅看训练数据拟合情况。

---

## 8. 回归基本方法论总结

构建模型需要：
1. **训练数据集**
2. **可调模型**
3. **质量指标**
4. **优化过程**

模型的最终质量必须在部署阶段评估。

---

## 9. "回归"一词的由来

19世纪，Galton 观察到高个子父母的孩子往往比平均高——但不如父母高。Galton 称之为"回归向平庸"。现在称为**均值回归**。
