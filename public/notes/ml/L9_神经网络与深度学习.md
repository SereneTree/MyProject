# L9 神经网络与深度学习 - 学习笔记

## 1. 模式与结构

### 1.1 定义
- **模式（Pattern）**：数据中的规律性
- **结构（Structure）**：目标人群中的规律性
- 机器学习通过识别数据中的模式来发现底层结构
- 主要挑战：区分**相关模式**与**虚假模式**

### 1.2 短宽数据集 vs 高维数据
- 高维数据（属性多、样本少）是常见挑战
- 添加不相关属性不会相互抵消，而是表现为虚假模式

---

## 2. 维度灾难

### 2.1 问题
- 维度增加 → 数据变得更稀疏
- 不相关属性给随机性更多欺骗你的机会
- **添加更多属性可能使模型性能更差**

### 2.2 解决方案
- 使用特征选择技术降低维度
- 利用领域知识选择相关属性

---

## 3. 网格数据（Grid Data）

- 定义：排列在网格上的数据，值之间有邻域关系
- 示例：
  - 音频/语音信号：时间排列
  - 图像：空间排列
  - 图数据：节点连接邻居

---

## 4. 神经网络基础

### 4.1 历史
- 1940年代首次提出
- 70-80年代流行
- 90年代失宠（其他算法更好、参数多难训练、难分析）
- 2010年代复兴（优化改进、计算力增强、大数据、迁移学习）

### 4.2 定义
- 松散模仿人类神经系统的计算系统
- 功能：输入 x → 输出 ŷ = h_W(x)
- 权重 W 可调（训练）

### 4.3 感知器（Perceptron）
基本计算单元：

> **a = h(x^T w)**

- x：扩展向量 [1, x₁, x₂, ..., x_K]^T
- w：权重向量 [w₀, w₁, ..., w_K]^T
- w₀：偏置（bias）
- h(·)：**激活函数**（非线性的）

### 4.4 层（Layer）
- 一组使用相同输入的感知器
- L 个感知器 + K 个输入 → L × (K+1) 个权重

### 4.5 架构（Architecture）
- 描述层如何连接
- **输入层**：预测变量向量
- **隐藏层**：产生内部特征
- **输出层**：产生预测

### 4.6 神经网络
- 感知器按层排列，按架构连接
- 每个连接一个参数（权重）
- 每层产生中间特征
- **层数决定网络的深度**（浅层 vs 深层）

---

## 5. 感知器能做什么？

### 5.1 线性分类器
- 阶跃激活函数的感知器 = 线性分类器
- h_step(d) = 1 if d > 0, else 0

### 5.2 基本逻辑函数
| 逻辑函数 | 权重 | 输出 |
|---------|------|------|
| AND | w₀=-1.5, w_A=1, w_B=1 | 两输入都为1时输出1 |
| OR | w₀=-0.5, w_A=1, w_B=1 | 任一输入为1时输出1 |

### 5.3 增加深度获得新逻辑函数
- AND 感知器 + OR 感知器 → 可实现更复杂逻辑
- 示例：AND(OR(A,B), NOT(AND(A,B))) → XOR

### 5.4 网格模式检测器
- 感知器可检测图像中的水平/垂直边缘
- 增加深度可检测复杂模式（如十字形）

### 5.5 组合线性分类器与逻辑函数
- L_v（垂直线性边界）+ L_h（水平线性边界）+ AND/OR
- 可创建复杂决策区域

### 5.6 关键结论
- 单个感知器：线性边界、逻辑函数、网格模式检测器
- 连接感知器：复杂边界、复杂逻辑、复杂模式
- **从基本操作构建复杂性**
- 手动指定网络权重不是机器学习！

---

## 6. 神经网络作为机器学习模型

### 6.1 可调管道
神经网络 = 整个可调的机器学习管道：
- 每个感知器定义一个导出特征/概念
- 增加层内感知器数 → 每层创建更多新概念
- 增加层数（更深）→ 创建更复杂的概念

### 6.2 深度神经网络的挑战
- 更高灵活性 → 过拟合风险增加
- 大量参数需调优 → 计算需求高
- 复杂输入（如百万像素图片）更严重

### 6.3 代价函数
**分类**（二分类，标签 0/1）：

> **l(W) = -(1/N) Σ [y_i log(ŷ_i) + (1-y_i) log(1-ŷ_i)]**

- 负对数似然函数
- 可扩展到多分类

### 6.4 梯度下降与反向传播

**反向传播（Back-propagation）**：
- 高效计算梯度的算法
- 利用**链式法则**
- 从输出层开始反向计算各隐藏层的梯度
- 每层只需下一层的信息

### 6.5 训练注意事项

| 问题 | 解决方案 |
|------|---------|
| 初始权重为零 | 反向传播失效，需**随机初始化** |
| 过拟合 | 正则化 + 验证早停 |
| 非凸性 | 从不同随机起点重新训练 |
| 输入缩放 | 标准化，确保输入被同等对待 |
| 架构选择 | 不同架构适合不同问题 |

### 6.6 迁移学习
- 问题 A 训练好的网络可复用于相关问题 B
- 早期阶段保持不变 → 固定转换 T(x)
- 后期阶段用新数据重新训练 f(z)

**优势**：
- 无需训练 T(x)
- 问题 B 的最优参数接近问题 A → 训练时间更短

**数学定义**：
- 源域：X_s, D_s = {X_s, P_s(X)}, T_s = {Y_s, P_s(Y|X)}
- 目标域：X_T, D_T = {X_T, P_T(X)}, T_T = {Y_T, P_T(Y|X)}
- D_s ≠ D_T, T_s ≠ T_T

## 7. 层的类型

### 7.1 全连接层（Fully-Connected Layer）
- 每个感知器接收上一层的所有输出
- 参数量巨大
- 1000×1000 RGB 图片 → 每个感知器 3,000,001 个权重！

### 7.2 等变性（Equivariance）
- 图像和时间序列具有等变性质：**同一模式可出现在网格不同位置**
- 全连接层对每个位置独立学习 → 参数浪费

### 7.3 卷积层（Convolutional Layer）

**核心思想**：
- 感知器排列为网格（**特征图/Feature Map**）
- 每个感知器只关注输入的**有限区域**
- 所有感知器**共享参数**（**核/Kernel**）

**特征图计算** = 核与输入的**卷积**（滤波）

**多特征图**：
- 每个特征图关联一个不同的概念
- 形成特征图栈

**核的维度**：H × W × D
- H：高度，W：宽度，D：深度（输入特征图数）
- 每个核的权重数 = H × W × D + 1（偏置）

### 7.4 池化层（Pooling Layer）
- 减小特征图尺寸
- 插在连续卷积层之间
- **不需要训练！**

| 类型 | 输出 |
|------|------|
| **最大池化（Max Pooling）** | 滤波区域内的最大值 |
| **平均池化（Average Pooling）** | 滤波区域内的平均值 |

## 8. 深度学习架构

### 8.1 通用模式
- 早期层：少数简单概念
- 后期层：许多复杂概念
- 特征图随深度缩小
- 相同中间概念可服务于不同目标 → 迁移学习

### 8.2 VGG16 示例
- 为 ImageNet 大规模视觉识别挑战设计
- 16层，3×3 核，1.38亿个权重

---

## 9. 神经网络的三种视角

| 视角 | 描述 |
|------|------|
| **功能视角** | 输入 x → 输出 ŷ 的系统，调 W 改变映射 |
| **认知视角** | 从原始数据和其他概念创建新概念，调 W 创建不同概念 |
| **计算视角** | 互连计算单元（感知器）的管道，调 W 改变计算 |

---

## 10. 神经网络的核心概念

### 10.1 模型族 vs 特定模型
- 神经网络不是单一模型（如逻辑回归），而是一**族模型**
- 每个神经网络有**架构**
- 最简架构 = 单个感知器
- 应说"这个神经网络架构表现好"，而非"神经网络表现好"

### 10.2 通用机器
- 对任何问题，都能找到解决它的神经网络架构
- 但这不意味着：
  - 某个特定架构能解决任何问题
  - 我们一定能找到合适的架构
- 灵活性 = 增加复杂性 → 过拟合风险增加

### 10.3 专家 vs 暴力
- **专家**：为问题设计正确的架构，利用迁移学习
- **暴力使用者**：用所有算力和数据训练尽可能多的复杂架构（碳足迹巨大）

## 11. 关键公式汇总

| 公式 | 用途 |
|------|------|
| a = h(x^T w) | 感知器输出 |
| ŷ = h_W(x) | 神经网络输出 |
| l(W) = -(1/N) Σ [y_i log ŷ_i + (1-y_i) log(1-ŷ_i)] | 二分类代价函数 |
| w_new = w_old - ε ∇E(w) | 梯度下降更新 |
| σ(z) = 1/(1+e^{-z}) | 逻辑/ sigmoid 激活函数 |
