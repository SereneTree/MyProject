# L8 密度估计 - 学习笔记

## 1. 概率密度

### 1.1 数据分布
- 数据集是属性空间中的样本集合
- 样本并不占据整个空间

### 1.2 基本问题
1. 大部分样本在哪里？
2. 我应该期望在某个区域找到样本吗？
3. 在某区域找到样本的概率是多少？
4. 给定概率，下一个样本在哪里？

### 1.3 分而数之
- 将空间分成小区域，统计每个区域内的样本数
- 将计数转换为比率 → 概率密度

### 1.4 概率密度的定义
- 概率密度描述数据的**真实分布**
- 允许量化：
  - 在空间某区域提取样本的概率
  - 位于某区域的人群样本比例
- 在整个属性空间中找到样本的总概率 = 1
- 概率密度**不均匀**：某些区域更密集

### 1.5 密度估计
- 在机器学习中，使用数据构建概率密度 → **密度估计**
- 可构建考虑所有属性的概率密度，或部分属性的**边际概率密度**

符号：
- p(x₁, x₂) 或 p(x)：联合概率密度
- p(x₁), p(x₂)：边际概率密度

## 2. 非参数方法

### 2.1 直方图
- 最简单的非参数密度估计方法
- 将特征空间分为等大小的区域（**箱/bins**）
- 密度 ≈ 落入每个箱的样本比例

**箱大小的影响**：
| 箱大小 | 效果 |
|--------|------|
| 太小 | 估计密度尖刺（过拟合） |
| 太大 | 估计密度平坦，丢失结构（欠拟合） |

### 2.2 核方法
- 先在每个样本周围构建个体密度
- 然后将所有密度组合
- 个体密度具有相同形状（**核**），如高斯核

### 2.3 非参数方法总结
- 不假设概率密度的特定形状
- 含需指定的超参数（箱大小、核类型）
- 直方图 → 离散概率密度
- 核方法 → 平滑概率密度

> **维度灾难**：高维空间中，直方图可能每箱只有一个样本；核方法中的个体分布可能彼此孤立。

## 3. 参数密度估计

### 3.1 概述
- 参数方法**指定概率密度的形状**
- 密度估计问题 = 估计其参数

常见模型：高斯分布、对数正态分布、均匀分布、Gamma 分布等

### 3.2 高斯（正态）分布

**一维**：
> p(x₁) = (1/σ√2π) exp[-(x₁-μ)²/(2σ²)]

参数：μ（均值）和 σ（标准差），σ²（方差）

### 3.3 中心极限定理（CLT）
> 大量独立随机量之和服从高斯分布

这解释了：
- 电子电路噪声是高斯的（大量带电粒子的随机热运动）
- 某些物理特征是高斯的（受基因、营养等大量因素影响）

> CLT 是高斯分布成为最常用密度模型的主要原因。

### 3.4 多元高斯分布
> p(x) = (1/√[(2π)^k |Σ|]) exp[-(x-μ)^T Σ^{-1} (x-μ)/2]

参数：μ（均值向量）和 Σ（协方差矩阵）

### 3.5 高斯分布与独立属性
**等价条件**：
1. 属性 x₁ 和 x₂ 独立
2. 协方差矩阵 Σ 是对角矩阵
3. p(x₁, x₂) = p(x₁) × p(x₂)（联合 = 边际之积）

> 记住这个性质，后面讲朴素贝叶斯时会用到！

### 3.6 高斯分布参数估计
**最大似然估计**：

一维：
> μ̂ = (1/N) Σ x_i
> σ̂² = (1/N) Σ (x_i - μ̂)²

多维：
> μ̂ = (1/N) Σ x_i
> Σ̂ = (1/N) Σ (x_i - μ̂)(x_i - μ̂)^T

### 3.7 高维问题
- 高维度总是有问题的 → 容易过拟合
- 解决方法：对协方差矩阵施加约束、正则化

### 3.8 混合模型（GMM）
- 数据集可能有多个模式（簇），单一高斯不适用
- **高斯混合模型（GMM）**：

> p(x) = Σ_m g_m(x) π_m

- g_m(x)：第 m 个高斯密度（均值 μ_m，协方差 Σ_m）
- π_m：混合系数

**EM 算法**：迭代拟合 GMM，类似 K-Means

## 4. 密度估计的应用

### 4.1 噪声与异常值
- **噪声**：同人群样本的随机偏差
- **异常值/离群点**：偏离大到令人怀疑属于不同人群的样本

异常值检测的重要性：
- 应用：欺诈检测、网络安全
- 影响：训练时可能产生负面影响

### 4.2 两类方法

| 方法 | 目标 |
|------|------|
| **异常检测算法** | 识别异常值，通常后跟移除操作 |
| **鲁棒性设计** | 减轻异常值的影响（如使用不同代价函数） |

### 4.3 基本异常检测算法
1. 从数据集估计 μ 和 Σ
2. 约定阈值 T
3. 若 p(x_i) < T → x_i 是异常值

> 概率密度低的区域 → 样本可能是异常值

### 4.4 分类：估计类密度
- 应用贝叶斯规则的分类器需要**类密度** p(x|C)
- 每个类别单独拟合概率分布

### 4.5 朴素贝叶斯分类器
- 高斯分布是最常用的类密度模型
- P 个预测变量 → P（均值）+ P²（协方差）个参数

**朴素假设**：预测变量独立 →

> p(x) = p(x₁) × p(x₂) × ... × p(x_P)

- 只需 P（均值）+ P（方差）= 2P 个参数
- 大幅减少参数 → **降低过拟合风险**

### 4.6 聚类中的密度估计
- **K-Means** 可看作 GMM 的特例（高斯分布具有相同对角协方差矩阵 → 球形簇）
- **GMM** 可作为聚类方法：先拟合 K 个高斯密度，再将样本分配到最可能的密度
- GMM 产生**椭球形簇**，K-Means 产生**球形簇**

## 5. 总结表

| 方法 | 类型 | 假设形状 | 超参数 |
|------|------|---------|--------|
| 直方图 | 非参数 | 无 | 箱大小 |
| 核方法 | 非参数 | 无 | 核类型、带宽 |
| 高斯分布 | 参数 | 高斯 | 无 |
| GMM | 参数 | 多高斯 | 簇数 K |
