# 第9章 离散时间系统结构 (Structures for Discrete-Time Systems)

## 9.1 基本概念

差分方程: $y[n] - ay[n-1] = b_0 x[n] + b_1 x[n-1]$

系统函数: $H(z) = \frac{b_0 + b_1 z^{-1}}{1-az^{-1}}$

实现方式: 递归计算 $y[n] = ay[n-1] + b_0 x[n] + b_1 x[n-1]$（比离散卷积高效）

## 9.2 方框图基本元素

| 元素 | 功能 | 符号 |
|------|------|------|
| 加法器 | 信号相加 | 圆圈 + |
| 乘法器 | 乘以系数 | 方框 $a$ |
| 延迟器 | 延迟一个样本 | 方框 $z^{-1}$ |

## 9.3 直接形式

### 9.3.1 直接I型

系统函数分解为: $H(z) = H_2(z) H_1(z)$

$$H_2(z) = \sum_{k=0}^{M} b_k z^{-k}, \quad H_1(z) = \frac{1}{1-\sum_{k=1}^{N} a_k z^{-k}}$$

先实现 $H_2(z)$（前馈部分），再实现 $H_1(z)$（反馈部分）。

**中间变量**: $V(z) = H_2(z) X(z)$, $Y(z) = H_1(z) V(z)$

### 9.3.2 直接II型

利用线性系统级联可交换性: $H(z) = H_1(z) H_2(z)$

$$w[n] = \sum_{k=1}^{N} a_k w[n-k] + x[n]$$
$$y[n] = \sum_{k=0}^{M} b_k w[n-k]$$

**优点**: 只需一组延迟器（$N$ 个），比直接I型（$N+M$ 个）更节省存储。

> 直接II型也称为**规范形式**，因为使用了最少数量的延迟器。

### 9.3.3 计算示例

$$H(z) = \frac{1+2z^{-1}}{1-1.5z^{-1}+0.9z^{-2}}$$

- 分子系数: $b_0=1, b_1=2$
- 分母系数: $a_1=-1.5, a_2=0.9$
- 直接II型需要2个延迟器

## 9.4 IIR系统的基本结构

### 9.4.1 级联形式

将系统函数分解为二阶节的级联:

$$H(z) = \prod_{k=1}^{N_s} \frac{b_{0k}+b_{1k}z^{-1}+b_{2k}z^{-1}}{1-a_{1k}z^{-1}-a_{2k}z^{-2}}$$

每个二阶节用直接II型实现。

**差分方程**:
- $y_0[n] = x[n]$
- $w_k[n] = a_{1k}w_k[n-1] + a_{2k}w_k[n-2] + y_{k-1}[n]$
- $y_k[n] = b_{0k}w_k[n] + b_{1k}w_k[n-1] + b_{2k}w_k[n-2]$
- $y[n] = y_{N_s}[n]$

**示例**: $H(z) = \frac{(1+z^{-1})(1+z^{-2})}{(1-0.5z^{-1})(1-0.25z^{-1})}$

分解为两个一阶节的级联。

### 9.4.2 并联形式

将系统函数做部分分式展开:

$$H(z) = \sum_{k=0}^{N_p} C_k z^{-k} + \sum_{k=1}^{N_s} \frac{e_{0k}+e_{1k}z^{-1}}{1-a_{1k}z^{-1}-a_{2k}z^{-2}}$$

每个二阶节用直接II型实现，输出相加。

**差分方程**:
- $w_k[n] = a_{1k}w_k[n-1] + a_{2k}w_k[n-2] + x[n]$
- $y_k[n] = e_{0k}w_k[n] + e_{1k}w_k[n-1]$
- $y[n] = \sum_{k=0}^{N_p} C_k x[n-k] + \sum_{k=1}^{N_s} y_k[n]$

**示例**: 并联形式可用一阶或二阶节实现。

## 9.5 三种实现形式比较

| 形式 | 优点 | 缺点 |
|------|------|------|
| 直接I型 | 直观，易从差分方程得到 | 延迟器多 |
| 直接II型 | 延迟器最少 | 对系数量化敏感 |
| 级联形式 | 对系数精度要求低，可单独调整每节 | 零极点配对需要考虑 |
| 并联形式 | 各支路独立，可并行计算 | 无法单独控制零点 |
