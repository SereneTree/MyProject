# 第8章 LTI系统的变换分析 (Transform Analysis)

## 8.1 基本关系

LTI系统可由冲激响应 $h[n]$ 完全表征:

- 时域: $y[n] = x[n] \star h[n]$
- 频域: $Y(e^{j\omega}) = X(e^{j\omega}) H(e^{j\omega})$
- Z域: $Y(z) = X(z) H(z)$

其中 $H(z)$ 为系统函数，$H(e^{j\omega})$ 为频率响应。

## 8.2 频率响应

### 8.2.1 幅度和相位

$$H(e^{j\omega}) = |H(e^{j\omega})| e^{j\angle H(e^{j\omega})}$$

- **幅度响应** $|H(e^{j\omega})|$: 增益
- **相位响应** $\angle H(e^{j\omega})$: 相移

输出与输入的关系:
- 幅度: $|Y(e^{j\omega})| = |H(e^{j\omega})| \cdot |X(e^{j\omega})|$
- 相位: $\angle Y(e^{j\omega}) = \angle H(e^{j\omega}) + \angle X(e^{j\omega})$

### 8.2.2 群延迟

$$\tau(\omega) = -\frac{d}{d\omega} \angle H(e^{j\omega})$$

群延迟表示信号包络通过系统时的延迟。

**理想延迟系统**: $h[n] = \delta[n-n_d]$

- $H(e^{j\omega}) = e^{-j\omega n_d}$
- $|H(e^{j\omega})| = 1$, $\angle H(e^{j\omega}) = -\omega n_d$
- 群延迟: $\tau(\omega) = n_d$（常数）

### 8.2.3 频率响应计算示例

**例**: 差分方程 $y[n] = x[n] - 0.5y[n-1]$，输入 $x[n] = \cos(\pi n)$

$$H(z) = \frac{1}{1+0.5z^{-1}} \Rightarrow H(e^{j\omega}) = \frac{1}{1+0.5e^{-j\omega}}$$

在 $\omega = \pi$ 处: $H(e^{j\pi}) = \frac{1}{1+0.5e^{-j\pi}} = \frac{1}{1-0.5} = 2$

输出: $y[n] = 2\cos(\pi n)$

## 8.3 系统函数

### 8.3.1 有理系统函数

差分方程: $\sum_{k=0}^{N} a_k y[n-k] = \sum_{k=0}^{M} b_k x[n-k]$

系统函数: $H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{\sum_{k=0}^{N} a_k z^{-k}}$

**因式分解形式**:

$$H(z) = \frac{b_0}{a_0} \frac{\prod_{k=1}^{M}(1-c_k z^{-1})}{\prod_{k=1}^{N}(1-d_k z^{-1})}$$

其中 $c_k$ 为零点，$d_k$ 为极点。

### 8.3.2 稳定性和因果性

| 性质 | Z域条件 |
|------|---------|
| 因果 | ROC在最外层极点之外（$h[n]$ 为右边序列） |
| 稳定 | ROC包含单位圆 |
| 因果且稳定 | 所有极点在单位圆内 |

**示例**: $H(z) = \frac{1}{1-\frac{5}{2}z^{-1}+z^{-2}} = \frac{1}{(1-\frac{1}{2}z^{-1})(1-2z^{-1})}$

极点: $z = 1/2$ 和 $z = 2$

| ROC假设 | 因果性 | 稳定性 |
|---------|--------|--------|
| $|z| > 2$（因果） | 因果 | **不稳定**（单位圆不在ROC内） |
| $1/2 < |z| < 2$ | 非因果 | 稳定 |
| $|z| < 1/2$ | 非因果 | 不稳定 |

## 8.4 逆系统

逆系统 $H_i(z)$ 满足: $H(z) H_i(z) = 1$

即 $H_i(z) = 1/H(z)$

时域条件: $h[n] \star h_i[n] = \delta[n]$

**示例**: $H(z) = \frac{1-0.5z^{-1}}{1-0.9z^{-1}}$, $|z| > 0.9$

逆系统: $H_i(z) = \frac{1-0.9z^{-1}}{1-0.5z^{-1}}$, $|z| > 0.5$

## 8.5 有理系统函数的冲激响应

部分分式展开后（一阶极点，因果系统）:

$$h[n] = \sum_{r=0}^{M-N} B_r \delta[n-r] + \sum_{k=1}^{N} A_k (d_k)^n u[n]$$

- 若有 $(d_k)^n u[n]$ 项（$d_k \neq 0$）→ IIR系统
- 若所有 $d_k = 0$（无极点）→ FIR系统

## 8.6 频率响应的几何解释

$$|H(e^{j\omega})| = \frac{|b_0|}{|a_0|} \frac{\prod |1-c_k e^{-j\omega}|}{\prod |1-d_k e^{-j\omega}|}$$

$$= \frac{|b_0|}{|a_0|} \frac{\prod \text{到零点的距离}}{\prod \text{到极点的距离}}$$

> 单位圆上的点 $e^{j\omega}$ 到零点/极点的距离分别影响幅度响应的谷/峰。

### 8.6.1 一阶系统

零点因子 $H(z) = 1 - re^{j\theta}z^{-1}$ 或极点因子 $H(z) = \frac{1}{1-re^{j\theta}z^{-1}}$

- 增益 (dB): $\pm 10\log_{10}(1+r^2-2r\cos(\omega-\theta))$
- 相位贡献: $\pm \arctan\frac{r\sin(\omega-\theta)}{1-r\cos(\omega-\theta)}$
- 群延迟贡献: $\pm \frac{r^2-r\cos(\omega-\theta)}{1+r^2-2r\cos(\omega-\theta)}$

### 8.6.2 二阶IIR系统

共轭极点对: $H(z) = \frac{1}{1-2r\cos\theta z^{-1}+r^2 z^{-2}}$

对应差分方程: $y[n] - 2r\cos\theta y[n-1] + r^2 y[n-2] = x[n]$

## 8.7 考试重点

- 从系统函数判断因果性和稳定性（极点位置与ROC）
- 频率响应的计算（将 $z = e^{j\omega}$ 代入）
- 频率响应的几何解释（零点→谷，极点→峰）
- 群延迟的定义和计算
- 逆系统的概念和求解
- 增益的dB表示
