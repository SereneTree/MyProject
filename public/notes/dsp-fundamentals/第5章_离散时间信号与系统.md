# 第5章 离散时间信号与系统 (Discrete-Time Signals and Systems)

## 5.1 离散时间信号

### 5.1.1 基本概念

在DSP中，信号用数值序列（样本）表示：

$$x = \{x[n]\}, \quad -\infty < n < \infty$$

序列可通过采样模拟信号获得：$x[n] = x_a(nT)$，$T$ 为采样周期。

### 5.1.2 基本序列

| 序列名称 | 定义 | 图形特点 |
|---------|------|---------|
| 单位冲激序列 $\delta[n]$ | $\delta[n] = \begin{cases}1, & n=0\\0, & n\neq 0\end{cases}$ | 仅 $n=0$ 处为1 |
| 单位阶跃序列 $u[n]$ | $u[n] = \begin{cases}1, & n \geq 0\\0, & n < 0\end{cases}$ | $n\geq0$ 全为1 |

**冲激与阶跃的关系**:
- $u[n] = \sum_{k=-\infty}^{n} \delta[k]$
- $\delta[n] = u[n] - u[n-1]$

**任意序列的冲激分解**:

$$x[n] = \sum_{k=-\infty}^{\infty} x[k]\delta[n-k]$$

### 5.1.3 指数序列

一般形式: $x[n] = A\alpha^n$

设 $\alpha = |\alpha|e^{j\omega_0}$, $A = |A|e^{j\phi}$，则：

$$x[n] = |A||\alpha|^n [\cos(\omega_0 n + \phi) + j\sin(\omega_0 n + \phi)]$$

| 参数 | 效果 |
|------|------|
| $|\alpha| < 1$ | 信号衰减 |
| $|\alpha| > 1$ | 信号增长 |
| $|\alpha| = 1$ | 信号等幅 |
| $\alpha < 0$ | 信号交替（$\omega_0 = \pi$） |

## 5.2 离散时间系统

### 5.2.1 定义

离散时间系统是一个变换: $y[n] = T\{x[n]\}$

**示例**:
- 理想延迟系统: $y[n] = x[n-n_d]$
- 滑动平均系统: $y[n] = \frac{1}{M_1+M_2+1}\sum_{k=-M_1}^{M_2} x[n-k]$

### 5.2.2 LTI系统

**线性系统**（叠加原理）:

$$T\{a_1 x_1[n] + a_2 x_2[n]\} = a_1 T\{x_1[n]\} + a_2 T\{x_2[n]\}$$

**时不变系统**: 输入的延迟导致输出的等量延迟

**非线性的例子**: $y[n] = \log_{10}(|x[n]|)$ — 不满足齐次性

**时变的例子**: 压缩器 $y[n] = x[Mn]$ — 输出不是输入的简单延迟

### 5.2.3 因果性

系统因果: 输出 $y[n_0]$ 仅取决于 $n \leq n_0$ 的输入值

- 前向差分 $y[n] = x[n+1] - x[n]$: **非因果**
- 后向差分 $y[n] = x[n] - x[n-1]$: **因果**

## 5.3 卷积和

### 5.3.1 推导

由叠加原理和时不变性:

$$y[n] = \sum_{k=-\infty}^{\infty} x[k]h[n-k] = x[n] \star h[n]$$

### 5.3.2 计算示例

**例1**: $h[n] = (\frac{1}{2})^n u[n]$, $x[n] = u[n]$

$$y[n] = \sum_{k=0}^{n} (\frac{1}{2})^k = 2\left(1 - \left(\frac{1}{2}\right)^{n+1}\right)u[n]$$

### 5.3.3 卷积性质

| 性质 | 公式 |
|------|------|
| 交换律 | $x[n] \star h[n] = h[n] \star x[n]$ |
| 分配律 | $x[n] \star (h_1[n] + h_2[n]) = x[n] \star h_1[n] + x[n] \star h_2[n]$ |
| 结合律 | $(x \star h_1) \star h_2 = x \star (h_1 \star h_2)$ |

## 5.4 线性常系数差分方程

### 5.4.1 一般形式

$$\sum_{k=0}^{N} a_k y[n-k] = \sum_{k=0}^{M} b_k x[n-k]$$

等价地（假设 $a_0 = 1$）:

$$y[n] = \sum_{k=0}^{M} b_k x[n-k] - \sum_{k=1}^{N} a_k y[n-k]$$

### 5.4.2 递归 vs 非递归

| 类型 | 特点 | 冲激响应 |
|------|------|---------|
| 递归系统 | $a_k$ 不全为零（有反馈） | IIR（无限冲激响应） |
| 非递归系统 | 除 $a_0=1$ 外所有 $a_k=0$（无反馈） | FIR（有限冲激响应） |

**FIR示例**: $h[n] = \delta[n] + 2\delta[n-1] + 3\delta[n-2]$（有限长）

**IIR示例**: $h[n] = (\frac{1}{2})^n u[n]$（无限长，指数衰减）

> **判断FIR/IIR的方法**: 看冲激响应是否有限长，而非看差分方程形式。

## 5.5 频率响应

### 5.5.1 特征函数

LTI系统对复指数输入的响应:

输入 $x[n] = e^{j\omega n}$ → 输出 $y[n] = H(e^{j\omega}) e^{j\omega n}$

其中频率响应: $H(e^{j\omega}) = \sum_{k=-\infty}^{\infty} h[k] e^{-j\omega k}$

### 5.5.2 频率响应的性质

- **周期性**: $H(e^{j(\omega + 2\pi)}) = H(e^{j\omega})$，周期为 $2\pi$
- **复数**: $H(e^{j\omega}) = |H(e^{j\omega})| e^{j\theta(\omega)}$
  - 幅度响应 $|H(e^{j\omega})|$
  - 相位响应 $\theta(\omega) = \angle H(e^{j\omega})$

### 5.5.3 滤波器分类

| 滤波器类型 | 通过频率 | 阻止频率 |
|-----------|---------|---------|
| 低通 (LP) | 低频 | 高频 |
| 高通 (HP) | 高频 | 低频 |
| 带通 (BP) | 中间频段 | 两端频率 |
| 带阻 (BS) | 两端频率 | 中间频段 |

## 5.6 离散时间傅里叶变换 (DTFT)

### 5.6.1 定义

**正变换**: $X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n] e^{-j\omega n}$

**逆变换**: $x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega$

### 5.6.2 对称性质（实序列 $x[n]$）

| 性质 | 公式 |
|------|------|
| 共轭对称 | $X(e^{j\omega}) = X^*(e^{-j\omega})$ |
| 实部偶 | $X_R(e^{j\omega}) = X_R(e^{-j\omega})$ |
| 虚部奇 | $X_I(e^{j\omega}) = -X_I(e^{-j\omega})$ |
| 幅度偶 | $|X(e^{j\omega})| = |X(e^{-j\omega})|$ |
| 相位奇 | $\angle X(e^{j\omega}) = -\angle X(e^{-j\omega})$ |

### 5.6.3 重要变换对

$$a^n u[n] \xleftrightarrow{\mathcal{F}} \frac{1}{1-ae^{-j\omega}}, \quad |a| < 1$$

### 5.6.4 卷积定理

$$x[n] \star h[n] \xleftrightarrow{\mathcal{F}} X(e^{j\omega}) \cdot H(e^{j\omega})$$
