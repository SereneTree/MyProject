# 第2章 复数复习 (Complex Numbers Review)

## 2.1 学习目标

- 用直角坐标形式和极坐标形式表示复数
- 对复数进行加、减、乘、除运算
- 计算复数的模、相位和共轭
- 应用欧拉公式将正弦信号表示为指数形式

## 2.2 复数的表示方法

### 2.2.1 直角坐标形式（笛卡尔形式）

$$z = a + jb$$

其中 $j = \sqrt{-1}$，$a$ 和 $b$ 为实数：
- **实部**: $a = \text{Re}\{z\}$
- **虚部**: $b = \text{Im}\{z\}$

**示例**: $z = 4 + j3$

### 2.2.2 极坐标形式

$$z = re^{j\theta}$$

其中：
- $r > 0$: 复数的**模**（幅度），$r = |z|$
- $\theta$: 复数的**相位**（角度），$\theta = \angle z$

### 2.2.3 两种形式的转换关系

由欧拉公式 $e^{j\theta} = \cos\theta + j\sin\theta$，可得：

| 从直角坐标到极坐标 | 从极坐标到直角坐标 |
|---|---|
| $r = \sqrt{a^2 + b^2}$ | $a = r\cos\theta$ |
| $\theta = \tan^{-1}(b/a)$ | $b = r\sin\theta$ |

**示例**: $z = 3 + j4$ → $r = 5$, $\theta = 53.1°$, 即 $z = 5e^{j53.1°}$

## 2.3 复数运算

### 2.3.1 加法（直角坐标最方便）

$$z_1 + z_2 = (a_1 + a_2) + j(b_1 + b_2)$$

### 2.3.2 减法（直角坐标最方便）

$$z_1 - z_2 = (a_1 - a_2) + j(b_1 - b_2)$$

### 2.3.3 乘法（极坐标最方便）

**极坐标形式**：模相乘，角相加

$$z_1 z_2 = r_1 r_2 e^{j(\theta_1 + \theta_2)}$$

**直角坐标形式**：

$$z_1 z_2 = (a_1 a_2 - b_1 b_2) + j(a_1 b_2 + a_2 b_1)$$

### 2.3.4 复共轭

$$z^* = a - jb = re^{-j\theta}$$

**共轭的重要性质**（考试常考）:

| 性质 | 公式 |
|------|------|
| 1 | $zz^* = r^2$ (模的平方) |
| 2 | $z/z^* = e^{j2\theta}$ |
| 3 | $z + z^* = 2\text{Re}\{z\}$ |
| 4 | $z - z^* = j2\text{Im}\{z\}$ |
| 5 | $(z_1 + z_2)^* = z_1^* + z_2^*$ |
| 6 | $(z_1 z_2)^* = z_1^* z_2^*$ |
| 7 | $(z_1/z_2)^* = z_1^*/z_2^*$ |

### 2.3.5 除法（极坐标最方便）

**极坐标形式**：模相除，角相减

$$\frac{z_1}{z_2} = \frac{r_1}{r_2} e^{j(\theta_1 - \theta_2)}$$

**直角坐标形式**（分子分母同乘分母共轭）：

$$\frac{z_1}{z_2} = \frac{z_1 z_2^*}{|z_2|^2}$$

## 2.4 欧拉公式

$$e^{j\theta} = \cos\theta + j\sin\theta$$

**正弦信号的指数表示**:

| 信号 | 指数形式 |
|------|---------|
| $\cos\omega_0 t$ | $\frac{1}{2}e^{j\omega_0 t} + \frac{1}{2}e^{-j\omega_0 t}$ |
| $\sin\omega_0 t$ | $\frac{1}{j2}e^{j\omega_0 t} - \frac{1}{j2}e^{-j\omega_0 t}$ |

## 2.5 复函数示例

考虑 $X(\omega) = \frac{2 + j\omega}{3 + j4\omega}$:

1. **直角坐标形式**: 分子分母同乘分母的共轭 $(3 - j4\omega)$，分离实部和虚部
2. **极坐标形式**: 分别的模和相位，模相除角相减

## 2.6 考试重点

- 熟练掌握直角坐标与极坐标的转换
- 加减用直角坐标，乘除用极坐标
- 共轭的7条性质必须牢记
- 欧拉公式的正反运用
- 复数除法的"有理化"技巧（乘共轭）
