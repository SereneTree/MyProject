# 第4章 信号与系统 Part 2 — 系统分类与卷积 (Systems & Convolution)

## 4.1 系统分类

系统是将输入信号变换为输出信号的数学模型，记为 $y(t) = T\{x(t)\}$ 或 $y[n] = T\{x[n]\}$。

### 4.1.1 系统分类总览

| 分类 | 说明 |
|------|------|
| 连续/离散时间系统 | 取决于输入输出信号类型 |
| 确定性/随机系统 | 取决于信号是否随机 |
| 有记忆/无记忆系统 | 输出是否依赖过去/未来输入 |
| 因果/非因果系统 | 输出是否依赖未来输入 |
| 线性/非线性系统 | 是否满足叠加原理 |
| 时不变/时变系统 | 时间平移是否导致相同输出平移 |
| 稳定/不稳定系统 | BIBO稳定性 |

### 4.1.2 有记忆 vs 无记忆

- **无记忆系统**: 输出仅取决于当前时刻的输入
  - 例: $y(t) = Rx(t)$（无记忆）
- **有记忆系统**: 输出还依赖其他时刻的输入
  - 例: $y(t) = \frac{1}{C}\int_{-\infty}^{t}x(\tau)d\tau$（有记忆）
  - 例: $y[n] = \sum_{k=-\infty}^{n}x[k]$（有记忆）

### 4.1.3 因果 vs 非因果

- **因果系统**: 输出仅依赖于当前和过去的输入值
  - 例: $y(t) = x(t-1)$（因果）
- **非因果系统**: 输出依赖于未来的输入值
  - 例: $y(t) = x(t+1)$（非因果）
  - 例: $y[n] = x[n+2]$（非因果）

### 4.1.4 线性 vs 非线性

线性系统必须满足**叠加原理**（齐次性 + 可加性）:

$$T\{\alpha_1 x_1 + \alpha_2 x_2\} = \alpha_1 T\{x_1\} + \alpha_2 T\{x_2\}$$

**判断方法**: 分别检验齐次性和可加性

**示例**:
- $y(t) = x(t)^2$: **非线性**（$(x_1 + x_2)^2 \neq x_1^2 + x_2^2$）
- $y[n] = x[n-1] + 1$: **非线性**（零输入产生非零输出）

### 4.1.5 时不变 vs 时变

时不变系统: 输入的时间平移导致输出的相同时间平移

- 连续: $T\{x(t-\tau)\} = y(t-\tau)$
- 离散: $T\{x[n-k]\} = y[n-k]$

**示例**:
- $y(t) = x(t-1)$: 时不变
- $y[n] = nx[n]$: **时变**（系数随时间变化）

### 4.1.6 LTI系统

同时满足**线性**和**时不变**的系统称为 LTI（线性时不变）系统。

### 4.1.7 BIBO稳定

**有界输入有界输出 (BIBO) 稳定**: 若 $|x| < k_1$，则 $|y| < k_2$

**示例**:
- $y(t) = x(t-1)$: 稳定
- $y[n] = nx[n]$: **不稳定**（输出随 $n$ 增长）

## 4.2 卷积

### 4.2.1 离散时间卷积和

**关键思想**: 任意离散信号可表示为加权移位冲激之和

$$x[n] = \sum_{k=-\infty}^{\infty} x[k]\delta[n-k]$$

LTI系统的输出为加权移位冲激响应之和:

$$y[n] = \sum_{k=-\infty}^{\infty} x[k]h[n-k] = x[n] \star h[n]$$

其中 $h[n]$ 为系统的冲激响应。

### 4.2.2 连续时间卷积积分

$$y(t) = \int_{-\infty}^{\infty} x(\tau)h(t-\tau)d\tau = x(t) \star h(t)$$

**示例**: $x(t) = e^{-at}u(t)$, $h(t) = u(t)$:

$$y(t) = \int_0^t e^{-a\tau}d\tau = \frac{1}{a}(1-e^{-at}), \quad t > 0$$

## 4.3 LTI系统性质

### 4.3.1 交换律

$$x[n] \star h[n] = h[n] \star x[n]$$
$$x(t) \star h(t) = h(t) \star x(t)$$

### 4.3.2 分配律

$$x \star (h_1 + h_2) = x \star h_1 + x \star h_2$$

### 4.3.3 结合律

$$x \star (h_1 \star h_2) = (x \star h_1) \star h_2$$

### 4.3.4 可逆性

逆系统的冲激响应 $h_1(t)$ 满足: $h(t) \star h_1(t) = \delta(t)$

### 4.3.5 因果性条件

LTI系统因果的充要条件:
- 离散: $h[n] = 0, \forall n < 0$
- 连续: $h(t) = 0, \forall t < 0$

### 4.3.6 稳定性条件

LTI系统BIBO稳定的充要条件: 冲激响应绝对可和/可积

- 离散: $\sum_{n=-\infty}^{\infty} |h[n]| < \infty$
- 连续: $\int_{-\infty}^{\infty} |h(t)| dt < \infty$

## 4.4 连续时间傅里叶变换

### 4.4.1 定义

$$X(j\Omega) = \int_{-\infty}^{\infty} x(t) e^{-j\Omega t} dt$$

### 4.4.2 卷积定理

时域卷积 = 频域相乘:

$$y(t) = x(t) \star h(t) \leftrightarrow Y(j\Omega) = X(j\Omega) \cdot H(j\Omega)$$
