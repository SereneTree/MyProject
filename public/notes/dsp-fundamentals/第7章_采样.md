# 第7章 连续时间信号的采样 (Sampling)

## 7.1 周期采样

### 7.1.1 采样过程

从连续时间信号 $x_c(t)$ 获得离散序列:

$$x[n] = x_c(nT), \quad -\infty < n < \infty$$

其中:
- $T$: 采样周期（秒/样本）
- $f_s = 1/T$: 采样频率（样本/秒，Hz）
- $\Omega_s = 2\pi f_s = 2\pi/T$: 采样角频率（rad/s）

### 7.1.2 采样的两阶段模型

1. **冲激串调制**: $x_s(t) = x_c(t) \cdot s(t)$，其中 $s(t) = \sum_{n=-\infty}^{\infty} \delta(t-nT)$
2. **冲激串到序列的转换**: 从 $x_s(t)$ 提取样本值得到 $x[n]$

$$x_s(t) = \sum_{n=-\infty}^{\infty} x_c(nT) \delta(t-nT)$$

## 7.2 采样的频域表示

### 7.2.1 采样信号的傅里叶变换

$$X_s(j\Omega) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X_c(j(\Omega - k\Omega_s))$$

**物理意义**: 采样信号的频谱是原信号频谱以 $\Omega_s$ 为周期的**周期延拓**，幅度缩小为 $1/T$。

### 7.2.2 DTFT与连续频谱的关系

$$X(e^{j\omega}) = \frac{1}{T} \sum_{k=-\infty}^{\infty} X_c\left(j\left(\frac{\omega}{T} - \frac{2\pi k}{T}\right)\right)$$

**频率映射关系**: $\omega = \Omega T$（数字频率 = 模拟频率 × 采样周期）

## 7.3 重建

### 7.3.1 理想重建

用理想低通滤波器从采样信号恢复原信号:

$$X_r(j\Omega) = H_r(j\Omega) X_s(j\Omega)$$

理想低通滤波器的截止频率: $\Omega_c = \Omega_s / 2$

### 7.3.2 重建公式

$$x_r(t) = \sum_{n=-\infty}^{\infty} x[n] h_r(t-nT)$$

其中理想重建滤波器的冲激响应: $h_r(t) = \frac{\sin(\pi t/T)}{\pi t/T}$（sinc函数）

## 7.4 混叠失真 (Aliasing)

当 $\Omega_s < 2\Omega_N$ 时，频谱副本发生重叠，原信号频谱无法通过低通滤波恢复，造成**混叠失真**。

> 混叠后的频谱不再是原频谱的简单复制，高频分量"折叠"到低频区域。

## 7.5 奈奎斯特-香农采样定理

### 7.5.1 定理内容

设 $x_c(t)$ 是带限信号，$X_c(j\Omega) = 0$ for $|\Omega| \geq \Omega_N$，则 $x_c(t)$ 由其样本 $x[n] = x_c(nT)$ 唯一确定的充要条件是:

$$\Omega_s = \frac{2\pi}{T} \geq 2\Omega_N$$

### 7.5.2 关键术语

| 术语 | 定义 |
|------|------|
| 奈奎斯特频率 $\Omega_N$ | 信号最高频率分量 |
| 奈奎斯特率 $2\Omega_N$ | 完全重建所需最低采样频率 |
| 采样频率 $\Omega_s$ | 实际使用的采样频率 |

### 7.5.3 采样频率选择

- $\Omega_s > 2\Omega_N$: 无混叠，可完全重建
- $\Omega_s = 2\Omega_N$: 临界采样（理论上可重建）
- $\Omega_s < 2\Omega_N$: 混叠发生，无法完全重建

## 7.6 频率映射示例

设采样频率 $f_s = 1$ kHz:

| 连续信号 $x_c(t)$ | 模拟频率 $f_0$ | 数字频率 $\omega_0 = 2\pi f_0/f_s$ | 是否满足奈奎斯特 |
|---|---|---|---|
| $\cos(2\pi \cdot 125 t)$ | 125 Hz | $\pi/4$ | 是 ($125 < 500$) |
| $\cos(2\pi \cdot 250 t)$ | 250 Hz | $\pi/2$ | 是 ($250 < 500$) |
| $\cos(2\pi \cdot 375 t)$ | 375 Hz | $3\pi/4$ | 是 ($375 < 500$) |
| $\cos(2\pi \cdot 500 t)$ | 500 Hz | $\pi$ | 临界 |
| $\cos(2\pi \cdot 625 t)$ | 625 Hz | $5\pi/4$ → 混叠为 $3\pi/4$ | 否 (混叠) |

> **注意**: 当 $f_0 > f_s/2$ 时，采样后的序列与较低频率的信号采样结果相同，即发生混叠。

## 7.7 采样与重建示例

**例**: 采样 $x_c(t) = \cos(4000\pi t)$，采样周期 $T = 1/6000$ s

- 采样频率: $\Omega_s = 2\pi/T = 12000\pi$ rad/s
- 信号最高频率: $\Omega_0 = 4000\pi$ rad/s
- 奈奎斯特条件: $\Omega_s = 12000\pi \geq 2 \times 4000\pi = 8000\pi$ ✓
- 离散信号: $x[n] = \cos(2\pi n/3)$, $\omega_0 = 2\pi/3$

## 7.8 模拟信号的数字处理

完整的数字信号处理系统流程:

1. 抗混叠滤波器（低通，截止频率 $\leq f_s/2$）
2. C/D转换（采样+量化）
3. 数字信号处理
4. D/C转换（数模转换+重建滤波器）

## 7.9 考试重点

- 奈奎斯特采样定理的条件与应用
- 频率映射关系 $\omega = \Omega T$
- 判断给定采样频率是否会产生混叠
- 混叠频率的计算
- 采样信号频谱的周期延拓特性
