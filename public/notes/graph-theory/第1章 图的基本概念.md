## 1. 图的定义

### 直觉理解
图是用来对"关系"建模的数学工具。城市之间的道路、网页之间的超链接、人与人之间的认识关系——都可以用图来表示。图论的强大之处在于：一旦把问题建模成图，几十年积累的高效算法就可以直接使用。

### 正式定义

> **定义 1.1（图、顶点、边）：** 图 `G` 由有限顶点集 `V = {v₁, v₂, ..., vₘ}` 和边集 `E = {e₁, e₂, ..., eₙ}` 组成，记为 `G = (V, E)`。每条边对应两个顶点，称为它的**端点**。
>
> - `V(G)` 称为 **顶点集**，`E(G)` 称为 **边集**
> - 两个顶点 `u, v` 若有边相连，称它们**相邻**（adjacent）
> - **自环**（loop）：两端点相同的边
> - **重边**（multiple edge）：端点相同的两条边
> - **简单图**：无自环且无重边（本课程默认讨论简单图）

### 举例

```
V = {u, v, w, x}
E = {uv, uw, wx}

u — v
|
w — x
```

> 🎯 **考点：** 一个有 `n` 个顶点的简单图最多有 `C(n,2) = n(n−1)/2` 条边（定理 1.5）。
> 顶点集为 `V` 的简单图共有 `2^(|V|取2)` 种不同的图（推论 1.6）。

## 2. 特殊图

| 图名 | 符号 | 描述 |
|------|------|------|
| 空图 | `Eₙ` | n 个顶点，无边 |
| 完全图 | `Kₙ` | 每对顶点之间恰好一条边，共 `n(n−1)/2` 条边 |
| 路径 | `Pₙ` | n 个顶点首尾相连成一条链：`1—2—3—…—n` |
| 圈 | `Cₙ` | n ≥ 3 个顶点围成一个圈 |

> 🎯 **考点：**
> - `Pₙ` 有 `n` 个顶点，`n−1` 条边
> - `Cₙ` 有 `n` 个顶点，`n` 条边
> - `Kₙ` 有 `n(n−1)/2` 条边

## 3. 图的矩阵表示

### 邻接矩阵（Adjacency Matrix）

> **定义 1.11：** 简单图 `G` 的**邻接矩阵** `A` 是 n×n 矩阵，其中：
> - `A[u][v] = 1`，若 `uv ∈ E(G)`
> - `A[u][v] = 0`，否则

**性质：**
- 对角线全为 0（无自环）
- 矩阵对称（无向图）
- 第 `v` 行的行和 = `deg(v)`

**例：** `P₄`（4顶点路径）的邻接矩阵：
```
     1  2  3  4
1  [ 0  1  0  0 ]
2  [ 1  0  1  0 ]
3  [ 0  1  0  1 ]
4  [ 0  0  1  0 ]
```

### 关联矩阵（Incidence Matrix）

> **定义 1.10：** 图 `G` 的**关联矩阵** `M` 是 `|V|×|E|` 矩阵：
> - `M[v][e] = 1`，若 `v` 是 `e` 的端点之一
> - `M[v][e] = 2`，若 `e` 是从 `v` 出发的自环
> - `M[v][e] = 0`，否则

### 度矩阵与拉普拉斯矩阵（Laplacian Matrix）

> **定义 1.24–1.25：**
> - **度矩阵** `D`：对角矩阵，`D[i][i] = deg(vᵢ)`
> - **拉普拉斯矩阵** `L(G) = D(G) − A(G)`

```
L[i][j] =  deg(vᵢ)   若 i = j
          = −1         若 vᵢvⱼ ∈ E
          =  0         否则
```

> 🎯 **考点：** 习题集第 2–5 题直接考查邻接矩阵和关联矩阵的构造，务必熟练。

## 4. 度与握手引理

### 直觉
每条边恰好连接两个顶点。把所有顶点的度加起来，每条边被计算了恰好两次。

> **定义 1.15（邻域、度）：**
> - `N(v)`：`v` 的所有相邻顶点的集合（邻域）
> - `deg(v)` 或 `d(v)`：顶点 `v` 的度（自环计 2）
> - 在简单图中：`deg(v) = |N(v)|`

### 握手引理

> **引理 1.16（握手引理）：** 对任意图 `G`，
> $$\sum_{v \in V(G)} \deg(v) = 2|E(G)|$$

> **推论 1.17：** 任意图中，**奇数度顶点的数目是偶数**。

### 应用举例
> 若一个图有 6 个顶点，其中 2 个度为 4，4 个度为 2：
> 度之和 = 2×4 + 4×2 = 16 = 2×8，故 |E| = **8**。（习题集第 7 题）

> 🎯 **考点：** 握手引理是几乎所有图论证明的基础工具。推论 1.17 也高频出现（习题集第 19 题直接使用）。

## 5. 度序列与 Havel-Hakimi 算法

### 定义

> **定义 1.18：** 图的**度序列**是其所有顶点度的非递增排列。
> 若某个非负整数序列是某个简单图的度序列，称该序列是**可图的（graphic）**。

### Havel-Hakimi 算法

> **算法 1.19：** 给定非增序列 `A = (s, t₁, ..., tₛ, d₁, ..., dₙ)`，判断是否可图：
> 1. 去掉最大元素 `s`，将紧接的 `s` 个元素各减去 1，得到新序列 `A'`
> 2. 将 `A'` 重新排成非递增序列
> 3. 重复上述步骤，直到序列全为零（**可图** ✓）或出现负数（**不可图** ✗）

**结论：** `A` 可图 ⟺ `A'` 可图。

### 举例
判断 `(4, 3, 3, 3, 3)` 是否可图：
```
第1步: 去掉4，后面4个各减1: (2, 2, 2, 2)
第2步: 去掉2，后面2个各减1: (1, 1)
第3步: 去掉1，后面1个各减1: (0)
全为零 → 可图 ✓
```

> 🎯 **考点：** 习题集第 8、9 题直接考查度的可行性，必须会使用 Havel-Hakimi。

## 6. 图同构

### 直觉
两个图同构，意思是它们有完全相同的结构，只是顶点的名字不同——就像把一张图的顶点重新贴标签。

### 定义

> **定义 1.12（图同构）：** 简单图 `G₁` 和 `G₂` 同构（记作 `G₁ ≅ G₂`），若存在双射 `φ: V(G₁) → V(G₂)`，使得：
> $$uv \in E(G_1) \iff \varphi(u)\varphi(v) \in E(G_2)$$

### 同构的必要条件（均不充分！）
1. 顶点数相同
2. 边数相同
3. 度序列相同
4. 圈的结构相同

**证明同构的方法：** 显式给出双射 `φ`，并逐一验证边的保持关系。

**证明不同构的方法：** 找到某个上述必要条件不满足即可。

> 🎯 **考点：** 习题集第 10–12 题全部要求**证明同构**，必须构造出明确的双射并验证。仅比较度序列是不够的。

## 7. 子图与导出子图

### 定义

> **定义 1.13（子图）：** 若 `V(H) ⊆ V(G)` 且 `E(H) ⊆ E(G)`，则 `H` 是 `G` 的**子图**。
>
> **定义 1.14（导出子图）：** 给定 `X ⊆ V(G)`，`G` 关于 `X` 的**导出子图** `G[X]` 是顶点集为 `X`，边集为 `G` 中两端点均在 `X` 内的所有边的图。

**关键区别：**

| 类型 | 顶点 | 边 |
|------|------|-----|
| 子图 | `V(H) ⊆ V(G)` | 任意 `E(H) ⊆ E(G)` |
| 导出子图 | 固定顶点集 `X` | 自动包含 `G` 中 `X` 内所有边 |

**记住：** 导出子图 ⊆ 子图（导出子图是更受限的）

```
G:   1 — 2 — 3
         |
         4

G[{1,2,4}]：  1 — 2   （保留 G 中端点均在 {1,2,4} 的边：12, 24）
                  |
                  4
```

## 8. 有向图与网络

### 有向图（Digraph）

> **定义 1.20：** **有向图** `D` 中每条边（称为**弧**，arc）有确定的方向，弧 `uv` 的**尾**（tail）为 `u`，**头**（head）为 `v`。

- **出度** `d⁺(v)`：以 `v` 为尾的弧的数目
- **入度** `d⁻(v)`：以 `v` 为头的弧的数目

> **引理 1.22（有向握手引理）：** 对任意有向图 `D`，
> $$\sum_{v} d^+(v) = \sum_{v} d^-(v) = |A(D)|$$

### 网络（Network）

> **定义 1.23：** **网络**是图或有向图 `G`，加上权重函数 `w: E(G) → ℝ`，为每条边赋予一个权重。

**邻接矩阵的区别：** 有向图的邻接矩阵一般**不对称**（无向图对称）。

## 常见错误

- **同构**：仅比较度序列是**必要不充分**条件，必须给出具体的双射映射。
- **自环的度贡献**：自环对其顶点的度贡献为 **2**，不是 1。
- **子图 vs 导出子图**：导出子图必须包含所选顶点之间在原图中的**所有边**。
- **Havel-Hakimi**：每步去掉最大元素后必须**重新排序**再进行下一步。
- **最大边数**：n 个顶点最多 `n(n−1)/2` 条边，不是 `n²`。
