# 第5章 最小生成树与最短路径

> **考试优先级：极高** ——本章是全课程算法最密集的一章。Prim、Kruskal、Dijkstra、Bellman-Ford 全部是必考算法。习题集第 31–37 题全部涉及本章。

## 核心知识速览

| 概念/算法 | 一句话含义 | 考试权重 |
|----------|-----------|---------|
| 最小生成树（MST） | 权重之和最小的生成树 | ⭐⭐⭐ |
| Prim 算法 | 从一个顶点出发，每次加最轻的"跨树边" | ⭐⭐⭐ |
| Kruskal 算法 | 按边权排序，依次加不成圈的最轻边 | ⭐⭐⭐ |
| 逆删算法 | 从完整图出发，依次删最重的非桥边 | ⭐⭐ |
| Dijkstra 算法 | 非负权图中单源最短路径（类 Prim 的贪心） | ⭐⭐⭐ |
| Bellman-Ford 算法 | 允许负权边的单源最短有向路径（动态规划） | ⭐⭐⭐ |
| 负圈检测 | Bellman-Ford 第 n 轮若仍有更新 → 存在负圈 | ⭐⭐ |
| 最长路径（DAG） | 将权重取反后用 Bellman-Ford | ⭐⭐ |

## 1. 最小生成树（MST）

### 定义

> **定义 5.1：** 网络 `(G, w)` 的**最小生成树（Minimum Spanning Tree，MST）**是所有生成树中权重（所有边的权重之和）最小的生成树。

---

## 2. Prim 算法

### 直觉
类似 BFS/DFS 的树扩展，但每次选择的是**连接树内与树外的最轻边**。贪心策略：眼前最便宜的扩展。

> **算法 5.2（Prim）：** 给定网络 `(G, w)` 和起始顶点 `s`：
> - 初始化：`V(T) = {s}`，`E(T) = ∅`
> - 重复：
>   1. 令 `F = {uv ∈ E(G) : u ∈ V(T), v ∉ V(T)}`；若 `F = ∅` 则停止
>   2. 选 `uv ∈ F` 使 `w(u,v)` 最小
>   3. 将 `v` 加入 `V(T)`，`uv` 加入 `E(T)`

**运行时间：** 基本实现 `O(|V|·|E|)`，优化后 `O(|V|²)`，再优化 `O(|E| + |V| log|V|)`。

### 逐步举例

网络（5个顶点）：

```
v₁ —2— v₃ —5— v₄
|       |       |
1       2       1
|       |       |
v₂ —2— v₃     v₅
（边权：v₁v₂=1, v₁v₃=2, v₂v₃=2, v₃v₄=5, v₃v₂=4, v₁v₄=1（注：以讲义图为准）
```

从 `v₁` 出发（参考讲义图 5.1 的网络）：
```
初始: T = {v₁}
轮1: F = {v₁v₂(w=1), v₁v₃(w=2), v₁v₄(w=1)}, 选最小 v₁v₃(w=2) 或并列最小
     → 加入 v₃，边 v₁v₃
轮2: 更新 F，选权最小的跨树边
     → 加入 v₂，边 v₂v₃(w=2)
轮3: → 加入 v₄，边 v₃v₄(w=5)
轮4: → 加入 v₅，边 v₄v₅(w=1)
MST 边集: {v₁v₃, v₂v₃, v₃v₄, v₄v₅}，总权重 = 2+2+5+1 = 10
```

> 🎯 **考点：** 习题集第 31、32 题用 Prim 算法求 MST，要展示每步加入的边和顶点。

## 3. Kruskal 算法

### 直觉
把所有边按权重从小到大排队，依次"考虑"每条边：若加入后不形成圈，就加入；否则跳过。

> **算法 5.4（Kruskal）：** 给定网络 `(G, w)`：
> - 将 `E(G)` 中的边按权重非递减排序，得序列 `F`
> - 初始化：`V(T) = V(G)`，`E(T) = ∅`
> - 对 `F` 中每条边 `uv`：若加入 `uv` 不形成圈，则将 `uv` 加入 `E(T)`

**运行时间：** 排序 `O(|E| log|E|)`，判圈每次 `O(|V|)`，总 `O(|E| log|E| + |V|·|E|)`；优化判圈后可达 `O(|E| log|E|)`。

### 举例

以讲义图 5.1 网络，边按权重排序：
```
v₄v₅(1), v₁v₃(2), v₂v₃(2), v₁v₂(2), v₃v₄(5), ...
```

执行：
```
加 v₄v₅(1)  ✓（不成圈）
加 v₁v₃(2)  ✓
加 v₂v₃(2)  ✓
考虑 v₁v₂(2)：v₁和v₂已经通过v₃相连 → 跳过（会成圈）
加 v₃v₄(5)  ✓ → 生成树完成（5个顶点4条边）
```

> 🎯 **考点：** 习题集第 33、34 题用 Kruskal 求 MST，注意每次判断是否成圈时，可通过"是否在同一连通分量"来判断。

## 4. Prim 与 Kruskal 算法正确性

两个算法都基于同一关键定理：

> **定理 5.8（最轻跨越边定理）：** 设 `S ⊆ V(G)`，`F = {uv ∈ E(G) : u ∈ S, v ∉ S}`（"割"中的边）：
> - 若 `w(uv) = min_{st∈F} w(st)`（最轻跨越边），则**存在一棵 MST 包含 `uv`**
> - 若 `w(uv) < min_{st∈F\{uv}} w(st)`（唯一最轻），则**每棵 MST 都包含 `uv`**

> **定理 5.11（最重圈边定理）：** 设 `F` 是某个圈中的边集：
> - 若 `w(uv) = max_{st∈F} w(st)`（最重圈内边），则**存在一棵 MST 不包含 `uv`**
> - 若 `w(uv) > max_{st∈F\{uv}} w(st)`（唯一最重），则**没有 MST 包含 `uv`**

**MST 唯一性：**
> **定理 5.13：** MST 唯一 ⟺ 对每条不在 MST 中的边 `e = uv`，树中 `u-v` 唯一路径上的每条边 `d` 都满足 `w(e) > w(d)`。

## 5. Dijkstra 算法（非负权最短路径）

### 直觉
类似 Prim，但贪心选择的不是"最轻跨树边"，而是"距起点最近的未访问顶点"。

> **算法 5.14（Dijkstra）：** 给定网络 `(G, w)`（`w ≥ 0`）和起始顶点 `s`：
> - 初始化：`V(T) = {s}`，`E(T) = ∅`，`δ(s) = 0`
> - 重复：
>   1. 令 `F = {uv ∈ E(G) : u ∈ V(T), v ∉ V(T)}`；若 `F = ∅` 则停止
>   2. 对每个 `u ∈ V(T)`，`δ(u)` = 树中 `s-u` 路径的长度（已知）
>   3. 选 `uv ∈ F` 使 `δ(u) + w(u,v)` 最小
>   4. 将 `v` 加入 `V(T)`，`uv` 加入 `E(T)`，`δ(v) = δ(u) + w(u,v)`

**运行时间：** `O(|V|·|E|)`，优化后 `O(|V|²)`，再优化 `O(|E| + |V| log|V|)`。

### 关键定理

> **定理 5.16：** Dijkstra 算法（非负权）产生从 `s` 到同连通分量所有顶点的**最短路径树**。

**⚠️ 重要限制：**
> 若网络中**存在负权边**，Dijkstra 可能给出错误结果！

**反例（讲义例 5.17）：**
```
v₁ —1→ v₂
 \         
  2→   
 v₃ —(−2)→ v₂

Dijkstra 从 v₁ 出发：先选 v₁→v₂（距离 1）
但实际最短路 v₁→v₃→v₂ 的距离 = 2 + (−2) = 0 < 1，Dijkstra 给出了错误答案！
```

### 逐步举例

网络（讲义图 5.1）从 `v₁` 出发：

| V(T) | δ值 | 选择的边 |
|------|-----|---------|
| {v₁} | δ(v₁)=0 | 考虑 v₁v₂(0+1), v₁v₃(0+2), v₁v₄(0+1)，选 v₁v₃(最小2) |
| {v₁,v₃} | δ(v₃)=2 | 更新：v₁v₂=0+1=1, v₃v₂=2+2=4, v₃v₄=2+5=7, 选 v₁v₂(δ=1) |
| {v₁,v₃,v₂} | δ(v₂)=1 | ... |

> 🎯 **考点：** 习题集第 35 题用 Dijkstra 找最短路径树，要展示每步选择的顶点、当前 δ 值和选择的边。

## 6. Bellman-Ford 算法（允许负权边）

### 直觉
不像 Dijkstra 贪心地一次性确定一个顶点的最短路，Bellman-Ford 逐步放宽：先找"最多 1 条弧"的最短路，再找"最多 2 条弧"的，…，直到"最多 n-1 条弧"。

### 递推公式

设 `δₖ(v)` = 从 `s` 出发，使用**至多 k 条弧**的 s-v 有向最短路长度：

$$\delta_0(v) = \begin{cases} 0 & v = s \\ +\infty & \text{否则} \end{cases}$$

$$\delta_k(v) = \min\left(\delta_{k-1}(v),\ \min_{u \in V\setminus\{v\}} [\delta_{k-1}(u) + w(u,v)]\right)$$

> **算法 5.18（Bellman-Ford）：** 对有向网络 `(D, w)` 和起点 `s`，顶点数 `n = |V(D)|`：
> 1. 初始化 `δ₀(s) = 0`，`δ₀(v) = +∞`（v ≠ s）
> 2. 对 `k = 1, 2, ..., n−1`：按上述递推公式更新 `δₖ(v)` 和前驱 `p(v)`
> 3. **第 n 轮检测**：再运行一轮，若任意 `v` 的 `δₙ(v) < δₙ₋₁(v)`，则图中存在**负权圈**，算法失败

**运行时间：** `O(|V|³)`（朴素），优化后 `O(|V|·|A|)`。

### 逐步举例（讲义例 5.19）

有向网络（图 5.2 左图），从 `v₁` 出发，顶点 `v₁,...,v₅`，弧及权重：
`v₁→v₂(4), v₁→v₃(3), v₁→v₄(3), v₂→v₃(−2), v₃→v₄(−1), v₃→v₅(2), v₄→v₅(1)`

| k | v₁ | v₂ | v₃ | v₄ | v₅ |
|---|----|----|----|-----|-----|
| 0 | 0 | ∞ | ∞ | ∞ | ∞ |
| 1 | 0 | 4(v₁) | 3(v₁) | 3(v₁) | ∞ |
| 2 | 0 | 4(v₁) | 2(v₂) | 2(v₃) | 4(v₃) |
| 3 | 0 | 4(v₁) | 2(v₂) | 1(v₃) | 3(v₃) |
| 4 | 0 | 4(v₁) | 2(v₂) | 1(v₃) | 2(v₄) |
| 5 | 0 | 4(v₁) | 2(v₂) | 1(v₃) | 2(v₄) |

第 5 轮（k=5=n）无变化 → 无负圈，结果正确。

**最短路径树**（各顶点的前驱）：
```
v₁←前驱无（起点）
v₂←v₁（路径 v₁→v₂，长度4）
v₃←v₂（路径 v₁→v₂→v₃，长度2）
v₄←v₃（路径 v₁→v₂→v₃→v₄，长度1）
v₅←v₄（路径 v₁→v₂→v₃→v₄→v₅，长度2）
```

## 7. Prim vs Dijkstra vs Bellman-Ford 横向对比

| 特性 | Prim | Dijkstra | Bellman-Ford |
|------|------|----------|--------------|
| 目标 | 最小生成树 | 无向/有向图单源最短路 | 有向图单源最短路 |
| 贪心准则 | 跨树最轻边 | 距起点最近的新顶点 | 逐步放宽（动态规划） |
| 负权边 | 可以（MST 定义无影响） | **不支持** | **支持**（无负圈时） |
| 负圈 | 不适用 | 不适用 | 能检测出来 |
| 基本运行时间 | `O(\|V\|·\|E\|)` | `O(\|V\|·\|E\|)` | `O(\|V\|³)` |
| 优化后 | `O(\|V\|²)` | `O(\|V\|²)` | `O(\|V\|·\|A\|)` |

## 8. 负圈检测与最长路径

### 负圈检测
对任意有向网络，加入虚拟顶点 `u`，从 `u` 向所有原顶点连权重为 0 的弧，再从 `u` 运行 Bellman-Ford。若第 n 轮仍有更新，则存在负圈。

### DAG 中的最长路径
将所有权重乘以 `-1`，再用 Bellman-Ford 求最短路径，即得原问题的最长路径。

## 常见错误

- **Dijkstra 和负权**：Dijkstra 仅适用于**非负权**图，有负权边时答案可能错误。
- **Prim vs Kruskal 的区别**：Prim 从一个顶点出发扩展树；Kruskal 直接对所有边排序逐步加入。两者结果（MST）相同，过程不同。
- **Bellman-Ford 轮数**：需要运行 `n-1` 轮（n 为顶点数）才能保证收敛；第 `n` 轮用于检测负圈。
- **最短路径 vs 最短路径树**：Dijkstra 和 Bellman-Ford 都产生一棵"最短路径树"，不只是一条路径。
- **前驱 `p(v)` 的使用**：找最短路径时需要从终点沿前驱反向追溯。
