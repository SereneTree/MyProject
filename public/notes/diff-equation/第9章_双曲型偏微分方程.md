# 第9章 双曲型偏微分方程的数值方法

> 对应课件：`15-18-双曲型偏微分方程(1).pptx`

---

## 9.1 问题模型

考虑一维**波动方程**的初边值问题：

$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad 0 < x < l,\ 0 < t \leq T$$

边界条件：$u(0, t) = g_1(t),\quad u(l, t) = g_2(t)$

初始条件：$u(x, 0) = \varphi(x),\quad u_t(x, 0) = \psi(x)$

---

## 9.2 网格剖分

- 空间步长 $h$，节点 $x_i = ih$
- 时间步长 $\tau$，节点 $t_n = n\tau$
- 记 $u_i^n \approx u(x_i, t_n)$，网格比 $\lambda = c\tau/h$（Courant 数）

---

## 9.3 显式差分格式

对时间二阶导和空间二阶导分别用中心差商：

$$\frac{u_i^{n+1} - 2u_i^n + u_i^{n-1}}{\tau^2} = c^2 \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{h^2}$$

整理得**显式三层格式**：

$$\boxed{u_i^{n+1} = 2u_i^n - u_i^{n-1} + \lambda^2(u_{i+1}^n - 2u_i^n + u_{i-1}^n)}$$

其中 $\lambda = c\tau/h$。

### 初始层的处理

由初始条件 $u(x, 0) = \varphi(x)$ 和 $u_t(x, 0) = \psi(x)$，推导第一层 $u_i^1$：

$$u_i^1 = u_i^0 + \tau \psi(x_i) + \frac{\tau^2}{2}\left[c^2 \varphi''(x_i)\right] + O(\tau^3)$$

近似取：

$$u_i^1 \approx u_i^0 + \tau \psi_i + \frac{\lambda^2}{2}(u_{i+1}^0 - 2u_i^0 + u_{i-1}^0)$$

---

## 9.4 显格式的稳定性分析

将显格式等价改写为关于 $(u^n, u^{n-1})$ 的**一阶方程组两层格式**，增长矩阵为：

$$G(\xi) = \begin{pmatrix} 2 - 4\lambda^2\sin^2(\xi h/2) & -1 \\ 1 & 0 \end{pmatrix}$$

特征值 $\mu_{1,2}$ 满足：

$$\mu^2 - \left[2 - 4\lambda^2\sin^2\!\frac{\xi h}{2}\right]\mu + 1 = 0$$

稳定条件（Von Neumann 方法）：$|\mu_{1,2}| \leq 1$

经分析，稳定条件为：

$$\boxed{\lambda = \frac{c\tau}{h} \leq 1}$$

即 **CFL 条件**（Courant-Friedrichs-Lewy 条件）。

---

## 9.5 隐式差分格式

$$\frac{u_i^{n+1} - 2u_i^n + u_i^{n-1}}{\tau^2} = \frac{c^2}{4}\left[\delta_x^2 u_i^{n+1} + 2\delta_x^2 u_i^n + \delta_x^2 u_i^{n-1}\right]$$

整理后需每步求解三对角线性方程组。

### 隐式格式的稳定性

增长矩阵的特征多项式为：

$$\mu^2 - \frac{2 - 4\lambda^2\sin^2(\xi h/2)}{1 + \lambda^2\sin^2(\xi h/2)}\mu + 1 = 0$$

可以证明：对所有 $\lambda > 0$，特征值均满足 $|\mu| = 1$，故隐式格式**无条件稳定**。

---

## 9.6 显式 vs 隐式格式对比

| 比较项 | 显式格式 | 隐式格式 |
|--------|----------|----------|
| 计算方式 | 直接推进 | 每步解三对角方程组 |
| 截断误差 | $O(\tau^2 + h^2)$ | $O(\tau^2 + h^2)$ |
| 稳定条件 | $\lambda \leq 1$（CFL） | 无条件稳定 |
| 实用建议 | 小 $\lambda$ 时高效 | 需大步长时使用 |

---

## 9.7 稳定性判断的一般准则（Godunov-Ryabenkii 定理）

对一般二阶差分方程：

$$\alpha u_i^{n+1} + \beta u_i^n + \gamma u_i^{n-1} = \cdots$$

增长因子 $g$ 满足特征多项式。稳定的充要条件为：

- 特征多项式的根满足 $|g| \leq 1$；若 $|g| = 1$ 则根是单特征根。

**实用判别法（定理4.4）**：

若差分格式的增长矩阵 $G(\xi)$ 满足：

$$\|G^n(\xi)\| \leq C \quad \text{对所有 } n, \xi$$

则格式稳定。应用时注意以下两个简单事实：
1. 矩阵谱半径 $\rho(G) \leq 1$ 是稳定的必要条件
2. 对于正规矩阵，$\rho(G) \leq 1 \Leftrightarrow$ 稳定

---

## 9.8 强迫振动模型

带外力项的波动方程：

$$u_{tt} = c^2 u_{xx} + F(x, t)$$

**方法一**：直接用前述差分格式求解（加入源项 $F_i^n$）；

**方法二**：利用 Fourier 变换（在地球物理、电子技术领域常用）——将空间变量展开为 Fourier 级数，转化为关于时间的常微分方程组。

---

## 9.9 抛物型与双曲型方程稳定性对比

| 方程类型 | 格式 | 稳定条件 |
|----------|------|----------|
| 抛物型 | 向前差分 | $r = a^2\tau/h^2 \leq 1/2$ |
| 抛物型 | C-N 格式 | 无条件稳定 |
| 双曲型 | 显格式 | $\lambda = c\tau/h \leq 1$（CFL） |
| 双曲型 | 隐格式 | 无条件稳定 |

---

## 总结

- 波动方程差分格式为**三层格式**，需要两层初值启动
- 显格式效率高，但受 **CFL 条件** $\lambda \leq 1$ 约束，否则解发散
- 隐式格式无条件稳定，但每步需解三对角方程组
- Fourier（Von Neumann）方法是分析稳定性的通用工具
- CFL 条件有物理意义：数值信息传播速度不应超过物理波速
