## 1.0 引言：信任问题

### 为什么需要区块链？

人类社会存在三类信任困境：

| 信任类型 | 特点 | 问题 |
|---------|------|------|
| 熟人信任 | 基于人际关系 | 成本高、范围窄、易被破坏 |
| 中介信任 | 基于第三方机构（银行、支付宝等）| 中介本身可能失信；手续费高 |
| 互联网信任 | 基于网络平台 | 网络谣言、AI 造假盛行 |

> **区块链的本质**：一种基于机器的新型信任模型，让信任规则由代码自动执行，无需依赖人或机构。

---

## 1.1 区块链的定义

### 官方定义（工信部）
> 区块链是分布式数据存储、点对点传输、共识机制、加密算法等计算机技术的新型应用模式。

**四大核心技术**：
- 分布式数据存储（Distributed Storage）
- 点对点传输（Peer-to-Peer, P2P）
- 共识机制（Consensus Mechanism）
- 加密算法（Cryptography）

### 区块链七个维度

区块链并非单一全新技术，而是对已有计算机技术的**创新融合**。

### 典型应用案例
- **区块链电子发票**（深圳税务局 × 腾讯）
  - 从受票、开票、流转到报销全程可追溯
  - 多方共同记账，数据无法篡改

---

## 1.2 区块链的分类

| 类型 | 特点 | 代表 |
|------|------|------|
| **公有链**（Public Chain）| 完全去中心，任何人可参与 | 比特币、以太坊 |
| **联盟链**（Consortium Chain）| 多机构共管，半中心化 | Hyperledger Fabric |
| **私有链**（Private Chain）| 单机构内部使用，中心化 | 企业内部账本 |

---

## 1.3 区块链的特征

| 特征 | 说明 |
|------|------|
| **去中心化**（Decentralization）| 无单一控制节点，所有节点地位平等 |
| **开放性**（Openness）| 数据对全网公开（私有链除外） |
| **自治性**（Autonomy）| 规则由共识协议自动执行 |
| **匿名性**（Anonymity）| 用户以地址（公钥哈希）参与，无需实名 |
| **不可篡改**（Immutability）| 已上链数据极难修改 |

### 去中心化的优势
- 无单点故障
- 抗审查
- 各节点利益对齐，不依赖对单一中心的信任

---

## 1.4 区块链运行机制

### 基本流程（四步）

```
1. 构建分布式节点网络
   └── 每个节点保存完整/部分账本副本

2. 发起交易
   └── 发送方用私钥签名，广播至全网

3. 共识验证
   └── 节点按共识机制（如 PoW）验证交易，达成一致

4. 写入区块链
   └── 新区块附加到链尾，全网同步更新
```

### 关键原则
- **多节点共同记账**：每次新数据加入，所有节点参与验证
- **一致性保证**：只有验证通过，数据才进入链

---

## 重点总结

- 区块链的本质是**建立信任的新模型**，核心是"去中介、建规则"
- 三类链（公有链 / 联盟链 / 私有链）各有适用场景
- 四大核心技术缺一不可：存储 + 传输 + 共识 + 加密
- 特征口诀：**去开自匿不**（去中心、开放、自治、匿名、不可篡改）
