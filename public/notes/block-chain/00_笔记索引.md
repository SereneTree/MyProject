## 核心知识点速览

### 区块链基础

- **区块链本质**：建立机器信任的新模型，核心技术 = 分布式存储 + P2P + 共识机制 + 加密算法
- **三类链**：公有链（比特币/以太坊）/ 联盟链（Hyperledger）/ 私有链
- **五大特征**：去中心化、开放性、自治性、匿名性、不可篡改

### 发展历程

| 版本 | 代表 | 核心创新 |
|------|------|---------|
| 1.0 | 比特币 | 数字货币 |
| 2.0 | 以太坊 | 智能合约 |
| 3.0 | Hyperledger | 产业应用 |
| 4.0 | BSN | 信任社会 |

### 密码学

| 知识点 | 核心 |
|--------|------|
| 哈希函数 | 单向、抗碰撞、雪崩效应 |
| SHA-256 | 比特币使用，输出 256 位 |
| SM3 | 中国国密哈希标准，输出 256 位 |
| 默克尔树 | 哈希二叉树，SPV 交易验证 |
| RSA | 大整数分解，1024+ 位密钥 |
| ECC/ECDSA | 椭圆曲线离散对数，160 位密钥，区块链主流 |
| 数字签名 | 哈希 → 私钥签名 → 公钥验证 |

### P2P 网络

| 知识点 | 核心 |
|--------|------|
| 全节点 | 完整账本副本，安全性最高 |
| 轻节点（SPV）| 只存区块头，依赖全节点验证 |
| Bloom 过滤器 | 概率型，无假阴性，有假阳性，保护轻节点隐私 |
| UTXO | 比特币账户模型，哈希表高效查验 |
| 交易池 | mempool（比特币）/ pending queue（以太坊）|

### 以太坊

| 知识点 | 核心 |
|--------|------|
| FLP 定理 | 异步系统中完美共识不可能 |
| CAP 原理 | 一致性/可用性/分区容错，最多满足两个 |
| EVM | 完全隔离的沙箱虚拟机 |
| Ethash | 内存密集型 PoW，抗 ASIC |
| PoS | 基于持币权益，引入币龄，节约资源 |
| 两类账户 | EOA（外部）vs CA（合约），合约无私钥 |
| 账户四字段 | nonce / balance / storageHash / codeHash |
| Gas 机制 | 交易费 = Gas × GasPrice |
| 三棵树 | 状态树 / 交易树 / 收据树（MPT 结构）|

### 多价值链数据共享

| 知识点 | 核心 |
|--------|------|
| 五层架构 | 资源层→集成层→区块链服务→共享层→服务层 |
| 三维上链决策 | 数据规模 × 交互频率 × 敏感程度 |
| 链上存证 | 保障共享行为不可抵赖 |
| 改进方向 | 分层多链 + 联邦学习/ZKP/ABE + 激励机制 |
