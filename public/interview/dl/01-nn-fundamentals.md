## 一、前向传播

### 单层计算

```
z = Wx + b          (线性变换)
a = σ(z)            (非线性激活)
```

### 多层网络

```
输入 x → [W1, b1] → σ → [W2, b2] → σ → ... → [WL, bL] → ŷ
```

**参数量计算公式**：
- 全连接层：`参数量 = 输入维度 × 输出维度 + 输出维度（bias）`
- 示例：输入 784，隐藏 256，输出 10
  - 第一层：784 × 256 + 256 = 200,960
  - 第二层：256 × 10 + 10 = 2,570

## 二、反向传播（⭐ 最高频考点）

### 核心思想：链式法则

```
∂L/∂W_l = ∂L/∂a_L · ∂a_L/∂z_L · ∂z_L/∂a_{L-1} · ... · ∂z_l/∂W_l
```

### 手推示例（两层网络）

```
网络：x → (W1) → ReLU → (W2) → Softmax → L(cross-entropy)

前向：
  z1 = W1·x + b1
  a1 = ReLU(z1)
  z2 = W2·a1 + b2
  ŷ  = Softmax(z2)
  L  = -Σ y_i · log(ŷ_i)

反向：
  ∂L/∂z2 = ŷ - y                          (Softmax + CE 的优美梯度)
  ∂L/∂W2 = (ŷ - y) · a1^T
  ∂L/∂a1 = W2^T · (ŷ - y)
  ∂L/∂z1 = ∂L/∂a1 ⊙ ReLU'(z1)           (逐元素乘)
  ∂L/∂W1 = ∂L/∂z1 · x^T
```

### 计算图视角

```
x ──→ [×W1] ──→ [+b1] ──→ [ReLU] ──→ [×W2] ──→ [+b2] ──→ [Softmax+CE] ──→ L
                                                                            ↑
                                                                           y(标签)
反向传播：沿计算图逆向，每个节点贡献"局部梯度 × 上游梯度"
```

### 必背结论

| 结论 | 解释 |
|------|------|
| Softmax + CrossEntropy 的梯度 = ŷ - y | 推导简洁，工程中合并计算 |
| ReLU 的梯度 = 0 或 1 | 正区间梯度恒为 1，不衰减 |
| Sigmoid 的梯度 = σ(1-σ) | 最大值 0.25，深层连乘必然消失 |

## 三、激活函数

### 常见激活函数对比

| 函数 | 公式 | 优点 | 缺点 |
|------|------|------|------|
| Sigmoid | 1/(1+e^(-x)) | 输出 (0,1)，适合概率 | 梯度消失、非零中心 |
| Tanh | (e^x-e^(-x))/(e^x+e^(-x)) | 零中心输出 | 仍有梯度消失 |
| ReLU | max(0, x) | 计算快、缓解梯度消失 | Dead ReLU（负区间梯度为 0） |
| Leaky ReLU | max(αx, x), α=0.01 | 解决 Dead ReLU | α 是超参数 |
| GELU | x·Φ(x) | 平滑 + 概率解释 | 计算稍贵 |
| Swish/SiLU | x·σ(x) | 自门控、平滑 | 计算略贵 |

### 选择策略

```
隐藏层默认：ReLU / GELU
输出层分类：Softmax（多分类）/ Sigmoid（多标签）
输出层回归：无激活 / ReLU（非负输出）
Transformer 中：GELU（BERT）/ SwiGLU（LLaMA）
```

## 四、梯度消失与梯度爆炸

### 原因

```
∂L/∂W_1 = ∂L/∂a_L · (∏_{l=2}^{L} ∂a_l/∂a_{l-1}) · ∂a_1/∂W_1

若每层梯度 < 1 → 连乘趋向 0 → 梯度消失
若每层梯度 > 1 → 连乘趋向 ∞ → 梯度爆炸
```

### 解决方案速查表

| 问题 | 解决方案 | 原理 |
|------|---------|------|
| 梯度消失 | ReLU 替代 Sigmoid | ReLU 正区间梯度恒为 1 |
| 梯度消失 | 残差连接（ResNet） | 梯度可直通 shortcut 路径 |
| 梯度消失 | BatchNorm | 稳定各层输入分布，避免进入饱和区 |
| 梯度消失 | LSTM 门控 | Cell State 提供无衰减梯度通道 |
| 梯度爆炸 | 梯度裁剪 | `clip_grad_norm_(max_norm=1.0)` |
| 梯度爆炸 | 权重正则化 | L2 约束权重大小 |
| 两者 | 合理初始化 | Xavier（Sigmoid/Tanh）、He（ReLU） |

## 五、权重初始化

### 设计目标

使每层输出的方差与输入方差相当，避免信号在传播过程中放大或衰减。

### 常用方案

| 方法 | 公式 | 适用激活函数 |
|------|------|-------------|
| Xavier (Glorot) | W ~ N(0, 2/(n_in + n_out)) | Sigmoid, Tanh |
| He (Kaiming) | W ~ N(0, 2/n_in) | ReLU 系列 |

### 推导直觉（He 初始化）

```
Var(y) = n_in · Var(w) · E[x²]
ReLU 将一半输出置零 → E[x²] = Var(x)/2
要求 Var(y) = Var(x) → Var(w) = 2/n_in
```

## 速答 6 道

**Q1：反向传播的本质是什么？**

→ 利用链式法则，在计算图上从输出到输入逆向传播梯度，每个节点只需计算"局部梯度 × 上游传来的梯度"，复杂度与前向传播相当（O(n)），避免暴力重复计算。

**Q2：为什么 Sigmoid 会导致梯度消失？**

→ Sigmoid 导数最大值仅 0.25，多层连乘后梯度指数衰减趋近于 0；且输出非零中心，导致参数更新效率低。

**Q3：ReLU 的 Dead Neuron 问题怎么解决？**

→ 使用 Leaky ReLU（负区间给小斜率 α）、PReLU（α 可学习）、ELU（负区间指数衰减）、或使用合理的学习率和 He 初始化避免神经元死亡。

**Q4：Xavier 和 He 初始化的区别？**

→ Xavier 假设激活函数关于 0 对称（线性区），适合 Sigmoid/Tanh；He 考虑了 ReLU 会将一半激活置零，方差需乘 2 补偿，适合 ReLU 系列。

**Q5：为什么用交叉熵而不是 MSE 做分类？**

→ MSE 对 Softmax 求导后梯度含 σ'(z) 项，在错误预测时梯度反而很小（学习慢）；交叉熵 + Softmax 的梯度 = ŷ - y，错误越大梯度越大，收敛更快。

**Q6：什么是计算图？PyTorch 的自动微分怎么实现？**

→ 计算图是将前向计算拆解为基本算子的有向无环图；PyTorch 动态构建计算图，每个 Tensor 记录其 grad_fn（对应反向计算规则），调用 `.backward()` 时沿图逆序逐节点累加梯度。
