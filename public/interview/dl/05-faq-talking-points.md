## 🔥 Top 10 必考题

### Q1：请解释反向传播算法

**答**：反向传播本质是链式法则的高效实现。前向传播中，数据从输入逐层流到输出得到 Loss；反向传播从 Loss 出发，沿计算图反向传播，每个节点只需计算局部梯度与上游梯度的乘积，最终得到所有参数的梯度。时间复杂度与前向传播相当（O(n)），避免了暴力重复计算。PyTorch 通过动态计算图实现自动微分，每个 Tensor 记录 grad_fn，调用 backward() 自动完成。

---

### Q2：梯度消失和梯度爆炸的原因与解决方案

**答**：深层网络反向传播时梯度需要多层连乘，若每层梯度绝对值 < 1 则趋向 0（消失），> 1 则趋向 ∞（爆炸）。

**解决梯度消失**：①用 ReLU 替代 Sigmoid（正区间梯度恒为 1）②残差连接（梯度可直通 shortcut）③BatchNorm（避免进入饱和区）④LSTM 门控机制。

**解决梯度爆炸**：①梯度裁剪（clip_grad_norm）②合理的权重初始化（He/Xavier）③正则化。

---

### Q3：BatchNorm 的原理和作用

**答**：BN 对每个 mini-batch 在特征维度做标准化（减均值除标准差），再通过可学习的 γ、β 缩放平移。

**作用**：①加速收敛（允许用更大学习率）②缓解梯度消失（稳定激活值分布）③隐式正则化（batch 统计引入随机性）。

**注意**：训练时用 batch 统计，推理时用 running mean/var；小 batch 时不稳定，可改用 GroupNorm 或 LayerNorm。

---

### Q4：ResNet 残差连接为什么有效

**答**：设要学习的映射为 H(x)，残差块学习 F(x) = H(x) - x，即"在恒等映射基础上的微小修正"。

**三个好处**：
1. 梯度直通：反向传播时 ∂L/∂x 多了一条 shortcut 路径，梯度不会消失
2. 训练更容易：学习残差（小量修正）比学习完整映射更容易优化
3. 退化保底：最差情况 F(x)→0，网络退化为恒等映射，不会比浅网络差

---

### Q5：Transformer 的 Self-Attention 机制

**答**：Self-Attention 将输入通过三个线性变换得到 Q、K、V。用 Q 与 K 的点积计算相似度，除以 √d_k 后 softmax 归一化得到注意力权重，再加权求和 V。

**核心优势**：①任意两个位置直接交互（O(1) 路径长度）②全局依赖建模③完全并行（不像 RNN 顺序计算）。

**除以 √d_k 的原因**：QK 点积方差 = d_k，不归一化会导致 softmax 进入饱和区（梯度接近 0）。

---

### Q6：Adam 优化器的原理

**答**：Adam 维护两个动量：一阶动量 m（梯度的指数移动平均，方向估计）和二阶动量 v（梯度平方的指数移动平均，步长调节）。更新公式：θ -= lr × m̂/(√v̂ + ε)。

**直觉**：梯度大的参数用小步长（自适应），梯度方向稳定的参数步子更大（动量）。兼顾了 Momentum 的方向性和 RMSProp 的自适应性。

**选型**：NLP/Transformer 首选 AdamW（解耦权重衰减）；大规模 CV 可用 SGD+Momentum（泛化更好）。

---

### Q7：Dropout 的原理和为什么有效

**答**：训练时每个神经元以概率 p 随机被屏蔽（输出置 0），推理时所有神经元参与。用 Inverted Dropout 除以 keep_prob 保持输出期望一致。

**有效原因**：①模型集成：每次 drop 不同 = 训练了指数级子网络的集成②打破共适应：迫使每个神经元独立工作③等价于隐式 L2 正则。

---

### Q8：LSTM 如何解决长期依赖问题

**答**：LSTM 引入 Cell State 作为信息传递的"高速公路"，通过三个门控制信息流：
- 遗忘门：决定丢弃多少旧信息（f_t ≈ 1 时信息完全保留）
- 输入门：决定写入多少新信息
- 输出门：决定输出多少 Cell 内容

**关键**：Cell State 的梯度 ∂C_t/∂C_{t-1} = f_t，是逐元素乘法而非矩阵乘法，遗忘门可学习为接近 1，使梯度长距离传播不衰减。

---

### Q9：为什么 Transformer 需要位置编码

**答**：Self-Attention 是集合运算（置换不变），输入顺序打乱结果不变，因此需要显式注入位置信息。

**sin/cos 编码优势**：①可推广到任意长度（不受训练长度限制）②PE(pos+k) 可表示为 PE(pos) 的线性变换（隐式学习相对位置）③不增加可学习参数。

**现代方案**：RoPE（旋转位置编码，LLaMA/GPT-NeoX 使用），将位置信息编码为旋转矩阵，直接作用在 Q/K 上。

---

### Q10：过拟合如何诊断和解决

**答**：

**诊断**：训练 loss 低 + 验证 loss 高；训练准确率 >> 验证准确率。

**解决方案（优先级）**：
1. 更多数据 / 数据增强（最根本）
2. 正则化：L2、Dropout、Label Smoothing
3. 早停（监控验证集 loss）
4. 减小模型容量（减少层数/宽度）
5. 集成学习（多模型 + 平均）

## 📋 进阶 20 题

### Q11：1×1 卷积有哪些用途？

→ ①通道降维/升维（Bottleneck 结构中压缩计算）②跨通道信息融合③增加非线性（后接 ReLU）④等价于对每个像素位置做全连接。

---

### Q12：深度可分离卷积的计算量优势？

→ 标准卷积 FLOPs = K²·C_in·C_out·H·W；深度可分离 = K²·C_in·H·W + C_in·C_out·H·W。压缩比 ≈ 1/C_out + 1/K² ≈ 1/8~1/9（3×3 卷积）。MobileNet 核心设计。

---

### Q13：为什么用交叉熵而不是 MSE 做分类？

→ MSE + Softmax 的梯度含 σ'(z) 项，在错误预测时梯度反而小（学习慢）；交叉熵 + Softmax 梯度 = ŷ - y，错误越大梯度越大，收敛更快更稳。

---

### Q14：Label Smoothing 的作用？

→ 将 hard label [0,0,1,0] 软化为 [ε/K, ε/K, 1-ε+ε/K, ε/K]（ε=0.1）。防止模型对 logit 过度自信（输出趋向 ±∞），提升泛化能力，改善校准性。

---

### Q15：BN 在训练和推理时的区别？

→ 训练：用当前 batch 的均值/方差归一化，同时用指数移动平均更新 running_mean/var。推理：用积累的 running_mean/var（固定值），BN 退化为线性变换，可与前一层 Conv 融合加速。

---

### Q16：为什么 GAN 训练不稳定？怎么改善？

→ 生成器和判别器的博弈容易陷入模式崩溃（generator 只产生少数样本骗过 discriminator）。改善：①WGAN：Wasserstein 距离替代 JS 散度②谱归一化③渐进式训练④多尺度判别器。

---

### Q17：知识蒸馏的原理？

→ Teacher（大模型）输出 soft label（概率分布），Student（小模型）同时学习 hard label（真实标签）和 soft label（包含类间相似度信息）。温度 T 软化分布：softmax(z/T)，T 越大分布越平滑，暗含更多结构信息。

---

### Q18：数据增强的常见方法？

→ **CV**：翻转、旋转、裁剪、颜色抖动、Cutout、Mixup、CutMix、RandAugment。**NLP**：同义词替换、回译、随机删除/插入/交换、EDA。**核心原则**：增强后的数据分布不应偏离真实分布太远。

---

### Q19：学习率 warmup 为什么重要？

→ ①训练初期权重随机 → 梯度方向不可靠 → 大 lr 易发散②Adam 的自适应项 v_t 初始估计不准（接近 0 → 实际 lr 过大）③warmup 给一个"缓冲期"，等统计量稳定后再用正常 lr。

---

### Q20：多卡训练时如何处理 BatchNorm？

→ 默认 BN 在每个 GPU 上独立计算统计量（有效 batch = 单卡 batch），小了会不稳定。解决：SyncBN（跨卡同步 BN 统计量），或使用 GroupNorm（不依赖 batch）。

---

### Q21：什么是梯度累积？什么场景用？

→ 多步前向反向后再统一更新参数，等效于大 batch 训练。用于 GPU 显存不够跑大 batch 的场景。注意：BN 统计量仍基于实际 batch size。

---

### Q22：FP16 混合精度训练的注意事项？

→ ①Loss Scaling：放大 loss 防止 FP16 梯度下溢②Master Weights 保持 FP32 精度③部分运算（Softmax、LayerNorm、Loss）保持 FP32 避免数值不稳定。收益：显存减半 + A100 Tensor Core 加速 2~3×。

---

### Q23：对比学习（Contrastive Learning）的核心思想？

→ 无监督地学习表示：同一样本的不同增强视图为正样本对（拉近），不同样本为负样本对（推远）。InfoNCE Loss = -log(exp(sim(z_i, z_j)/τ) / Σ exp(sim(z_i, z_k)/τ))。代表：SimCLR、MoCo、BYOL。

---

### Q24：ViT（Vision Transformer）的核心思想？

→ 将图像切成 16×16 patches → 展平为序列 → 加 Position Embedding → 送入标准 Transformer Encoder → CLS token 做分类。证明了纯 Attention 架构在大规模数据下可以匹配甚至超越 CNN。

---

### Q25：模型量化 INT8 的原理？

→ 将 FP32 权重/激活映射到 INT8 范围（-128~127）。对称量化：x_q = round(x / scale)；非对称：x_q = round(x / scale) + zero_point。标定：用校准集确定 scale。精度损失通常 < 1%，推理速度提升 2~4×。

---

### Q26：什么是残差学习？为什么学残差比直接学映射更容易？

→ 网络学习 F(x) = H(x) - x（偏差/修正），而非直接学习 H(x)。直觉：如果最优映射接近恒等（深层网络中常见），学"修正量 → 0"比学"恒等映射"对优化器更友好（Loss 面更平滑）。

---

### Q27：注意力机制中 Q/K/V 分别代表什么？

→ Query = "我在找什么"，Key = "我有什么可以提供的"，Value = "我实际的内容"。Q·K 计算相关性（"你要的和我有的匹不匹配"），高分的 V 被更多地聚合到输出中。

---

### Q28：为什么 Transformer 的 FFN 维度是 4d？

→ 经验设计：d_ff = 4 × d_model 提供足够的非线性变换容量。类似"先升维 → 非线性 → 降维"的 bottleneck 反向结构。最近的 LLM（如 LLaMA）使用 SwiGLU 激活 + d_ff = 8d/3。

---

### Q29：Pre-Norm vs Post-Norm 的区别？

→ Post-Norm：x + LayerNorm(SubLayer(x))（原始 Transformer）→ 训练不稳定需要 warmup。Pre-Norm：x + SubLayer(LayerNorm(x))（GPT-2+）→ 残差路径不经过 LN，梯度更顺畅，训练稳定，但可能牺牲一点最终精度。

---

### Q30：如何判断模型是否在有效学习？

→ ①Loss 曲线平稳下降（非震荡剧烈）②梯度范数保持合理范围（不是 0 也不是 NaN）③验证集指标持续提升④各层激活值分布稳定（不全 0 或饱和）⑤权重更新比率 ||ΔW||/||W|| 在 1e-3 量级。
