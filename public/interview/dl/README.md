## 🎯 必背核心考点（Top 15）

> 这 15 题占面试出现率 **80%+**，没复习时间也要先把这些拿下。

| 排名 | 考点 | 一句话答案 |
|------|------|-----------|
| 1 | 反向传播的本质？ | 链式法则逐层求导，从 Loss 到每层参数的梯度 |
| 2 | 梯度消失/梯度爆炸？ | 深层网络连乘导致梯度趋0或趋∞；解决：ResNet/BN/梯度裁剪 |
| 3 | BatchNorm 的作用和原理？ | 对 mini-batch 做标准化再缩放，加速收敛 + 正则化效果 |
| 4 | ReLU vs Sigmoid vs Tanh | ReLU 不饱和、计算快、缓解梯度消失；Sigmoid 有梯度消失 |
| 5 | 1×1 卷积的作用？ | 跨通道信息融合 + 降/升维 + 减少参数量 |
| 6 | ResNet 为什么能训练很深？ | 残差连接让梯度可直通，解决退化问题 |
| 7 | LSTM 如何解决梯度消失？ | 门控机制 + Cell State 提供梯度高速公路 |
| 8 | Transformer Self-Attention | Q·K^T/√d → Softmax → V，全局依赖 + 并行计算 |
| 9 | 为什么除以 √d_k？ | 防止 QK 点积过大导致 Softmax 梯度消失（进入饱和区）|
| 10 | Adam 优化器原理？ | 一阶动量 + 二阶动量自适应学习率，兼顾方向和步长 |
| 11 | Dropout 为什么有效？ | 训练时随机屏蔽神经元，等价于模型集成，减少过拟合 |
| 12 | 过拟合如何解决？ | 数据增强 / Dropout / 正则化 / 早停 / 减小模型 |
| 13 | 卷积输出尺寸公式？ | (W - K + 2P) / S + 1 |
| 14 | 感受野如何计算？ | 逐层递推：RF_l = RF_{l-1} + (K_l - 1) × stride_prod |
| 15 | 位置编码为什么用 sin/cos？ | 可泛化到训练中未见的序列长度 + 相对位置可由线性变换得到 |

## ⚡ 答题黄金三段式

面试回答建议按以下结构组织：

```
是什么 → 为什么（设计动机 / 解决了什么问题）→ 怎么用（工程经验 / 注意事项）
```

### 万能开头话术

- "这个问题可以从 **原理层面** 和 **工程实践** 两个角度来回答…"
- "我理解这个概念的核心是…，它解决的问题是…"
- "在我之前的项目中，关于这个问题我的经验是…"

### 答完加分动作

- 主动关联："这和 XX 问题有联系，可以一起看…"
- 对比分析："如果和 XX 方案对比的话…"
- 工程视角："实际落地时还需要注意…"
