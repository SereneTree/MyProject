# OSI 与 TCP/IP 模型 —— 面试高频考点

> 网络分层是理解所有网络协议的基础框架，面试中几乎必问"各层职责"和"数据封装"。

## 三、重点考点深入

### 考点1：数据封装与解封装

```
发送方（自顶向下封装）:

应用层数据: [HTTP请求内容]
     ↓ + TCP头(端口号、序列号)
传输层:    [TCP头 | HTTP数据]
     ↓ + IP头(源IP、目的IP)
网络层:    [IP头 | TCP头 | HTTP数据]
     ↓ + 帧头(MAC地址) + 帧尾(FCS校验)
链路层:    [帧头 | IP头 | TCP头 | HTTP数据 | FCS]
     ↓ 转为比特流
物理层:    101010110011001...

接收方: 反向逐层剥离头部（解封装）
```

**面试常问**：
```
Q: 为什么要分层？
A: 1. 各层独立：修改某层实现不影响其他层（如将以太网换成Wi-Fi）
   2. 降低复杂度：每层只关心自己的职责
   3. 标准化：不同厂商在同一层可以互通

Q: TCP/IP模型为什么只有四层？
A: 实践中发现OSI的5/6/7层界限模糊，很多协议同时跨越多层
   TCP/IP模型更贴合实际实现（BSD Socket API就是按四层设计的）
```

### 考点2：每层的寻址方式

| 层次 | 地址类型 | 示例 | 作用范围 |
|------|---------|------|---------|
| 应用层 | URL/域名 | www.baidu.com | 全球唯一 |
| 传输层 | 端口号 | 80, 443, 8080 | 主机内唯一 |
| 网络层 | IP地址 | 192.168.1.1 | 网络内逻辑唯一 |
| 链路层 | MAC地址 | AA:BB:CC:DD:EE:FF | 全球物理唯一 |

### 考点3：协议分布图

```
应用层:   HTTP  HTTPS  DNS   FTP  SMTP  SSH  DHCP  SNMP
           |     |     |     |    |     |     |      |
传输层:   ====TCP====  ==UDP==  ===TCP===   ==UDP==
```

## 四、典型面试题 & 答案

### 题1：请描述OSI七层模型，每层的作用是什么？

**答**：OSI模型从底到顶分七层：
- **物理层**：传输原始比特流，定义电气和机械规范
- **数据链路层**：将比特组装成帧，提供点到点的可靠传输（MAC寻址、差错检测）
- **网络层**：逻辑寻址和路由选择，实现跨网络的数据包转发（IP地址）
- **传输层**：提供端到端的可靠传输（TCP）或高效传输（UDP），端口复用
- **会话层**：管理会话的建立、维护和终止
- **表示层**：数据格式转换、加密解密、数据压缩
- **应用层**：为应用程序提供网络服务（HTTP、DNS等）

**加分**：实际中常用TCP/IP四层模型，将会话层/表示层/应用层合并为应用层。

### 题2：数据从应用到网卡经过了什么过程？

**答**：
1. 应用层生成HTTP请求数据
2. 传输层添加TCP/UDP头部（源端口、目的端口、序列号等）→ 形成**段(Segment)**
3. 网络层添加IP头部（源IP、目的IP、TTL等）→ 形成**包(Packet)**
4. 链路层添加以太网帧头（源MAC、目的MAC）和帧尾（FCS校验）→ 形成**帧(Frame)**
5. 物理层将帧转为电信号/光信号在介质上传输

接收方按相反顺序逐层解封装，最终将数据交给应用程序。

### 题3：为什么需要MAC地址和IP地址两个地址？

**答**：
- **IP地址**是逻辑地址，用于**跨网络**路由选路（"找到目标网络"）
- **MAC地址**是物理地址，用于**同一链路**内定位具体设备（"在本网段找到具体机器"）

类比：IP地址 = 收件人地址（省市区街道），MAC地址 = 快递员交给最后一个人的身份证号。

网络通信中数据包的IP地址（最终目标）保持不变，但MAC地址每经过一个路由器就会改变（变为下一跳的MAC）。

## 五、面试加分点

### 常见追问与应对

```
Q: 知道哪些协议是工作在哪一层的？
A: 传输层: TCP, UDP
   网络层: IP, ICMP, ARP(严格说跨2-3层), OSPF, BGP
   应用层: HTTP, HTTPS, DNS, FTP, SMTP, SSH, WebSocket

Q: 三层交换机和路由器有什么区别？
A: 三层交换机=交换机+路由功能，用硬件ASIC加速路由
   适合局域网内部VLAN间路由（速度快）
   路由器适合广域网/跨网段路由（功能更灵活，支持NAT/VPN等）

Q: 为什么ARP有时归网络层有时归链路层？
A: ARP协议横跨两层：它的目标是将网络层IP映射为链路层MAC
   从功能看属于网络层辅助，从实现看直接操作以太网帧
   TCP/IP模型中一般归为网络层(Internet层)
```
