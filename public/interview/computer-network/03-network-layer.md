# 网络层：IP 与路由 —— 面试高频考点

> 网络层负责"跨网络"通信，IP编址、子网划分和NAT是面试中等频率考点。

---

## 一、核心知识框架

```
网络层核心职责
├── 逻辑寻址: IP地址体系（IPv4/IPv6）
├── 路由选择: 确定数据包转发路径
├── 分组转发: 逐跳(hop-by-hop)传递
├── 分片重组: 适应不同链路MTU
└── 辅助协议: ICMP(诊断), ARP(地址映射), NAT(地址转换)

路由协议
├── 内部网关协议(IGP)
│   ├── RIP (距离向量)
│   └── OSPF (链路状态)
└── 外部网关协议(EGP)
    └── BGP (路径向量)
```

## 二、IPv4 地址体系

### IP地址组成

```
IP地址 = 网络号 + 主机号    (由子网掩码区分)

示例: 192.168.1.100 / 255.255.255.0 (即 /24)
  网络号:  192.168.1.0    (前24位)
  主机号:  .100           (后8位)
  可用主机: 2^8 - 2 = 254 (去掉网络地址和广播地址)
```

### 特殊IP地址

| 地址 | 用途 |
|------|------|
| 0.0.0.0 | 本网络（启动时不知道自己IP） |
| 127.0.0.1 | 本地回环（localhost） |
| 255.255.255.255 | 本网段广播 |
| 10.0.0.0/8 | 私有地址A类 |
| 172.16.0.0/12 | 私有地址B类 |
| 192.168.0.0/16 | 私有地址C类 |

### 子网划分（CIDR）

```
题目: 将192.168.1.0/24划分为4个子网

解法:
  需要4个子网 → 借2位主机位做子网位 (2^2=4)
  新掩码: /24 + 2 = /26 (255.255.255.192)
  
  子网1: 192.168.1.0/26   (主机: .1 ~ .62)
  子网2: 192.168.1.64/26  (主机: .65 ~ .126)
  子网3: 192.168.1.128/26 (主机: .129 ~ .190)
  子网4: 192.168.1.192/26 (主机: .193 ~ .254)
  
  每个子网可用主机数: 2^6 - 2 = 62
```

## 三、重点考点深入

### 考点1：NAT（网络地址转换）

**为什么需要NAT？**
- IPv4地址只有 ~43亿个，不够全球设备使用
- NAT允许多台私网设备共享一个公网IP

**NAT工作原理**：
```
内网主机A(192.168.1.10:5000) → 访问百度(110.242.68.3:80)

出方向(SNAT):
  原始: Src=192.168.1.10:5000, Dst=110.242.68.3:80
  NAT后: Src=公网IP:60001, Dst=110.242.68.3:80
  NAT表记录: (192.168.1.10:5000 ↔ 公网IP:60001)

回方向(DNAT):
  收到: Src=110.242.68.3:80, Dst=公网IP:60001
  查NAT表: 公网IP:60001 → 192.168.1.10:5000
  转发: Src=110.242.68.3:80, Dst=192.168.1.10:5000
```

**NAT类型**：
| 类型 | 描述 | 用途 |
|------|------|------|
| 静态NAT | 1:1 固定映射 | 服务器对外暴露 |
| 动态NAT | 多:多 动态分配 | IP池轮用 |
| PAT/NAPT | 多:1 端口区分 | 最常用，一个公网IP对应多私网IP |

### 考点2：IP分片

```
问题: 不同链路的MTU(最大传输单元)不同
  以太网MTU=1500字节，某链路MTU=800字节

IP头部相关字段:
  - 标识(Identification): 同一数据报的分片使用相同标识
  - 标志(Flags): DF(不分片) / MF(更多分片)
  - 片偏移(Fragment Offset): 当前分片在原始数据报中的位置(8字节为单位)

示例: 4000字节数据，MTU=1500
  分片1: 偏移=0,    数据=1480字节, MF=1
  分片2: 偏移=185,  数据=1480字节, MF=1  (185×8=1480)
  分片3: 偏移=370,  数据=1040字节, MF=0
```

### 考点3：路由算法

**距离向量 vs 链路状态**：

| 对比 | 距离向量(RIP) | 链路状态(OSPF) |
|------|-------------|---------------|
| 信息交换 | 只和邻居交换路由表 | 向全网泛洪链路状态 |
| 算法 | Bellman-Ford | Dijkstra最短路径 |
| 收敛速度 | 慢（可能环路） | 快（全局信息） |
| 规模 | 小型网络(≤15跳) | 大型网络 |
| 计数到无穷 | 有此问题 | 无 |

### 考点4：ICMP协议

```
ICMP(Internet Control Message Protocol):
  网络诊断和错误报告协议，封装在IP包内

常见ICMP消息:
  - Echo Request/Reply (Type 8/0): ping命令
  - Destination Unreachable (Type 3): 目标不可达
  - Time Exceeded (Type 11): TTL减到0 → traceroute利用此机制
  - Redirect (Type 5): 路由重定向

traceroute原理:
  发送TTL=1的包 → 第一跳路由器回Time Exceeded
  发送TTL=2的包 → 第二跳路由器回Time Exceeded
  ...逐步发现整条路径
```

## 四、典型面试题 & 答案

### 题1：说说NAT的工作原理？有什么优缺点？

**答**：NAT在路由器上修改IP包的源/目的地址，实现私网与公网之间的地址转换。

**优点**：
1. 节约公网IP地址（多设备共享一个公网IP）
2. 隐藏内网拓扑，提供一定安全性
3. 内网结构变化不影响外网

**缺点**：
1. 破坏端到端通信（外网无法主动访问内网）
2. 增加处理延迟（每包都要查NAT表）
3. 某些协议不兼容（如FTP主动模式、SIP）
4. NAT设备成为单点故障和性能瓶颈

### 题2：IP地址和MAC地址各自的作用？

**答**：
- **IP地址**：逻辑地址，负责**跨网络寻址和路由**。数据包从源到目的的全程中IP地址不变（NAT除外）。
- **MAC地址**：物理地址，负责**同一链路内寻址**。每经过一个路由器，帧头的MAC地址就会改变为下一跳的MAC。

**协作过程**：IP负责规划"走哪条路"（路由），MAC负责"这一段路交给谁"（逐跳转发）。

### 题3：TTL的作用是什么？

**答**：TTL(Time To Live)限制数据包在网络中的生存时间：
- 每经过一个路由器TTL减1
- 减到0时路由器丢弃该包并回送ICMP Time Exceeded
- **目的**：防止数据包因路由环路而无限循环
- **常见默认值**：Linux=64, Windows=128, 路由器=255

### 题4：IPv4和IPv6的主要区别？

**答**：

| 对比 | IPv4 | IPv6 |
|------|------|------|
| 地址长度 | 32位(~43亿) | 128位(几乎无限) |
| 地址表示 | 点分十进制 192.168.1.1 | 冒号十六进制 2001:db8::1 |
| 头部大小 | 20~60字节(可变) | 固定40字节 |
| 分片 | 中间路由器可分片 | 只有源端可分片 |
| NAT | 普遍使用 | 理论上不需要 |
| 广播 | 支持 | 用多播替代 |
| 自动配置 | DHCP | SLAAC(无状态自动配置) |

## 五、面试加分点

### 常见追问与应对

```
Q: 路由器的转发过程？
A: 1. 收到帧 → 解析IP头部获取目的IP
   2. 查路由表 → 找到最长前缀匹配的下一跳
   3. TTL减1 → 重新计算IP头校验和
   4. 查ARP表获取下一跳MAC → 封装新帧 → 从对应接口发出

Q: 什么是最长前缀匹配？
A: 路由表中可能多条规则匹配同一目的IP
   选择掩码最长(最精确)的那条
   例: 目的IP=192.168.1.100
     192.168.0.0/16 → 匹配
     192.168.1.0/24 → 匹配(更精确) ← 选这条

Q: DHCP工作过程？
A: Discover(广播找DHCP服务器) → Offer(服务器提供IP) 
   → Request(客户端选择) → ACK(确认)
   简记: DORA
```
