## 🎯 必背核心考点（Top 20）

> 这 20 题占面试出现率 **85%+**，没复习时间也要先把这些拿下。

| 排名 | 考点 | 一句话答案 |
|------|------|-----------|
| 1 | TCP三次握手过程？ | SYN→SYN+ACK→ACK，防止历史重复连接被建立（旧SYN到达） |
| 2 | TCP四次挥手为什么要四次？ | 全双工连接，每个方向需独立关闭（FIN+ACK各一对） |
| 3 | TCP vs UDP核心区别？ | TCP可靠有序连接，UDP无连接不可靠但快；选择看业务需求 |
| 4 | TCP如何保证可靠传输？ | 序列号+确认号+超时重传+校验和+滑动窗口+流量控制 |
| 5 | TCP拥塞控制四阶段？ | 慢启动→拥塞避免→快速重传→快速恢复（Reno/Cubic） |
| 6 | 滑动窗口的作用？ | 允许发送方连续发多个包不必逐个确认，提高吞吐量 |
| 7 | OSI七层模型各层功能？ | 物数网传会表应：传输比特→帧→包→段→数据→编码→交互 |
| 8 | HTTP和HTTPS的区别？ | HTTPS = HTTP + TLS加密；端口443；防窃听/篡改/冒充 |
| 9 | DNS解析过程？ | 浏览器缓存→本地hosts→递归/迭代查询（根→顶级→权威） |
| 10 | ARP协议的作用和原理？ | IP→MAC映射；广播ARP请求，目标主机单播回复 |
| 11 | NAT的工作原理？ | 修改IP包的源/目的地址，实现私网↔公网地址转换 |
| 12 | HTTP/1.1 vs HTTP/2 vs HTTP/3？ | 持久连接→多路复用+头压缩→QUIC(UDP)+0-RTT |
| 13 | TIME_WAIT状态的作用？ | 确保最后ACK到达对方 + 等待旧报文在网络中消亡(2MSL) |
| 14 | Cookie与Session区别？ | Cookie存客户端(不安全)，Session存服务端(占内存)；Session ID通过Cookie传 |
| 15 | 子网掩码的作用？ | 区分IP地址的网络部分和主机部分，确定子网范围 |
| 16 | TCP粘包/拆包原因和解决？ | TCP面向字节流无边界；解决：定长/分隔符/长度头 |
| 17 | HTTPS建立连接的完整过程？ | TCP三次握手→TLS握手(证书验证+密钥协商)→加密通信 |
| 18 | 从输入URL到页面显示发生了什么？ | DNS→TCP→TLS→HTTP请求→服务器处理→响应→渲染 |
| 19 | 交换机和路由器的区别？ | 交换机工作在L2(MAC转发)，路由器工作在L3(IP路由) |
| 20 | WebSocket和HTTP的区别？ | WebSocket全双工持久连接，服务端可主动推送；HTTP半双工请求-响应 |

## ⚡ 答题黄金三段式

面试回答建议按以下结构组织：

```
是什么（定义/机制） → 为什么（设计动机/解决什么问题） → 怎么用（工程经验/注意事项）
```

### 万能开头话术

- "这个问题可以从 **协议设计** 和 **工程实践** 两个角度来回答…"
- "我理解这个机制的核心是…，它解决的问题是…"
- "和 XX 对比来看，它的关键区别在于…"

### 答完加分动作

- 主动对比："如果和 XX 协议对比的话…"
- 画图辅助："我画个时序图/分层图来说明…"
- 工程视角："在实际项目中，这个问题我遇到过…"
- 延伸扩展："这引申出 XX 问题，可以用 XX 解决…"

## 📐 网络排查常见命令（加分项）

| 命令 | 用途 | 面试场景 |
|------|------|---------|
| `ping` | 测试连通性和延迟(ICMP) | "网络不通先ping看是DNS还是路由问题" |
| `traceroute` | 追踪路由路径 | "定位哪一跳开始丢包" |
| `netstat/ss` | 查看连接状态 | "看TIME_WAIT连接数是否过多" |
| `tcpdump` | 抓包分析 | "分析三次握手是否正常" |
| `curl -v` | HTTP调试 | "看HTTP头部和TLS协商过程" |
| `nslookup/dig` | DNS查询 | "排查DNS解析是否正确" |
