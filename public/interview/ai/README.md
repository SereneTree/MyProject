## 🎯 必背核心考点（Top 15）

> 这 15 题占面试出现率 **80%+**，没复习时间也要先把这些拿下。

| 排名 | 考点 | 一句话答案 |
|------|------|-----------|
| 1 | A*算法的完备性和最优性？ | 在启发式h(n)可容许(admissible)且一致(consistent)时，A*既完备又最优 |
| 2 | BFS vs DFS vs UCS vs A*如何选择？ | 无权→BFS；有权无启发→UCS；有启发→A*；内存紧张→DFS/IDA* |
| 3 | 什么是可容许启发式(admissible)？ | h(n)永远不高估到目标的实际代价，保证A*找到最优解 |
| 4 | CSP的回溯搜索如何优化？ | MRV选变量 + LCV选值 + Forward Checking/AC-3约束传播 |
| 5 | Minimax算法的核心思想？ | MAX层选最大值，MIN层选最小值，交替递归模拟双方最优博弈 |
| 6 | α-β剪枝为什么正确？ | 被剪枝的分支不可能影响最终决策，因为对手不会让你到达更好的状态 |
| 7 | MDP的五元组？ | (S, A, T, R, γ)：状态、动作、转移函数、奖励函数、折扣因子 |
| 8 | Bellman方程的含义？ | V*(s) = max_a [R(s,a) + γ Σ T(s,a,s')V*(s')]，当前价值=即时奖励+折扣未来价值 |
| 9 | 值迭代 vs 策略迭代？ | 值迭代每轮更新V直到收敛；策略迭代交替评估策略和贪心改进策略 |
| 10 | Q-Learning为什么是off-policy？ | 更新时用max Q(s',a')选最优动作，而非实际执行的动作，行为策略≠目标策略 |
| 11 | 探索(Exploration) vs 利用(Exploitation)？ | ε-greedy/UCB/Boltzmann：不能只走已知最优路径，需要尝试未知获取信息 |
| 12 | 图搜索 vs 树搜索？ | 图搜索维护closed set避免重复扩展，树搜索可能陷入死循环但省空间 |
| 13 | 一致性(consistency)启发式的作用？ | 保证A*不会重新打开已扩展节点（单调性），效率更高 |
| 14 | Expectimax与Minimax的区别？ | Expectimax的对手层取期望而非最小值，适用于对手不完全理性的场景 |
| 15 | 强化学习与监督学习的本质区别？ | RL没有标注数据，通过试错获取延迟奖励；存在探索-利用、信用分配问题 |

## ⚡ 答题黄金三段式

面试回答建议按以下结构组织：

```
是什么（定义/公式） → 为什么（设计动机/解决什么问题） → 怎么用（适用场景/注意事项/变体）
```

### 万能开头话术

- "这个问题可以从 **算法原理** 和 **实际应用** 两个角度来回答…"
- "我理解这个算法的核心是…，它解决的问题是…"
- "相比 XX 方法，它的改进点在于…"

### 答完加分动作

- 主动对比："如果和 XX 算法对比的话，各自适用于…"
- 复杂度分析："时间复杂度是 O(...)，空间复杂度是 O(...)"
- 工程视角："在实际项目中，这个算法的瓶颈通常在于…"
- 画图辅助："我画个搜索树/状态转移图来说明…"
