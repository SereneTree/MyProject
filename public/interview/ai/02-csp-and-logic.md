# 约束满足与逻辑推理 —— 面试高频考点

> CSP 是 AI 面试中"建模能力"的核心考察点，重点考查如何将实际问题抽象为约束满足问题并高效求解。

---

## 一、核心知识框架

```
CSP 三要素
├── 变量 (Variables): X = {X1, X2, ..., Xn}
├── 域 (Domains): D = {D1, D2, ..., Dn}（每个变量的取值范围）
└── 约束 (Constraints): C = {C1, C2, ..., Cm}（变量间的限制）

求解策略
├── 回溯搜索 (Backtracking Search)
│   ├── 变量选择: MRV / Degree Heuristic
│   ├── 值选择: LCV (Least Constraining Value)
│   └── 推理: Forward Checking / AC-3
├── 约束传播 (Constraint Propagation)
│   ├── 节点一致性 (Node Consistency)
│   ├── 弧一致性 (Arc Consistency)
│   └── 路径一致性 (Path Consistency)
└── 局部搜索 (Local Search)
    └── Min-Conflicts
```

## 三、重点考点深入

### 考点1：回溯搜索优化三件套

**① MRV（Minimum Remaining Values）—— 变量选择**

```
策略: 优先选择剩余合法值最少的变量
原理: "Fail-first"——越受约束的变量越早尝试，早发现冲突早回溯
效果: 显著减少搜索节点数
```

**② LCV（Least Constraining Value）—— 值选择**

```
策略: 优先选择对其他变量约束最少的值
原理: "Fail-last"——给未来留下最多选择余地
计算: 对每个候选值，统计它排除掉邻居变量多少个合法值
```

**③ Forward Checking / AC-3 —— 推理**

```
Forward Checking:
  给Xi赋值后 → 检查所有与Xi有约束的未赋值变量Xj
  从Xj的域中删除与Xi当前值冲突的值
  若Xj域变空 → 立即回溯（无需继续）

AC-3 (弧一致性):
  维护一个弧队列，初始包含所有约束弧
  对每条弧(Xi, Xj): 
    如果Xi域中存在值，在Xj域中找不到满足约束的值 → 删除该值
    如果Xi域被修改 → 将所有(Xk, Xi)重新入队
  直到队列为空或某变量域为空
```

### 考点2：AC-3算法详解

**伪代码**：
```
function AC-3(csp):
    queue = 所有约束弧 {(Xi, Xj) | Cij ∈ C}
    while queue 非空:
        (Xi, Xj) = queue.pop()
        if REVISE(Xi, Xj):
            if Di 为空: return false  // 无解
            for 每个Xi的邻居Xk (Xk ≠ Xj):
                queue.add((Xk, Xi))
    return true

function REVISE(Xi, Xj):
    revised = false
    for 每个 x ∈ Di:
        if 在Dj中不存在y使得(x,y)满足约束Cij:
            Di.remove(x)
            revised = true
    return revised
```

**时间复杂度**：O(ed³)
- e = 约束边数
- d = 最大域大小

**面试常问**：
```
Q: AC-3能完全解决CSP吗？
A: 不能。AC-3只做弧一致性过滤（剪枝），可能剩余域仍有多个值
   但不满足全局约束。需要配合回溯搜索使用。
   只有在特殊结构（如树形CSP）时，AC可以直接求解。

Q: Forward Checking vs AC-3？
A: FC只检查"当前赋值变量→未赋值变量"的弧
   AC-3检查"所有弧"，传播更彻底，剪枝效果更强
   但AC-3计算开销也更大
```

### 考点3：CSP问题结构利用

**树形CSP**：O(nd²) 可解
```
1. 选择根节点，拓扑排序
2. 从叶子到根做弧一致性
3. 从根到叶子依次赋值（保证有解）
```

**Cutset Conditioning**：
```
找到环切割集（删除后变成树）→ 枚举切割集变量的赋值 → 剩余树结构多项式求解
复杂度: O(d^c · (n-c)d²)，c=切割集大小
```

## 四、典型面试题 & 答案

### 题1：MRV和LCV的设计思想有何区别？

**答**：
- **MRV（选变量）**：Fail-first策略——选最受约束的变量优先赋值，目的是**尽早发现矛盾**，减少无效搜索
- **LCV（选值）**：Fail-last策略——选约束最少的值，目的是**给后续变量最大灵活性**，增加找到解的概率
- **本质区别**：MRV在"选哪个变量"时激进（先处理难的），LCV在"选什么值"时保守（选影响小的）

### 题2：请用CSP建模一个课程安排问题

**答**：
```
变量: 每门课 Ci (i=1,...,n)
域: Di = {(时段, 教室)} 的所有合法组合
约束:
  - 同一教师不能同一时段上两门课
  - 同一教室不能同一时段安排两门课
  - 某些课有前置要求（时段顺序）
  - 教室容量 ≥ 选课人数
优化策略:
  - 用MRV选约束最多的课优先安排
  - AC-3提前过滤不可能的时段-教室组合
```

### 题3：AC-3和FC的区别是什么？分别什么时候用？

**答**：
| 对比 | Forward Checking | AC-3 |
|------|-----------------|------|
| 检查范围 | 只检查当前变量到未赋值变量 | 检查所有弧（传播链式反应） |
| 触发时机 | 每次赋值后 | 预处理 或 每次赋值后 |
| 剪枝效果 | 较弱（可能遗漏间接冲突） | 较强（传播更彻底） |
| 计算开销 | 较小 | 较大 O(ed³) |
| 适用场景 | 约束较松的问题 | 约束较紧需要强剪枝 |

### 题4：什么是约束传播？它和搜索的关系？

**答**：
- **约束传播**：通过约束之间的逻辑推理，缩小变量的合法域，不做试探性赋值
- **与搜索的关系**：约束传播是搜索的"加速器"——
  - 单独使用：只能剪枝，不一定能求解
  - 配合回溯：每次赋值后传播 → 减少回溯次数
- **类比**：约束传播像"数独中根据已知数字排除可能性"，搜索像"猜一个数试试"

### 常见追问与应对

```
Q: CSP和一般搜索问题的区别？
A: CSP利用了问题的"可分解结构"——变量之间的约束关系
   一般搜索把状态看作黑盒，CSP可以利用约束做推理和剪枝
   CSP解的路径无关（只关心最终赋值，不关心赋值顺序）

Q: 如果CSP无解，怎么处理？
A: ① 松弛约束（软约束→优化）
   ② 最大化满足的约束数量（Max-CSP）
   ③ 报告最小冲突集（帮助用户修改需求）

Q: CSP和SAT/SMT的关系？
A: SAT是布尔变量的CSP，SMT是SAT+理论约束
   工业界很多调度/验证问题都用SAT/SMT求解器
```
