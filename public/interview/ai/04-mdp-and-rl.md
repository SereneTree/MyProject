# MDP与强化学习 —— 面试高频考点

> MDP和RL是AI面试中"理论深度"的考察重点，Bellman方程推导、Q-Learning更新过程几乎必问。

---

## 一、核心知识框架

```
MDP (马尔可夫决策过程)
├── 定义: (S, A, T, R, γ) 五元组
├── 求解
│   ├── 值迭代 (Value Iteration)
│   └── 策略迭代 (Policy Iteration)
└── 关键概念: 马尔可夫性、折扣因子、策略

强化学习 (Reinforcement Learning)
├── Model-Based RL
│   └── 先学转移/奖励模型，再规划
├── Model-Free RL
│   ├── 被动学习 (Passive)
│   │   ├── Direct Evaluation
│   │   └── TD Learning
│   └── 主动学习 (Active)
│       ├── Q-Learning (off-policy)
│       └── SARSA (on-policy)
└── 核心问题
    ├── 探索 vs 利用
    ├── 信用分配
    └── 样本效率
```

## 二、MDP速查表

### MDP五元组

| 元素 | 含义 | 示例（网格世界） |
|------|------|----------------|
| S (States) | 所有可能状态的集合 | 网格中的每个位置 |
| A (Actions) | 所有可能动作的集合 | {上,下,左,右} |
| T(s,a,s') | 转移函数 P(s'\|s,a) | 80%按意图走，10%左偏，10%右偏 |
| R(s,a,s') | 奖励函数 | 到达终点+1，掉入陷阱-1，每步-0.04 |
| γ (gamma) | 折扣因子 ∈ [0,1] | 0.9（未来奖励衰减） |

### Bellman方程

**最优值函数**：
```
V*(s) = max_a [ Σ T(s,a,s') · (R(s,a,s') + γ · V*(s')) ]
         a      s'

含义: 最优策略下，状态s的长期期望累积奖励
```

**最优Q函数**：
```
Q*(s,a) = Σ T(s,a,s') · (R(s,a,s') + γ · max Q*(s',a'))
          s'                              a'

含义: 在状态s执行动作a后，后续最优策略下的期望累积奖励
```

**最优策略**：
```
π*(s) = argmax_a Q*(s,a)
```

## 三、重点考点深入

### 考点1：值迭代 vs 策略迭代

| 对比 | 值迭代 (VI) | 策略迭代 (PI) |
|------|------------|--------------|
| 更新内容 | 值函数 V(s) | 策略 π(s) + 值函数 V^π(s) |
| 每轮操作 | V(s) ← max_a [R + γΣT·V(s')] | ①评估π的V^π ②贪心改进π |
| 收敛速度 | 较慢（线性） | 较快（策略数有限，指数快） |
| 每轮开销 | 较小（一次Bellman更新） | 较大（求解线性方程组） |
| 适用场景 | 状态空间大，每轮要快 | 状态空间中等，要少轮数 |

**值迭代伪代码**：
```
初始化 V(s) = 0 for all s
repeat:
    for each state s:
        V(s) ← max_a [ Σ T(s,a,s') · (R(s,a,s') + γ·V(s')) ]
until |V_new - V_old| < ε

π*(s) = argmax_a [ Σ T(s,a,s') · (R(s,a,s') + γ·V*(s')) ]
```

**策略迭代伪代码**：
```
初始化 π 为任意策略
repeat:
    // 策略评估: 求解 V^π
    V^π(s) = Σ T(s,π(s),s') · (R(s,π(s),s') + γ·V^π(s'))  (线性方程组)
    
    // 策略改进: 贪心更新π
    π_new(s) = argmax_a [ Σ T(s,a,s') · (R(s,a,s') + γ·V^π(s')) ]
until π_new == π
```

### 考点2：Q-Learning

**核心更新公式**：
```
Q(s,a) ← Q(s,a) + α · [r + γ · max Q(s',a') - Q(s,a)]
                         └───────────────────────────┘
                              TD target - 当前估计 = TD error
```

**关键性质**：
| 性质 | 说明 |
|------|------|
| Off-policy | 行为策略（用于探索）≠ 目标策略（用于更新） |
| Model-free | 不需要知道 T 和 R，直接从交互中学习 |
| 收敛条件 | 每个(s,a)被无限次访问 + 学习率满足Robbins-Monro条件 |
| 时间差分 | 用一步样本估计替代完整轨迹，bootstrap |

**Q-Learning vs SARSA**：
```
Q-Learning (off-policy):
  Q(s,a) ← Q(s,a) + α·[r + γ·max_a' Q(s',a') - Q(s,a)]
  更新用 max（贪心目标策略）

SARSA (on-policy):
  Q(s,a) ← Q(s,a) + α·[r + γ·Q(s',a') - Q(s,a)]
  更新用实际执行的a'（跟随行为策略）

区别:
  Q-Learning: 更激进，学最优策略（可能忽视风险）
  SARSA: 更保守，学"当前探索策略"的值（考虑探索风险）
```

### 考点3：探索与利用(Exploration vs Exploitation)

**核心困境**：
```
利用(Exploit): 选当前已知最优动作 → 可能错过更好的选项
探索(Explore): 尝试未知动作 → 可能浪费时间但获取新信息
```

**常见策略**：

| 策略 | 公式/方法 | 特点 |
|------|----------|------|
| ε-greedy | P(探索)=ε, P(利用)=1-ε | 简单，ε需调参 |
| ε衰减 | ε随时间减小 | 早期多探索，后期多利用 |
| UCB | a* = argmax[Q(a) + c√(lnN/N(a))] | 平衡不确定性 |
| Boltzmann | P(a) ∝ exp(Q(a)/τ) | τ控制随机程度 |

### 考点4：折扣因子γ的作用

```
γ = 0: 完全短视，只看即时奖励
γ → 1: 极度远视，未来奖励几乎和当前等值
γ = 0.9: 10步后的奖励权重 0.9^10 ≈ 0.35

γ的工程影响:
  - γ太小: 策略短视，可能错过长期高收益路径
  - γ太大: 收敛慢，且对远期不确定性敏感
  - 通常取 0.9~0.99
```

## 四、典型面试题 & 答案

### 题1：MDP和一般搜索问题的区别？

**答**：
| 对比 | 搜索问题 | MDP |
|------|---------|-----|
| 环境 | 确定性（动作结果确定） | 随机性（动作结果有概率分布） |
| 求解 | 找一条最优路径 | 找一个完整策略 π(s)→a |
| 输出 | 动作序列 [a1,a2,...] | 策略函数 π: S→A |
| 为什么 | 执行前就知道会到哪 | 执行前不确定会到哪，需要每个状态都有对策 |

### 题2：为什么Q-Learning是off-policy？

**答**：
- **Off-policy的含义**：用来收集数据的策略（行为策略）≠ 正在优化的策略（目标策略）
- **Q-Learning中**：
  - 行为策略：ε-greedy（带探索）
  - 目标策略：greedy（max Q），即更新时用 max_a' Q(s',a')
- **优势**：可以用任意策略收集数据（甚至历史数据），都能学到最优Q
- **对比SARSA**：SARSA是on-policy，更新用实际执行的a'，学的是"当前策略"的值

### 题3：Model-Based vs Model-Free RL

**答**：

| 对比 | Model-Based | Model-Free |
|------|-------------|------------|
| 是否学模型 | 先学 T(s,a,s') 和 R | 不学模型，直接学V/Q/π |
| 样本效率 | 高（模型可反复"规划"） | 低（每个经验只用一次） |
| 计算开销 | 大（维护模型+规划） | 小（只做TD更新） |
| 模型偏差 | 有（模型不完美会误导） | 无 |
| 代表算法 | Dyna-Q、MBPO | Q-Learning、SARSA、PPO |

### 题4：TD Learning vs Monte Carlo

**答**：

| 对比 | TD Learning | Monte Carlo |
|------|-------------|-------------|
| 更新时机 | 每步更新（在线） | 回合结束后更新 |
| 偏差/方差 | 有偏差（bootstrap），低方差 | 无偏差，高方差 |
| 收敛 | 适用于连续任务 | 仅适用于有终止的回合任务 |
| 学习信号 | 一步奖励 + 估计值 | 完整回报 Gt |

```
TD更新: V(s) ← V(s) + α·[r + γV(s') - V(s)]
MC更新: V(s) ← V(s) + α·[Gt - V(s)]

Gt = r1 + γr2 + γ²r3 + ... (完整回合累积奖励)
```

### 题5：手推Q-Learning更新过程

**答题模板**：
```
已知: Q表初始为0, γ=0.9, α=0.1
经历: (s1, a1, r=5, s2) → (s2, a2, r=-1, s3)

第一步:
  Q(s1,a1) ← 0 + 0.1×[5 + 0.9×max_a Q(s2,a) - 0]
           = 0 + 0.1×[5 + 0.9×0 - 0] = 0.5

第二步:
  Q(s2,a2) ← 0 + 0.1×[-1 + 0.9×max_a Q(s3,a) - 0]
           = 0 + 0.1×[-1 + 0] = -0.1
```

## 五、面试加分点

### 实际应用举例

| RL应用 | 场景 |
|--------|------|
| 推荐系统 | 用户交互建模为MDP，推荐动作优化长期留存 |
| 机器人控制 | 连续状态/动作空间的策略学习 |
| 资源调度 | 数据中心/配送调度的在线决策 |
| 对话系统 | 对话策略优化（何时追问/何时回答） |
| 游戏AI | AlphaGo、OpenAI Five、StarCraft |

### 常见追问与应对

```
Q: RL在实际工程中最大的挑战是什么？
A: ① 样本效率低（需要大量交互）
   ② 奖励设计难（sparse reward、reward shaping）
   ③ 安全性（探索可能导致危险动作）
   ④ sim-to-real gap（模拟器和真实环境差异）

Q: Deep RL（如DQN）相比表格Q-Learning的改进？
A: 用神经网络近似Q函数，处理连续/高维状态空间
   关键技巧：Experience Replay + Target Network

Q: 马尔可夫性质的含义和局限？
A: 含义：P(s'|s,a) = P(s'|s,a,history)，未来只依赖当前状态
   局限：很多现实问题不满足（如炒股需要看历史K线）
   解决：将历史信息编码进状态（POMDP/RNN）

Q: 如何判断一个问题适合用RL？
A: 核心四条件：①有序贯决策 ②有奖励反馈 
   ③环境可交互或可模拟 ④难以用规则穷举
```
