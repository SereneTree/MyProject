## 🎯 必背核心考点（Top 20）

> 这 20 题占图论面试出现率 **80%+**，没复习时间也要先把这些拿下。

| 排名 | 考点 | 一句话答案 |
|------|------|-----------|
| 1 | 图的两种存储方式？ | 邻接矩阵 O(V²)空间+O(1)查边；邻接表 O(V+E)空间+O(度)查边 |
| 2 | BFS和DFS分别用什么数据结构？ | BFS用队列(层序遍历)；DFS用栈/递归(深入回溯) |
| 3 | Dijkstra的适用条件与复杂度？ | 非负权图单源最短路；优先队列实现 O((V+E)logV) |
| 4 | Bellman-Ford的优势？ | 可处理负权边；能检测负权环；O(VE) |
| 5 | Floyd算法的本质？ | 动态规划：d[i][j] = min(d[i][j], d[i][k]+d[k][j])；全源最短路 O(V³) |
| 6 | 拓扑排序的应用？ | DAG中确定任务执行顺序；检测有向图是否有环 |
| 7 | Kruskal vs Prim？ | Kruskal按边排序+并查集O(ElogE)适合稀疏图；Prim逐步扩展O(ElogV)适合稠密图 |
| 8 | 什么是二分图？如何判定？ | 节点可分为两组，边只在组间存在；BFS/DFS染色法判定(2-着色) |
| 9 | 匈牙利算法求什么？ | 二分图最大匹配；核心操作是寻找增广路；O(VE) |
| 10 | 最大流最小割定理？ | 网络最大流 = 最小割容量；Ford-Fulkerson/Dinic求解 |
| 11 | 图着色的色数(χ)？ | 使相邻节点不同色所需的最少颜色数；NP-hard(一般图) |
| 12 | 欧拉路径/回路存在条件？ | 无向图：连通且奇度顶点=0(回路)/2(路径)；有向图：弱连通且入度=出度 |
| 13 | 哈密顿路径与TSP？ | 经过每个顶点恰好一次的路径；TSP=最短哈密顿回路；NP-hard |
| 14 | 强连通分量(SCC)怎么求？ | Tarjan算法(一次DFS+栈)或Kosaraju(两次DFS)；O(V+E) |
| 15 | 割点和桥的含义？ | 割点：删除后图不连通的节点；桥：删除后图不连通的边 |
| 16 | 并查集解决什么问题？ | 动态连通性判断/合并；路径压缩+按秩合并→近O(1)摊还 |
| 17 | DAG上最长路径怎么求？ | 拓扑排序+DP；或取负权转最短路；不能用Dijkstra |
| 18 | 平面图与四色定理？ | 任何平面图(无边交叉)最多4种颜色可着色；|E|≤3|V|-6 |
| 19 | 网络流如何建模匹配问题？ | 源→左集合(容量1)→右集合(容量1)→汇；最大流=最大匹配 |
| 20 | 图的同构怎么判断？ | 节点数/边数/度序列相同是必要条件；一般图同构是GI-complete |

## ⚡ 答题黄金三段式

面试回答建议按以下结构组织：

```
定义与直觉（是什么） → 算法原理与复杂度（怎么做） → 实际应用与工程考量（怎么用）
```

### 万能开头话术

- "这个问题可以从 **图的结构** 和 **算法策略** 两个角度来回答…"
- "这个算法的核心思想是…，它解决的问题是…，时间复杂度为…"
- "和 XX 算法对比，关键区别在于…"

### 答完加分动作

- 主动对比："Dijkstra和Bellman-Ford对比的话，关键区别在能否处理负权…"
- 量化补充："这个算法的时间复杂度是 O(ElogV)，空间复杂度是…"
- 工程视角："在工程实现中，通常会用优先队列优化/并查集加速…"
- 画图辅助："我画一下这个图的BFS过程/松弛过程来说明…"
- 举反例："如果有负权边的话，Dijkstra就会失败，举个例子…"

## 📐 常用公式与复杂度速查卡

| 公式/结论 | 含义 | 记忆口诀 |
|----------|------|---------|
| Σdeg(v) = 2\|E\| | 握手定理 | 所有度之和=边数的两倍 |
| 树: \|E\| = \|V\| - 1 | 树的边数 | n个节点的树恰好n-1条边 |
| V - E + F = 2 | 欧拉公式(平面图) | 顶点-边+面=2 |
| \|E\| ≤ 3\|V\| - 6 | 简单平面图边数上界 | 平面图边不能太多 |
| Dijkstra: O((V+E)logV) | 优先队列实现 | 每条边最多松弛一次 |
| Bellman-Ford: O(VE) | V-1轮全边松弛 | 第V轮还能松弛=有负环 |
| Floyd: O(V³) | 全源最短路DP | 三重循环k-i-j |
| Kruskal: O(ElogE) | 排序+并查集 | 贪心选最小边不成环 |
| Prim: O(ElogV) | 优先队列BFS扩展 | 贪心选最小跨边 |
| 匈牙利: O(VE) | 二分图最大匹配 | 反复找增广路 |
| KM: O(V³) | 最大权完美匹配 | 顶标+增广 |
| Dinic: O(V²E) | 最大流 | 层次图+阻塞流 |
| Tarjan SCC: O(V+E) | 强连通分量 | DFS+low值+栈 |
| 并查集: O(α(n)) | 近O(1)摊还 | 路径压缩+按秩合并 |
| χ(G) ≤ Δ(G) + 1 | 着色上界 | 最大度+1种颜色一定够 |

## 🔑 面试中常见的「陷阱题」

| 陷阱 | 正确理解 |
|------|---------|
| "Dijkstra可以处理负权边" | ❌ 不行！Dijkstra贪心策略在负权下失效 |
| "DFS可以求最短路" | ❌ BFS在无权图可以，DFS不保证最短 |
| "拓扑排序结果唯一" | ❌ 可能有多种合法拓扑序(入度同时为0的选择) |
| "最小生成树唯一" | ❌ 边权有相同值时可能有多棵MST |
| "欧拉回路=哈密顿回路" | ❌ 欧拉过每条边恰一次，哈密顿过每个顶点恰一次 |
| "二分图一定是树" | ❌ 二分图可以有环(只要是偶环) |
| "最大流一定有唯一解" | ❌ 最大流值唯一但流的分配方式可能不唯一 |
