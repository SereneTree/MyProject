## 🎯 必背核心考点（Top 20）

> 这 20 题占复杂网络面试出现率 **80%+**，没复习时间也要先把这些拿下。

| 排名 | 考点 | 一句话答案 |
|------|------|-----------|
| 1 | 什么是小世界网络？ | 同时具有高聚集系数和短平均路径长度的网络（WS模型） |
| 2 | 什么是无标度网络？ | 度分布服从幂律 P(k)∝k^(-γ) 的网络，存在少数超级hub节点（BA模型） |
| 3 | ER随机图的特性？ | 度分布为泊松分布，聚集系数低∝1/N，有相变临界点 p_c=1/N |
| 4 | BA模型的两个机制？ | 增长(Growth) + 优先连接(Preferential Attachment)，"富者更富" |
| 5 | 度中心性 vs 介数中心性？ | 度=直接连接数(局部)；介数=经过该节点的最短路径数(全局桥梁) |
| 6 | 什么是聚集系数？ | 节点邻居之间实际连边数/最大可能连边数，衡量"朋友的朋友也是朋友" |
| 7 | 什么是模块度(Modularity)？ | Q = 社区内实际边数 - 随机情况下的期望边数；衡量社区划分质量 |
| 8 | Louvain算法原理？ | 两阶段迭代：贪心移动节点到增益最大社区→合并为超节点→重复 |
| 9 | SIR模型三状态？ | S(易感)→I(感染)→R(恢复免疫)；β感染率，γ恢复率，R₀=β/γ |
| 10 | 无标度网络为什么对随机故障鲁棒？ | hub节点极少，随机移除大概率移除普通节点，对连通性影响小 |
| 11 | 无标度网络为什么对定向攻击脆弱？ | 攻击hub节点后网络迅速碎片化，最大连通分量急剧缩小 |
| 12 | PageRank算法核心思想？ | 一个节点的重要性取决于链接到它的节点的重要性(递归定义) |
| 13 | 什么是渗流阈值？ | 节点/边被保留的概率超过阈值时，突然出现巨大连通分量（相变） |
| 14 | 配置模型(Configuration Model)？ | 给定度序列，随机匹配半边(stubs)生成零模型网络 |
| 15 | 接近中心性的含义？ | 节点到其他所有节点最短路径之和的倒数，越大越"位置中心" |
| 16 | 六度分隔理论？ | 任意两人平均只需6步中间人即可连接；对应小世界网络的短路径 |
| 17 | 网络中的幂律分布如何验证？ | 双对数坐标下度分布近似直线；斜率=-γ（通常2<γ<3） |
| 18 | 强连通 vs 弱连通？ | 有向图中：强连通=任意u→v和v→u都有路径；弱连通=忽略方向后连通 |
| 19 | 什么是网络的同配性(Assortativity)？ | 高度节点倾向连接高度节点=同配(社交网络)；反之=异配(生物/技术网络) |
| 20 | 影响力最大化问题？ | 选k个种子使传播覆盖最大；NP-hard，贪心保证(1-1/e)近似 |

## ⚡ 答题黄金三段式

面试回答建议按以下结构组织：

```
定义与直觉（是什么） → 数学/模型原理（为什么） → 实际应用与工程考量（怎么用）
```

### 万能开头话术

- "这个概念可以从 **网络拓扑** 和 **动态过程** 两个角度来解释…"
- "我理解这个模型的核心假设是…，它解决的问题是…"
- "和 XX 模型/指标对比来看，关键区别在于…"

### 答完加分动作

- 主动对比："如果和ER随机图对比的话，真实网络的这个特征…"
- 量化补充："这个指标的计算复杂度是 O(n²)，工业界通常用…近似"
- 工程视角："在实际项目中，这个算法需要注意的是…"
- 画图辅助："我画个度分布图/传播曲线来说明…"

## 📐 常用公式速查卡

| 公式 | 含义 | 记忆口诀 |
|------|------|---------|
| C_i = 2E_i / (k_i(k_i-1)) | 聚集系数 | 邻居实际连边/最大可能连边 |
| C_C(v) = (N-1) / Σd(v,u) | 接近中心性 | 到其他节点距离和的倒数 |
| C_B(v) = Σ σ_st(v)/σ_st | 介数中心性 | 经过v的最短路占总最短路比例 |
| P(k) ∝ k^(-γ) | 幂律分布 | 双对数图上是直线 |
| R₀ = β/γ | 基本再生数 | R₀>1传播爆发，<1传播消亡 |
| Q = (1/2m)Σ[A_ij - k_ik_j/2m]δ(c_i,c_j) | 模块度 | 实际边-期望边(在社区内) |
| p_c = 1/<k> (ER) | ER巨分量阈值 | 平均度=1时巨分量出现 |
| p_c ≈ 1/N (ER连通阈值) | ER连通临界点 | p > lnN/N 时几乎确定连通 |
