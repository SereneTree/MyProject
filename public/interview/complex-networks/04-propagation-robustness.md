# 04 传播动力学与鲁棒性

> 本模块覆盖网络上的传播过程（信息/疾病/影响力）和网络在攻击/故障下的鲁棒性分析。

---

## 一、传播动力学模型

### 1.1 SIR 模型

```
三状态:
  S (Susceptible/易感): 健康但可能被感染
  I (Infected/感染):    已感染且正在传播
  R (Recovered/恢复):   已恢复并获得免疫（不再被感染）

转移规则:
  S → I: 易感节点被感染邻居以概率β感染（每个时间步对每个感染邻居）
  I → R: 感染节点以概率γ恢复

关键参数:
  β: 感染率/传播率
  γ: 恢复率
  R₀ = β/γ × <k>: 基本再生数（网络版本）
```

**SIR在网络上的动力学方程（均场近似）**：
```
dS/dt = -β × S × <k> × I / N
dI/dt = β × S × <k> × I / N - γ × I
dR/dt = γ × I

传播条件: R₀ = β<k>/γ > 1 时传播爆发
传播阈值: β_c = γ/<k>
```

**面试必背**：
> "SIR模型中，传播是否爆发取决于基本再生数 R₀=β<k>/γ。当 R₀>1 时传播爆发，<1时自然消亡。在网络上，平均度<k>越大，传播越容易爆发——这就是为什么hub节点在传播中特别危险。"

### 1.2 SIS 模型

```
两状态:
  S (易感): 健康
  I (感染): 感染中

区别于SIR: 恢复后不免疫，回到S状态→可反复感染
  S → I: 概率β（同SIR）
  I → S: 概率γ（恢复但不免疫）

应用: 流感等可反复感染的疾病；信息的反复传播
平稳态: 存在一个感染者比例的稳态 ρ* > 0（当R₀>1时）
```

### 1.3 IC模型 (Independent Cascade)

```
信息传播模型:
  每个被激活的节点只有一次机会去激活其邻居
  对每个未激活邻居，以概率 p(u,v) 独立尝试激活
  无论是否成功，不再有第二次机会

特点:
- 离散时间
- 单调递增（激活的节点不会变回未激活）
- 适合建模信息/创新的传播
```

### 1.4 LT模型 (Linear Threshold)

```
每个节点v有一个随机阈值 θ_v ∈ [0,1]
节点v被激活当且仅当: Σ_{u∈Active_Neighbors} w(u,v) ≥ θ_v

即: 当足够多的邻居被激活，自己也被激活（从众效应）
```

### 1.5 传播模型对比

| 模型 | 状态 | 传播机制 | 应用 | 传播阈值 |
|------|------|---------|------|---------|
| SIR | S→I→R | 邻居感染+自愈免疫 | 疫情、一次性传播 | β_c = γ/<k> |
| SIS | S→I→S | 邻居感染+自愈不免疫 | 反复传播、流感 | β_c = 1/<k> |
| IC | 未→已激活 | 每边一次机会 | 信息级联、口碑 | 取决于边概率 |
| LT | 未→已激活 | 邻居影响累积超阈值 | 社会压力、从众 | 取决于阈值分布 |

## 二、传播阈值与无标度网络

### 2.1 传播阈值

```
均匀网络(ER): β_c = 1/<k>
  → 平均度越大，传播越容易（阈值越低）

异质网络(无标度): β_c = <k> / <k²>
  → 如果度分布是幂律且γ≤3，则<k²>→∞
  → β_c → 0 ！
  → 无标度网络的传播阈值趋近于零！
```

**面试必背**：
> "无标度网络最令人震惊的传播特性是：传播阈值趋近于零。这意味着无论病毒多弱（β多小），都能在无标度网络上存活和传播。原因是hub节点的存在——它们连接众多节点，充当'超级传播者'，使得传播永远有维持下去的途径。"

### 2.2 免疫策略

| 策略 | 方法 | 效果 | 适用场景 |
|------|------|------|---------|
| 随机免疫 | 随机选节点接种 | 低效（需要免疫大部分节点） | 均匀网络 |
| 定向免疫 | 优先免疫高度节点(hub) | 极高效（少量hub即可阻断传播） | 知道网络结构时 |
| 熟人免疫 | 随机选人→接种其随机朋友 | 中高效（友谊悖论自动找到高度节点） | 不知道全局结构时 |

**友谊悖论**：
> "你的朋友平均比你拥有更多的朋友。"
> 数学：E[k_neighbor] = <k> + σ²/<k> > <k>
> 应用：随机选人的朋友，大概率选到度较高的节点→近似定向免疫

## 三、网络鲁棒性

### 3.1 渗流理论框架

```
节点渗流: 以概率(1-f)随机保留节点，f是移除比例
边渗流:   以概率(1-f)随机保留边

监测指标:
- 巨连通分量大小 S(f): 最大连通分量占比
- 平均路径长度 L(f): 网络通达效率
- 网络效率 E(f)

临界阈值 f_c: 当移除比例f超过f_c时，巨分量突然消失（相变）
```

### 3.2 随机故障 vs 定向攻击

| 攻击方式 | ER均匀网络 | BA无标度网络 |
|---------|-----------|-------------|
| 随机故障 | f_c ≈ 1 - 1/(κ-1)，较早崩塌 | f_c 很大（极为鲁棒！） |
| 定向攻击(度) | 与随机类似 | f_c 很小（极为脆弱！） |
| 定向攻击(介数) | — | 比按度攻击更致命 |

```
κ = <k²>/<k>: 度分布的异质性指标

无标度网络:
  随机故障: 需要移除 >95% 节点才能摧毁巨分量
           因为hub极少，随机几乎选不到它们
  定向攻击: 只需移除 ~5-15% 的hub即可摧毁巨分量
           hub是网络的"阿喀琉斯之踵"
```

**面试必背**：
> "无标度网络呈现出'鲁棒且脆弱'(robust-yet-fragile)的双面特性：对随机故障极度鲁棒（因为大多数节点度小，移除它们对网络影响很小），但对针对hub节点的定向攻击极度脆弱（少量hub被移除就导致网络碎片化）。这是hub节点'双刃剑'效应。"

### 3.3 级联失效 (Cascading Failure)

```
场景: 节点失效后，其负载重新分配给邻居
      如果邻居超载 → 也失效 → 负载继续重分配 → 级联

实例:
- 电网: 一条线路断开→负载转移→其他线路超载→连环断开→大停电
- 交通: 一条路堵死→车辆涌入旁边道路→也堵→拥堵扩散
- 金融: 一家银行倒闭→债务违约→关联银行也倒闭→系统性风险

模型:
  每个节点i有容量 C_i = (1+α) × L_i₀
  L_i₀: 初始负载(通常=介数中心性)
  α: 容量冗余参数
  当某节点负载L_i > C_i时失效
```

### 3.4 鲁棒性指标

| 指标 | 定义 | 含义 |
|------|------|------|
| R-index | Σ S(q) / N，q=1/N, 2/N,...,1 | 面积-曲线下面积，越大越鲁棒 |
| 临界阈值 f_c | S(f_c)突然→0的点 | f_c越大越鲁棒 |
| 第二大分量峰值 | max S₂(f) | 峰值时即为相变点 |
| 网络效率变化率 | ΔE / Δf | 衡量效率衰减速度 |

## 四、影响力最大化

### 4.1 问题定义

```
给定网络G和传播模型，选择k个种子节点S⊂V
使得从S出发的期望传播范围σ(S)最大化

max σ(S)  s.t. |S| = k

性质:
- NP-hard
- σ(S)是子模函数(submodular): 边际收益递减
- 子模性保证贪心算法有(1-1/e)≈0.63的近似比
```

### 4.2 贪心算法

```
S = {}
for i = 1 to k:
    v* = argmax_{v∉S} [σ(S∪{v}) - σ(S)]  // 最大边际增益
    S = S ∪ {v*}

时间复杂度: O(k × N × 蒙特卡洛模拟次数) → 很慢
优化: CELF (利用子模性，上一轮的边际增益是本轮的上界→大量剪枝)
```

### 4.3 近似算法

| 算法 | 思想 | 复杂度 | 近似比 |
|------|------|--------|-------|
| 贪心+蒙特卡洛 | 模拟传播取均值 | O(kNR) | 1-1/e |
| CELF | 利用子模性剪枝 | 700x加速 | 1-1/e |
| TIM/TIM+ | 反向可达集采样 | 接近线性 | 1-1/e-ε |
| IMM | 理论最优采样数 | O((k+l)(m+n)log²n/ε²) | 1-1/e-ε |
| 启发式(度/PageRank) | 直接选高中心性节点 | O(N) | 无保证 |

## 五、本模块面试问答

### Q1: SIR和SIS模型的关键区别？

> **SIR**：感染后恢复并获得**永久免疫**，不会再被感染。适用于一次性传播（如麻疹、信息的首次传播）。传播最终会停止（没有易感者或没有感染者）。
> 
> **SIS**：恢复后**不免疫**，重回易感状态，可被再次感染。适用于反复传播（如流感、八卦的反复流传）。可能达到稳态（始终有一定比例的感染者）。
> 
> 数学区别：SIR有终止态(R吸收态)，SIS有非零平衡点。

### Q2: 为什么无标度网络的传播阈值为零？

> 传播阈值公式 β_c = <k>/<k²>。
> 无标度网络度分布P(k)∝k^(-γ)，当γ≤3时，二阶矩<k²>趋向无穷。
> 因此 β_c = <k>/<k²> → 0。
> 
> 物理解释：hub节点度极高，即使感染概率β极小，hub的大量连接使它几乎必然被感染；一旦hub被感染，它又能感染大量邻居。hub充当"永不熄灭的火种"。
> 
> 实际意义：在社交网络上，任何病毒（无论多弱）都可能存活——这就是为什么需要定向免疫hub节点。

### Q3: 什么是"鲁棒且脆弱"(robust-yet-fragile)？

> 指无标度网络的双面特性：
> - **鲁棒**(对随机故障)：随机移除节点时，由于绝大多数节点度很小（不是hub），它们的移除对网络连通性影响甚微。需要移除95%+的节点才能摧毁巨分量。
> - **脆弱**(对定向攻击)：如果有目的地攻击度最高的hub节点，网络非常快就会碎片化。只需移除约5-15%的hub即可达到临界点。
> 
> 比喻：无标度网络像一个"星型+外围"结构——星星（hub）被摘掉后整个网络就散架了，但随便摘几个外围叶子节点几乎无影响。

### Q4: 熟人免疫策略为什么有效？它利用了什么原理？

> 策略：随机选一个人→问他"你认识谁"→去给那个朋友接种疫苗。
> 
> 原理是"友谊悖论"：你随机选的人的朋友，其平均度高于随机选的人本身。
> 数学：邻居的平均度 = <k> + σ²_k/<k>，总是 ≥ <k>。
> 在幂律网络中，方差σ²很大→邻居平均度远高于人群平均→高概率选中hub。
> 
> 优势：不需要知道全局网络结构，只需要局部信息（问一个人他认识谁），就能近似定向免疫效果。

### Q5: 影响力最大化为什么是NP-hard？贪心为什么能给出好的近似？

> NP-hard：穷举所有C(N,k)种k节点子集不可行（指数级）。已被证明即使在IC/LT模型下也是NP-hard。
> 
> 贪心有效的原因：传播函数σ(S)是**子模的**——即边际收益递减。
> 直觉：已选了很多种子后，再加一个新种子的边际贡献会越来越小（因为覆盖范围重叠）。
> 
> 理论保证：Nemhauser定理——对于非负单调子模函数最大化问题，贪心算法保证达到最优解的(1-1/e)≈63%。这是NP-hard问题中非常好的近似比。
