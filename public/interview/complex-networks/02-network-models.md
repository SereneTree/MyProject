# 02 经典网络模型

> 本模块覆盖三大经典网络模型（ER/WS/BA）及其衍生模型，是复杂网络面试的核心中的核心。

---

## 一、ER 随机图模型

### 1.1 两种等价形式

| 形式 | 定义 | 参数 |
|------|------|------|
| G(N, M) | N个节点中随机选M条边 | 固定边数 |
| G(N, p) | 每对节点间以概率p独立连边 | 固定概率（更常用） |

### 1.2 核心性质

| 性质 | 公式/结论 | 面试要点 |
|------|----------|---------|
| 期望边数 | <M> = p × N(N-1)/2 | |
| 平均度 | <k> = p(N-1) ≈ pN | |
| 度分布 | 泊松分布 P(k) = e^(-<k>) <k>^k / k! | 围绕<k>集中，无hub |
| 聚集系数 | C = p = <k>/(N-1) → 0 | 远小于真实网络 |
| 平均路径 | L ∝ lnN / ln<k> | 具有小世界效应 |
| 直径 | D ∝ lnN | |

### 1.3 相变（最重要！）

```
ER随机图的演化（随p增大）存在多个相变点：

p << 1/N:  只有孤立节点和小树
p = 1/N:   临界点！巨连通分量刚好出现
p > 1/N:   巨连通分量快速增长，吞并小分量
p = lnN/N: 图几乎确定连通（所有节点在一个分量中）
```

**面试必背**：
> "ER随机图最重要的结论是巨分量的相变：当平均度 <k>=1 时（即 p=1/N），网络中突然涌现出一个包含 O(N^(2/3)) 节点的巨分量。这是一个连续相变（二阶），类似物理中的渗流转变。当 p 超过 lnN/N 时，图几乎确定完全连通。"

### 1.4 ER模型的局限性

| 真实网络特征 | ER模型表现 | 差距 |
|------------|-----------|------|
| 幂律度分布 | 泊松度分布 | ER无法产生hub节点 |
| 高聚集系数 | C→0 (N大时) | ER三角形太少 |
| 社区结构 | 无社区 | ER是完全均匀随机的 |
| 度-度相关性 | 无相关 | 真实网络有同配/异配 |

## 二、WS 小世界模型

### 2.1 构造过程

```
Step 1: 环形格子 — N个节点围成环，每个节点连接最近的K个邻居
Step 2: 随机重连 — 以概率p对每条边重连到随机节点
         p=0: 规则格子（高聚集、长路径）
         p=1: 完全随机图（低聚集、短路径）
         p~0.01-0.1: 小世界网络（高聚集 + 短路径）✓
```

### 2.2 核心性质

| 性质 | p=0 (格子) | 0<p<1 (小世界) | p=1 (随机) |
|------|-----------|---------------|-----------|
| 聚集系数 C | 3(K-2)/(4(K-1)) ≈ 3/4 | 高（缓慢下降） | ~K/N → 0 |
| 平均路径 L | ~N/(2K) | ~lnN（急剧下降） | ~lnN/lnK |
| 度分布 | δ(k-K) | 近似δ+微扰 | 泊松 |

### 2.3 关键发现

```
               C/C(0)                L/L(0)
          1.0 ─────────╲               ╱──── 1.0
               ┆        ╲             ╱
               ┆         ╲           ╱
               ┆          ╲─────────╱
          0.0 ─┆──────────┆────────────
              0.001     0.01   0.1    1.0
                      重连概率 p

发现：L在p极小时就骤降，而C在p较大时才明显下降
→ 存在一个窗口(p~0.01)同时满足高C+低L = 小世界！
```

**面试话术**：
> "WS模型的核心发现是：只需要少量随机快捷连接（p~1%的边被重连），就能将平均路径从 O(N) 骤降到 O(lnN)，同时聚集系数几乎不变。这解释了为什么真实社交网络既有紧密的朋友圈（高聚集）又有六度分隔（短路径）。"

### 2.4 WS模型的局限

- 度分布仍然近似均匀（不是幂律）
- 无法产生hub节点
- 是一个静态模型（不描述网络如何生长）

## 三、BA 无标度模型

### 3.1 两个核心机制

| 机制 | 说明 | 类比 |
|------|------|------|
| 增长(Growth) | 网络不断加入新节点 | 新用户不断注册 |
| 优先连接(Preferential Attachment) | 新节点以正比于已有节点度的概率连接 | "富者更富/马太效应" |

### 3.2 构造过程

```
初始: m₀ 个全连接节点
每步: 加入1个新节点，连接m条边到已有节点
      连接节点i的概率: Π(k_i) = k_i / Σ_j k_j

经过t步: N = m₀ + t 个节点, M = m×t 条边
```

### 3.3 核心性质

| 性质 | 公式/结论 | 面试要点 |
|------|----------|---------|
| 度分布 | P(k) ∝ k^(-3)（γ=3） | 精确的幂律，指数固定为3 |
| 平均度 | <k> = 2m | 取决于参数m |
| 聚集系数 | C ∝ (lnN)²/N → 0 | 不高！这是BA的缺陷 |
| 平均路径 | L ∝ lnN/lnlnN ("超小世界") | 比ER还短 |
| hub节点 | 最早加入的节点度最高 | "先发优势" |

### 3.4 幂律指数 γ=3 的推导（简化版）

```
平均场近似：
∂k_i/∂t = m × k_i / (2mt) = k_i / (2t)

解得: k_i(t) = m × √(t/t_i)

P(k_i < k) = P(t_i > m²t/k²) = 1 - m²t/(k² × (m₀+t))

→ p(k) = 2m²/k³ ∝ k^(-3)   (γ=3)
```

**面试话术**：
> "BA模型通过增长+优先连接两个简单机制就能产生幂律度分布，解释了为什么互联网、社交网络等真实网络呈现无标度特性。核心直觉是'富者更富'——度高的节点获得新连接的概率更大，导致度的异质性不断加剧。"

### 3.5 BA模型的局限

| 局限 | 说明 | 改进模型 |
|------|------|---------|
| γ固定为3 | 不能调节幂律指数 | 非线性优先连接 Π∝k^α |
| 聚集系数低 | 不产生三角形 | 层次网络模型(Hierarchical) |
| 无社区结构 | 节点无分组倾向 | LFR基准模型 |
| 无老化/衰退 | 节点永远活跃 | 适应度模型(Fitness Model) |

## 四、配置模型（零模型）

### 4.1 定义与用途

```
目的: 给定一个度序列 {k₁, k₂, ..., k_N}，生成随机网络作为"零模型"
     用于判断真实网络的某些特征是否仅由度序列就能解释

构造:
1. 每个节点i有 k_i 个"半边"(stub)
2. 随机配对所有半边形成完整边
3. 移除自环和重边（得到简单图）
```

### 4.2 面试应用

> "配置模型是网络分析中最重要的零模型。当我们发现真实网络的某个特征（如高聚集系数），需要判断：这是度序列本身导致的，还是网络有额外的组织结构？方法就是生成保持相同度序列的配置模型，对比两者。"

## 五、三大模型对比（面试必背！）

| 维度 | ER随机图 | WS小世界 | BA无标度 |
|------|---------|---------|---------|
| 生成机制 | N个节点随机连边 | 格子+随机重连 | 增长+优先连接 |
| 度分布 | 泊松 | 近δ分布 | 幂律 P(k)∝k^(-3) |
| 聚集系数 | 低 (~<k>/N) | 高 (~3/4) | 低 (~(lnN)²/N) |
| 平均路径 | lnN/ln<k> | ~lnN | lnN/lnlnN |
| hub节点 | 无 | 无 | 有(度极高) |
| 社区结构 | 无 | 局部有 | 无 |
| 对随机攻击 | 脆弱(均匀分布) | 类似ER | 鲁棒(hub不易被选中) |
| 对定向攻击 | 类似随机 | 类似ER | 极脆弱(攻击hub) |
| 动态/静态 | 静态 | 静态 | 动态(演化) |
| 真实网络匹配 | 差 | 中(路径+聚集) | 中(度分布) |
| 代表论文 | Erdős-Rényi 1959 | Watts-Strogatz 1998 | Barabási-Albert 1999 |

## 六、其他重要模型

### 6.1 适应度模型(Fitness Model)

```
Π(k_i) ∝ η_i × k_i

η_i: 节点i的"适应度"（内在吸引力）
→ 即使后来的节点，如果适应度高，也能超越先来者
→ 可以产生 γ≠3 的幂律分布
```

### 6.2 LFR 基准模型(Lancichinetti-Fortunato-Radicchi)

```
用途: 生成有社区结构的人工网络，用于评测社区检测算法

参数: 幂律度分布指数、社区大小分布指数、混合参数μ
μ→0: 社区结构明显
μ→1: 社区结构消失
```

### 6.3 随机块模型(SBM: Stochastic Block Model)

```
N个节点分为K组，组i和组j之间的连接概率为 p_ij

对角线 p_ii > p_ij: 产生社区结构
对角线 p_ii < p_ij: 产生二部图结构
等概率: 退化为ER模型
```

## 七、本模块面试问答

### Q1: 真实网络和ER随机图最大的区别是什么？

> 三个关键区别：
> 1. **度分布不同**：真实网络通常是幂律/重尾分布，ER是泊松分布（没有hub）
> 2. **聚集系数不同**：真实网络聚集系数显著高于ER（社区结构）
> 3. **度-度相关性**：真实网络有同配/异配特性，ER无相关
> 总结：ER作为最简单的零模型有理论价值，但不能作为真实网络的模型。

### Q2: WS模型解决了什么问题？留下了什么问题？

> 解决：同时产生高聚集系数和短路径（小世界特性）
> 留下：度分布仍然近似均匀，无法产生幂律分布和hub节点。
> 也就是说WS解释了"小世界"但没解释"无标度"。BA模型解决了后者。

### Q3: 优先连接的物理意义是什么？现实中对应什么？

> 物理意义：节点获得新连接的速率正比于其当前连接数。
> 现实对应：
> - 社交网络：粉丝越多→曝光越多→新粉丝增长越快
> - 学术引用：被引次数越多→被看到概率越大→继续被引
> - 网页链接：流量大的网站更容易被新网站链接
> 本质上是一种正反馈/马太效应。

### Q4: BA模型的幂律指数为什么固定是3？如何调节？

> BA模型中线性优先连接 Π∝k 严格导致 γ=3。如果需要其他指数：
> - 非线性优先连接：Π∝k^α（α>1 → γ<3；α<1 → γ>3）
> - 初始吸引力：Π∝k+A（加常数偏移）
> - 适应度模型：Π∝η·k（引入内在异质性）
> 真实网络的γ通常在2~3之间。
