## 一、社交网络与推荐

### 1.1 好友推荐

| 方法 | 原理 | 网络理论基础 |
|------|------|-------------|
| 共同好友推荐 | 推荐共同好友最多的人 | 高聚集系数→三角形闭合 |
| Adamic-Adar | 稀有共同好友权重更大 | 链接预测指标 |
| 二阶邻居扩展 | 朋友的朋友可能认识 | 小世界效应(短路径) |
| 社区内推荐 | 同社区的未连接用户 | 社区检测 |
| 图嵌入推荐 | 嵌入空间距离近的用户 | Node2Vec/GraphSAGE |

### 1.2 信息流排序

```
应用: 微信朋友圈、微博时间线
方法: PersonalRank（个性化PageRank）
  - 以用户为起点做随机游走
  - 经常"路过"的好友 → 亲密度高 → 动态排名靠前
  - 利用互动网络(点赞/评论/聊天频率)作为边权
```

### 1.3 影响力营销

```
应用: KOL投放选择
方法: 影响力最大化
  - 选择位于不同社区桥接位置的KOL → 最大化覆盖
  - 不只看粉丝数(度)，要看实际传播力(级联深度/广度)
  - 多层网络融合: 关注网络 + 互动网络 + 内容标签网络
```

**面试话术**：
> "社交推荐的本质是链接预测问题。工业界通常融合多种网络拓扑特征（共同邻居、Jaccard、PageRank等）加上用户画像特征，输入机器学习模型来排序候选推荐。图神经网络（GNN）是目前最先进的方法，可以自动学习网络中的高阶结构特征。"

## 二、搜索引擎

### 2.1 PageRank

```
核心思想: 网页的重要性 = 被重要网页链接的程度
算法: 
  PR(v) = (1-d)/N + d × Σ_{u→v} PR(u)/k_out(u)
  迭代至收敛（通常20-50次）

Google早期: PageRank + 文本相关性 → 搜索结果排名
```

### 2.2 HITS算法

```
Authority(权威值): 好的内容页面，被很多好的hub页面链接
Hub(枢纽值): 好的导航页面，链接到很多好的authority页面

迭代更新:
  a(v) = Σ_{u→v} h(u)  (authority = 入链的hub值之和)
  h(v) = Σ_{v→u} a(u)  (hub = 出链的authority值之和)

与PageRank区别: HITS区分内容页和导航页，且是查询相关的
```

## 三、金融风控

### 3.1 欺诈团伙检测

| 应用 | 网络建模 | 检测方法 |
|------|---------|---------|
| 刷单团伙 | 买家-卖家交易二部图 | 异常密集子图检测 |
| 洗钱链路 | 资金转账有向图 | Fan-in/Fan-out motif |
| 虚假账号 | 设备/IP共享网络 | 社区密度异常检测 |
| 担保圈风险 | 企业互保有向图 | 环检测 + 连通分量 |

### 3.2 系统性风险评估

```
银行间网络:
  节点: 银行
  边: 银行间拆借/债务关系
  权重: 借贷金额

分析:
  - 太大而不能倒(Too Big to Fail) → 高介数/高度中心性
  - 级联违约 → 级联失效模型
  - 系统重要性排名 → DebtRank算法
```

**面试话术**：
> "金融风控中，图方法的优势在于能发现单点检测无法识别的组织化欺诈行为。单个账户行为可能看起来正常，但当你把多个账户的关联关系（共享设备、共同IP、互相转账）构建成网络后，异常模式就浮现出来了——比如欺诈团伙会形成异常密集的子图，洗钱会形成特定的Fan-in/Fan-out模式。"

## 四、交通网络

### 4.1 路径规划

| 问题 | 网络建模 | 算法 |
|------|---------|------|
| 最短路径 | 路口=节点，道路=加权边 | Dijkstra / A* / CH |
| 动态路径 | 边权随时间变化 | 时间依赖Dijkstra |
| 多目标路径 | 时间+距离+费用多权重 | Pareto最优路径 |

### 4.2 拥堵分析

```
拥堵传播 → 类SIR模型在路网上的扩散
关键路段 → 边介数中心性最高的路段
脆弱性 → 渗流分析(移除拥堵路段后网络连通性)
相变 → 拥堵比例超过临界阈值后全网崩溃
```

### 4.3 公共交通优化

```
地铁网络分析:
  - 中心性分析 → 识别关键换乘站
  - 社区检测 → 识别服务覆盖的区域模块
  - 鲁棒性 → 评估线路故障对网络的影响
  - 网络流 → 优化线路频次和运力分配
```

## 五、生物网络

### 5.1 蛋白质相互作用网络(PPI)

```
节点: 蛋白质
边: 物理/功能相互作用
特征: 无标度分布、hub蛋白(必需基因)
应用: 药物靶点发现 → 攻击hub蛋白可能致死→潜在药靶
```

### 5.2 基因调控网络

```
节点: 基因
有向边: 转录因子→靶基因（激活/抑制）
特征: 模块化(功能模块)、层次结构
应用: 关键调控因子识别 → 度中心性/介数中心性排名
```

### 5.3 传染病防控

```
接触网络:
  节点: 个体
  边: 物理接触/共处一室
  
分析:
  - SIR/SIS模型预测传播规模
  - 超级传播者识别 → hub节点
  - 免疫策略 → 定向免疫/熟人免疫
  - 传播阈值估计 → 指导公共卫生政策
```

## 七、图神经网络(GNN)简介

### 7.1 核心思想

```
消息传递(Message Passing):
  每个节点从邻居聚合信息 → 更新自身表示 → 多层堆叠

Layer l:
  h_v^(l) = UPDATE(h_v^(l-1), AGGREGATE({h_u^(l-1) : u ∈ N(v)}))

变体:
  GCN: AGGREGATE = 均值聚合 + 归一化
  GraphSAGE: AGGREGATE = 采样邻居 + 均值/LSTM/池化
  GAT: AGGREGATE = 注意力加权聚合
```

### 7.2 与传统网络分析的关系

| 传统方法 | GNN方法 | 对比 |
|---------|---------|------|
| 手工设计中心性特征 | 自动学习节点嵌入 | GNN端到端，省去特征工程 |
| 社区检测(Louvain) | GNN + 聚类 | GNN可融合节点属性 |
| 链接预测(CN/AA) | GNN编码器+解码器 | GNN可学非线性模式 |
| 传播模拟(SIR) | GNN预测传播 | GNN更快(不需蒙特卡洛) |

## 八、本模块面试问答

### Q1: 复杂网络理论在推荐系统中有哪些应用？

> 1. **好友推荐**：链接预测（共同邻居、Adamic-Adar等指标）
> 2. **物品推荐**：用户-物品二部图上的随机游走（ItemRank）
> 3. **冷启动**：利用社交网络传播用户偏好（社交推荐）
> 4. **多样性**：利用社区结构确保推荐覆盖不同"兴趣圈"
> 5. **GNN方法**：图卷积直接在交互图上学习用户和物品表示
> 
> 核心优势：捕捉高阶协同信号（不只看直接交互，还看多跳路径上的间接关系）。

### Q2: 如何用网络方法做金融反欺诈？

> 三层方法：
> 1. **图构建**：构建异构关联网络（账户-设备-IP-手机-地址-商户）
> 2. **模式检测**：
>    - Motif检测：找Fan-in/Fan-out/环形转账等异常子图模式
>    - 社区异常：密度过高的社区→可能是团伙
>    - 标签传播：从已知欺诈节点扩散风险分数
> 3. **GNN分类**：用GraphSAGE等GNN做节点分类（正常vs欺诈）
> 
> 关键点：单点特征容易被绕过，但网络结构特征难以伪造。

### Q3: 复杂网络分析和传统图算法有什么区别？

> **传统图算法**：关注具体问题的精确解（最短路径、最大流、匹配等）
> **复杂网络分析**：关注大规模真实网络的统计规律和动力学行为
> 
> 区别：
> - 规模：传统图算法可精确求解；复杂网络通常需要近似/采样
> - 关注点：传统关注单个问题的算法；复杂网络关注网络"涌现特性"
> - 方法论：传统是确定性的；复杂网络大量使用统计物理方法
> - 目标：传统是解决问题；复杂网络是理解和预测系统行为

### Q4: 举一个网络分析改变商业决策的案例？

> **案例：抖音KOL投放优化**
> 
> 问题：选10个KOL做品牌推广，如何最大化覆盖用户数？
> 
> 传统方案：选粉丝最多的10个人 → 覆盖重叠严重（粉丝高度重合）
> 
> 网络方案：影响力最大化算法
> 1. 构建用户关注+互动网络
> 2. 做社区检测，识别不同兴趣圈
> 3. 在每个主要社区中选影响力最高的KOL
> 4. 确保种子集覆盖多个社区（最大化边际增益）
> 
> 效果：相同预算下传播覆盖提升60%+
> 
> 关键洞察：网络方法考虑了**覆盖的多样性**，而非单纯追求个体影响力最大。
