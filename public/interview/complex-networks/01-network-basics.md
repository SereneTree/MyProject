# 01 网络基础与度量

> 本模块覆盖复杂网络的基本概念和核心统计量，是理解后续所有模型与算法的基石。

---

## 一、图的基本表示

### 1.1 图的定义

| 类型 | 定义 | 应用举例 |
|------|------|---------|
| 无向图 G=(V,E) | 边无方向，{u,v}={v,u} | 社交好友关系、蛋白质相互作用 |
| 有向图 G=(V,E) | 边有方向，(u,v)≠(v,u) | 微博关注、网页链接、资金流向 |
| 加权图 G=(V,E,W) | 每条边有权重 w(u,v) | 交通网络（距离）、通信网络（带宽） |
| 二部图 G=(U,V,E) | 节点分两组，边只在组间 | 用户-商品、论文-作者 |

### 1.2 图的存储

| 存储方式 | 空间 | 查询边O(?) | 适用场景 |
|---------|------|-----------|---------|
| 邻接矩阵 | O(N²) | O(1) | 稠密图、矩阵运算 |
| 邻接表 | O(N+M) | O(k) | 稀疏图（真实网络大多稀疏） |
| 边列表 | O(M) | O(M) | 存储简单、流处理 |

**面试话术**：
> "真实网络通常是稀疏的（边数M远小于N²），所以邻接表是工业界的标准选择。只有在做矩阵分解、谱分析时才用邻接矩阵。"

## 二、度与度分布

### 2.1 度的定义

```
无向图: k_i = 节点i的连接边数
有向图: k_in(入度) + k_out(出度) = 总度

平均度: <k> = 2M/N (无向图) 或 M/N (有向图的入度=出度平均)
```

### 2.2 度分布 P(k)

| 网络类型 | 度分布形态 | 特征 |
|---------|-----------|------|
| ER随机网络 | 泊松分布 | 集中在 <k> 附近，无极端hub |
| 真实社交网络 | 幂律分布 P(k)∝k^(-γ) | 少数超级hub，多数小度节点 |
| 格子/规则网络 | δ分布 | 所有节点度相同 |
| 交通/地铁网络 | 指数分布 | 受空间约束，无极端hub |

### 2.3 幂律分布的验证

```
方法1: 双对数坐标(log-log plot) → 直线
方法2: 互补累积分布 CCDF → 更稳定
方法3: 极大似然估计(MLE) + KS检验 → 最严谨
```

**面试必背**：
> "幂律分布意味着网络是异质的——大多数节点度很小，但存在少数度极高的hub节点。这导致了无标度网络对随机故障鲁棒但对定向攻击脆弱的特性。"

## 三、聚集系数

### 3.1 局部聚集系数

```
C_i = 2 × E_i / (k_i × (k_i - 1))

E_i: 节点i的邻居之间实际存在的边数
k_i: 节点i的度
k_i(k_i-1)/2: 邻居之间最多可能的边数
```

**直觉**：你的朋友之间互相认识的比例。

### 3.2 全局聚集系数（传递性）

```
C_global = 3 × 三角形数 / 三元组数(connected triples)
```

### 3.3 各类网络的聚集系数

| 网络 | 聚集系数 | 解释 |
|------|---------|------|
| ER随机图 | C ≈ p = <k>/N → 0 (N→∞) | 随机连接，三角形很少 |
| WS小世界 | C ≈ 3/4 (重连概率p=0时) | 格子结构天然高聚集 |
| BA无标度 | C ∝ (lnN)²/N → 0 | 优先连接不产生三角形 |
| 真实社交网络 | C ≈ 0.1~0.6 | 显著高于同规模随机图 |

**面试对比**：
> "高聚集系数是真实网络区别于ER随机图的关键特征之一。它说明网络中存在明显的社区结构——朋友的朋友大概率也是朋友。"

## 四、路径与距离

### 4.1 最短路径

```
d(u,v): 节点u到v的最短路径长度（跳数或加权距离）
直径 D = max_{u,v} d(u,v): 网络中最长的最短路径
平均路径长度 L = (1/(N(N-1))) × Σ d(u,v)
```

### 4.2 小世界效应

```
真实网络的平均路径长度通常满足:
L ∝ ln(N) / ln(<k>)

即使网络有数十亿节点，平均路径长度也只有个位数（6度分隔）
```

### 4.3 各类网络的平均路径

| 网络 | 平均路径长度 | 原因 |
|------|------------|------|
| 规则格子(d维) | L ∝ N^(1/d) | 必须沿格子"走"，很慢 |
| ER随机图 | L ∝ lnN/ln<k> | 随机长程连接大大缩短路径 |
| WS小世界 | L ∝ lnN (少量重连后骤降) | 少量快捷连接即可产生小世界 |
| BA无标度 | L ∝ lnlnN | hub节点充当"高速公路"，路径更短 |

**面试话术**：
> "小世界效应的关键发现是：只需要极少量的随机长程连接（重连概率p~0.01），就能将平均路径长度从 N^(1/d) 骤降到 lnN，同时保持高聚集系数不变。"

## 五、连通性

### 5.1 连通分量

| 概念 | 定义 |
|------|------|
| 连通分量(无向图) | 任意两点间存在路径的最大子图 |
| 强连通分量(有向图) | 任意u→v和v→u都有有向路径 |
| 弱连通分量(有向图) | 忽略边方向后的连通分量 |
| 巨连通分量(GCC) | 包含大部分节点的最大连通分量 |

### 5.2 巨分量的出现（相变）

```
ER随机图: 当平均度 <k> > 1 时 (即 p > 1/N)
  → 巨连通分量突然出现（二阶相变）
  → 这是ER随机图最重要的性质之一
```

**面试必背**：
> "ER随机图存在一个临界点 p_c = 1/N：当 p < p_c 时网络是碎片化的小连通分量；当 p 刚超过 p_c 时，突然出现一个巨大连通分量——这是一种相变现象，类似物理中的渗流转变。"

## 六、其他重要度量

### 6.1 网络密度

```
D = 2M / (N(N-1))  (无向图)

稀疏网络: D << 1, M ∝ N  (大多数真实网络)
稠密网络: D ~ O(1), M ∝ N²
```

### 6.2 同配系数(Assortativity)

```
r > 0: 同配网络（高度连高度）→ 社交网络
r < 0: 异配网络（高度连低度）→ 技术网络、生物网络
r = 0: 中性
```

### 6.3 网络效率

```
E_global = (1/(N(N-1))) × Σ 1/d(u,v)

比平均路径长度更好：可处理不连通网络（d=∞时贡献为0）
```

## 八、本模块面试问答

### Q1: 什么是复杂网络？和普通图有什么区别？

> 复杂网络是指具有非平凡拓扑特征的大规模网络——不同于完全随机图也不同于规则格子。它的典型特征包括：小世界效应（短路径）、高聚集系数、异质度分布（幂律）、社区结构。普通图论关注的是抽象的图结构和算法；复杂网络更关注真实大规模网络的统计特性和动力学行为。

### Q2: 如何判断一个网络是否是"小世界"的？

> 需要同时满足两个条件：
> 1. 平均路径长度 L 和同规模ER随机图相当（L ~ lnN）
> 2. 聚集系数 C 远高于同规模ER随机图（C >> <k>/N）
> 即"短路径 + 高聚集"。可以用 σ = (C/C_random) / (L/L_random) > 1 来量化。

### Q3: 度分布为什么重要？

> 度分布是网络最基本的统计特征，它决定了网络的许多宏观性质：
> - 泊松分布 → 均匀网络，对各种攻击响应类似
> - 幂律分布 → 存在hub，对随机故障鲁棒但对定向攻击脆弱
> - 度分布还影响传播阈值（无标度网络传播阈值趋近于0）
> - 它是构建网络零模型（配置模型）的基础
