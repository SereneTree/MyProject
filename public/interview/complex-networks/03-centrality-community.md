# 03 中心性与社区检测

> 本模块覆盖"谁是网络中最重要的节点"和"网络如何划分成社区"两大核心问题。

---

## 一、中心性度量

### 1.1 五种核心中心性对比

| 中心性 | 公式 | 直觉含义 | 计算复杂度 |
|--------|------|---------|-----------|
| 度中心性 | C_D(v) = k_v/(N-1) | 直接连接多=社交广 | O(1) 查表 |
| 接近中心性 | C_C(v) = (N-1)/Σd(v,u) | 到大家都近=位置好 | O(NM) BFS |
| 介数中心性 | C_B(v) = Σ σ_st(v)/σ_st | 最短路必经之地=桥梁 | O(NM) Brandes |
| 特征向量中心性 | Ax = λx, C_E(v) = x_v | 连接重要人=圈子好 | O(N²) 迭代 |
| PageRank | PR(v) = (1-d)/N + d×Σ PR(u)/k_out(u) | 被重要页面链接=权威 | O(N+M) 迭代 |

### 1.2 度中心性 (Degree Centrality)

```
C_D(v) = k_v / (N-1)

优点: 最简单、计算最快
缺点: 只看局部(一阶邻居)，忽略全局位置
适用: 快速筛选"连接数多"的节点
```

**面试话术**：
> "度中心性是最基础的指标，但它只衡量局部连接数量。一个度很高但位于网络边缘的节点，其全局影响力可能不如一个度中等但位于网络桥接位置的节点。"

### 1.3 接近中心性 (Closeness Centrality)

```
C_C(v) = (N-1) / Σ_{u≠v} d(v,u)

直觉: 离所有人都近的节点→信息传播最快的源头
局限: 要求图连通；不连通时需用调和接近中心性
      C_H(v) = Σ 1/d(v,u) / (N-1)
```

### 1.4 介数中心性 (Betweenness Centrality)

```
C_B(v) = Σ_{s≠v≠t} σ_st(v) / σ_st

σ_st: s到t的最短路径总数
σ_st(v): 其中经过v的数量

直觉: 控制信息流动的"瓶颈"/"桥梁"
应用: 识别网络中的关键节点（移除后网络断裂）
```

**面试必背**：
> "介数中心性衡量的是节点作为'通信桥梁'的重要性。高介数的节点不一定度最高，但它控制着不同部分之间的信息流。这在社交网络中对应'消息灵通的中间人'，在交通网络中对应'必经的交通枢纽'。"

### 1.5 特征向量中心性 (Eigenvector Centrality)

```
x_i = (1/λ) × Σ_{j∈N(i)} x_j

即: Ax = λ₁x (邻接矩阵的主特征向量)

直觉: 你的重要性取决于你邻居的重要性（递归定义）
和度中心性的区别: 不是"有多少朋友"，而是"朋友有多重要"
```

### 1.6 PageRank

```
PR(v) = (1-d)/N + d × Σ_{u→v} PR(u)/k_out(u)

d: 阻尼因子(通常0.85)，代表随机游走继续跟随链接的概率
1-d: 随机跳转到任意页面的概率

本质: 有阻尼的随机游走在网络上的平稳分布
```

**面试话术**：
> "PageRank可以理解为一个无聊的上网者：85%的时间点击当前页面的链接（按概率随机选），15%的时间随机跳到任何页面。最终每个页面被访问的概率就是它的PageRank值。被很多高PR页面链接的页面PR也高。"

### 1.7 各中心性的区别与选用

| 场景 | 推荐中心性 | 原因 |
|------|-----------|------|
| 疾病传播的超级传播者 | 度中心性 | 直接接触多=传播快 |
| 信息传播最快的源 | 接近中心性 | 离所有人距离短 |
| 网络瓶颈/桥梁节点 | 介数中心性 | 最短路经过它 |
| 社交影响力排名 | PageRank/特征向量 | 考虑邻居质量 |
| 网络脆弱性分析 | 介数中心性 | 移除高介数节点影响最大 |

## 二、社区检测

### 2.1 什么是社区？

```
社区定义（直觉）: 网络中节点的分组，组内连接密集，组间连接稀疏

形式化: 社区内边密度 >> 社区间边密度
        或: 社区内边数 > 随机情况下的期望边数（模块度定义）
```

### 2.2 模块度 (Modularity)

```
Q = (1/2m) × Σ_{ij} [A_ij - k_i×k_j/(2m)] × δ(c_i, c_j)

A_ij: 邻接矩阵元素
k_i, k_j: 节点度
m: 总边数
δ(c_i, c_j): 节点i和j是否在同一社区（1或0）

解读:
- A_ij: 实际边数
- k_i×k_j/(2m): 在配置模型（随机零模型）下的期望边数
- Q > 0: 社区内实际边 > 随机期望 → 有社区结构
- Q的范围: [-0.5, 1]，通常 Q > 0.3 认为有显著社区
```

**面试必背**：
> "模块度的核心思想是将实际网络与一个保持相同度序列的随机零模型（配置模型）对比。如果社区内的边数显著超过随机情况下的期望，说明社区划分是有意义的。模块度是大多数社区检测算法的优化目标。"

### 2.3 Louvain 算法

```
Phase 1 (局部移动):
  for each node i:
    尝试将i移入每个邻居所在社区
    选择模块度增益ΔQ最大的移动
    重复直到无节点再移动

Phase 2 (网络聚合):
  将每个社区合并为一个"超节点"
  社区间的边合并为超节点间的加权边
  社区内的边变为超节点的自环权重

重复 Phase1 + Phase2 直到Q不再增加
```

**模块度增益公式**：
```
ΔQ = [Σ_in + 2k_{i,in}] / (2m) - [(Σ_tot + k_i)/(2m)]²
   - [Σ_in/(2m) - (Σ_tot/(2m))² - (k_i/(2m))²]

Σ_in: 社区C内部的边权重之和
Σ_tot: 社区C所有节点的度之和
k_i: 节点i的度
k_{i,in}: 节点i到社区C内节点的边权重之和
```

**优缺点**：

| 优点 | 缺点 |
|------|------|
| 快：O(N log N) | 分辨率限制：无法检测很小的社区 |
| 无需预设社区数 | 结果可能不稳定（依赖遍历顺序） |
| 层次化结构 | 非确定性算法 |
| 可处理加权图 | 可能陷入局部最优 |

### 2.4 标签传播算法 (Label Propagation)

```
Step 1: 每个节点初始标签唯一
Step 2: 每个节点采用其邻居中最多的标签（投票）
Step 3: 重复直到稳定（所有节点标签不再变化）

优点: 极快 O(M), 近线性时间
缺点: 结果不稳定, 可能振荡, 可能退化(所有节点同一标签)
```

### 2.5 谱聚类 (Spectral Clustering)

```
Step 1: 计算图拉普拉斯矩阵 L = D - A
Step 2: 求L的前k个最小特征值对应的特征向量
Step 3: 用特征向量作为节点的嵌入表示
Step 4: 在嵌入空间做K-means聚类

理论基础: Fiedler向量(第二小特征值对应的特征向量)
         给出最优的min-cut二分方案的松弛解
```

### 2.6 社区检测算法对比

| 算法 | 时间复杂度 | 需要K？ | 优势 | 劣势 |
|------|-----------|--------|------|------|
| Louvain | O(N logN) | 否 | 快、可扩展、层次化 | 分辨率限制 |
| 标签传播 | O(M) | 否 | 最快 | 不稳定 |
| 谱聚类 | O(N³) | 是 | 理论优美 | 计算量大 |
| Girvan-Newman | O(M²N) | 否 | 层次结果 | 极慢 |
| Infomap | O(M) | 否 | 基于信息论 | 小社区问题 |

## 三、链接预测

### 3.1 问题定义

```
给定当前网络 G(t)，预测未来可能出现的新边 E(t+1)
应用: 好友推荐、知识图谱补全、蛋白质相互作用预测
```

### 3.2 常用指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 共同邻居(CN) | \|N(x) ∩ N(y)\| | 共同好友数 |
| Jaccard系数 | CN / \|N(x) ∪ N(y)\| | 归一化版本 |
| Adamic-Adar | Σ_{z∈CN} 1/log(k_z) | 稀有共同好友权重更大 |
| 资源分配(RA) | Σ_{z∈CN} 1/k_z | 类似AA，惩罚更强 |
| Katz指数 | Σ_{l=1}^∞ β^l \|paths_l(x,y)\| | 考虑所有路径 |
| Preferential Attachment | k_x × k_y | 度高的节点更容易产生新连接 |

## 四、本模块面试问答

### Q1: 度中心性和介数中心性有什么区别？什么时候用哪个？

> 度中心性只看局部连接数量（一阶邻居数），适合识别"认识人多"的节点；
> 介数中心性看全局最短路径经过情况，适合识别"信息流通瓶颈"的桥梁节点。
> 
> 举例：一个位于两个社区之间的"桥接者"可能度不高，但介数极高——它是两个社区信息交流的唯一通道。移除它会导致网络分裂。
> 
> 选用：分析传播扩散→用度中心性；分析网络脆弱性/瓶颈→用介数中心性。

### Q2: Louvain算法的"分辨率限制"是什么意思？

> 模块度优化天然有一个分辨率极限：当社区太小时（边数 < √(2m)），即使内部完全连通，将其合并到更大社区的模块度增益也可能更高。
> 
> 结果：Louvain无法检测到小社区——它倾向于将小社区合并为大社区。
> 
> 解决方案：多分辨率方法（引入分辨率参数γ）、Leiden算法（Louvain的改进版）。

### Q3: PageRank和特征向量中心性的联系与区别？

> 联系：都考虑了"邻居的重要性"（递归定义）。
> 
> 区别：
> - 特征向量中心性：无阻尼，只在强连通图上有良好定义
> - PageRank：加入阻尼因子d（随机跳转），保证任何图上都收敛
> - PageRank考虑出度归一化（重要节点的"票"被均匀分配给其出链）
> - 特征向量中心性不考虑出度（指向你的人越重要，你就越重要）
> 
> 工程选择：有向图用PageRank；无向图两者类似但PageRank更稳定。

### Q4: 如何评估社区检测的质量？

> 1. **有ground truth时**：NMI（归一化互信息）、ARI（调整兰德指数）
> 2. **无ground truth时**：模块度Q值；内部密度 vs 外部密度
> 3. **稳定性评估**：多次运行看结果一致性
> 4. **可视化验证**：将社区标记在网络可视化图上目视检查
