## 🎯 必背核心考点（Top 20）

> 这 20 题占面试出现率 **85%+**，没复习时间也要先把这些拿下。

| 排名 | 考点 | 一句话答案 |
|------|------|-----------|
| 1 | 数组和链表的区别？ | 数组连续存储随机访问O(1)但插删O(n)；链表离散存储插删O(1)但访问O(n) |
| 2 | HashMap底层实现原理？ | 数组+链表/红黑树；哈希函数定位桶，冲突时链表，长度>8转红黑树 |
| 3 | 快速排序的原理和时间复杂度？ | 选pivot分区，递归排序两侧；平均O(nlogn)，最坏O(n²)(有序数组) |
| 4 | 二叉树的前中后序遍历？ | 前序(根左右)、中序(左根右)、后序(左右根)；递归/迭代栈实现 |
| 5 | 红黑树的性质和用途？ | 自平衡BST，保证最长路径≤2×最短路径；用于TreeMap/HashMap(JDK8) |
| 6 | B+树为什么适合数据库索引？ | 多路平衡，减少磁盘IO；叶子有序链表，范围查询高效；非叶存索引不存数据 |
| 7 | 栈和队列的区别与应用？ | 栈LIFO(括号匹配/递归/撤销)；队列FIFO(BFS/消息队列/缓冲区) |
| 8 | 堆的应用场景？ | Top K问题、优先队列、堆排序、合并K个有序链表、中位数维护 |
| 9 | 什么是哈希冲突？如何解决？ | 不同key映射到同一桶位；开放寻址(线性/二次探测)或链地址法 |
| 10 | 图的BFS和DFS区别？ | BFS用队列按层遍历(最短路径)；DFS用栈深入探索(连通性/拓扑排序) |
| 11 | 链表如何判断有环？ | 快慢指针：快指针每次走2步，慢指针走1步，相遇则有环 |
| 12 | 二分查找的条件和边界？ | 前提：有序数组；注意左闭右开/闭区间写法；mid计算防溢出 |
| 13 | 归并排序的原理？ | 分治：递归拆分至单个元素，两两合并有序序列；稳定O(nlogn) |
| 14 | AVL树和红黑树的区别？ | AVL严格平衡(查询快)但插删旋转多；红黑树近似平衡(插删快)综合性能好 |
| 15 | 什么是拓扑排序？ | 有向无环图(DAG)的线性序列，满足所有边u→v中u在v前；用于依赖分析 |
| 16 | Dijkstra和Bellman-Ford区别？ | Dijkstra贪心O(ElogV)不支持负权边；BF松弛O(VE)支持负权可检测负环 |
| 17 | 跳表的原理和优势？ | 多层链表+随机化；O(logn)查找/插删；实现简单、并发友好、范围查询天然支持 |
| 18 | HashMap扩容机制？ | 负载因子>0.75触发；容量翻倍；rehash重新分配(JDK8高位判断优化) |
| 19 | 稳定排序和不稳定排序？ | 稳定：归并/冒泡/插入/计数；不稳定：快排/堆排/希尔/选择 |
| 20 | LRU缓存如何实现？ | 哈希表+双向链表：哈希O(1)查找，链表维护访问顺序，O(1)淘汰 |

## 💡 答题黄金三段式

面试中回答数据结构问题，推荐使用**「定义→对比→场景」**三段式：

```
第一段：「是什么」—— 简明定义 + 核心性质 (10秒)
第二段：「对比谁」—— 与相似结构对比优劣 (20秒)
第三段：「用在哪」—— 实际应用场景/工程案例 (20秒)
```

**示例：什么是红黑树？**

> ① 红黑树是一种自平衡二叉搜索树，通过红黑着色和旋转规则保证最长路径不超过最短路径的2倍。
> ② 对比AVL树，红黑树牺牲了严格平衡性换取更少的旋转次数，综合插删改查性能更优。
> ③ 工程中 Java TreeMap、HashMap(链表>8转树)、Linux CFS调度器都使用红黑树。
