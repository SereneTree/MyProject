## 通用设计原则

1. **问题抽象为图**：识别业务中的"实体"→节点，"关系"→边，是图论落地的第一步
2. **选择合适的图模型**：有向/无向、加权/无权、DAG/一般图，直接影响算法选择
3. **工程化近似**：课本算法复杂度可能过高(如TSP的NP-hard)，工业界大量使用启发式/近似算法
4. **动态与增量**：真实系统中图是动态变化的，需要增量更新而非全量重算
5. **分布式处理**：亿级节点的图必须分布式存储与计算(Pregel/GraphX/自研)
