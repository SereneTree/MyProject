## 通用设计原则

1. **图思维建模**：将真实业务抽象为节点+边的网络结构，是复杂网络落地的第一步
2. **分层分析**：宏观(全局统计特性) → 中观(社区/模块) → 微观(关键节点) 三层分析
3. **动态演化**：真实网络是动态变化的，需要增量更新而非全量重建
4. **工程近似**：课本算法往往 O(n³)不可用，工业界用近似/采样/分布式来降低复杂度
5. **多网络融合**：单一关系不够，融合社交、行为、设备等多层网络提升分析效果
