## 通用设计原则

1. **离线训练 + 在线推理分离**：训练集群用 GPU 跑大规模实验，线上用轻量模型 + 模型蒸馏保证延迟
2. **特征工程仍是关键**：深度模型不代表不做特征，大厂往往有百亿级特征体系
3. **AB 实验驱动迭代**：任何模型改进都必须通过线上 AB 实验验证，拒绝"理论更优但线上无增益"
4. **模型服务化**：统一的模型服务平台（TFServing / Triton / 自研框架）支撑多业务复用
5. **数据闭环**：线上日志 → 样本构建 → 训练 → 部署 → 线上日志，形成持续进化闭环
