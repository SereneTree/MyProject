## 通用设计原则

1. **空间换时间**：布隆过滤器用少量位图空间换取 O(1) 判重速度，跳表用多层索引换取快速有序访问
2. **分层设计**：LSM-Tree 将热数据(内存) 与冷数据(磁盘) 分层管理，平衡读写性能
3. **概率容忍**：在大规模场景下接受一定误判率(如布隆过滤器假阳性)，以换取数量级的空间和时间优势
4. **简单高效**：Redis 选择跳表而非红黑树，因为跳表实现更简单、并发友好、范围查询天然支持
5. **组合拳思维**：单一数据结构往往不够，LSM-Tree = 红黑树 + 跳表 + 布隆过滤器 + 分层归并
