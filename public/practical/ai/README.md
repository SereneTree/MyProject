## 通用设计原则

1. **分层架构**：轻量模型快速过滤 + 重型模型精细决策，兼顾效率与效果
2. **人机协同**：AI 做初判/推荐，人工做终审/确认，逐步提升自动化率
3. **数据飞轮**：线上反馈 → 标注数据 → 模型迭代 → 效果提升 → 更多数据
4. **安全可控**：AI 系统必须有兜底策略、可解释性和人工干预通道
5. **业务导向**：技术选型以业务指标（转化率/满意度/时效）为准，拒绝"为了AI而AI"
