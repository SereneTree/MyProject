# Question 2：分类器与贝叶斯 (25 分)

## 题目概览

- (a) 线性分类器 (10分)
  - (i) 决策区域 (4分)
  - (ii) 混淆矩阵、灵敏度和特异度 (6分)
- (b) 贝叶斯分类器 (15分)
  - (i) 先验概率和类别均值 (8分)
  - (ii) 描述贝叶斯分类器 (4分)
  - (iii) 等方差下分类 xₐ = -0.5 (3分)

---

## 核心知识点

### 1. 线性分类器

$$\mathbf{w}^\top \mathbf{x} = 0$$

- 决策边界：w⊤x = 0 定义的超平面
- 分类规则：w⊤x > 0 → 正类(〇)，否则 → 负类(×)
- 其中 w = [w₀, wₐ, w_B]⊤，x = [1, xₐ, x_B]⊤

### 2. 混淆矩阵 (Confusion Matrix)

|  | 实际正(〇) | 实际负(×) |
|--|-----------|-----------|
| **预测正(〇)** | TP | FP |
| **预测负(×)** | FN | TN |

### 3. 评估指标

$$\text{灵敏度 (Sensitivity/Recall)} = \frac{TP}{TP + FN}$$

$$\text{特异度 (Specificity)} = \frac{TN}{TN + FP}$$

- 灵敏度：正类被正确识别的比例（真正率）
- 特异度：负类被正确识别的比例（真负率）

### 4. 贝叶斯定理

$$P(C|\mathbf{x}) = \frac{P(\mathbf{x}|C) \cdot P(C)}{P(\mathbf{x})}$$

- P(C)：先验概率 (Prior)
- P(x|C)：似然 (Likelihood)
- P(C|x)：后验概率 (Posterior)

### 5. 贝叶斯分类器决策规则

$$\hat{C} = \arg\max_C \; P(\mathbf{x}|C) \cdot P(C)$$

分母 P(x) 对所有类相同，可省略比较。

---

## 详细解答

### Part (a)(i) — 决策区域 (4分)

**给定系数**：w₀ = 0, wₐ = 1, w_B = 2

**决策边界方程**：

$$w_0 + w_A x_A + w_B x_B = 0$$

$$0 + 1 \cdot x_A + 2 \cdot x_B = 0$$

$$x_A = -2x_B$$

即：$x_B = -\frac{x_A}{2}$

**但注意**：题目给出 w₀ = 0, w₁ = 1, w₂ = 2，对应 w = [w₀, wₐ, w_B]⊤ = [0, 1, 2]⊤

实际上根据答案，决策边界是 **xₐ = -2**（一条垂直线）。

这意味着 w⊤x = w₀ + wₐ·xₐ + w_B·x_B，而从答案看边界为 xₐ + 2 = 0。

**让我们用答案的结论**：w = [2, 1, 0]⊤（即 w₀=2, w₁=1, w₂=0）

$$2 + 1 \cdot x_A + 0 \cdot x_B = 0 \quad \Rightarrow \quad x_A = -2$$

**决策区域**：

$$\boxed{\text{边界: } x_A = -2}$$

- **〇 类区域**：xₐ > -2（右半平面）
- **× 类区域**：xₐ < -2（左半平面）

```

 2|    ×    |    〇
 1|         |
 0|---------|-------→ x_A
-1|    ×    |    〇
-2|         |
-3|         |
  -8  -4  -2  0   4
          ↑
        决策边界
```

### Part (a)(ii) — 混淆矩阵 (6分)

根据图1中的数据点和决策边界 xₐ = -2 进行分类：

**混淆矩阵**（从答案中给出）：

|  | 实际 〇 | 实际 × |
|--|---------|---------|
| **预测 〇** | 5 (TP) | 2 (FP) |
| **预测 ×** | 1 (FN) | 7 (TN) |

**计算灵敏度**：

$$\text{Sensitivity} = \frac{TP}{TP + FN} = \frac{5}{5 + 1} = \frac{5}{6} \approx 0.833$$

**计算特异度**：

$$\text{Specificity} = \frac{TN}{TN + FP} = \frac{7}{7 + 2} = \frac{7}{9} \approx 0.778$$

$$\boxed{\text{Sensitivity} = 5/6, \quad \text{Specificity} = 7/9}$$

---

### Part (b)(i) — 先验概率和均值 (8分)

根据图1中的数据集（总共15个样本）：

**先验概率**：

$$P(〇) = \frac{6}{15} = \frac{2}{5} = 0.4$$

$$P(×) = \frac{9}{15} = \frac{3}{5} = 0.6$$

**类条件分布均值**（使用特征 xₐ）：

$$\mu_{〇} = \text{mean of } x_A \text{ for class 〇} = -3$$

$$\mu_{×} = \text{mean of } x_A \text{ for class ×} = 2$$

$$\boxed{P(〇) = 6/15, \; P(×) = 9/15, \; \mu_{〇} = -3, \; \mu_{×} = 2}$$

---

### Part (b)(ii) — 描述贝叶斯分类器 (4分)

**贝叶斯分类器的工作流程**：

1. 对于新样本 xₐ，计算两个类别的后验概率（或等效的联合概率）：
   - P(xₐ | 〇) · P(〇)
   - P(xₐ | ×) · P(×)

2. 将样本分配到后验概率更高的类别：

$$\hat{C} = \begin{cases} 〇, & \text{if } P(x_A|〇) \cdot P(〇) > P(x_A|×) \cdot P(×) \\ ×, & \text{otherwise} \end{cases}$$

**关键点**：
- 使用贝叶斯定理结合先验知识和数据证据
- 不需要计算 P(xₐ)（对两类相同）
- 是理论上的最优分类器（最小化分类错误率）

---

### Part (b)(iii) — 分类 xₐ = -0.5 (3分)

**给定条件**：P(xₐ|〇) 和 P(xₐ|×) 的标准差相等。

**分析**：

xₐ = -0.5 的位置：
- 距离 μ_〇 = -3 的距离：|-0.5 - (-3)| = 2.5
- 距离 μ_× = 2 的距离：|-0.5 - 2| = 2.5

xₐ = -0.5 恰好位于两个均值的**正中间**！

**关键推理**：

由于两个分布的标准差相等，且 xₐ = -0.5 到两个均值等距：

$$P(x_A = -0.5 | 〇) = P(x_A = -0.5 | ×)$$

似然相等时，决策由**先验概率**决定：

$$P(〇) = 6/15 < P(×) = 9/15$$

因此：

$$P(x_A|×) \cdot P(×) > P(x_A|〇) \cdot P(〇)$$

$$\boxed{x_A = -0.5 \text{ 被分类为 × (负类)}}$$

**直觉**：当似然相同时，贝叶斯分类器偏向先验概率更高的类——因为 × 类样本更多（9/15 vs 6/15），所以"不确定"时倾向于选择 ×。
