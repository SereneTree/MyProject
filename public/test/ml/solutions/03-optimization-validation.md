# Question 3：模型优化与验证 (25 分)

## 题目概览

- (a) K-Means 与局部最小值 (15分)
  - (i) 局部最小值和全局最小值概念 (5分)
  - (ii) K-Means 收敛到局部最小值的含义 (5分)
  - (iii) 改进 K-Means 的策略 (5分)
- (b) 验证集方法 (10分)
  - (i) 利用验证误差选择模型 (4分)
  - (ii) 用训练误差比较模型是否合理 (6分)

---

## 核心知识点

### 1. 误差函数 (Error/Cost Function)

误差函数将每个候选模型映射到一个误差值（标量），用于衡量模型的"好坏程度"。

对于 K-Means，误差函数（目标函数）为：

$$J = \sum_{i=1}^{N} \|x_i - \mu_{c_i}\|^2$$

即所有样本到各自所属聚类中心距离的平方和。

### 2. 局部最小值 vs 全局最小值

| 概念 | 定义 |
|------|------|
| **局部最小值** | 在某个邻域内误差最小的模型（但不一定是全局最小） |
| **全局最小值** | 在所有候选模型中误差绝对最小的模型 |

```
误差 J
 ↑
 |  *           *
 | / \         / \
 |/   \   *   /   \
 |     \ / \ /     \
 |      *   *       *
 |   局部  全局   局部
 |   最小  最小   最小
 +——————————————————→ 参数空间
```

### 3. K-Means 算法流程

1. **初始化**：随机选择 K 个初始聚类中心
2. **分配**：将每个样本分配到最近的聚类中心
3. **更新**：重新计算每个聚类的中心（均值）
4. **重复**：直到收敛（分配不再变化）

### 4. 训练误差 vs 验证误差

| 误差类型 | 数据来源 | 评估目标 |
|---------|---------|---------|
| 训练误差 | 训练数据 | 模型对训练数据的拟合程度 |
| **验证误差** | **独立数据** | **模型的泛化能力** |

### 5. 泛化能力 (Generalisation)

模型在**未见过的新数据**上的表现能力。这才是模型实际部署时的性能指标。

## 详细解答

### Part (a)(i) — 局部/全局最小值概念 (5分)

**误差函数的作用**：

误差函数（或代价函数）E(θ) 将候选模型的参数 θ 映射为一个标量误差值。我们的目标是找到使误差最小的参数。

**局部最小值 (Local Minimum)**：

$$\boxed{\text{在参数空间的某个邻域内，误差值最低的模型}}$$

即：存在 ε > 0，对所有满足 ‖θ - θ*‖ < ε 的 θ，都有 E(θ*) ≤ E(θ)。

**全局最小值 (Global Minimum)**：

$$\boxed{\text{在整个参数空间中，误差值绝对最低的模型}}$$

即：对所有可能的 θ，都有 E(θ*) ≤ E(θ)。

**关系**：全局最小值一定是局部最小值，但反过来不一定成立。非凸优化问题通常有多个局部最小值。

---

### Part (a)(ii) — K-Means 收敛到局部最小值 (5分)

**K-Means 的迭代过程**：

K-Means 算法定义了一个迭代过程，每一步都保证不增加目标函数（聚类误差）：

$$J^{(t+1)} \leq J^{(t)}$$

**"收敛到局部最小值"的含义**：

$$\boxed{\text{K-Means 最终会停在距离初始点最近的局部最小值处，而非全局最小值}}$$

具体来说：
1. K-Means 从随机初始聚类中心出发
2. 每次迭代降低误差（贪心策略）
3. 最终收敛到**初始点附近的**最佳解
4. 这个解是局部最优的，但**不一定是全局最优**
5. 不同的初始化可能导致不同的最终结果

---

### Part (a)(iii) — 改进 K-Means 的策略 (5分)

**核心思路**：既然 K-Means 总是收敛到离初始点最近的局部最小值，那么我们可以用**多次随机重启**来探索更多的参数空间。

**策略：Random Restart（随机重启）**

$$\boxed{\text{从不同的随机初始点多次运行 K-Means，选择误差最低的结果}}$$

**具体步骤**：

1. 设定重启次数 R（例如 R=100）
2. 对 r = 1, 2, ..., R：
   - 随机初始化 K 个聚类中心
   - 运行 K-Means 直到收敛
   - 记录最终误差 J_r
3. 选择 J_r 最小的那次运行结果作为最终模型

**为什么有效**：
- 不同初始点→收敛到不同的局部最小值
- 通过充分多次尝试，有更大概率发现接近全局最小值的解
- 计算成本线性增加（R倍），但效果显著改善

---

### Part (b)(i) — 验证误差选择模型 (4分)

**题目**：f₁ 的验证误差 E₁ = 10，f₂ 的验证误差 E₂ = 12

**分析与判断**：

$$\boxed{\text{原则上 f₁ (E₁=10) 表现更好，但需要评估这个差异是否具有统计显著性}}$$

**关键考虑**：

1. **表面结论**：E₁ < E₂，f₁ 的泛化性能更好
2. **但需谨慎**：验证误差的差异（10 vs 12）可能仅仅是**随机波动**导致的
3. **正确做法**：
   - 进行统计显著性检验（如配对t检验）
   - 使用交叉验证获得更可靠的误差估计
   - 考虑模型复杂度（奥卡姆剃刀：性能相似时选简单模型）

**核心要点**：不能仅凭一次验证结果的微小差异就断言一个模型优于另一个——需要统计显著性支撑。

---

### Part (b)(ii) — 训练误差能否用于模型比较 (6分)

**建议**：由于样本少，用全部数据训练模型，然后基于训练误差比较。

**这个建议是错误的！**

$$\boxed{\text{训练误差绝不能用于评估模型性能}}$$

**原因分析**：

**1. 训练误差不评估泛化能力**

训练误差只反映模型对**已见过的数据**的拟合程度，而不是对新数据的预测能力。

**2. 过拟合陷阱**

复杂模型的训练误差总是更低（甚至为0），但在新数据上可能表现很差。

- 例如：三次多项式在4个点上训练误差=0，但泛化到新数据时误差可能很大

**3. 不公平比较**

不同复杂度的模型在训练集上的误差比较是无意义的——更复杂的模型总是"赢"。

**正确做法**：

即使样本少，也应该使用：
- **交叉验证 (Cross-Validation)**：如 K-fold CV，重复使用有限数据
- **留一法 (Leave-One-Out)**：适合极小数据集
- **Bootstrap 方法**：有放回采样估计误差

## 模型选择流程总结

```
数据集
  │
  ├── 划分为 训练集 + 验证集
  │         │           │
  │    训练模型      评估泛化
  │         │           │
  │    训练误差      验证误差 ← 用这个选模型！
  │   (不能用!)          │
  │                     │
  └── 选择验证误差最低的模型
       │
       └── 检查统计显著性
            │
            └── 最终模型
```

## 知识点速查表

| 概念 | 要点 | 考试得分关键 |
|------|------|-------------|
| 局部最小值 | 邻域内最优 | 与"全局最小值"对比说明 |
| 全局最小值 | 全空间最优 | 强调可能有多个局部最小值 |
| K-Means收敛 | 贪心下降→最近局部最小值 | 依赖初始化 |
| 随机重启 | 多次运行取最优 | 描述完整步骤 |
| 验证误差 | 评估泛化能力 | 可能受随机性影响 |
| 训练误差 | **不能**评估性能 | 不评估泛化→无效指标 |
| 统计显著性 | 差异是否由随机造成 | 提到需要检验 |
