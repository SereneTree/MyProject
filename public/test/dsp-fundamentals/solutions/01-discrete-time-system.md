# Question 1：离散时间系统分析 (25 分)

## 题目

考虑如图所示的离散时间系统：

```
x[n] → [h₁[n] = (1/4)ⁿ u[n+10]] → v[n] → [× u[n]] → y[n]
```

其中 h₁[n] = (1/4)ⁿ u[n+10]，系统先对输入做卷积，再乘以单位阶跃函数 u[n]。

(a) 求输出 y[n] 关于输入 x[n] 的表达式 (5分)  
(b) 求系统的冲激响应 (5分)  
(c) 判断系统是否为 LTI 系统 (5分)  
(d) 判断系统是否因果 (5分)  
(e) 判断系统是否稳定 (5分)

---

## 核心知识点

### 1. 卷积 (Convolution)

$$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] \cdot h[n-k]$$

- 卷积是 LTI 系统输入-输出关系的核心
- 性质：交换律、结合律、分配律

### 2. 冲激响应 (Impulse Response)

- 定义：系统对 δ[n] 的响应，即 h[n] = T{δ[n]}
- LTI 系统完全由 h[n] 描述

### 3. 系统性质判据

| 性质 | 判据 |
|------|------|
| 线性 | T{ax₁+bx₂} = aT{x₁}+bT{x₂} |
| 时不变 | y[n-n₀] = T{x[n-n₀]} |
| 因果 | h[n] = 0, ∀n < 0 |
| BIBO 稳定 | Σ\|h[n]\| < ∞ |

### 4. 单位阶跃函数

$$u[n] = \begin{cases} 1, & n \geq 0 \\ 0, & n < 0 \end{cases}$$

---

## 详细解答

### (a) 输出表达式 (5分)

**分步分析系统结构：**

**第一步**：输入 x[n] 经过 h₁[n] 卷积：

$$v[n] = x[n] * h_1[n] = x[n] * \left(\frac{1}{4}\right)^n u[n+10]$$

**第二步**：v[n] 乘以 u[n]：

$$y[n] = u[n] \cdot v[n] = u[n] \cdot \left(x[n] * \left(\frac{1}{4}\right)^n u[n+10]\right)$$

**关键理解**：
- 卷积产生中间信号 v[n]
- 乘以 u[n] 相当于将 n < 0 的部分置零（截断）

---

### (b) 冲激响应 (5分)

**令 x[n] = δ[n]**：

$$h[n] = T\{\delta[n]\} = u[n] \cdot \left(\delta[n] * \left(\frac{1}{4}\right)^n u[n+10]\right)$$

**计算卷积**：δ[n] * f[n] = f[n]（δ函数是卷积的单位元），因此：

$$\delta[n] * \left(\frac{1}{4}\right)^n u[n+10] = \left(\frac{1}{4}\right)^n u[n+10]$$

**代入**：

$$h[n] = u[n] \cdot \left(\frac{1}{4}\right)^n u[n+10]$$

**化简**：当 n ≥ 0 时，u[n] = 1 且 u[n+10] = 1（因为 n+10 > 0）。当 n < 0 时，u[n] = 0。

$$\boxed{h[n] = \left(\frac{1}{4}\right)^n u[n]}$$

---

### (c) LTI 判断 (5分)

**时不变性验证**：需要检查 y[n-n₀] = T{x[n-n₀]}

**计算 T{x[n-n₀]}**（将 x[n-n₀] 作为输入）：

$$T\{x[n-n_0]\} = u[n] \cdot \left(x[n-n_0] * \left(\frac{1}{4}\right)^n u[n+10]\right)$$

**计算 y[n-n₀]**（将 y[n] 延迟 n₀）：

$$y[n-n_0] = u[n-n_0] \cdot \left(x[n-n_0] * \left(\frac{1}{4}\right)^{(n-n_0)} u[n+10-n_0]\right)$$

**比较**：
- T{x[n-n₀]} 中出现 **u[n]**
- y[n-n₀] 中出现 **u[n-n₀]**

两者**不相等**！

$$\boxed{\text{系统不是 LTI 系统（不满足时不变性）}}$$

**直觉解释**：乘以 u[n] 是一个与时间相关的操作（在 n=0 处截断），输入延迟后截断位置不随之移动。

---

### (d) 因果性判断 (5分)

**因果性条件**：h[n] = 0, ∀n < 0

由 (b) 得到：

$$h[n] = \left(\frac{1}{4}\right)^n u[n]$$

当 n < 0 时，u[n] = 0，所以 h[n] = 0。

$$\boxed{\text{系统是因果的}}$$

**物理意义**：输出只依赖于当前和过去的输入，不需要"未来"信息。

---

### (e) 稳定性判断 (5分)

**BIBO 稳定条件**：

$$\sum_{n=-\infty}^{\infty} |h[n]| < \infty$$

**计算**：

$$\sum_{n=-\infty}^{\infty} |h[n]| = \sum_{n=-\infty}^{\infty} \left|\left(\frac{1}{4}\right)^n u[n]\right| = \sum_{n=0}^{\infty} \left(\frac{1}{4}\right)^n$$

这是公比为 1/4 的几何级数：

$$= \frac{1}{1 - \frac{1}{4}} = \frac{4}{3}$$

因为 4/3 < ∞：

$$\boxed{\text{系统是稳定的}}$$

**关键**：|1/4| < 1 保证了几何级数收敛。若公比 |r| ≥ 1，系统将不稳定。

---

| 概念 | 公式/条件 | 本题结果 |
|------|----------|---------|
| 卷积单位元 | δ[n] * f[n] = f[n] | 简化冲激响应计算 |
| u[n]·u[n+10] | = u[n]（n≥0时两者都为1） | h[n] = (1/4)ⁿu[n] |
| 时不变性 | u[n] vs u[n-n₀] 不匹配 | 非时不变 |
| 因果性 | h[n]=0, n<0 | 因果 ✓ |
