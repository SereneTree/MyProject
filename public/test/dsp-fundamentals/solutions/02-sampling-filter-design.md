# Question 2：采样与滤波器设计 (25 分)

## 题目

心电图（ECG）信号采集时存在 60Hz 工频干扰。已知：
- 有用信号带宽：1 kHz（即 Xₐ(f) = 0, |f| > 1 kHz）
- 采用理想 ADC 采样，得到离散信号 x[n] = xₐ(nT)
- 离散系统差分方程：y[n] = x[n] + ax[n-1] + bx[n-2]
- 滤波后通过理想 DAC 还原为连续信号

(a) 防止混叠的最小采样频率是多少？(5分)  
(b) 应使用什么类型的滤波器？为什么？(5分)  
(c) 设计滤波器参数以消除 60Hz 干扰 (15分)

---

## 核心知识点

### 1. 奈奎斯特采样定理

$$f_S > 2f_{max}$$

- fₘₐₓ：信号最高频率分量
- fₛ：采样频率
- 违反该定理会产生**混叠 (Aliasing)**

### 2. 数字频率与模拟频率的关系

$$\omega = \frac{2\pi f}{f_S} \text{ (rad/sample)}$$

- ω：数字角频率
- f：模拟频率 (Hz)
- fₛ：采样频率 (Hz)

### 3. 滤波器类型

| 类型 | 英文 | 作用 |
|------|------|------|
| 低通 | Low-Pass | 保留低频，去除高频 |
| 高通 | High-Pass | 保留高频，去除低频 |
| 带通 | Band-Pass | 保留某频段 |
| **带阻** | **Band-Stop** | **去除某频段（陷波）** |

### 4. 零点设计法

- 在 z 平面上将零点放在目标频率对应的位置
- 零点位置：z = e^(jω₀)
- 对于实系数滤波器，零点成共轭对出现

---

## 详细解答

### (a) 最小采样频率 (5分)

由奈奎斯特定理：

$$f_S > 2 f_{max} = 2 \times 1\text{kHz} = 2\text{kHz}$$

$$\boxed{f_S > 2\text{kHz}（最小采样频率为 2kHz）}$$

**注意**：这里 fₘₐₓ 是有用信号的带宽上限 1kHz，不是干扰频率 60Hz。

---

### (b) 滤波器类型选择 (5分)

**应使用带阻滤波器 (Band-Stop Filter / Notch Filter)**

**原因**：
- 干扰信号集中在**特定频率**（60Hz）
- 有用信号频带为 0~1kHz，包含 60Hz 附近的分量
- 带阻滤波器可以**精确去除 60Hz**，同时保留其他频率分量不受影响
- 如果用低通滤波器会同时丢失 60Hz 以上的有用信号

$$\boxed{\text{带阻滤波器（Band-Stop），因为干扰集中在特定频带内}}$$

---

### (c) 滤波器设计 (15分)

**第一步：选择采样频率**

选择 fₛ = 2kHz（满足奈奎斯特条件的最小值）。

**第二步：求系统函数 H(z)**

差分方程：y[n] = x[n] + ax[n-1] + bx[n-2]

对应系统函数（取 Z 变换）：

$$H(z) = 1 + az^{-1} + bz^{-2}$$

这是一个 **FIR 系统**（只有零点，无极点），阶数为 2。

**第三步：计算 60Hz 对应的数字频率**

$$\omega_i = \frac{2\pi \times 60}{f_S} = \frac{2\pi \times 60}{f_S} = \frac{120\pi}{f_S}$$

若 fₛ = 2000Hz：

$$\omega_i = \frac{120\pi}{2000} = 0.06\pi \text{ rad/sample}$$

**第四步：在目标频率放置零点**

要消除 60Hz 干扰，需要 H(e^(jωᵢ)) = 0。

将零点放在 z = e^(jωᵢ) 和 z = e^(-jωᵢ)（共轭对，保证实系数）：

$$H(z) = (1 - e^{j\omega_i}z^{-1})(1 - e^{-j\omega_i}z^{-1})$$

**展开**：

$$H(z) = 1 - (e^{j\omega_i} + e^{-j\omega_i})z^{-1} + e^{j\omega_i} \cdot e^{-j\omega_i} z^{-2}$$

$$= 1 - 2\cos(\omega_i)z^{-1} + z^{-2}$$

**第五步：确定系数**

对比 H(z) = 1 + az⁻¹ + bz⁻²：

$$\boxed{a = -2\cos\left(\frac{120\pi}{f_S}\right), \quad b = 1}$$

若 fₛ = 2000Hz：
$$a = -2\cos(0.06\pi) = -2\cos(10.8°) \approx -1.9646$$

**验证**：

在 ω = ωᵢ 处：

$$H(e^{j\omega_i}) = 1 - 2\cos(\omega_i)e^{-j\omega_i} + e^{-j2\omega_i}$$

$$= 1 - 2\cos(\omega_i)e^{-j\omega_i} + e^{-j2\omega_i} = (1 - e^{-j\omega_i})(1 - e^{j\omega_i})e^{-j\omega_i}... $$

直接验证：两个零点在 z = e^(±jωᵢ)，所以 H(z) 在 z = e^(jωᵢ) 处为零 ✓

---

## 设计总结

```
输入：ECG + 60Hz干扰
    ↓ ADC (fs = 2kHz)
离散信号 x[n]
    ↓ 带阻滤波器: y[n] = x[n] + ax[n-1] + bx[n-2]
    ↓   a = -2cos(120π/fs)
    ↓   b = 1
滤波后 y[n]（60Hz已消除）
    ↓ DAC
输出：干净的 ECG 信号
```

---

## 关键公式对照

| 步骤 | 公式 | 数值(fs=2kHz) |
|------|------|------|
| 数字频率 | ωᵢ = 2π×60/fₛ | 0.06π rad |
| 零点位置 | z = e^(±jωᵢ) | 单位圆上 |
| a 系数 | -2cos(ωᵢ) | ≈ -1.9646 |
| b 系数 | 1 | 1 |

## 延伸知识

- **陷波器 (Notch Filter)**：极窄带宽的带阻滤波器，本题即为典型陷波器
- **工频干扰**：中国为 50Hz，北美为 60Hz，ECG/EEG 常见问题
- **零点在单位圆上**：保证该频率处增益恰好为 0
- **实际中还需加极点**：在零点附近放极点可以减小对相邻频率的影响
