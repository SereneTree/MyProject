# Question 3：递归系统与频率响应 (25 分)

## 题目

给定系统：

$$y[n] = x[n] - 0.25y[n-2]$$

(a) 将系统分类为递归或非递归 (5分)  
(b) 求系统函数 H(z)，并判断系统是 FIR 还是 IIR (5分)  
(c) 将系统分类为低通/高通/带通/带阻滤波器 (5分)  
(d) 输入 x[n] = cos(πn/2)，求输出 y[n] (10分)

---

## 核心知识点

### 1. 递归 vs 非递归系统

| 类型 | 特征 | 例子 |
|------|------|------|
| **递归 (Recursive)** | 输出依赖过去的输出值 | y[n] = x[n] + ay[n-1] |
| **非递归 (Non-recursive)** | 输出只依赖输入值 | y[n] = x[n] + bx[n-1] |

### 2. FIR vs IIR

| 类型 | 冲激响应 | 系统函数 |
|------|---------|---------|
| **FIR** (有限冲激响应) | h[n] 有限长 | H(z) 只有零点 |
| **IIR** (无限冲激响应) | h[n] 无限长 | H(z) 有极点（分母≠常数） |

### 3. 极点与滤波器类型

极点位置决定频率响应的峰值位置：
- 极点靠近 ω=0（z=1）→ **低通**
- 极点靠近 ω=π（z=-1）→ **高通**
- 极点靠近 ω=π/2（z=±j）→ **带通**
- 零点在某频率 + 极点在其他位置 → **带阻**

### 4. 正弦信号通过 LTI 系统

对于 LTI 系统，输入 x[n] = A cos(ω₀n + φ)：

$$y[n] = A|H(e^{j\omega_0})| \cos(\omega_0 n + \phi + \angle H(e^{j\omega_0}))$$

**关键**：只改变幅度和相位，不改变频率！

---

## 详细解答

### (a) 递归/非递归分类 (5分)

差分方程：y[n] = x[n] - 0.25y[n-2]

**判断**：y[n] 依赖于 **y[n-2]**（过去的输出值）。

$$\boxed{\text{系统是递归的 (Recursive)}}$$

**原因**：当前输出使用了过去的输出来计算当前输出。

---

### (b) 系统函数 H(z) (5分)

对差分方程两边取 Z 变换：

$$Y(z) = X(z) - 0.25z^{-2}Y(z)$$

$$Y(z)(1 + 0.25z^{-2}) = X(z)$$

$$H(z) = \frac{Y(z)}{X(z)} = \frac{1}{1 + 0.25z^{-2}}$$

**因式分解分母**：

$$1 + 0.25z^{-2} = (1 - j0.5z^{-1})(1 + j0.5z^{-1})$$

验证：$(1 - j0.5z^{-1})(1 + j0.5z^{-1}) = 1 - (j0.5)^2 z^{-2} = 1 + 0.25z^{-2}$ ✓

**极点位置**：

$$z_1 = j0.5, \quad z_2 = -j0.5$$

即极点在 z = ±j0.5（虚轴上，模为 0.5）。

**部分分式展开**：

$$H(z) = \frac{A_1}{1 - j0.5z^{-1}} + \frac{A_2}{1 + j0.5z^{-1}}$$

其中 A₂ = A₁*（共轭对）。

**冲激响应**（逆 Z 变换）：

$$h[n] = 2|A_1|(0.5)^n \cos\left(\frac{\pi}{2}n + \theta\right)u[n]$$

h[n] 是无限长的（(0.5)ⁿ 衰减但永不为零）。

$$\boxed{\text{系统是 IIR（无限冲激响应）}}$$

---

### (c) 滤波器分类 (5分)

系统极点：z₁ = j0.5 = 0.5e^(jπ/2)，z₂ = -j0.5 = 0.5e^(-jπ/2)

极点对应的数字频率：

$$\omega_{pole} = \pm\frac{\pi}{2}$$

**分析**：
- 极点在 ω = ±π/2 方向（单位圆上 z = ±j 的方向）
- 频率响应在极点附近的频率处达到**最大值**
- ω = π/2 对应信号的中间频段（不是 0 也不是 π）

$$\boxed{\text{系统是带通滤波器 (Band-Pass Filter)}}$$

**直觉**：极点"吸引"频率响应曲线，在极点对应的角频率 π/2 处产生峰值。

---

### (d) 输出信号计算 (10分)

输入：x[n] = cos(π/2 · n)，即 ω₀ = π/2

**第一步：计算频率响应 H(e^jω)**

$$H(e^{j\omega}) = H(z)\big|_{z=e^{j\omega}} = \frac{1}{1 + 0.25e^{-j2\omega}}$$

**第二步：在 ω = π/2 处求值**

$$H(e^{j\pi/2}) = \frac{1}{1 + 0.25e^{-j\pi}}$$

因为 e^(-j2·π/2) = e^(-jπ) = -1：

$$H(e^{j\pi/2}) = \frac{1}{1 + 0.25 \times (-1)} = \frac{1}{1 - 0.25} = \frac{1}{0.75} = \frac{4}{3} \approx 1.333$$

**第三步：确定相位**

$$H(e^{j\pi/2}) = \frac{4}{3}$$

这是一个**实数且为正值**，因此相位 ∠H(e^(jπ/2)) = 0。

**第四步：写出输出**

由正弦信号通过 LTI 系统的公式：

$$y[n] = |H(e^{j\pi/2})| \cdot \cos\left(\frac{\pi}{2}n + \angle H(e^{j\pi/2})\right)$$

$$\boxed{y[n] = \frac{4}{3}\cos\left(\frac{\pi}{2}n\right) \approx 1.333\cos\left(\frac{\pi}{2}n\right)}$$

**验证带通特性**：输入频率恰好是 ω = π/2（极点位置），增益 > 1（放大），证实了带通特性。

---

## 频率响应全景

| ω | e^(-j2ω) | 1 + 0.25e^(-j2ω) | \|H(e^jω)\| |
|---|----------|-------------------|-------------|
| 0 | 1 | 1.25 | 0.8 |
| π/4 | e^(-jπ/2) = -j | 1 - 0.25j | ≈ 0.97 |
| **π/2** | **e^(-jπ) = -1** | **0.75** | **1.333** ← 峰值 |
| 3π/4 | e^(-j3π/2) = j | 1 + 0.25j | ≈ 0.97 |
| π | e^(-j2π) = 1 | 1.25 | 0.8 |

- ω = 0 和 ω = π 处增益最小（0.8）
- ω = π/2 处增益最大（1.333）
- 典型的**带通**特征 ✓
