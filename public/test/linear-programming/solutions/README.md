## 知识体系总览

```
线性规划与博弈论 (LP & Games)
├── 线性规划基础
│   ├── 标准不等式形式 (Standard Inequality Form): max c⊤x, s.t. Ax≤b, x≥0
│   ├── 标准等式形式 (Standard Equation Form): max c⊤x, s.t. Ax=b, x≥0
│   ├── 可行域 (Feasible Region): 凸多面体
│   ├── 可行解 / 最优解 / 无界
│   └── 极点 (Extreme Point) = 基本可行解 (BFS)
├── 图形法 (Graphical Method)
│   ├── 约束画线 → 确定可行域
│   ├── 目标函数等值线 (Level Curve)
│   └── 法向量方向平移 → 找最优极点
├── 标准形式转换
│   ├── min → max: 取负
│   ├── ≥ 约束 → ≤: 两边乘 -1
│   ├── = 约束 → 两个 ≤ 约束
│   └── 矩阵记法: max c⊤x, Ax≤b, x≥0
├── 单纯形法 (Simplex Method)
│   ├── 基变量 / 非基变量
│   ├── 单纯形表 (Tableau)
│   ├── 主元列 (Pivot Column): 目标行最正系数
│   ├── 主元行 (Pivot Row): 最小正比率测试
│   └── 最优判据: 目标行所有系数 ≤ 0
├── 对偶理论 (Duality)
│   ├── 对偶构造
│   ├── 弱对偶定理 / 强对偶定理
│   └── 互补松弛条件
└── 博弈论 (Game Theory)
    ├── 2人零和博弈
    ├── 纯策略纳什均衡
    ├── 混合策略
    └── 极大极小定理 (Minimax Theorem)
```

## 备考重点

1. **概念判断**：熟记可行解、极点、BFS、无界等定义
2. **凸性证明**：掌握"凸组合仍可行"的标准证明模式
3. **图形法**：画约束线、确定可行域、目标函数等值线平移
4. **标准形式转换**：min↔max、≥↔≤、等式约束处理
5. **单纯形法**：读表能力（基变量/目标值/主元选取）
6. **对偶与博弈**：对偶构造、互补松弛、纯策略/混合策略
