## Part (a) — 图形法 (7分)

### 题目

$$\text{maximize } 4x_1 + 3x_2$$

$$\text{subject to } x_1 + x_2 \leq 4, \quad 5x_1 + 3x_2 \leq 15, \quad x_1, x_2 \geq 0$$

---

### 知识点：图形法步骤

1. **画约束边界线**（将 ≤ 变成 =）
2. **确定可行域**（满足所有约束的交集区域）
3. **画目标函数等值线**（level curve）
4. **沿法向量方向平移**等值线，找到离开可行域的最后一个点

---

### (i) 画可行域 (3分)

**约束1**：x₁ + x₂ = 4
- 截距：(4, 0) 和 (0, 4)

**约束2**：5x₁ + 3x₂ = 15
- 截距：(3, 0) 和 (0, 5)

**符号约束**：x₁ ≥ 0, x₂ ≥ 0（第一象限）

**可行域顶点（极点）**：

| 顶点 | 求法 | 坐标 |
|------|------|------|
| O | 原点 | (0, 0) |
| A | x₁轴上, 约束2 | (3, 0) |
| B | 约束1 ∩ 约束2 | 解方程组 |
| C | x₂轴上, 约束1 | (0, 4) |

**求交点 B**：

$$\begin{cases} x_1 + x_2 = 4 \\ 5x_1 + 3x_2 = 15 \end{cases}$$

由第一个方程：x₂ = 4 - x₁

代入第二个：5x₁ + 3(4 - x₁) = 15 → 2x₁ = 3 → x₁ = 3/2

x₂ = 4 - 3/2 = 5/2

$$B = \left(\frac{3}{2}, \frac{5}{2}\right)$$

**可行域**：由 O(0,0), A(3,0), B(3/2, 5/2), C(0,4) 围成的凸多边形。

```
x₂
 5|     ·
  |    / \  (5x₁+3x₂=15)
 4|---·C
  |   |\ \
  |   | \ \
5/2|...|..B\
  |   | / \
  |   |/   \
  |   / 可行域
  |  /|
  | / |
  |/__|_________ x₁
  O   A(3,0)
      3/2  3  4
```

---

### (ii) 目标函数等值线 (1分)

画 4x₁ + 3x₂ = 2 这条线：
- 截距：(1/2, 0) 和 (0, 2/3)
- 法向量方向：(4, 3) — 目标函数增大的方向

---

### (iii) 最优解 (3分)

**方法**：沿法向量 (4, 3) 方向平移等值线，直到即将离开可行域为止。

**在各顶点计算目标函数值**：

| 顶点 | 坐标 | 目标值 4x₁+3x₂ |
|------|------|----------------|
| O | (0, 0) | 0 |
| A | (3, 0) | 12 |
| **B** | **(3/2, 5/2)** | **4(3/2)+3(5/2) = 6+7.5 = 13.5** |
| C | (0, 4) | 12 |

$$\boxed{\text{最优解在 } B = (3/2, 5/2) \text{ 处取得，最优值为 } 13.5}$$

**解释**：等值线 4x₁+3x₂ = c 沿法向量 (4,3) 方向平移时，最后接触可行域的点是 B，即两条约束线的交点。在该点目标值最大。

## Part (b) — 标准不等式形式转换 (5分)

### 题目

$$\text{minimize } -25x_1 + 23x_2 - 50x_3$$

$$\text{subject to:}$$
$$x_1 + 4x_2 + 8x_3 \geq 15$$
$$-x_1 + 3x_2 + 9x_3 \leq 25$$
$$x_1 + x_3 = 7$$
$$x_1, x_2, x_3 \geq 0$$

---

### 知识点：转换规则

| 原始形式 | 标准不等式形式 (max, ≤, ≥0) |
|---------|--------------------------|
| minimize f | maximize **-f** |
| ≥ 约束 | 两边乘 **-1** → ≤ |
| = 约束 | 拆成 **≤ 和 ≥**，再将 ≥ 转为 ≤ |

---

### (i) 转换为标准不等式形式 (2分)

**Step 1**：min → max（取负）

$$\text{maximize } 25x_1 - 23x_2 + 50x_3$$

**Step 2**：≥ 约束 → ≤（乘 -1）

$$x_1 + 4x_2 + 8x_3 \geq 15 \quad \Rightarrow \quad -x_1 - 4x_2 - 8x_3 \leq -15$$

**Step 3**：= 约束 → 两个 ≤ 约束

$$x_1 + x_3 = 7 \quad \Rightarrow \quad \begin{cases} x_1 + x_3 \leq 7 \\ -x_1 - x_3 \leq -7 \end{cases}$$

**Step 4**：≤ 约束保持不变

$$-x_1 + 3x_2 + 9x_3 \leq 25$$

**最终标准不等式形式**：

$$\boxed{\text{maximize } 25x_1 - 23x_2 + 50x_3}$$

$$\text{subject to:}$$
$$-x_1 - 4x_2 - 8x_3 \leq -15$$
$$-x_1 + 3x_2 + 9x_3 \leq 25$$
$$x_1 + x_3 \leq 7$$
$$-x_1 - x_3 \leq -7$$
$$x_1, x_2, x_3 \geq 0$$

---

### (ii) 矩阵记法 (3分)

$$\text{maximize } c^\top x \quad \text{subject to } Ax \leq b, \; x \geq 0$$

其中：

$$c = \begin{pmatrix} 25 \\ -23 \\ 50 \end{pmatrix}, \quad x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix}$$

$$A = \begin{pmatrix} -1 & -4 & -8 \\ -1 & 3 & 9 \\ 1 & 0 & 1 \\ -1 & 0 & -1 \end{pmatrix}, \quad b = \begin{pmatrix} -15 \\ 25 \\ 7 \\ -7 \end{pmatrix}$$

## Part (c) — 单纯形表解读 (6分)

### 题目

给定单纯形表（标准等式形式，变量 x₁,x₂,x₃ ≥ 0，松弛变量 s₁,s₂ ≥ 0）：

| Basic | x₁ | x₂ | x₃ | s₁ | s₂ | Solution |
|-------|-----|-----|-----|-----|-----|----------|
| s₁ | 4 | 0 | -4 | 1 | -1 | 4 |
| x₂ | -3 | 1 | 2 | 0 | 1 | 3 |
| -z | 6 | 0 | -3 | 0 | -2 | -6 |

---

### 知识点：单纯形表解读

| 信息 | 位置 |
|------|------|
| 基变量 | 最左列 (Basic) |
| 基变量的值 | 最右列 (Solution) |
| 非基变量的值 | = 0 |
| 目标值 | 目标行最右列的**相反数** |
| 主元列 | 目标行中**最正的系数** |
| 主元行 | Solution列/主元列正元素 → 最小比率 |

---

### (i) 基本可行解与基变量 (2分)

**基变量**：s₁ 和 x₂（出现在 Basic 列中）

**非基变量**：x₁ = 0, x₃ = 0, s₂ = 0

**基本可行解**：

$$\boxed{(x_1, x_2, x_3, s_1, s_2) = (0, 3, 0, 4, 0)}$$

- s₁ = 4（从第1行 Solution 列读出）
- x₂ = 3（从第2行 Solution 列读出）

---

### (ii) 当前目标值 (1分)

目标行（-z 行）的 Solution 列为 -6。

由于表示的是 -z = -6，所以：

$$\boxed{z = 6}$$

当前目标函数值为 **6**。

---

### (iii) 主元列和主元行 (3分)

**选择主元列 (Pivot Column)**：

在目标行 (-z 行) 中，找最正的系数：

| 变量 | x₁ | x₂ | x₃ | s₁ | s₂ |
|------|-----|-----|-----|-----|-----|
| 系数 | **6** | 0 | -3 | 0 | -2 |

最正系数 = 6，对应 **x₁ 列**。

$$\boxed{\text{主元列 (Pivot Column): } x_1 \text{ 列}}$$

**选择主元行 (Pivot Row)**：

对 x₁ 列中的**正元素**，计算最小比率：

| 行 | x₁列系数 | Solution | 比率 |
|----|---------|----------|------|
| s₁ 行 | **4** (>0) | 4 | 4/4 = **1** ← 最小 |
| x₂ 行 | -3 (<0) | 3 | — (负数跳过) |

只有 s₁ 行有正系数，比率 = 4/4 = 1。

$$\boxed{\text{主元行 (Pivot Row): } s_1 \text{ 行}}$$

**主元素 (Pivot Element)** = 4（s₁行 × x₁列的交叉处）

**下一步操作**：
- x₁ 将进入基（replacing s₁）
- 对主元行除以4，然后消元使 x₁ 列成为单位向量

---

### 单纯形法判据总结

```
当前表是否最优？
    └── 目标行所有系数 ≤ 0 ?
         ├── Yes → 当前解是最优解，停止
         └── No  → 继续迭代
              │
              选主元列: 目标行最正系数的列
              │
              选主元行: 主元列正元素中最小比率
              │
              └── 主元列全部 ≤ 0? 
                   ├── Yes → LP无界 (unbounded)
                   └── No  → 执行主元操作，进入下一表
```
