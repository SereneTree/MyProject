## Part (a) — True/False 判断题 (10分)

### 题目与答案

| # | 陈述 | 答案 | 解析 |
|---|------|------|------|
| 1 | 标准不等式形式LP的可行解满足所有约束和符号限制 | **True** ✓ | 可行解定义：满足所有约束条件 Ax≤b **且** x≥0 |
| 2 | LP的极点解是内点解 | **False** ✗ | 极点(extreme point)在可行域边界上，不是内点(internal point)。极点不能表示为其他两个可行解的严格凸组合 |
| 3 | 标准等式形式LP中，极点解是基本可行解 | **True** ✓ | 这是LP的核心定理：标准等式形式中 极点 ⟺ 基本可行解(BFS) |
| 4 | 可行域是满足约束和符号限制的所有可能解的集合 | **True** ✓ | 这就是可行域(feasible region)的定义 |
| 5 | 所有LP中，每个可行解都自动是最优解 | **False** ✗ | 显然错误。可行解只需满足约束，最优解还需要使目标函数取到最值 |
| 6 | 每个2人零和博弈都有纯策略纳什均衡 | **False** ✗ | 反例：石头剪刀布。不是所有零和博弈都有纯策略NE，但一定有混合策略NE（极大极小定理） |
| 7 | 对于任何原始LP，其对偶LP总有唯一的基本可行解 | **False** ✗ | 对偶可能无可行解（当原始无界时），也可能有多个BFS |
| 8 | 对于可行解x和y分别是原始和对偶的最优解，目标值应相等 | **True** ✓ | 强对偶定理：若原始和对偶都有最优解，则最优目标值相等 |
| 9 | 2人零和博弈中，行玩家的最佳纯策略是最小化其最大收益的策略 | **False** ✗ | 行玩家应**最大化**其**最小**收益（maximin），而非最小化最大收益 |
| 10 | 若原始LP可行但目标无界，则对偶有唯一可行最优解 | **False** ✗ | 若原始无界，则对偶**无可行解**(infeasible)，而非有唯一解 |

### 知识点详解

#### 1. 可行解 (Feasible Solution)

满足所有约束条件和符号限制的解 x。

对于标准不等式形式 max c⊤x, s.t. Ax≤b, x≥0：
- x 是可行解 ⟺ Ax≤b **且** x≥0

#### 2. 极点 (Extreme Point)

可行域中**不能**表示为其他两个不同可行解的严格凸组合的点。

即：若 x = λy + (1-λ)z（0<λ<1），y,z 可行，则必须 y=z=x。

#### 3. 基本可行解 (BFS)

在标准等式形式 Ax=b, x≥0 中：
- 选择 m 个线性无关列形成基 B
- 基变量 x_B = B⁻¹b，非基变量 x_N = 0
- 若 x_B ≥ 0，则为 BFS

**核心定理**：极点 ⟺ BFS

#### 4. 对偶关系

| 原始 | 对偶 |
|------|------|
| 可行且有界 | 可行且有界，最优值相等 |
| 可行但无界 | **无可行解** |
| 无可行解 | 无界 或 无可行解 |

#### 5. 极大极小 (Minimax)

- **行玩家**策略：maximin（最大化最小收益）
- **列玩家**策略：minimax（最小化最大损失）

## Part (b) — 凸性证明与定义 (8分)

### (i) 证明凸组合仍为可行解 (4分)

**题目**：给定 LP: max c⊤x, s.t. Ax≤b, x≥0。若 x₁, x₂ 是可行解，证明 x = (1/3)x₁ + (2/3)x₂ 也是可行解。

**证明**：

**需要验证两个条件**：Ax≤b 且 x≥0

**条件1：Ax ≤ b**

$$Ax = A\left(\frac{1}{3}x_1 + \frac{2}{3}x_2\right) = \frac{1}{3}Ax_1 + \frac{2}{3}Ax_2$$

因为 x₁ 可行：Ax₁ ≤ b  
因为 x₂ 可行：Ax₂ ≤ b

所以：

$$Ax = \frac{1}{3}Ax_1 + \frac{2}{3}Ax_2 \leq \frac{1}{3}b + \frac{2}{3}b = b$$

（利用 1/3 + 2/3 = 1 且系数非负） ✓

**条件2：x ≥ 0**

因为 x₁ ≥ 0 且 x₂ ≥ 0，且 1/3 > 0, 2/3 > 0：

$$x = \frac{1}{3}x_1 + \frac{2}{3}x_2 \geq \frac{1}{3} \cdot 0 + \frac{2}{3} \cdot 0 = 0$$

✓

**结论**：x = (1/3)x₁ + (2/3)x₂ 满足所有约束和符号限制，是可行解。 ∎

---

### (ii) 最优解的定义 (2分)

**定义**：可行解 y ∈ Rⁿ 是LP (1) 的最优解，如果对所有可行解 x：

$$c^\top y \geq c^\top x$$

即 y 在所有可行解中使目标函数 c⊤x 取到最大值。

---

### (iii) 何时称LP为无界 (2分)

**定义**：当存在一系列可行解使得目标函数值可以任意大时，称 LP 为无界(unbounded)。

即：对任意 M > 0，都存在可行解 x 使得 c⊤x > M。

换言之：目标函数在可行域上没有上界（对于最大化问题）。

## Part (c) — 可行解与基本可行解判定 (4分)

### 题目

给定LP：

$$\text{maximize } \begin{pmatrix} 5 & 2 & -1 & 3 \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{pmatrix}$$

$$\text{subject to } \begin{pmatrix} 1 & 1 & -1 & 4 \\ 1 & -2 & -1 & 1 \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{pmatrix} = \begin{pmatrix} 8 \\ 2 \end{pmatrix}$$

$$x_1, x_2, x_3, x_4 \geq 0$$

判断以下向量的可行性和是否为 BFS：

---

### 解答

**约束矩阵和右端项**：

$$A = \begin{pmatrix} 1 & 1 & -1 & 4 \\ 1 & -2 & -1 & 1 \end{pmatrix}, \quad b = \begin{pmatrix} 8 \\ 2 \end{pmatrix}$$

m = 2 (约束数), n = 4 (变量数)

**判定标准**：
1. **可行解**：Ax = b 且 x ≥ 0
2. **BFS**：可行解 + 基变量对应的列线性无关（即选 m=2 个非零分量对应的列构成满秩矩阵）

---

#### x₁⊤ = (6, 2, 0, 0)

**检查可行性** (Ax = b)：

$$Ax_1 = \begin{pmatrix} 1(6) + 1(2) + (-1)(0) + 4(0) \\ 1(6) + (-2)(2) + (-1)(0) + 1(0) \end{pmatrix} = \begin{pmatrix} 8 \\ 2 \end{pmatrix} = b \quad ✓$$

**检查符号**：x₁ = 6≥0, x₂ = 2≥0, x₃ = 0≥0, x₄ = 0≥0 ✓

**是否为 BFS**？

非零分量对应列：第1列和第2列

$$B = \begin{pmatrix} 1 & 1 \\ 1 & -2 \end{pmatrix}, \quad \det(B) = -2-1 = -3 \neq 0$$

B 满秩 ✓

$$\boxed{x_1^\top = (6,2,0,0) \text{ 是可行解，也是基本可行解 (BFS)}}$$

---

#### x₂⊤ = (3, 1, 0, 1)

**检查可行性** (Ax = b)：

$$Ax_2 = \begin{pmatrix} 1(3) + 1(1) + (-1)(0) + 4(1) \\ 1(3) + (-2)(1) + (-1)(0) + 1(1) \end{pmatrix} = \begin{pmatrix} 8 \\ 2 \end{pmatrix} = b \quad ✓$$

**检查符号**：全部 ≥ 0 ✓

**是否为 BFS**？

非零分量有 3 个（x₁=3, x₂=1, x₄=1），但基的大小应为 m=2。

一个 BFS 最多有 m=2 个非零分量（基变量数=约束数）。因为有 3 个非零分量 > m=2 个基变量位置，所以**不是 BFS**。

> 更严格地说：BFS 要求存在一组 m 个列使其线性无关且对应的基解等于 x。这里非零分量多于 m，说明 x₂ 是可行解但不是基本可行解（它在可行域内部，不是极点）。

$$\boxed{x_2^\top = (3,1,0,1) \text{ 是可行解，但不是基本可行解}}$$

---

#### x₃⊤ = (-3, 0, 1, 2)

**检查可行性**：

首先检查符号：x₁ = **-3 < 0** ✗

$$\boxed{x_3^\top = (-3,0,1,2) \text{ 不是可行解（违反 x₁≥0），也不是 BFS}}$$

> 注：即使不检查 Ax=b，符号限制已被违反。

---

### 判定流程总结

```
给定 x:
    ├── x ≥ 0 ?  ── No → 不可行，不是 BFS
    │                      (如 x₃)
    ├── Ax = b ?  ── No → 不可行，不是 BFS
    │
    └── 可行 ✓
         │
         └── 非零分量个数 ≤ m 且对应列线性无关?
              ├── Yes → BFS (如 x₁)
              └── No  → 可行但不是 BFS (如 x₂)
```

## 核心公式速查

| 概念 | 条件 |
|------|------|
| 可行解 | Ax=b (或 Ax≤b) 且 x≥0 |
| BFS | 可行 + 非零分量≤m个 + 对应列线性无关 |
| 极点=BFS | 标准等式形式中的核心等价关系 |
| 凸组合可行性 | λ₁+λ₂=1, λᵢ≥0 → Σλᵢxᵢ 仍可行 |
| 强对偶 | 原始最优=对偶最优（都可行时） |
| 原始无界 | ⟹ 对偶无可行解 |
| Maximin | 行玩家最大化最小收益 |
