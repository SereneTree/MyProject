# Q5：NAT 网络地址转换（占 10%）

## 题型说明

本题专门考察 **NAT（Network Address Translation）**：
- NAT 的工作原理
- NAT 转换表的填写与分析
- 地址端口映射的计算
- NAT 的不同类型

---

## 核心知识点一：NAT 基本原理

### 什么是 NAT？

**NAT（网络地址转换）** 是一种在路由器上将**私有IP地址**转换为**公有IP地址**的技术，使内网设备能够访问互联网。

### 为什么需要 NAT？

| 原因 | 说明 |
|------|------|
| IPv4 地址不足 | 43亿地址不够全球设备使用 |
| 安全性 | 隐藏内部网络结构 |
| 灵活性 | 内部地址可自由规划，不受外部影响 |
| 节省成本 | 只需少量公网IP |

### 私有地址范围

| 类别 | 地址范围 | CIDR | 可用主机数 |
|------|---------|------|-----------|
| A类私有 | 10.0.0.0 – 10.255.255.255 | 10.0.0.0/8 | 约1677万 |
| B类私有 | 172.16.0.0 – 172.31.255.255 | 172.16.0.0/12 | 约104万 |
| C类私有 | 192.168.0.0 – 192.168.255.255 | 192.168.0.0/16 | 约6.5万 |

> 这些私有地址**不能**在公网上路由，必须通过 NAT 转换后才能上网。

## 核心知识点二：NAT 工作流程

### 图示

```
内部网络 (Private)          NAT路由器           外部网络 (Public)
                        ┌─────────────┐
PC1: 192.168.1.10 ─────>|             |──────> 目标: 8.8.8.8
     (源端口: 3000)      | 公网IP:      |       (使用 203.0.113.1:5001)
                        | 203.0.113.1 |
PC2: 192.168.1.20 ─────>|             |──────> 目标: 1.1.1.1
     (源端口: 4000)      |             |       (使用 203.0.113.1:5002)
                        └─────────────┘
```

### 分步骤解释

#### 出站流程（Internal → External）

| 步骤 | 动作 | 数据包变化 |
|------|------|-----------|
| 1 | PC1 发出数据包 | 源: 192.168.1.10:3000 → 目标: 8.8.8.8:80 |
| 2 | NAT路由器收到包 | 查看NAT表或创建新条目 |
| 3 | 替换源地址和端口 | 源: **203.0.113.1:5001** → 目标: 8.8.8.8:80 |
| 4 | 记录映射到NAT表 | 192.168.1.10:3000 ↔ 203.0.113.1:5001 |
| 5 | 转发到公网 | 外部服务器看到来自203.0.113.1的请求 |

#### 入站流程（External → Internal）

| 步骤 | 动作 | 数据包变化 |
|------|------|-----------|
| 1 | 服务器回复 | 源: 8.8.8.8:80 → 目标: 203.0.113.1:5001 |
| 2 | NAT路由器收到包 | 查询NAT表 |
| 3 | 替换目标地址和端口 | 源: 8.8.8.8:80 → 目标: **192.168.1.10:3000** |
| 4 | 转发到内网 | PC1 收到回复 |

## 核心知识点三：NAT 转换表

### 典型题目
> Given the following network scenario, fill in the NAT translation table.

### NAT 表示例

| 内部地址 (Private) | 内部端口 | 外部地址 (Public) | 外部端口 | 目标地址 | 目标端口 |
|-------------------|---------|------------------|---------|---------|---------|
| 192.168.1.10 | 3000 | 203.0.113.1 | 5001 | 8.8.8.8 | 80 |
| 192.168.1.20 | 4000 | 203.0.113.1 | 5002 | 1.1.1.1 | 443 |
| 192.168.1.10 | 3001 | 203.0.113.1 | 5003 | 142.250.1.1 | 80 |

**关键点**：
- 同一台内网主机的**不同连接**会映射到**不同外部端口**
- NAT 路由器通过**端口号**区分不同的内部连接
- 一个公网IP通过端口复用可以支持**数万个**并发连接

## 核心知识点四：NAT 类型

### 三种 NAT 类型

| 类型 | 名称 | 特点 |
|------|------|------|
| 静态 NAT | Static NAT | 一对一固定映射（内网IP ↔ 公网IP） |
| 动态 NAT | Dynamic NAT | 从公网IP池中动态分配（多对多） |
| PAT/NAPT | Port Address Translation | **端口地址转换**（多对一，最常用） |

### PAT（最常见的 NAT 类型）

PAT 也叫 **NAT Overload**，是考试中最常考的类型：
- 多个内网设备共享**一个**公网IP
- 通过不同的**端口号**区分不同会话
- 家庭路由器使用的就是 PAT

---

## 核心知识点五：NAT 的优缺点

| 优点 | 缺点 |
|------|------|
| 节省公网IP地址 | 破坏端到端连接性 |
| 隐藏内网结构（安全） | 某些协议不兼容（如FTP主动模式） |
| 内网地址自由规划 | 增加路由器处理开销 |
| 易于更换ISP | 使得某些P2P应用困难 |
| | 违反IP层设计原则 |

## 典型计算题

### 题目示例

> Host A (192.168.1.5:2000) sends a packet to Server (74.125.24.100:443) through a NAT router with public IP 150.1.1.1. The NAT assigns port 40000. Show the packet headers at each stage.

### 解答

**阶段1：内网到NAT路由器**
| 字段 | 值 |
|------|------|
| 源IP | 192.168.1.5 |
| 源端口 | 2000 |
| 目标IP | 74.125.24.100 |
| 目标端口 | 443 |

**阶段2：NAT路由器到公网（NAT转换后）**
| 字段 | 值 |
|------|------|
| 源IP | **150.1.1.1** ← 替换为公网IP |
| 源端口 | **40000** ← 替换为映射端口 |
| 目标IP | 74.125.24.100 |
| 目标端口 | 443 |

**阶段3：服务器回复到NAT路由器**
| 字段 | 值 |
|------|------|
| 源IP | 74.125.24.100 |
| 源端口 | 443 |
| 目标IP | 150.1.1.1 |
| 目标端口 | 40000 |

**阶段4：NAT路由器转发到内网（NAT还原后）**
| 字段 | 值 |
|------|------|
| 源IP | 74.125.24.100 |
| 源端口 | 443 |
| 目标IP | **192.168.1.5** ← 还原为私有IP |
| 目标端口 | **2000** ← 还原为原始端口 |

## 答题技巧

1. **画出网络拓扑**：标注内网、NAT路由器、外网
2. **明确标注IP和端口的变化**：哪些字段被修改了
3. **NAT表一定要完整**：包括内部地址、内部端口、外部地址、外部端口
4. **时间分配**：Q5 占 10%（约 12 分钟），画图 + 表格 + 解释
